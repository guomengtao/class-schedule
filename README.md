## 应用概览

**Ev课程表** 是一款运行在 Xiaomi Quick App（快应用）平台上的智能手表应用，专为手表小屏幕优化设计。用户可以：

- 按天查看课程安排，支持左右滑动切换日期
- 快速添加课程（一键添加 + 完整表单两种方式）
- 实时查看当前上课状态（正在上课/即将上课/休息中）
- 上课前震动提醒，多种震动模式可选
- 管理多张课程表，支持复制、重命名、删除
- 周视图总览，一目了然整周课程分布
- 自定义字体大小，适配不同视力需求
- 设置个性化昵称

## 页面功能介绍

### 1. 主页（课程表首页）

**路径**: `pages/index`

主页是用户最常使用的页面，分为上下两个区域：

**上半部分 — 课程卡片区域**

- **日期导航栏**：顶部显示当前星期（如"星期一"），左右箭头按钮可切换日期，同时支持在卡片区域**左右滑动**切换日期。
- **状态栏**：动态显示当前的上课状态，点击可跳转到对应日期：
  - 📚 **正在上课**：显示当前课程名称 + 剩余分钟数
  - ⏰ **即将上课**：显示下一节课名称 + 等待分钟数
  - 📅 **未来课程**：当日无课时显示最近的下一节课
  - 🎉 **暂无课程**：整周无课时显示休息提示
- **课程卡片列表**：每张卡片显示课程名称、时间和地点
  - 左滑卡片可**显示删除按钮**，点击删除对应课程
  - 点击卡片进入**课程详情/编辑页**
- **空状态**：当天无课时显示"今天没有课"

**下半部分 — 快捷操作区域**

- **快速添加**：一键添加数学、英语、科学三门常用课程（预设时间、老师、地点）
- **添加课程按钮**：进入完整的添加课程流程
- **设置按钮**：进入设置页面
- **课程表指示器**：显示当前使用的课程表编号，点击进入**课程表管理页**

---

### 2. 添加课程页

**路径**: `pages/add-course`

采用**4步向导式**流程，逐步引导用户完成课程添加：

| 步骤 | 内容 | 说明 |
|------|------|------|
| Step 1 | 选择课程 | 以卡片滑动方式从预设课程（数学/英语/科学/历史）中选择，带圆点指示器 |
| Step 2 | 设置时间 | 上下箭头调整开始和结束时间（小时步长1，分钟步长5），实时预览时间字符串 |
| Step 3 | 填写地点 | 可选输入教室或地点，可留空 |
| Step 4 | 确认信息 | 汇总展示课程名称、时间、地点，确认无误后保存 |

- 每一步都有**步骤指示器**（圆点+连线），清晰展示当前进度
- 支持**前进/后退**导航，可随时返回修改
- 所有文字大小根据用户设置的字体缩放比例动态调整

---

### 3. 课程详情/编辑页

**路径**: `pages/detail`

- 展示课程完整信息：**课程名称、开始时间、结束时间、老师、地点、备注**
- 所有字段均可编辑，时间使用上下箭头调整（小时/分钟独立控制）
- **删除课程**按钮位于页面顶部，醒目易操作
- 自动从存储中读取课程 ID 和日期，加载对应课程数据
- 保存后自动返回上一页，数据实时更新

---

### 4. 设置页

**路径**: `pages/settings`

提供丰富的个性化设置：

**字体大小设置**

- 5档预设字体：28px / 36px / 48px / 62px / 76px
- 支持 +/- 按钮逐档调整
- 实时预览区展示当前字体大小的效果（示例：数学 08:00 - 08:45 301教室）

**上课提醒设置**

- 震动提醒开关（ON/OFF）
- 提前提醒时间设置（1-30分钟可调）
- **6种震动样式**可选，点击即可试听效果：

| 震动样式 | 说明 |
|----------|------|
| 短震 | 轻点一下 |
| 长震 | 持续震动 |
| 双短震 | 轻点两下 |
| 短+长 | 先短后长 |
| 长+短+长 | 长-短-长 |
| 三连震 | 连续三下 |

**昵称设置**

- 显示当前昵称，点击进入昵称编辑页

---

### 5. 课程表管理页

**路径**: `pages/schedule-manager`

支持管理**多张独立的课程表**（例如不同学期、不同班级）：

- **课程表列表**：展示所有课程表，当前使用的标记"使用中"
- **切换课程表**：点击即可切换到另一张课程表
- **重命名**：点击课程表名称旁的"重命名"链接，底部弹出编辑栏
- **复制**：一键复制整张课程表（含所有课程数据），自动生成"（副本）"后缀
- **总览**：点击"总览"链接进入该课程表的周视图
- **删除**：删除非当前使用的课程表（至少保留一张）
- **新增**：底部"新增课程表"按钮，自动生成"课程表N"名称

---

### 6. 周视图总览页

**路径**: `pages/week-view`

以**矩阵表格**形式展示一周课程分布：

- 顶部显示当前课程表名称
- 列头：周一至周日（Mon-Sun）
- 行头：按时间排序的时间段
- 每个单元格显示课程名的**首字符**，空白时段显示 "."
- 点击有课程的单元格可跳转到**课程详情页**
- 底部显示课程总数统计
- 支持滚动查看所有时间段

---

### 7. 昵称编辑页

**路径**: `pages/nickname-edit`

- 进入页面自动弹出系统对话框输入昵称
- 点击显示区域可重新打开编辑对话框
- 保存后昵称持久化存储，设置页实时显示

---

### 8. 样式演示页

**路径**: `pages/style-demo`

开发调试辅助页面，展示不同字号（48px/42px/36px/30px/24px/18px/12px）在各种样式（普通/粗体/不同颜色）下的渲染效果，用于验证字体缩放功能。

### 9. 分步添加课程流程（Step1-5）

**路径**: `pages/add-course-step1` ~ `pages/add-course-step5`

另一个添加课程入口，采用**5步独立页面**流程，适合大屏设备：

| 步骤 | 页面 | 内容 |
|------|------|------|
| Step 1/5 | add-course-step1 | 输入课程名称 |
| Step 2/5 | add-course-step2 | 设置时间（上/下箭头） |
| Step 3/5 | add-course-step3 | 输入老师姓名 |
| Step 4/5 | add-course-step4 | 输入上课地点 |
| Step 5/5 | add-course-step5 | 输入备注 + 保存 |

每个步骤独立一页，带步骤指示器，数据通过 `$app.$data` 全局传递。

## 核心亮点

### 🎯 智能状态感知

主页状态栏实时计算当前时间与课程时间的匹配关系：
- 精确到分钟的计算，判断"正在上课"、"即将上课"、"今日课程已结束"等状态
- 当日无课时自动查找未来最近的一节课，显示日期和课程名
- 每分钟自动刷新状态（60秒定时器）

### 📳 上课提醒系统

- 结合系统震动 API，在课程开始前指定分钟数自动震动提醒
- 6种震动模式满足不同场景需求（安静环境用短震，嘈杂环境用三连震）
- 智能去重：同一课程不会重复提醒

### 🗂️ 多课程表管理

- 支持创建多张独立课程表，数据完全隔离
- 每张课程表有独立的课程数据存储空间
- 复制功能一键克隆整张课程表，方便新学期微调使用

### 📱 手表屏幕深度适配

- 全局字体缩放系统，5档可调，所有页面文字大小统一响应
- 通过 `store.getFontScale()` 统一管理，所有页面自动适配
- 支持触摸滑动切换日期（左滑上一天，右滑下一天）
- 左滑卡片显示删除按钮，充分利用手势操作

### 🔄 双存储引擎

- 优先使用 SQLite 数据库存储，性能更优
- SQLite 不可用时自动降级为 Storage（键值存储）
- 数据迁移机制：旧版单课程表数据自动迁移到新版多课程表结构
- 默认预置示例课程数据（周一至周五各4节课），开箱即用

### 🎨 深色主题设计

- 全局深色配色方案（#1a1a2e 背景 + #7ec8e3 强调色），护眼且省电
- 统一的视觉风格，卡片式布局，圆角边框
- 适合 OLED 屏幕手表的深色主题

## 数据架构

### 存储层级

```
@system.storage（持久化键值存储）
├── allCourses_0 / allCourses_1 / ...   ← 每张课程表的课程数据
├── currentScheduleIndex                ← 当前使用的课程表编号
├── scheduleNames                       ← 所有课程表名称列表
├── fontScale                           ← 字体缩放比例
├── remindSettings                      ← 提醒设置 {enabled, minutes}
├── vibrationStyle                      ← 震动样式
└── userNickname                        ← 用户昵称
```

### 数据模型

```javascript
// 课程对象
{
  id: "1",           // 唯一标识
  day: "星期一",      // 所属星期
  name: "数学",      // 课程名称
  time: "08:00 - 08:45",  // 时间段
  teacher: "王老师",  // 授课老师
  location: "301教室",   // 上课地点
  notes: "第五章"     // 备注
}
```

### 核心模块

| 模块 | 路径 | 职责 |
|------|------|------|
| database.js | `src/data/database.js` | 数据存取层，封装 SQLite/Storage 双模式 |
| store.js | `src/data/store.js` | 应用级配置存储（字体、提醒、昵称等） |
| schedule.js | `src/data/schedule.js` | 默认示例课程数据 |
