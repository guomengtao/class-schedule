## 色值属性说明

| 属性名 | 用途 |
|--------|------|
| bg | 页面背景色 |
| card | 卡片/区块背景色 |
| cardLight | 浅色卡片背景（如状态栏） |
| accent | 强调色/主色调（按钮、高亮文字） |
| text | 主文字颜色 |
| textSecondary | 次要文字颜色（描述、标签） |
| textMuted | 弱化文字颜色（占位符、提示） |
| border | 边框颜色 |
| borderLight | 浅边框颜色 |
| keyBg | 键盘/输入区域背景 |
| keyBorder | 键盘/输入区域边框 |
| btnSecondary | 次要按钮背景 |
| btnSecondaryText | 次要按钮文字颜色 |
| deleteBg | 删除按钮背景 |
| deleteText | 删除按钮文字颜色 |
| progressOngoing | 进行中课程进度条颜色 |
| progressDone | 已完成课程进度条颜色 |

## 分类

- **暗色系**（7套）：深空蓝、翡翠绿、珊瑚红、暗夜黑、深空灰、暗紫魅影、墨绿护眼、琥珀金
- **亮色系**（2套）：晨光白、暖阳米
- **默认免费**：深空蓝
- **跟随系统**：自动根据系统深色/浅色模式在暗夜黑和晨光白之间切换
