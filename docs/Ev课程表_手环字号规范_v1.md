# Ev课程表 手环快应用 UI 规范（v1）

> 适用范围：小米手环 9 / 9Pro / 10 / 10Pro、Xiaomi Watch S3/S4 等 Vela 快应用
> 标准定位：**胶囊屏与方形屏统一字号与控件标准**（物理观感一致）
> 制定日期：2026-09-10

---

## 一、核心原则

1. **以真机物理像素为准，不看模拟器观感。**
   模拟器按 DPR 放大显示（如 9Pro 336×480 / DPR 2.1，画面放大 2.1 倍），电脑上看着清晰的字，装到真机后会明显缩小。所有字号决策必须按本规范的真机物理观感执行。

2. **胶囊屏与方屏统一字号。**
   两款屏幕 PPI 几乎一致（胶囊 ≈325，方屏 ≈337，1px 物理尺寸仅差约 4%），同一字号在两块屏上物理观感基本一样，因此**字号本身全平台统一**，不区分屏型。

3. **差异只来自宽度，不来自字号。**
   胶囊屏 192px 宽、方屏 336px 宽，放得下多少字不同。遇到"放不下"时**降级字号或换行**，而不是为某个屏单独改体系。

## 二、字号档位总表

| 档位 | 字号 | 用途 | 典型示例 | 物理尺寸(约) |
|---|---|---|---|---|
| 特大 | **40px** | 特大数字 | 首页时间、日期 | ≈3.0mm |
| 标题 | **36px** | 页面主标题、课程名 | 「设置」「星期四」 | ≈2.7mm |
| 正文(舒适) | **34px** | 重要页面正文、信息稀的页面 | 设置页列表 | ≈2.55mm |
| **正文(基准)** | **32px** | **绝大多数阅读内容** | 列表项、时间、课程内容 | ≈2.4mm |
| 辅助 | **28px** | 次要说明、按钮、标签 | 「已启用」、右侧小字 | ≈2.1mm |
| 次要辅助 | **24px** | 状态文字、小注释 | 状态提示 | ≈1.8mm |
| 底线(护栏) | **20px** | 极次要内容（尽量不用） | 版本号 v1.4.145 | ≈1.5mm |

> **32px 是正文基准**：在 30cm 视距 ≈0.46° 视角、40cm 视距 ≈0.34° 视角，处于"清楚可读、不算大"的平衡点，是默认值。
> **34px 是正文舒适档**：信息稀的页面（如设置页）用 34 更稳妥；与 32 同属正文档，按页面信息密度选择。
> **20px 是护栏不是档位**：禁止任何文字低于 20px，但日常不用它。

---

## 三、阶梯规则

- 标准步进 **4px**：40 / 36 / 32 / 28 / 24 / 20
- 32 与 36 之间**正好差一档（4px）**，中间无默认档；如确需"强调正文"，可临时取 34px，但不写入默认体系，避免档位过多。
- 选号原则：**能取档位值就取档位值**，不随意出现 33/35/37 等中间值（34 除外，见上）。

## 四、典型场景示例

### 场景 1：设置页（列表菜单 / 链接列表）
| 元素 | 字号 | 说明 |
|---|---|---|
| 页面顶部标题「设置」 | 36px（标题） | 一眼识别页面 |
| 列表项主文字（如「主题配色」） | **32px（正文基准）** | 用户逐条阅读的主体 |
| 列表项右侧状态/说明（如「默认」「1 元永久」） | 28px（辅助） | 弱化信息 |
| 页面底部版本号 | 24px（次要辅助） | 不打扰阅读 |

> 列表菜单主文字用 **32px**：它是正文级内容，不是标题，不应放大到 36+。

### 场景 2：首页课程表（信息密集）
| 元素 | 字号 | 说明 |
|---|---|---|
| 星期/日期标题 | 36px（标题） | 页面主标题 |
| 课程名 | 32px（正文基准） | 核心内容 |
| 时间（如 08:00-09:40） | 32px（正文基准） | 核心内容 |
| 教室/备注 | 28px（辅助） | 次要信息 |

### 场景 3：胶囊屏放不下的处理
- 单行超过约 6 个汉字时，优先**换行**；仍放不下再降 2-4px（仍取档位值）。
- 例：课程名「大学英语听说（A班）」→ 可换行显示；时间「08:00-09:40」在胶囊屏 32px 下约 170px，可放下，无需降级。

### 场景 4：实验室页面（列表 + 手风琴展开，2026-09-10 实战示例）
页面结构：顶部返回按钮 + 「实验室」标题 → 可点击列表（每行=功能名+右侧说明）→ 点击进入子页或手风琴展开操作 → 底部版本号 + 小链接。

| 页面区域 | 元素 | 字号 | 档位 |
|---|---|---|---|
| 顶部 | 返回按钮（图标为主） | 图标 ≈36px | 标题档（触控优先） |
| 顶部 | 「实验室」标题 | 36px | 标题 |
| 列表 | 功能名（首页设置 / 颜色 / 字号设置） | 32px | 正文基准 |
| 列表 | 右侧功能说明（解释该行作用） | 28px | 辅助 |
| 手风琴展开 | 操作选项名（如「字体大小 32px」） | 32px | 正文基准 |
| 手风琴展开 | 选项附带说明 | 28px | 辅助 |
| 底部 | 版本号（v1.4.145） | 24px | 次要辅助 |
| 底部 | 小链接（如「使用帮助」） | 28px | 辅助（可点击，加大点击区域） |

设计逻辑（三级信息结构）：
- **36px** 一级：页面是什么（标题，一眼识别）
- **32px** 二级：用户在找什么（列表项名，逐条阅读的主体，不能降）
- **28px** 三级：这行是干嘛的（右侧说明，弱化形成主次）
- **24px** 四级：最不重要的（版本号，不打扰）
- 手风琴内的选项沿用 32/28 两级，展开后不跳档
- **可点击元素（链接）用 28px 而非 24px**：保证触控区域够大，28px 文字 + 上下留白才点得准；版本号不用点，24px 足够

> 通用模板：**标题 36 → 主内容 32 → 说明 28 → 脚注 24**，设置页、关于、帮助等页面均可套用。

### 场景 5：课程总览表（5 列 × 8 行网格，核心中的核心页面，2026-09-10 实战定稿）
一周 5 天（5 列）× 一天最多 8 节课（8 行），是**用户看最多、最重要的页面**，本场景允许特化处理（唯一允许"单格只显示 2 字"的页面）。

**5.1 物理约束（先算再设计）**

| | 方屏 336×480 | 胶囊 192×490 |
|---|---|---|
| 内容区宽度 | 304px | 160px |
| 每格宽（含 4px 间距） | ≈57.6px | ≈30.4px（放不下课程名） |
| 每格高（含表头 44px） | ≈47px | ≈48px |
| 28px 字可放汉字数 | **2 个** | 1 个（不可用） |

**5.2 方屏方案（5 列直接显示）**
- 表头「周一~周五」：24px，每格 2 字居中
- 课程格：**28px，最多 2 个汉字，第 3 字起省略，不换行**
- 格子尺寸 ≈57.6×47px，圆角 **8px**（小圆角层级），间距 4px（密集场景允许 4px）
- 当前节次：主题色底 + 白字高亮
- 有课=主题色块，无课=透明/浅底
- 点击格子进入课程详情（看全名）

**5.3 胶囊屏方案（横向滑动，不换行）**
- **显示 2.5~3.5 列，不要整数列**：刻意露出一半或 1/4 列（半截课程名），让用户知道"后面还有内容"，提示左右滑动
- 每格宽度 = 总宽 ÷ 2.5~3.5，约 50~64px，28px 字可放 **2 字**
- 左右滑动看全部 5 天，滑动惯性回弹
- 表头随列同步滑动（周一/周二…），当前节次高亮不变
- 不换行、不缩小字号硬塞 5 列（30px/格会导致文字完全无法辨认）

> 原则：**总览页宁可"露半截引导滑动"，也不牺牲字号清晰度**。胶囊屏课程总览是唯一采用横向滑动分页布局的页面。

## 五、按钮字号与行高规范

### 5.1 按钮字号（色块上可低一档）
按钮有背景色块衬托，可读性高于纯文字，且整体大小由高度/触控区域决定、不由字号决定，因此**按钮文字统一比正文低一档（28px 辅助档）**，避免"大色块+大字"整体偏大。

| 按钮类型 | 文字字号 | 说明 |
|---|---|---|
| 主按钮（实底色块，如「保存」「确定」） | **28px** | 色块提升可读性，已清晰 |
| 次要按钮（描边/透明底） | **28px** | 同上 |
| 文字按钮/链接（「使用帮助」） | **28px** | 可点击，保证触控区域 |
| 图标按钮（返回、箭头） | 图标 ≈32-36px | 无文字，按图标设计 |
| 按钮内小提示（如「已选 32px」） | 24px | 弱化 |

**关键约束：按钮高度 ≥ 48px**（手环触控最小安全区）；字号+上下内边距计入按钮高度，保证点得准、看得清。

### 5.2 行高（line-height）规范
**不要依赖默认值**（各渲染引擎默认不一致），必须显式设置：

| 场景 | 行高 | 说明 |
|---|---|---|
| 单行正文/标题（32/36px） | **1.2 × 字号** | 紧凑，手环空间有限 |
| 多行说明文字（28px，可能换行） | **1.35 × 字号** | 行间留呼吸，不挤 |
| 按钮内文字 | **不单独设行高** | 按钮高度固定 ≥48px，文字垂直居中（flex），行高由按钮决定 |
| 辅助/脚注（24px） | 1.2 × 字号 | 同单行规则 |

示例：32px 正文单行行高 = 38px；28px 说明多行行高 = 38px。

## 六、单行字数参考（尽量不换行）

算法：**内容区宽度 ÷ 字号**（中文一字 ≈ 1 倍字号；半角数字/英文 ≈ 0.55 倍字号）。内容区 = 屏宽 − 左右 padding（各 16px）。

**方屏（336px，内容区 ≈304px）**

| 字号 | 单行最多 | 建议安全值 |
|---|---|---|
| 36 标题 | 8 字 | ≤7 字 |
| 32 正文 | 9 字 | **≤8 字** |
| 28 辅助/按钮 | 10 字 | ≤9 字 |
| 24 脚注 | 12 字 | ≤10 字 |

**胶囊屏（192px，内容区 ≈160px）**

| 字号 | 单行最多 | 建议安全值 |
|---|---|---|
| 36 标题 | 4 字 | ≤4 字 |
| 32 正文 | 5 字 | **≤5 字** |
| 28 辅助/按钮 | 5 字 | ≤5 字 |
| 24 脚注 | 6 字 | ≤6 字 |

**页面落地规则**：
- 列表项主文字（32px）：方屏 ≤8 字、胶囊 ≤5 字，**超过就精简文案，不换行**
- 右侧说明文字（28px）：方屏 ≤9 字、胶囊 ≤5 字，超长用省略号截断或改短文案
- 数字时间（半角）按 0.55 换算：如「08:00-09:40」（10 个半角 ≈ 5.5 汉字宽），方屏 32px 下约 175px，可放下

## 八、间距与圆角体系

### 8.1 间距步进（统一 4px 步进：4 / 8 / 12 / 16 / 24）

| 场景 | 间距 |
|---|---|
| 屏幕/内容区左右边距 | **16px** |
| 列表项内部（文字与边缘） | 12-16px |
| 相邻元素/列表项间距 | 8px |
| 卡片与卡片间距 | **12px** |
| 分组间距（区块之间） | 24px |
| 图标与文字间距 | 8px |
| 弹窗内边距 | 16px |

> 间距只取 4px 步进值，不出现 5/7/13 等中间值；信息密集页面（首页课程表）允许降到 4px。

### 8.2 圆角体系（四级）

| 层级 | 圆角 | 应用 |
|---|---|---|
| 大圆角/卡片 | **16px** | 卡片、弹窗容器 |
| 中圆角/控件 | **12px** | 按钮、输入框、列表项容器 |
| 小圆角/标签 | **8px** | 小标签、状态点、小按钮 |
| 全圆角 | 999px（50%） | 圆形元素：返回按钮、圆形图标、开关 |

> 同一页面内圆角不超过两个层级，避免杂乱。

### 8.3 列表项规范

| 属性 | 标准 |
|---|---|
| 列表项高度 | **≥56px**（含 padding，保证触控） |
| 主文字 | 32px（正文基准） |
| 说明文字 | 28px（辅助） |
| 分隔线 | 1px 弱化色 #E8E8E8，左侧缩进 16px |
| 按压态 | 背景变深一档，即时反馈 |

## 九、表单控件规范（输入框）

| 属性 | 标准 | 说明 |
|---|---|---|
| 高度 | **56px** | 大于按钮（48px），输入更易点中 |
| 输入文字 | **28px** | 与按钮同级，输入态清晰 |
| 圆角 | **12px** | 与整体风格一致 |
| 左右内边距 | 16px | 与内容区 padding 一致 |
| 背景色 | 页面底色浅一档（如 #F5F6F7） | 区别于纯白背景区 |
| 边框 | 1px 弱化（#E0E0E0），聚焦时主题色高亮 | 反馈输入态 |
| 多行输入 | 高 = 56×行数 | 按内容 1-3 行 |
| 输入法避让 | 弹起时页面底部 padding ≥120px | 避免遮挡 |
| 占位文字 | 24px，浅灰色（如 #999999） | 弱化提示 |

## 十、二维码规范

| 属性 | 标准 |
|---|---|
| 方屏 | **240×240px** |
| 胶囊屏 | **160×160px**（192 宽放 160，留边距） |
| 背景色 | **纯白 #FFFFFF**（必须，扫码识别靠白底） |
| 前景色 | 纯黑 #000000 |

## 十一、输入法规范（官方 png 输入法）

**不自定义，遵循官方**——系统级组件，尺寸已定且较大，无法控制。只做两件事：
1. 输入框在输入法弹起时**避让**（页面上移或底部留白 ≥120px）
2. 课程名等字段尽量短（遵循单行字数规则 ≤8/5 字），减少输入法占用时长

---

## 十二、图标规范（禁字符图标，统一 png 图片集）

**背景**：Vela 渲染引擎对 Unicode 特殊字符（▲ → ✓ ★ 等）支持不稳定，真机可能渲染空白（模拟器正常也无效）。因此**一律禁止字符/字体图标，统一使用透明底 png 图片图标**。

**图标档位：**

| 档位 | 尺寸 | 用途 |
|---|---|---|
| 小图标 | **24px** | 列表右侧箭头、成功/失败标记、状态点 |
| 中图标 | **32px** | 返回箭头、星期/日切换箭头、设置项图标、按钮内图标 |
| 大图标 | **36px** | 首页快捷入口、导航 |
| 特大图标 | **48px** | 空状态插画、无课程提示 |

**固定图标清单（9 个，已生成 png 放网盘「图标集」）：**

| 图标 | 用途 | 推荐尺寸 |
|---|---|---|
| ← 返回 | 页面顶部返回 | 32px |
| ‹ / › 左右箭头 | 星期/日切换（替代原三角形） | 32px |
| ＋ / − 加减 | 添加删除、字号调节 | 32px |
| ✓ 勾选 | 保存成功、确认 | 24px |
| ✕ 关闭 | 取消、清除 | 24px |
| ⋯ 更多 | 更多入口 | 32px |
| 🗑 删除 | 删除课程、清空数据（配确认弹窗） | 32px |

**尺寸档位说明：** 一个图标不必全存 4 档，按实际用途精简（见网盘「图标集/图标使用说明.md」）；source 128px 为母版，需要新尺寸随时用脚本导出。PNG 位图特性：放大必糊、缩小必细，所以实际用到的尺寸要提前导好，不靠运行时缩放。

**规则：**
1. 新增图标必须先加入清单，不允许页面里自己找图（防风格杂乱）
2. 统一线性风格：描边 2px、圆头端点、白色/随主题色
3. 源图 128px 只缩小不放大
4. 全量 8 图标 × 5 尺寸约 15 KB，对包体无压力（实测 24px≈120-166B、32px≈140-192B、48px≈171-249B）

## 十三、Toast 提示规范（自制组件优先）

**背景**：系统 toast（`@system.prompt.showToast`）样式大概率写死，仅文字可控。为保证样式统一，**优先自制 Toast 组件**（居中浮层 div + 定时消失）。

| 属性 | 标准 |
|---|---|
| 高度 | ≈56px（含内边距） |
| 圆角 | 16px（大圆角层级） |
| 文字 | **28px**，最多 2 行，居中 |
| 背景 | 黑色 90% 透明（#000000E6） |
| 文字颜色 | 白色 #FFFFFF |
| 位置 | 页面底部居中，距底 **120px**（避开手环手势区） |

## 十六、适配实现方式（三选一，媒体查询为主 + JS 兜底）

1. **CSS 媒体查询（首选，需实测 Vela 支持度）**
   ```
   @media (min-width: 260px) { /* 方屏 336 宽 */ }
   @media (max-width: 259px) { /* 胶囊 192 宽 */ }
   ```
   只在"放不下"的场景用宽度查询微调，字号基准仍统一。

2. **JS 动态绑定（兜底，100% 生效）**
   ```
   const info = device.getDeviceInfo()
   data: { isWide: info.screenWidth >= 260 }
   ```
   模板：`<text style="font-size: {{isWide ? '32px' : '30px'}}">`

3. **rpx 相对单位（如支持）**：一套代码全自适应，需实测。

> 注意：`@media (shape: rect)` 区分不了两种矩形屏（胶囊与方屏都是矩形），**宽度查询或 screenWidth 才能区分**。

## 十七、验收方法

1. **模拟器缩放法**：AIoT IDE 模拟器窗口缩放比例调到约 1/DPR（9Pro 约 48%），画面大小接近真机。
2. **截图换算法**：模拟器截图后把宽度缩到 336px（胶囊 192px）再看，观感 ≈ 真机。
3. **真机验收（最准）**：装真机看；首页课程表（信息密）用 32，设置页列表（信息稀）用 34，两处都舒服即为达标。
