# 首页状态栏模块功能需求分析

## 一、功能定位

状态栏是首页的实时课程状态指示器，告诉用户当前正在上什么课，或者下一节课是什么、还有多久开始/结束。

**使用场景**：用户打开首页，状态栏显示「上课中 数学 15min」，一眼就知道现在在上数学课，还有15分钟下课。

## 二、界面布局格式要求

状态栏位于课程列表上方，占一行高度，左侧有彩色竖条装饰。

```
┌──────────────────────────────┐
│ ▎▎ [上课中] 数学    15min   │  ← 状态栏
├──────────────────────────────┤
│ ┌─────────┐ ┌─────────┐     │
│ │ 数学    │ │ 英语    │     │  ← 课程列表
│ │ 08:00   │ │ 08:55   │     │
│ └─────────┘ └─────────┘     │
└──────────────────────────────┘
```

- 左侧：彩色竖条装饰
- 左侧标签：状态标签（如「上课中」「即将上课」「暂无」）
- 中间：课程名称
- 右侧：倒计时（如「15min」「23min后」）

## 三、用户视角的功能描述

### 3.1 上课中状态

当前时间在某节课的时间范围内时，状态栏显示：

> **[上课中] 数学 15min**

表示正在上数学课，还有15分钟下课。倒计时每分钟更新。

### 3.2 即将上课状态

当前时间还没到下一节课的开始时，状态栏显示：

> **[即将上课] 英语 23min后**

表示下一节是英语课，23分钟后开始。倒计时每分钟更新。

### 3.3 无课状态

当天没有课程，或者所有课程都已结束时，状态栏显示：

> **[暂无] 今日无课程安排**

### 3.4 显隐控制

用户可以在设置中关闭状态栏，首页不再显示该行。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 进入首页 | 状态栏立即显示当前状态 |
| 每分钟自动更新 | 倒计时数字刷新 |
| 切换到其他日期 | 状态栏显示该日期的课程状态 |
| 在设置中关闭状态栏 | 状态栏消失 |
| 课程结束后 | 自动切换到下一节课或「暂无」状态 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 今天没有课 | 显示「暂无 今日无课程安排」 |
| 所有课已上完 | 显示「暂无 今日无课程安排」 |
| 当前日期不是今天 | 不显示上课中/即将上课，显示「暂无 今日无课程安排」 |
| 课程时间有重叠 | 按开始时间排序，显示第一个匹配的 |
| 状态栏关闭 | 整行不显示 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 课程列表 | 状态栏读取课程列表的时间数据来判断状态 |
| 时钟 | 状态栏依赖当前时间，但有自己的定时器，独立于时钟 |
| 日期导航栏 | 切换日期后状态栏自动刷新 |
| 设置页 | 控制状态栏显隐 |
