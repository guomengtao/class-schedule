# 独立首页方案 · 当前进度（schedule-panel-progress）

> 系列：7 个课表首页独立化改造（umbrella: evtask-D-evclass-sche-261019-wxfkmx）
> 本文件为第 1 页方案。文末「独立首页标准 v1」为全系列共用，后续 6 页方案直接引用。

## 1. 页面定位（重新规划）

「当前进度」是**今日进行中这节课的进度看板**：上课中显示课程名 + 起止时间 + 地点 + 进度条（已过/剩余分钟）；课间/无课时显示「距下节课 XhYm」或「今日课程已全部结束 / 今天没有课」。

作为**独立首页**它非常合适——抬腕一眼就能知道「现在在上什么、还有多久下课」，比默认首页（整日列表）更聚焦。因此本页**保留现有信息结构**，不做功能减法，只补「独立启动」能力。

## 2. 现状 vs 独立首页标准

| 维度 | 现状 | 是否达标 |
|---|---|---|
| 数据自加载 | `database.init` + `getAllCourses` + `store.getTheme`，不依赖父页传参 | ✅ |
| 主题适配 | 全部走 `store.getTheme` + theme 变量（深浅主题） | ✅ |
| 加载态 | `isLoading` 加载中提示 | ✅ |
| 空态 | 上课中/课间/今日结束/今天没课 四类文案齐备 | ✅ |
| 屏型适配 | `width >= 200 / >= 400` 断点 | ✅ |
| 生命周期 | 10s 定时器 + `onDestroy` 清理 | ✅ |
| **返回逻辑** | `goBack()` 直接 `router.back()`，**假设自己总被 push** | ❌ 作为 root 冷启动失效 |

**唯一缺口**：返回逻辑。当本页被设为手表首页冷启动（无父页面）时，`router.back()` 没有可退的栈帧，返回钮点按无效或异常退出；硬件返回键也没有兜底。

## 3. 改造项（独立首页标准落地）

复用全系列统一的「root 判定」机制（见文末标准 v1）：由「更多首页」目录页 `router.push` 时带 `fromPanel: '1'` 参数；**无该参数即视为 root（被设为首页冷启动）**。

1. `private` 新增 `fromPanel: ''`，`onInit` 读取参数（`this.fromPanel === '1'` 为被 push）。
2. 返回钮 `if="{{ !isRoot }}"`：**仅当被 push 时显示**；root 即首页，无返回钮（与默认首页 `index` 一致）。
3. `isRoot` 计算：`this.isRoot = this.fromPanel !== '1'`。
4. `goBack()`：`fromPanel` 态 → `router.back()`；root 态 → `utils.exitApp()`（退出应用，与 `index.onBackPress` 一致）。
5. `onBackPress()`：`fromPanel` 态 → `return false`（交还系统默认返回，回到更多首页）；root 态 → `return utils.exitApp() === true`（退出成功才消费返回键）。
6. `import utils from "../../data/utils.js"`。

## 4. 验收口径

- **单测**：`node test/schedule-panel.test.js` 全绿（既有断言不受影响；本页逻辑以「不破坏现有用例」为底线，新增 2 条回归断言：返回钮条件渲染字段 `isRoot` 存在、文件名/标题渲染正确）。
- **真机截图（vela-loop）**：
  - 经「更多首页」push 进入 → 顶部返回钮可见、标题「当前进度」居中。
  - 直接以 root 启动（vela-loop 指定该页）→ 顶部**无**返回钮、标题居中、课程卡片/空态正常。
- **硬返回键**：root 态按返回键退出应用（与默认首页一致）；push 态回到更多首页。

## 附：独立首页标准 v1（全系列共用）

一个页面达到「可独立作为手表首页使用」的标准，必须满足：

1. **双模启动安全**：被「更多首页」push（有父）**或** 被设为首页冷启动（无父/root）都正常工作。
   - 返回钮仅在被 push 时显示；root 态不显示（首页无返回）。
   - `goBack()`：`fromPanel` 态 `router.back()`，否则 `utils.exitApp()`。
   - `onBackPress()`：`fromPanel` 态 `return false`（系统回父），否则 `return utils.exitApp() === true`。
2. **数据自加载**：通过 `database` + `store` 自行取数，不依赖父页传参。
3. **主题完整**：全部走 `store.getTheme` + theme 变量，深/浅/暖主题自适应（**禁止硬编码颜色**）。
4. **空态 / 加载态齐备**：无课、无数据、加载中均有明确 UI。
5. **屏型自适应**：pill / rect / circle + 宽度断点，不溢出屏底。
6. **常驻首页级生命周期**：定时器 `onDestroy` 清理、`onShow` 刷新、无泄漏（已在进度/倒计时/智能切换具备）。

> 系统级「在首页设置里可将其选为默认首页」入口（homepage-settings / pinned-pages / manifest entry）属更大的跨页整合议题，**不在逐页改造范围**；本系列只把每个页面做成「具备独立运行能力的完整首页」，待统一议题再接入选择入口。
