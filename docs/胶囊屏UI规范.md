# Ev课程表 胶囊屏 UI 规范

> **适用范围**：所有胶囊屏设备（小米手环 9/9Pro/10/10Pro 等 192px 宽的胶囊形屏幕）
> **核心差异**：胶囊屏两端是半圆，顶部/底部约 96px 范围内容易被遮挡
> **配套文档**：[Ev课程表_手环字号规范_v1.md](./Ev课程表_手环字号规范_v1.md)（统一字号档位体系）

> **版本**：v1.1（2026-09-13 修订，修正 4 处问题）

## 一、物理约束（先算再设计）

### 1.1 屏幕参数

| 参数 | 方形屏（336px 宽） | 胶囊屏（192px 宽） |
|------|--------------------|--------------------|
| 屏幕宽度 | 336px | **192px** |
| 屏幕高度 | 480px（方形） | **490px**（胶囊总长） |
| 半圆直径 | — | = 屏宽 = **192px** |
| 半圆半径 | — | **96px** |
| 顶部半圆遮挡区 | — | **≈96px 高**（半圆覆盖） |
| 底部半圆遮挡区 | — | **≈96px 高**（半圆覆盖） |
| 安全可视区（矩形） | 336×480 | **192×298px**（中间矩形部分，y=96 到 y=394） |
| 内容区宽度 | 304px（-16×2） | **160px**（-16×2） |
| 内容区高度（避让后） | 448px（-16×2） | **430px**（490 − 顶避让30 − 底避让30） |

### 1.2 半圆遮挡原理（真实计算值）

胶囊屏两端是半径 96px 的半圆，圆心在 (96, 96) 和 (96, 394)。半圆方程：**(x−96)² + (y−96)² ≤ 96²**。

在顶部半圆范围内，**每个 y 位置的可显示宽度**（= 2×√(96² − (y−96)²)）：

| y 位置 | 可显示宽度 | 可用等级 | 说明 |
|--------|-----------|----------|------|
| 0~10px | 0~60px | ❌ 不可用 | 半圆顶点区域，极窄 |
| 10~30px | 60~129px | ⚠️ 极谨慎 | 可放图标，**禁止放文字** |
| 30~60px | 129~179px | ⚠️ 谨慎 | 可放返回按钮等独立控件 |
| 60~96px | 179~192px | ✅ 基本可用 | 文字可显示，但仍有圆角边缘 |
| **≥96px** | **192px** | ✅ 完全可用 | 进入中间矩形区，全宽无遮挡 |
| 394~490px | 对称顶部 | 对称 | 底部半圆，与顶部镜像 |

```
        ┌──────┐  y=0
       ╱        ╲
      │  ≈117px  │  y=20（可显示宽度）
       ╲        ╱
        │≈169px │  y=50
        │       │
        │ 192px │  y≥96（全宽，安全矩形区开始）
        │       │
       ╱        ╲
      │  ≈117px  │  y=470（底部镜像）
       ╲        ╱
        └──────┘  y=490
```

> **关键结论**：半圆 y=20 处实际可显示宽度约 **117px**（之前低估为 <60px），y=50 处约 **169px**（之前写 140px）。但我们统一用 `padding-top: 30px` 把内容推到 y=30，所以半圆区域的精确宽度值**不影响主避让方案**——只是头部绝对定位时的参考更准确了。

## 二、顶部/底部避让方案

### 2.1 顶部避让（最关键，优先级 P0）

**方案 A：顶部安全 padding —— 推荐 ✅**

```css
.page {
  padding-top: 30px;   /* 顶部让出 30px */
  padding-bottom: 30px; /* 底部让出 30px */
}
```

**30px 的计算依据**：
- 半圆顶部 0~10px 极窄不可用，10~30px 区域可显示宽度约 60~129px
- 从 y=30px 开始内容基本可用
- 总计 = **30px**

这样第一行内容会出现在 y=30px 位置，内容可见。

**方案 B：头部内容特殊布局（当页面必须用顶部区域时）**

如果页面有返回按钮等必须放顶部的元素（按真实宽度值限宽）：

```css
@media (shape: capsule), (shape: pill-shaped) {
  .header {
    position: absolute;
    top: 40px;        /* 在半圆半腰，此位置可显示宽度 ≈ 169px */
    left: 50%;
    transform: translateX(-50%);
    width: 150px;     /* 真实值 169px，留 19px 余量 = 150px 安全 */
  }
}
```

> **⚠️ 警告**：顶部半圆区域（y < 96px）**禁止放文字**——哪怕 117px 理论上够放 4 个 28px 字，抗锯齿和视觉拥挤也会让文字难以阅读。只有返回按钮这类**独立图标控件**可以放在 y=30~60px 区域（宽 129~179px，足够一个返回按钮）。

### 2.2 底部避让

与顶部对称处理，使用 `padding-bottom: 30px` 将最后一行内容推到底部。

**底部特殊情况 —— 手势区避让**：手环底部可能有手势操作区域，建议底部按钮/链接至少距底 **30px**。

### 2.3 全局胶囊屏避让模板

```css
/* 通用页面容器 —— 胶囊屏 */
@media (shape: capsule), (shape: pill-shaped) {
  .page {
    padding-top: 30px;
    padding-bottom: 30px;
    padding-left: 16px;
    padding-right: 16px;
  }

  /* 如有绝对定位的头部（返回按钮等） */
  .absolute-header {
    top: 40px;           /* 半圆半腰位置，可显示宽度 ≈ 169px */
    height: 56px;        /* 控制头部高度，不超半圆 */
    width: 150px;        /* 留余量的安全宽度 */
  }
}
```

## 三、胶囊屏字号规范

### 3.1 字号档位（胶囊屏专用，比方屏整体小 2~4px）

| 档位 | 方屏字号 | **胶囊屏字号** | 用途 | 物理尺寸(约) |
|------|----------|----------------|------|--------------|
| 特大数字 | 40px | **36px** | 首页时间、突出数值 | ≈2.7mm |
| 页面标题 | 36px | **30px** | 「设置」「实验室」 | ≈2.25mm |
| 列表主文字 | 32px | **28px** | 列表项名称、功能名 | ≈2.1mm |
| 辅助说明 | 28px | **24px** | 次要文字、描述、右侧说明 | ≈1.8mm |
| **弹窗辅助** | 26px | **22px** | 弹窗描述/列表项（弹窗专用档） | ≈1.65mm |
| 脚注/次要 | 24px | **20px** | 版本号、极小提示 | ≈1.5mm |
| **绝对底线** | 20px | **18px** | 极少用，仅非关键信息 | ≈1.35mm |

> **为什么整体缩小**：胶囊屏物理宽度只有方屏的 57%（192 vs 336），但 PPI 接近（胶囊≈325，方屏≈337），同一字号在胶囊屏上占比视觉更大（因为窄），适当缩小 2~6px 保持观感平衡。
> **22px 是弹窗专属档**：弹窗内容通常比页面列表信息密度更低（居中、卡片内、四周留白），22px 在弹窗卡片内可读性有卡片背景支撑，单独设立不与页面规范冲突。**仅在弹窗/卡片内部使用，页面列表和正文区域禁止用 22px**。

### 3.2 禁止字号缩放

```css
/* ❌ 禁止 */
.text { transform: scale(0.8); }
.text { font-size: 26px; transform: scale(1.1); }

/* ✅ 正确：直接用规范字号 */
.text { font-size: 28px; }
```

**原因**：transform scale 只改变视觉大小，不改变布局占位，容易导致文字被截断或重叠；且不同渲染引擎对 scale 的抗锯齿处理不一致，真机可能模糊。

### 3.3 字号选择决策树

```
在哪里用？
├── 页面正文/列表区域
│   ├── 页面最大标题 → 30px
│   ├── 列表项主文字 → 28px
│   ├── 辅助说明/右侧文字 → 24px
│   └── 版本号/极小提示 → 20px（底线 18px）
└── 弹窗/卡片内部
    ├── 弹窗标题 → 28px
    ├── 弹窗描述/功能列表项 → 22px（弹窗专属档）
    └── 弹窗按钮 → 28px
```

## 四、胶囊屏单行字数与换行规则

### 4.1 单行字数表（内容区 160px）

| 胶囊屏字号 | 单字占位 | 单行最多汉字 | 建议安全值 | 示例 |
|------------|----------|--------------|------------|------|
| 30px 标题 | ≈30px | **5 字** | **≤4 字** | 「高级版」「解锁」 |
| 28px 正文 | ≈28px | **5 字** | **≤5 字** | 「主题配色」「课程管理」 |
| 24px 辅助 | ≈24px | **6 字** | **≤5 字** | 「默认样式」「1元永久」 |
| 22px 弹窗档 | ≈22px | **7 字** | **≤6 字** | 弹窗内更长描述 |
| 20px 脚注 | ≈20px | **8 字** | **≤6 字** | 「v1.4.145」 |

### 4.2 半角字符换算

半角数字/英文 ≈ 0.55 倍字号宽度：
- 28px 下：「08:00」（5 半角 ≈ 2.75 汉字宽）→ 胶囊屏放得下 ✅
- 28px 下：「08:00-09:40」（11 半角 ≈ 6.05 汉字宽 ≈ 169px）→ 超出 160px，**换行**或降为 24px ✅

### 4.3 换行规则

1. **标题**（30px）：允许最多 2 行，**禁止 3 行以上**
2. **列表主文字**（28px）：**禁止换行** → 超过 5 字就**精简文案**
   - ❌ 不允许：「多课表管理与数据备份」（10 字，两行也挤）
   - ✅ 精简为：「多课表与备份」（5 字，单行正好）
3. **辅助说明**（24px）：允许 2 行，超过则用省略号截断
4. **弹窗描述**（22px）：允许最多 3 行
5. **按钮文字**（28px）：**必须单行**，最多 4 字 → 「立即解锁」「取消」「保存」

## 五、按钮规范（胶囊屏专用）

### 5.1 按钮尺寸与触控

手环触控区域较小（手指 ≈ 8~10mm 粗细），按钮必须保证可点。

| 属性 | 胶囊屏标准 | 方屏标准 | 说明 |
|------|------------|----------|------|
| **按钮高度** | **≥52px** | ≥48px | 胶囊屏手势多，需要更大触控区 |
| **按钮宽度** | **≥100px**（半宽） | ≥140px | 内容区 160px，半宽按钮 100px 足够 |
| **按钮圆角** | **26px**（全圆角） | 12~16px | 胶囊屏用全圆角按钮，与屏幕形状呼应 |
| **按钮内边距** | 0 20px | 0 16px | 左右留白让文字不贴边 |
| **按钮文字字号** | **28px** | 28px | 胶囊屏按钮文字同方屏（档位一致） |
| **按钮文字行高** | = 按钮高度 | = 按钮高度 | flex 垂直居中，不单独设行高 |

### 5.2 双按钮布局（弹窗常用）

胶囊屏宽度只有 192px，两个按钮并排很挤：

**方案 A：上下排列 —— 推荐 ✅**
```css
.btn-stack {
  flex-direction: column;  /* 改为纵向排列 */
  gap: 12px;               /* 按钮间距 12px */
}
.btn-primary, .btn-secondary {
  width: 100%;              /* 全宽 */
  height: 52px;
}
```

**方案 B：并排挤压（仅当按钮文字 ≤ 2 字时）**
```css
.btn-row {
  flex-direction: row;
  justify-content: space-between;
}
.btn-row .btn {
  width: 48%;               /* 各占一半 */
  height: 52px;
}
```

> **⚠️ 弹窗按钮建议**：胶囊屏弹窗内的「取消 + 确认」按钮，**一律用上下排列**（方案 A），确保每个按钮都有足够宽度（100% = 160px）。

### 5.3 按钮触控热区扩展

```css
.btn {
  height: 52px;
  /* 实际视觉按钮 */
}
.btn-wrapper {
  /* 包裹一层，扩展触控区 */
  padding: 8px 0;
  /* 这样即使视觉按钮只有 52px，
     手指误触到上下 8px 范围内也能点中 */
}
```

### 6.4 弹窗定位（胶囊屏）

弹窗必须**屏幕正中央**显示，不能靠底部：

```css
.overlay-modal {
  position: absolute;
  top: 0; left: 0;
  width: 100%;
  height: 100%;
  justify-content: center;    /* 垂直居中 */
  align-items: center;        /* 水平居中 */
}

.modal-card {
  width: 90%;                /* ≈173px */
  max-height: 60%;           /* ≈258px，防止超长 */
  overflow: hidden;
}
```

> **为什么不用底部弹窗**：胶囊屏底部半圆遮挡区有 96px，底部弹窗会直接被半圆吃掉一半内容，**居中弹窗是唯一安全选择**。

## 十、胶囊屏 CSS 适配实现方式

### 10.1 @media (shape:) —— **主力方案（项目已 100+ 处验证）**

小米 Vela/快应用引擎原生支持 `@media (shape:)` 媒体查询。**这是项目中所有页面统一使用的胶囊屏适配方式**，已真机验证可用。

支持的 shape 值：
- `circle` —— 圆形屏（旧款圆形表盘）
- `capsule` —— 胶囊屏（小米手环 9/10 系列）
- `pill-shaped` —— 胶囊屏（部分设备返回此值，需同时匹配）
- `rect` —— 方形屏

```css
/* ============== 胶囊屏通用适配 —— 可直接复制 ============== */
@media (shape: capsule), (shape: pill-shaped) {

  /* ----- 页面容器 ----- */
  .page {
    padding-top: 30px;
    padding-bottom: 30px;
    padding-left: 16px;
    padding-right: 16px;
  }

  /* ----- 头部（返回按钮+标题）----- */
  .header {
    top: 40px;
    height: 56px;
    width: 150px;
  }
  .page-title {
    font-size: 30px;          /* 方屏 36px → 胶囊 30px */
    line-height: 40px;
  }

  /* ----- 列表 ----- */
  .list-item {
    min-height: 64px;
    padding: 16px;
    margin-bottom: 12px;
    border-radius: 14px;
  }
  .item-main {
    font-size: 28px;          /* 方屏 32px → 胶囊 28px */
    line-height: 38px;
  }
  .item-sub {
    font-size: 24px;          /* 方屏 28px → 胶囊 24px */
    line-height: 32px;
  }

  /* ----- 按钮 ----- */
  .btn {
    height: 52px;
    border-radius: 26px;      /* 全圆角 */
    font-size: 28px;
  }
  .btn-row {
    flex-direction: column;   /* 双按钮改上下排列 */
    gap: 12px;
  }

  /* ----- 弹窗 ----- */
  .modal-card {
    width: 90%;
    max-height: 60%;          /* ≈258px */
    padding: 16px;
    border-radius: 16px;
  }
  .modal-title {
    font-size: 28px;
    line-height: 40px;
  }
  .modal-desc {
    font-size: 22px;
    line-height: 30px;
  }
  .modal-benefit {
    font-size: 22px;
    line-height: 30px;
  }

  /* ----- 输入框 ----- */
  .input-box {
    height: 56px;
    border-radius: 14px;
    font-size: 28px;
  }

  /* ----- 脚注 ----- */
  .footer-note {
    font-size: 20px;
    line-height: 28px;
  }
}
```

### 10.2 JS 检测 —— **补充方案（JS 动态样式或逻辑分支）**

当需要在 JS 代码中根据屏幕形状做逻辑判断时使用。API 已在项目中验证，`data.screenShape` 字段真实存在：

```javascript
import device from "@system.device"

// 在 onInit 中检测
device.getInfo({
  success: function(data) {
    var isCapsule = (data.screenShape === "capsule" ||
                     data.screenShape === "pill-shaped")
    this.isCapsule = isCapsule

    // 其他 shape 值:
    //   data.screenShape === "rect"   → 方形屏
    //   data.screenShape === "circle" → 圆形屏
  }
})

// 模板中使用（条件绑定样式）
// <text style="font-size: {{isCapsule ? '28px' : '32px'}}">标题</text>
```

> **项目中的实际用法**：项目中几乎所有视觉适配都用 §10.1 的 `@media (shape:)` 完成，JS 检测主要用于：① 模板中需要动态切换样式值时；② 需要根据屏幕形状做不同业务逻辑时（如 API 请求参数区分）。

### 10.3 不推荐：用 screenWidth 推测

```css
/* ❌ 不推荐 —— 仅宽度不够精确 */
@media (max-width: 260px) { /* 胶囊屏 */ }
@media (min-width: 260px) { /* 方屏 */ }
```

可能有中间宽度设备，不如 shape 查询精确。

## 十一、常见问题 Checklist

开发完成后，用这个清单逐一检查：

### A. 顶部/底部避让
- [ ] 页面 `padding-top` 是否为 **30px**？
- [ ] 页面 `padding-bottom` 是否为 **30px**？
- [ ] 顶部半圆区域（y < 96px）是否有文字？（**禁止**，只有返回按钮等独立图标可放 y=30~60px）
- [ ] 头部绝对定位的宽度是否 ≤ **150px**（y=40 处安全宽度）？

### B. 字号规范
- [ ] 页面标题是否为 **30px**？
- [ ] 列表主文字是否为 **28px**？
- [ ] 辅助说明是否为 **24px**？
- [ ] 弹窗描述/功能列表项是否为 **22px**（仅弹窗内可用）？
- [ ] 脚注是否为 **20px**？
- [ ] 页面正文/列表区域是否出现了 **22px**？（**禁止**，22px 仅限弹窗）
- [ ] 是否有 **26px、34px、25px** 等其他非规范字号？（**禁止中间值**）
- [ ] 是否使用了 **transform: scale()**？（**禁止**）
- [ ] 是否显式设置了 **line-height**？

### C. 按钮规范
- [ ] 按钮高度是否 **≥ 52px**？
- [ ] 按钮是否用了 **全圆角（≥ 26px）**？
- [ ] 弹窗双按钮是否 **上下排列**（`flex-direction: column`）？
- [ ] 按钮文字是否为 **28px**？
- [ ] 按钮文字是否 **单行 ≤ 4 字**？

### D. 弹窗规范
- [ ] 弹窗是否 **居中显示**（非底部抽屉）？
- [ ] 弹窗宽度是否 **90% 屏宽**？
- [ ] 弹窗最大高度是否限制为 **60% 内容区高（≈258px）**？
- [ ] 弹窗标题是否为 **28px**？
- [ ] 弹窗描述/列表项是否为 **22px**（弹窗专属）？
- [ ] 弹窗按钮是否 **全宽 + 上下排列**？

### E. 列表规范
- [ ] 列表项高度是否 **≥ 64px**？
- [ ] 列表项间距是否 **12px**？
- [ ] 列表主文字是否 **≤ 5 字**？（胶囊屏单行不换行）

### F. @media 适配
- [ ] 是否用了 **`@media (shape: capsule), (shape: pill-shaped)`**？
- [ ] 是否同时提供了 **`@media (shape: rect)`** 方屏规则？
- [ ] 是否需要 **`@media (shape: circle)`** 圆形屏兼容（如有圆形屏用户）？
