# 解锁弹窗实现方案

## 概述

标准版用户使用高级功能时，弹出解锁提示弹窗，引导用户前往「高级版」页面激活。

## 整体架构

```
用户点击高级功能
    ↓
页面调用 store.isPremiumUnlocked(callback)
    ↓
检查 premium_unlocked 存储键 或 auth-store 激活状态
    ↓
├── unlocked=true  → 执行高级功能
└── unlocked=false → 调用 store.showUnlockDialog() 弹出弹窗
                         ↓
                    用户点击「立即解锁」→ 跳转 /pages/activation
                    用户点击「继续使用标准版」→ 关闭弹窗
```

## 核心组件

### 1. unlock-dialog 组件

位置: `src/components/unlock-dialog.ux`

#### 模板结构
```html
<template>
  <div class="overlay" if="{{ visible }}" style="background-color: rgba(0,0,0,0.65)">
    <div class="dialog" style="background-color: {{ theme.card }}">
      <text class="dialog-title">解锁高级功能</text>
      <!-- 功能列表 -->
      <div class="benefits">
        <div for="{{ benefits }}">✓ {{ $item }}</div>
      </div>
      <!-- 价格说明 -->
      <text>一次性解锁，永久使用</text>
      <!-- 按钮 -->
      <input type="button" value="立即解锁" onclick="doUnlock" />
      <input type="button" value="{{ cancelText }}" onclick="doCancel" />
    </div>
  </div>
</template>
```

#### 关键方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `show(options)` | `{ title, benefits, cancelText, feature, onSuccess, onPayFail }` | 显示弹窗，设置 `visible=true` |
| `hide()` | 无 | 关闭弹窗，设置 `visible=false` |
| `doUnlock()` | 无 | 关闭弹窗，跳转 `/pages/activation` |
| `doCancel()` | 无 | 关闭弹窗 |

#### 默认参数
- `title`: "解锁高级功能"
- `benefits`: ["多课表管理", "数据备份与恢复", "首页自定义", "10套主题"]
- `cancelText`: "继续使用标准版"

### 2. store.isPremiumUnlocked(callback)

位置: `src/data/store.js`

#### 检查逻辑
```javascript
isPremiumUnlocked: function(callback) {
  // 1. 先检查 premium_unlocked 存储键
  storage.get({ key: "premium_unlocked", success: function(data) {
    if (data === "true") {
      callback(true)  // 已解锁
      return
    }
    // 2. 再检查 auth-store 激活状态
    var authStore = require("./auth-store")
    authStore.getAuthData(function(authData) {
      if (authData && (authData.isActivated || authData.isPermanent)) {
        callback(true)  // 已激活
      } else {
        callback(false)  // 标准版
      }
    })
  }, fail: function() {
    // 3. premium_unlocked 不存在，检查 auth-store
    var authStore = require("./auth-store")
    authStore.getAuthData(function(authData) {
      callback(authData && (authData.isActivated || authData.isPermanent))
    })
  }})
}
```

### 3. 页面集成方式

每个需要高级功能检查的页面，遵循以下模式：

#### 步骤 1: 导入组件
```html
<import name="unlock-dialog" src="../../components/unlock-dialog"></import>
```
> 注意: `import` 标签必须放在 `<template>` 外部

#### 步骤 2: 在模板中放置组件
```html
<template>
  <div class="page">
    <!-- 页面内容 -->
    <unlock-dialog id="unlockDialog"></unlock-dialog>
  </div>
</template>
```

#### 步骤 3: 功能调用时检查
```javascript
doSomething() {
  var self = this
  store.isPremiumUnlocked(function(unlocked) {
    if (unlocked) {
      self.performAction()  // 执行高级功能
    } else {
      store.showUnlockDialog({
        title: "解锁XXX功能",
        benefits: ["功能A", "功能B", "功能C"],
        cancelText: "继续使用标准版"
      })
    }
  })
}
```

## 调试检查清单

如果弹窗不显示，按以下顺序排查：

1. **`import` 标签位置**: 必须在 `<template>` 外部，与 `<template>` 同级
2. **组件 `onInit` 注册**: 组件在 `onInit` 中通过 `store._unlockDialogRef = this` 注册自身
3. **`isPremiumUnlocked` 回调**: 确认回调函数被正确调用（标准版用户应收到 `false`）
4. **`store.showUnlockDialog()`**: 确认页面调用 `store.showUnlockDialog({...})` 而非 `$element`
5. **组件可见性**: 组件通过 `if="{{ visible }}"` 控制显示，`show()` 方法设置 `visible=true`

## 架构说明

### 为什么用 store 引用而非 `$element`

在 Quick App 框架中，`$element(id)` 返回的是原生 DOM 元素，**无法获取自定义组件实例**。因此改用全局 store 引用模式：

1. `unlock-dialog` 组件在 `onInit` 时注册到 `store._unlockDialogRef`
2. 页面调用 `store.showUnlockDialog(options)` 触发弹窗
3. `store.showUnlockDialog` 通过 `_unlockDialogRef` 调用组件的 `show()` 方法
4. 组件 `onDestroy` 时清理引用，避免内存泄漏

### store 新增方法

| 方法 | 参数 | 说明 |
|------|------|------|
| `showUnlockDialog(options)` | `{ title, benefits, cancelText }` | 显示解锁弹窗 |
| `hideUnlockDialog()` | 无 | 隐藏解锁弹窗 |
| `_unlockDialogRef` | 内部属性 | 组件实例引用 |
