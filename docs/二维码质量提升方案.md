# 二维码质量提升方案

## 一、背景

当前激活页面（`pages/activation`）的"激活高级版"栏目中有两个二维码：

| 序号 | 二维码内容 | 当前尺寸 | 用途 |
|------|-----------|---------|------|
| 1 | 爱发电购买链接 (`afdianUrl`) | 120px × 120px | 扫码跳转爱发电购买兑换码 |
| 2 | 激活码兑换链接 (`qrText`) | 120px × 120px | 扫码打开兑换页面输入兑换码 |

两个二维码在手表/手环小屏幕上显示偏小，且缺少视觉边界，用户有时不确定二维码的扫描范围。本方案从尺寸、边框、背景三个维度提升二维码的可扫描性和视觉效果。

### 2.3 问题总结

| 问题 | 影响 |
|------|------|
| 二维码 120px 偏小 | 手表屏幕 390-466px，二维码仅占约 25-30%，手机扫描时识别距离受限 |

| 圆角过大 (12px) | 二维码四角被裁切，边缘定位图案可能不完整，影响扫描识别率 |
| padding 8px 浪费空间 | 在 120px 基础上再扣除 16px padding，实际二维码可视区域仅 104px |

## 三、提升方案

### 3.1 尺寸放大到 1 倍（推荐 140px → 160px）

**原理**：二维码的每个模块（小方块）需要足够大才能被手机摄像头清晰分辨。模块越小，需要的扫描距离越近、光线条件越好。手表屏幕本身较小，二维码尺寸应尽量利用可用空间。

**分析**：

- 当前 `120px` 在 390px 宽屏幕上约占 30%，在 466px 屏幕上约占 26%
- 放大到 `140px` 后占比约 36%/30%，仍在合理范围内
- 放大到 `160px` 后占比约 41%/34%，建议上限，避免挤压其他内容
- 二维码模块尺寸：120px 下每个模块约 5.7px（21 模块），140px 下约 6.7px，提升约 17%

**推荐值**：`140px × 140px`（兼顾空间与可扫描性）

```html
<qrcode value="{{ afdianUrl }}" style="color: #000000; background-color: #ffffff; width: 140px; height: 140px;"></qrcode>
```

### 3.2 增加圆角矩形描边

**方案**：在 `.qr-wrapper` 上增加边框（border），形成圆角矩形描边，使二维码从背景中清晰分离出来。

**设计要点**：

- 边框颜色使用主题强调色（`theme.accent`），与页面风格统一
- 圆角从 `12px` 调整为 `8px`，避免切到二维码四角的定位图案（Finder Pattern）
- 边框宽度 `2px`，不占用过多空间但足够醒目
- 二维码自身背景保持白色，边框作为外层装饰

**CSS 改动**：

```css
.qr-wrapper {
  border-radius: 8px;
  padding: 6px;
  border: 2px solid {{ theme.accent }};
}
```

**视觉效果**：

```
┌──────────────────────────────┐
│  ┌──────────────────────┐    │
│  │                      │    │
│  │   ███████████████    │    │  ← 白色二维码区域
│  │   ██  ██  ██  ██    │    │
│  │   ███████████████    │    │
│  │                      │    │
│  └──────────────────────┘    │
│      扫码打开爱发电           │
└──────────────────────────────┘
  ↑ 主题色圆角描边
```

### 3.3 白色背景对识别效率的影响

**结论：白色背景显著提升二维码识别效率。**

**原理分析**：

| 因素 | 说明 |
|------|------|
| **对比度** | QR 码标准要求前景色与背景色有足够对比度。黑色模块 + 白色背景 = 最高对比度，手机摄像头最容易识别 |
| **静区（Quiet Zone）** | QR 码规范要求四周有 4 个模块宽度的白色静区。白色背景天然满足此要求 |
| **环境光反射** | 手表 OLED 屏幕在强光下可能反光，白色背景比透明/深色背景反射更均匀，减少扫描干扰 |
| **自动对焦** | 手机相机自动对焦依赖边缘检测，白色背景 + 黑色模块的清晰边界帮助相机快速锁定二维码 |
| **二值化处理** | 扫描软件对图像做二值化（黑白化）时，白色背景确保模块边缘清晰，不会因为背景色过暗导致误判 |

**当前代码已正确设置**：

```html
<qrcode value="..." style="background-color: #ffffff; color: #000000;"></qrcode>
```

以及外层 wrapper：

```html
<div class="qr-wrapper" style="background-color: #ffffff">
```

**建议保持**：二维码背景 `#ffffff` 不变，这是最佳实践。

### 4.3 改动汇总

| 改动项 | 改前 | 改后 | 收益 |
|--------|------|------|------|
| 二维码尺寸 | 120px × 120px | 140px × 140px | 模块尺寸 +17%，扫描距离更远、成功率更高 |
| 圆角 | 12px | 8px | 避免切到定位图案，四角完整 |
| 内边距 | 8px | 6px | 减少浪费，二维码可视区域更大 |
| 描边 | 无 | 2px 主题色 | 视觉层次清晰，暗色主题下边界明确 |
| 背景色 | #ffffff | #ffffff（不变） | 保持最高对比度，已是最佳实践 |
