# 首页设置界面美化方案

## 一、当前问题

| 问题 | 说明 |
|------|------|
| 视觉单调 | 纯文字列表 + 开关，无图标、无层次感 |
| 自定义内容分离 | 开关和文字输入分两行，文字输入还条件隐藏（`if="{{ showCustomContent }}"`），逻辑割裂 |
| 无预览 | 看不出自定义内容在首页长什么样 |
| 无说明 | 各开关没有功能描述，新用户不知道"课程提醒"控制什么 |

## 三、具体改动

### 3.1 增加图标和描述

| 行 | 图标 | 描述 |
|----|------|------|
| 快速添加 | ⚡ | 首页底部快速添加课程入口 |
| 课程提醒 | 📢 | 首页状态栏上课/下课提示 |
| 时间显示 | 🕐 | 首页顶部实时时钟 |
| 自定义内容 | ✏️ | 在首页显示自定义文字 |

### 3.2 自定义内容合为一体

**现状**：开关和文字输入分两行，文字输入条件隐藏
```
自定义内容          [开关]
内容文字            点击输入    ← 只有在开关打开时才显示
```

**改为**：开关和输入框在同一卡片内，始终可见，开关关闭时输入框变灰禁用
```
✏️ 自定义内容        [开关]
┌─────────────────────────┐
│ 点击输入自定义文字...    │  ← 始终可见，开关关时灰色
└─────────────────────────┘
预览：好好学习天天向上       ← 开关打开且有内容时显示预览
```

### 3.3 视觉增强

| 元素 | 当前 | 改进 |
|------|------|------|
| 开关大小 | 40×22px | 44×24px，更易点击 |
| 行间距 | 10px padding | 12px padding，更透气 |
| 标签字号 | 14px | 15px，更清晰 |
| 描述文字 | 无 | 11px，theme.textMuted |
| 输入框 | 无 | 独立卡片样式，有边框 |
| 分区标题 | 无 | 加粗分组标题，section 间距加大 |

### 3.4 结构重组

```
page
├── header (返回 + 标题)
├── section: 显示控制
│   ├── 快速添加 (图标 + 标签 + 描述 + 开关)
│   ├── 课程提醒 (图标 + 标签 + 描述 + 开关)
│   └── 时间显示 (图标 + 标签 + 描述 + 开关)
├── section: 自定义内容
│   ├── 开关行 (图标 + 标签 + 开关)
│   ├── 输入框 (始终可见，点击打开键盘)
│   └── 预览文字 (有内容时显示)
└── section: 时间格式 (showTime 时显示)
    ├── 芯片选择器
    └── 预览文字
```

## 四、开关样式升级

```css
/* 更大更圆润的开关 */
.switch-track {
  width: 44px;
  height: 24px;
  border-radius: 12px;
}
.switch-thumb {
  width: 20px;
  height: 20px;
  border-radius: 10px;
  top: 2px;
}
/* 开关开时 thumb 位置 */
left: 22px  (on) / 2px (off)
```

## 五、实施步骤

1. 模板重排：调整 section 分组，每行增加图标和描述
2. 自定义内容合并：开关 + 输入框 + 预览放同一卡片
3. 样式升级：开关加大、间距加大、增加输入框样式
4. 脚本调整：输入框始终可点击（开关关时也能点，打开开关的同时允许输入）

## 六、注意事项

- 不引入 `@media` 查询
- 数据存储结构不变，向后兼容
- 输入框点击跳转 chinese-input 页面逻辑不变
- 保持与 vibration-lab 一致的深色主题风格
