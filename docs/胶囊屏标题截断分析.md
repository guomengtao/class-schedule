# 胶囊屏标题截断问题分析

## 一、问题根因

### 1.1 屏幕尺寸与布局结构

胶囊屏物理宽度为 **192px**。各页面通常有左右内边距：

- 8px 内边距 → 内容区域宽度 = **176px**
- 16px 内边距 → 内容区域宽度 = **160px**

标准页面头部（Header）布局为三栏结构：

```
[返回按钮 48px]  [标题 flex:1]  [占位符 48px]
```

标题可用宽度 = 内容区域宽度 − 48px（返回按钮）− 48px（占位符）

- 8px padding：标题可用 = 176 − 96 = **80px**
- 16px padding：标题可用 = 160 − 96 = **64px**

### 1.2 共享样式 header.css 的问题

[header.css](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/common/header.css) 定义了 `.header-title` 样式：

```css
.header-title {
  flex: 1;
  font-size: 26px;
  font-weight: bold;
  text-align: center;
  line-height: 34px;
  lines: 1;
  text-overflow: ellipsis;
}
```

关键问题：**header.css 中没有胶囊屏 `@media (shape: capsule)` 的适配规则**，只有 rect 和 circle 的适配。也就是说，胶囊屏会使用默认样式 `font-size: 26px`。

### 1.3 数学计算

4 个中文字符在 26px 字号下的渲染宽度：**4 × 26 = 104px**

104px 远超标题可用宽度（80px 或 64px），导致 `text-overflow: ellipsis` 触发，第 4 个字被省略号替代，显示为 `"设备信..."`。

### 1.4 修复方向

要确保 4 个中文字符完全显示，需要：

- **减小字号**：4 × 字号 ≤ 标题可用宽度
  - 80px 可用：字号 ≤ 20px → 建议 `font-size: 20px`
  - 64px 可用：字号 ≤ 16px → 太小不可行
- **或增加可用宽度**：缩小返回按钮/占位符尺寸
  - 如 `add-course` 页面的方案：`.header-placeholder { width: 0 }`
  - 如 `course-manager` 页面的方案：返回按钮 40px + 占位符 40px = 80px 留给标题

**推荐方案**：胶囊屏下减小字号至 20px 同时缩小两侧控件。

## 五、修复建议

### 方案 A：统一在 header.css 中添加胶囊屏适配（推荐）

在 [header.css](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/common/header.css) 末尾添加：

```css
@media (shape: capsule), (shape: pill-shaped) {
  .header-title {
    font-size: 20px;
    line-height: 28px;
  }
  .header-placeholder {
    width: 44px;
  }
  .back-btn-wrapper {
    width: 44px;
    height: 44px;
  }
}
```

这样所有使用 header.css 的页面自动适配：
- 标题可用：176 − 44 − 44 = **88px**
- 4 字 × 20px = **80px** ✅（可完全显示）

**注意**：此方案会覆盖 `statistics` 和 `activation` 等有自己 CSS 的页面，需单独处理。

### 方案 B：各页面单独修复

参照 `course-manager` 或 `add-course` 的做法，在各自页面的胶囊屏 `@media` 中添加 `.header-title` 的 font-size 覆盖。建议值：

- 内容区 176px（8px padding）：`font-size: 20px`，4 字 × 20 = 80px
- 内容区 160px（16px padding）：`font-size: 18px` 并缩小两侧控件
