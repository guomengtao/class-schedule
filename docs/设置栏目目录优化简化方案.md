# EV课程表「设置」栏目整理规划方案

> 分析日期：2026-10-08
> 问题：设置页栏目归类混乱、命名不准、内联展开过长。

---

## 一、现状

```
settings.ux  一个页面 26 行，展开手机遥控后几乎占满全屏
├── 昵称                 [弹窗编辑]
├── 主题配色             [底部抽屉]
├── 课程字号             [内联展开]
├── 周课表               [内联展开]
├── 首页设置             [跳转]
├── 手机连接管理         [内联展开 12 行!!!]
├── 反馈 / 工具          [跳转]
├── 数据备份 / 高级版 / 打赏 [跳转]
└── 恢复默认             [跳转]

tools.ux  入口混乱，含调试项
├── 设备信息 / 震动 / 倒数日 / 二维码
├── 已钉页面（放错地方）
├── 数据统计 / 课程表管理 V2（V2 标签泄露）
└── @media 语法测试（用户不该看到）
```

**核心问题：** 归类无逻辑、手机遥控 12 行侵占整个设置页、调试入口暴露给用户。

---

## 二、栏目重新归类（无论哪种实现，归类一致）

先把栏目按性质分成 7 组：

| 组 | 栏目 | 目前在哪 | 特点 |
|----|------|----------|------|
| 个人 | 昵称、主题配色、课程字号 | settings 内联 | 3 项，纯内联交互，无跳转 |
| 课表 | 首页设置、隐藏周末 | settings 内联 | 2 项简单偏好 |
| 手机遥控 | 找手机、静音、手电筒…共 12 项 | settings 内联 | **块头最大**，全即时操作 |
| 数据 | 备份与恢复、重置数据 | settings 跳转 | 2 项，跳转现有页 |
| 关于 | 高级版、打赏支持、帮助与反馈 | settings 跳转 | 3 项，跳转现有页 |
| 工具 | 倒数日、震动、二维码、统计、工作日、设备信息 | tools.ux | 6 项稳定功能，成熟 |
| 实验室 | 中文输入演示（未来：bug测试、新页面预览） | 原在 tools | 1 项，实验性质 |

---

## 三、三种实现方案对比

### 方案 A：全展开式（全部留在 settings.ux，分组折叠）

```
主设置页 (settings.ux)  所有内容一个文件

┌──────────────────────────┐
│ ← 设置                    │
│                           │
│ [个人]                 v  │  ← 折叠组
│   昵称 / 主题 / 字号       │
│                           │
│ [课表]                 v  │  ← 折叠组
│   首页设置 / 隐藏周末      │
│                           │
│ [手机遥控]             v  │  ← 折叠组，展开后 12 行
│   找手机 / 静音 / ...     │
│                           │
│ [数据]                    │  ← 始终展开
│   备份与恢复      ›        │
│   重置数据        ›        │
│                           │
│ [关于]                    │  ← 始终展开
│   高级版 / 打赏 / 反馈  › │
│                           │
│ 工具               ›       │  → tools.ux
│ 实验室             ›       │  → lab.ux (新建)
└──────────────────────────┘
```

| 优点 | 缺点 |
|------|------|
| 所有设置集中一处，用户不用来回跳 | 手机遥控 12 行仍然是页面炸弹 |
| 不产生新文件，改动最小 | 内联交互类型多（弹窗/抽屉/展开/跳转），一个文件承载 6 种不同交互 |
| 保持现有代码结构 | 未来加新栏目会继续膨胀这个文件 |

---

### 方案 B：全独立页（6 个一级入口 + 5 个新页面）

```
主设置页 (settings.ux)  6 行纯入口

┌──────────────────────────┐
│ ← 设置                    │
│ 个人              ›       │  → personal.ux (新建)
│ 课表              ›       │  → schedule.ux (新建)
│ 手机遥控          ›       │  → phone-remote.ux (新建)
│ 工具              ›       │  → tools.ux (已有改造)
│ 实验室            ›       │  → lab.ux (新建)
│ 关于              ›       │  → about.ux (新建)
└──────────────────────────┘
```

| 优点 | 缺点 |
|------|------|
| 每页单一职责，好维护 | ⚠️ **产生 5 个新页面**，工作量大 |
| 主设置页永远 6 行，不变 | 个人/课表/数据显示只有 2-3 项，独立成页价值低 |
| tool.ux 和 lab.ux 独立 | "关于"页只是 3 个跳转链接的集合，独立成页多余 |
| | 6 行一级入口太稀疏，视觉空洞 |

---

### 方案 C：混合式（推荐 ⭐）— 大块独立，小块折叠

```
主设置页 (settings.ux)  混合布局

┌──────────────────────────┐
│ ← 设置                    │
│                           │
│ 个人                    › │  ← 轻量内联页 or 始终展开
│   昵称 / 主题配色 / 字号   │     3 项简单调节，不需要独立页
│                           │
│ 课表                    › │
│   首页设置 / 隐藏周末      │     2 项偏好，折叠即够
│                           │
│ 手机遥控              ›   │  → phone-remote.ux  12 项独立成页
│                           │
│ 数据                    › │
│   备份与恢复 / 重置数据    │     2 项跳转，折叠即够
│                           │
│ 关于                    › │
│   高级版 / 打赏 / 反馈     │     3 项跳转，折叠即够
│                           │
│ 工具                  ›   │  → tools.ux  已有页面改造
│ 实验室                ›   │  → lab.ux    新建
└──────────────────────────┘
```

**新页面**：只新建 2 个 — `phone-remote.ux` + `lab.ux`

**不新建 pages**：
- 个人 / 课表 / 数据 / 关于 → 保留在 settings.ux，用折叠组展示
- tools.ux → 原有文件，只改内容不新建

| 优点 | 缺点 |
|------|------|
| 只新建 2 页，工作量小 | 手机遥控独立页需搬 12 个 JS 函数 |
| 主设置页保持单手可操作 | 折叠组仍需维护（但每组 ≤3 项，可控） |
| 简单的留本页，复杂的独立出去 | |
| 后续容易扩展：新栏目先进折叠组，稳定后独立 | |

## 五、三种方案量化对比

| 维度 | A 全折叠 | B 全独立页 | **C 混合（推荐）** |
|------|:--:|:--:|:--:|
| 新建 .ux 文件 | 0 | **5** | **2** |
| 改造现有文件 | 2 (settings, tools) | 2 | 2 |
| settings.ux 行数 | ~12（折叠态） | **6** | **~8** |
| 每页职责 | 重（6 种交互合一） | 轻 | 适中 |
| 手机遥控独立 | ❌ 仍在主页展开 | ✅ | ✅ |
| 用户跳转深度 | 1 层 | 2 层（6→5） | 1-2 层 |
| 后续扩展性 | 差，文件越来越长 | 好，加新文件即可 | **好**，新栏目先进折叠组，稳定后独立 |
| 实施工作量 | 小 | 大 | **中** |

## 六、栏目改名汇总

| 原名 | 改为 | 理由 |
|------|------|------|
| 手机连接管理 | **手机遥控** | 不是管连接，是遥控 |
| 数据备份 | **备份与恢复** | 加"恢复"方便用户查找 |
| 恢复默认 | **重置数据** | 原名像恢复出厂设置，吓人 |
| 反馈 | **帮助与反馈** | 加"帮助"暗示含 FAQ |
| 课程表管理 V2 | **课程表管理** | 去掉版本号 |

## 八、推荐结论

**选方案 C（混合式）**。

理由：
- 方案 A 没有解决手机遥控侵占页面的核心问题
- 方案 B 为 2-3 项内容新建独立页，杀鸡用牛刀
- 方案 C 只新建 2 页，处理两个真正需要独立空间的栏目（12 项遥控 + 实验室），其余保留折叠
