# 首页底部按钮模块功能需求分析

## 一、功能定位

底部按钮是首页底部的两个主要操作入口，分别用于添加新课程和进入设置页面。

**使用场景**：用户想添加一节课，点击「+ 添加课程」按钮进入完整的添加课程流程；想调整设置，点击「设置」按钮进入设置页面。

## 二、界面布局格式要求

底部按钮位于快速添加下方，占一行高度，两个按钮并排排列。

```
┌──────────────────────────────┐
│  ...                         │
├──────────────────────────────┤
│ 快速添加               09:00 │  ← 快速添加
│ [语文] [数学] [英语] [物理]→│
├──────────────────────────────┤
│  ┌──────────────┐ ┌────────┐ │
│  │ + 添加课程   │ │  设置  │ │  ← 底部按钮
│  └──────────────┘ └────────┘ │
├──────────────────────────────┤
│  ⇄ 课程表1                   │  ← 课程表切换
└──────────────────────────────┘
```

- 左侧：「+ 添加课程」按钮，圆角胶囊样式，主题色填充
- 右侧：「设置」按钮，圆角胶囊样式，卡片色填充

## 三、用户视角的功能描述

### 3.1 添加课程

用户点击「+ 添加课程」按钮，跳转到添加课程页面。该页面会自动填入当前日期，用户可以选择课程、设置时间、教师、地点等信息。

### 3.2 设置

用户点击「设置」按钮，跳转到设置页面。设置页面包含：主题配色、字体大小、首页设置、提醒设置、课程管理、功能实验室等。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 点击「+ 添加课程」 | 跳转到添加课程页面，当前日期自动填入 |
| 点击「设置」 | 跳转到设置页面 |
| 添加课程完成后返回 | 课程列表自动刷新 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 快速添加已展开 | 底部按钮在快速添加下方，不受影响 |
| 快速添加收起 | 底部按钮紧贴快速添加标题栏 |
| 快速添加关闭 | 底部按钮紧贴课程列表 |
| 添加课程页返回 | 课程列表自动刷新显示新课程 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 添加课程页 | 「+ 添加课程」按钮跳转到添加课程页 |
| 设置页 | 「设置」按钮跳转到设置页 |
| 快速添加 | 快速添加是快捷方式，底部按钮是完整入口，功能互补 |
| 课程列表 | 添加课程后课程列表自动刷新 |
