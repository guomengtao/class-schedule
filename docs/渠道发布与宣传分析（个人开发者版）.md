# Ev课程表 渠道发布与宣传分析（个人开发者版）

> 适用对象：Ev课程表（小米手环 / Vela 快应用，包名 `com.application.watch.classschedule`，交付格式 `.rpk`）的个人开发者。
> 目标：在「已主发米坛社区」的基础上，梳理还有哪些渠道值得投入、优先级如何、注册入口在哪、个人开发者有什么门槛。

---

## 一、结论先行

**三个核心判断：**

1. **`.rpk`（Vela 手表快应用）目前没有低门槛的官方商店通道。**
   小米官方「手表应用」发布走的是 **`.apk` + 软著 + APP 备案** 路线，且备案主体需具备统一社会信用代码，实际门槛偏向企业开发者；Vela 快应用的官方上架需走**生态伙伴/商务对接**。这意味着——**社区分发仍是当前的主战场，短期内不会被官方商店替代。**

2. **渠道应分三层：社区分发（主力）+ 内容平台引流（扩展）+ 官方商店（长线备份）。**
   社区直接给"能装到手表上"的 `.rpk` 下载；内容平台负责让更多人"知道你"；官方商店作为未来正规化通道，提前攒资质。

3. **对个人开发者最友好的组合：**
   米坛社区（已有）+ 轻腕社区 + HiWear + GitHub Release，配 B站/小红书/知乎 内容引流。

| 平台 | 网址 | 上架格式 | 关键门槛 |

| vivo 开放平台 | `http://dev.vivo.com.cn`（快应用上传 `https://dev.vivo.com.cn/quickApp/list`） | `.rpk` | 注册 vivo 开发者账号；可只上 vivo，也可经快应用联盟多厂商分发 |

| 荣耀开发者服务平台 | `https://developer.honor.com/` | `.rpk` | 需开发者认证 |

**关键提醒（避免踩坑）：**
- 手机快应用平台的审核对象是**手机端快应用**，手表端（Vela 手环）能否分发需**实测确认**，不要想当然。
- 官方通道的硬门槛是 **软著 + APP 备案**。个人开发者可先申请**软件著作权**（登记周期通常 1~3 个月，可加急），作为未来上架的"通行证"提前准备。

## 七、渠道优先级与执行建议

### 7.1 优先级矩阵

| 优先级 | 渠道 | 动作 | 频率 |
|---|---|---|---|
| **P0** | 米坛社区（12 个渠道位） | 分型号发讨论帖 + 资源页 | 每次发版 |
| **P0** | 轻腕社区 | 上传应用、同步更新 | 每次发版 |
| **P0** | GitHub | Release 出包 + Release Notes | 每次发版 |
| **P1** | HiWear | 发资源帖 | 每 2~3 个版本 |
| **P1** | B站 / 小红书 | 版本亮点演示短视频/图文 | 每月 1~2 条 |
| **P2** | 知乎 / 少数派 / 贴吧 | 教程与体验文章 | 每季度 |
| **P2** | 快应用联盟 / vivo / OPPO / 华为 | 试投手机端快应用，验证手表端分发可行性 | 半年评估 |
| **P3** | 小米官方手表应用商店 | 先办软著 + 备案，具备资质后再推进 | 长线 |

### 7.2 发布节奏建议

1. **统一发版节奏**：不要每版都全渠道铺开，建议**攒批发版**（如每积累 3~5 个版本或 1~2 周发一次），降低维护成本。
2. **一份素材多端复用**：一次录制演示视频 → 拆成 B站长视频 + 小红书图文 + 抖音短视频。
3. **正文模板化**：版本更新帖固定结构（本次更新 / 支持机型 / 安装方式 / 反馈渠道），保证各平台信息一致。
4. **埋渠道包**：继续用现有 14 渠道机制，**不同渠道发不同包**，便于统计各渠道真实下载量。

## 八、个人开发者注意事项

1. **官方商店 ≠ 现在能上**：小米手表应用需 `.apk` + 软著 + 备案，本项目当前是 `.rpk`，**两者不是同一通道**，不要混淆。
2. **软著可提前办**：即便暂不上架，也建议先登记软件著作权（成本低、周期长，早办早用）。
3. **合规红线**：不要引导用户绕过官方系统限制、不要分发来路不明的固件；应用内必须提供隐私说明或合规声明。
4. **版权与素材**：宣传图、字体、图标需确保可商用授权，避免侵权投诉。
5. **社区版规**：各社区对"资源帖""广告帖"有明确规定，发帖前先读版规，避免封号。
6. **求反馈优先**：社区渠道的核心价值是**真实反馈**（尤其是新机型适配），发帖时主动引导用户报机型与问题。

## 十、一页总结

- **现在的主力**：米坛社区（12 渠道位）+ 轻腕 + GitHub —— 继续深耕，不要分散。
- **最值得新增的**：HiWear（低成本高相关）+ B站/小红书（引流）。
- **暂时的天花板**：官方商店受"软著 + 备案"限制，个人开发者短期难以进入，**优先办软著，等资质齐备再谈上架**。
- **一句话建议**：**把 90% 的发布精力放在"能直接装到手表上"的穿戴社区，把 10% 放在内容平台做长尾引流；官方商店当长线，不押注。**
