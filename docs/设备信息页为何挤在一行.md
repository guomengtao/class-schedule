# 设备信息页为何还是"挤在一行"？

## 现象

删掉胶囊媒体查询里的特殊样式后，页面 `menu-item` 仍然是水平一排，不是希望的"2行"（label 在上、value 在下）。

## 根因：基础 CSS 就是横向布局

```css
/* 基础 CSS（@media 外面，始终生效） */
.menu-item {
  flex-direction: row;           /* ← 横向一排！ */
  justify-content: space-between;
  align-items: center;
}
```

基础 CSS 的设计就是 label 和 value 同行显示：

```
┌──────────────────────────┐
│  品牌    Huawei Band 9     │  ← 一行，挤
│  型号    BVL-AL00         │
│  系统    HarmonyOS 5.0    │
└──────────────────────────┘
```

之前看起来"2行"、不挤，是因为**胶囊媒体查询里有 `flex-direction: column`**，覆盖了基础 CSS 的 `row`：

```css
/* 之前的胶囊块（已删除） */
@media (shape: pill-shaped) {
  .menu-item {
    flex-direction: column;      /* ← 这行把 row 改成 column！ */
    align-items: flex-start;
  }
}
```

效果变成：

```
┌──────────────────────────┐
│  品牌                     │  ← 第一行
│  Huawei Band 9            │  ← 第二行
│                           │
│  型号                     │
│  BVL-AL00                │
│                           │
│  系统                     │
│  HarmonyOS 5.0            │
└──────────────────────────┘
```

## 为什么会误删

之前的逻辑是"胶囊块里的样式 = 过度优化，删掉靠基础 CSS更舒服"。但这个判断漏了一个关键点：

| 属性 | 基础 CSS | 胶囊块 | 应该保留？ |
|------|:---:|:---:|:---:|
| `padding: 16px` | 8px | 16px | ❌ 删掉，太宽 |
| `menu-label font-size: 22px` | 24px | 22px | ❌ 删掉，可继承 |
| `flex-direction: column` | **row** | **column** | ✅ **必须保留！** |

`flex-direction: column` 不是"过度优化"，它是**结构级改动**——基础 CSS 没有这个值。删了它就回到水平布局了。

## 修复方向

在胶囊块里**加回** `flex-direction: column`，其他属性不动（继续继承基础 CSS）：

```css
@media (shape: capsule), (shape: pill-shaped) {
  .page-body {
    padding: 38px 8px 10px 8px;
  }
  .menu-item {
    flex-direction: column;
    align-items: flex-start;
  }
}
```

这样就得到：**竖排布局 + 基础CSS 的字号/间距**——既不像第一版那样压缩过紧，也不像现在这样挤成一行。
