# 首页置顶页模块功能需求分析

## 一、功能定位

置顶页模块允许用户将常用页面「钉」到首页，以标签形式显示在课程列表上方，点击即可快速跳转。

**使用场景**：用户经常需要查看课程管理页面，将课程管理钉到首页后，每次打开首页都能看到「课程管理」标签，点击直接进入，省去在设置中翻找的步骤。

## 二、界面布局格式要求

置顶栏位于状态栏下方、课程列表上方，占一行高度，左侧有彩色竖条装饰。

```
┌──────────────────────────────┐
│ ▎▎ [上课中] 数学    15min   │  ← 状态栏
├──────────────────────────────┤
│ ▎ [课程管理] [二维码] [设置] │  ← 置顶栏
├──────────────────────────────┤
│ ┌─────────┐ ┌─────────┐     │
│ │ 数学    │ │ 英语    │     │  ← 课程列表
│ └─────────┘ └─────────┘     │
└──────────────────────────────┘
```

- 左侧：彩色竖条装饰
- 右侧：置顶页标签，圆角胶囊样式，横向排列
- 标签之间保持均匀间距

## 三、用户视角的功能描述

### 3.1 添加置顶

用户在某个页面（如课程管理、设备信息等）点击「钉到首页」按钮，该页面就出现在首页置顶栏中。

### 3.2 点击跳转

用户点击首页置顶栏中的标签，直接跳转到对应页面。

### 3.3 删除置顶

用户在置顶管理页面中取消置顶，首页对应标签消失。

### 3.4 空状态

如果用户没有置顶任何页面，首页不显示置顶栏。

### 3.5 显隐控制

用户可以在设置中关闭置顶栏，即使有置顶页面也不显示。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 在任意页面点击「钉到首页」 | 首页置顶栏出现该页面标签 |
| 点击首页置顶标签 | 跳转到对应页面 |
| 在置顶管理页取消置顶 | 首页对应标签消失 |
| 关闭置顶栏 | 整行不显示 |
| 所有置顶都取消后 | 置顶栏自动隐藏 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 没有置顶任何页面 | 置顶栏不显示 |
| 置顶了多个页面 | 标签横向排列，一行显示 |
| 置顶栏关闭 | 即使有置顶页面也不显示 |
| 置顶的页面被删除 | 标签自动消失 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 置顶管理页 | 管理置顶列表，增删置顶项 |
| 各个页面 | 页面需要提供「钉到首页」的入口 |
| 设置页 | 控制置顶栏显隐 |
