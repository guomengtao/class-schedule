# 倒数日农历换算：决策与实测（2026-10-21）

## 一、决策

| 档 | 内容 | 结论 |
|---|---|---|
| A | 农历/公历切换 + 一次性换算 | ✅ 本次实施 |
| B | `repeat: yearly`（每年重复） | ⚠️ 缓做：农历 yearly 会把表拉进首页依赖链，三个页面各 +3KB |
| C | daily / weekly / monthly 周期 | ❌ 不做 |

C 不做的三条理由：① 天/月周期没有终点，「剩余天数」核心指标失效（永远 0–1 / 0–30 抖动）；② 循环条目永不消失，首页从「稀缺的逼近终点」退化成待办清单；③ 模型要从 `date` 变 `rule`，月末溢出、跳过已过、锚点全要处理，三页全改。

## 二、实现

- 新增 `src/data/lunar.js`：1900–2099 年 17-bit 编码表（Fung F. Lee / Ricky Yeung 经典表），存成**一个长字符串常量**（1018 字符）而非 200 个数字常量，`split(" ")` + 自写 hex 解析，惰性缓存。
- 只做必要集：`toSolar` / `fromSolar` / `daysInMonth` / `monthList` / 月名日名。不做节气、干支、宜忌、完整万年历。
- **落盘口径不变**：农历只是输入视图，`dateStr` 永远是公历 `YYYY-MM-DD`，`data/countdown.js` 与首页零改动。
- 双真源（公历 `yearNum/monthNum/dayNum` + 农历 `lyNum/lmNum/ldNum/leapFlag`），**切换时整组换算一次**，不做实时双向同步——后者在闰月边界（该年无闰月、29↔30 天）会来回抖动。
- 闰月让「下标 = 月份 − 1」失效，月列额外维护 `monthKeys`（与 `monthStrs` 同下标），滑动时按 key 反查；换年后 `clampLunarMonth()` 把不存在的闰月退回同名正常月。
- 年范围扩到 `now−2 … now+6`：农历腊月会落到公历次年 1 月，公历 1 月也可能属上一个农历年。
- 显示名一律两字（`正月…冬月腊月`，闰月 `闰六`），52px 列宽才不会被撑破。

## 三、实测

- **换算正确性**：以 `lunardate` 为独立真值，11134 条样本（1900–2099 每年各月首/中/末 + 全部闰月）→ `toSolar` 0 不符、往返 `fromSolar` 0 不符。
- **状态机**：抽出 `.ux` 的 `<script>` 在 Node 里执行（打桩 `@system.storage/router`），29 项断言全过：切换不丢日期、2026 八月十五 → `2026-09-25`、2025 月列 13 项且第 7 项为「闰六」、闰六初一 → `2025-07-25`、跨闰月年自动退月、2100 越界不产出空串。
- **体积**（`npm run build`，同管线对比）：`countdown-edit.jsc` 43,772 → **49,355 B（+5,583 / +12.8%）**；`index.jsc` 96,616 B **未变**（依赖隔离成立）；rpk 总包 1.06 MB，增量 0.5%。
- **视觉**：公历态、农历闰月态各截图一张（`shots/countdown-edit-lunar-20261021.png`、`...-probe-20261021.png`）。首版预览行「农历闰六月初一 · 已过441天」超 168px 被 ellipsis 吃字，去掉冗余「农历」前缀后完整显示。

## 四、未闭环

模拟器 AVD 的输入注入整体失效（`drag` 无位移、`event mouse` 无响应），**切换按钮的真实点击与滚动手感必须在真机验证**。农历态截图是通过临时改默认态取得的探针，验收后已删除。
