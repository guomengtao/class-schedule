# 激活码验证规则

## 激活码格式

激活码为 **18 位纯数字**，由以下 4 个字段编码而成：

```
输入: 98ASDF39aA4D
      ││ │  ││ │  │
      ││ │  ││ │  └── 设备ID (4位: A-Z a-z 0-9)
      ││ │  ││ └── 月份数 (2位纯数字)
      ││ │  └── 校验码 (4位: A-Z 0-9)
      ││ └── 产品ID (2位纯数字)
```

| 字段 | 长度 | 字符集 | 示例 | 说明 |
|------|------|--------|------|------|
| 产品ID | 2位 | 纯数字 0-9 | `98` | 产品标识 |
| 校验码 | 4位 | 大写字母+数字 A-Z 0-9 | `ASDF` | 防伪造校验 |
| 月份数 | 2位 | 纯数字 0-9 | `39` | 激活的月数 |
| 设备ID | 4位 | 大小写字母+数字 A-Z a-z 0-9 | `aA4D` | 设备唯一标识 |

## 验证规则

### 规则 1：产品ID 校验

```
产品ID 必须等于 "01"
```

只有产品ID为 `01` 的激活码才被视为有效。其他产品ID的激活码一律拒绝。

### 规则 2：一次性使用校验

```
每个激活码只能使用一次，使用后标记为已使用
```

**流程：**
1. 查询本地使用记录，检查该激活码是否已存在
2. 若已存在 → 拒绝激活，提示"该激活码已被使用"
3. 若不存在 → 继续验证，验证通过后将该激活码写入使用记录

**使用记录存储：**
- 本地维护一个已使用激活码的列表（JSON 文件或数据库）
- 每次激活成功后，将激活码的 18 位数字追加到列表中
- 验证时先查询列表，确保不重复使用

### 规则 3：月份数激活

```
激活码中的月份数字段表示激活的月数时长
```

| 月份数 | 含义 |
|--------|------|
| `01` | 激活 1 个月时长 |
| `03` | 激活 3 个月时长 |
| `12` | 激活 12 个月时长 |
| `99` | 激活 99 个月时长（约 8 年） |

**处理逻辑：**
- 解密激活码，提取月份数字段
- 将月份数累加到当前设备的剩余有效时长中
- 例如：当前剩余 2 个月，激活码月份数为 `03`，则新剩余时长为 5 个月

### 规则 4：兑换码一次性使用

```
每个兑换码（校验码）只能兑换一次，使用后标记为已兑换
```

**说明：**
- 兑换码是激活码中的第 2 组（4位大写字母+数字），由服务器生成
- 同一个兑换码只能成功激活一次，防止同一兑换码在不同设备上重复使用
- 与规则 2（激活码一次性使用）的区别：规则 2 校验整个 18 位激活码是否重复，规则 4 校验其中的 4 位兑换码是否重复

**流程：**
1. 解密激活码，提取兑换码字段（4 位字符，如 `ASDF`）
2. 查询本地兑换记录，检查该兑换码是否已存在
3. 若已存在 → 拒绝激活，提示"该兑换码已被使用"
4. 若不存在 → 继续验证，验证通过后将该兑换码写入兑换记录

**兑换记录存储：**
- 本地维护一个已兑换的兑换码列表（4 位字符）
- 每次激活成功后，将兑换码追加到列表中
- 验证时先查询列表，确保不重复兑换

### 规则 5：设备ID 校验

```
激活码中设备ID的后四位必须与当前设备的设备ID后四位一致
```

**流程：**
1. 获取当前设备的设备ID（4 位字符，如 `aA4D`）
2. 解密激活码，提取其中的设备ID字段
3. 比对两者是否完全一致（大小写敏感）
4. 一致 → 验证通过
5. 不一致 → 拒绝激活，提示"设备ID不匹配"

## 完整验证流程

```
用户输入 18 位激活码
        │
        ▼
  ┌─ 1. 解密激活码 ─────────────────────┐
  │  提取: 产品ID、校验码、月份数、设备ID  │
  └──────────────────────────────────────┘
        │
        ▼
  ┌─ 2. 产品ID校验 ──────────────────────┐
  │  产品ID == "01" ?                     │
  │  否 → 提示"无效的产品ID"              │
  └──────────────────────────────────────┘
        │ 是
        ▼
  ┌─ 3. 一次性使用校验 ──────────────────┐
  │  激活码已被使用过?                     │
  │  是 → 提示"该激活码已被使用"          │
  └──────────────────────────────────────┘
        │ 否
        ▼
  ┌─ 4. 兑换码一次性使用校验 ─────────────┐
  │  兑换码已被使用过?                     │
  │  是 → 提示"该兑换码已被使用"          │
  └──────────────────────────────────────┘
        │ 否
        ▼
  ┌─ 5. 设备ID校验 ──────────────────────┐
  │  激活码中的设备ID == 当前设备ID?       │
  │  否 → 提示"设备ID不匹配"              │
  └──────────────────────────────────────┘
        │ 是
        ▼
  ┌─ 6. 激活成功 ────────────────────────┐
  │  - 增加月份数到剩余时长               │
  │  - 将激活码写入使用记录               │
  │  - 将兑换码写入兑换记录               │
  │  - 提示"激活成功，有效期延长 X 个月"  │
  └──────────────────────────────────────┘
```

## 伪代码

```javascript
function validateActivationCode(inputCode, currentDeviceId) {
  // 1. 解密激活码
  var decoded = decryptActivationCode(inputCode);
  if (!decoded.valid) {
    return { success: false, message: "激活码格式无效" };
  }

  // 2. 产品ID校验
  if (decoded.productIdIndex !== "01") {
    return { success: false, message: "无效的产品ID" };
  }

  // 3. 一次性使用校验（整个激活码）
  var usedCodes = loadUsedCodes();
  if (usedCodes.indexOf(inputCode) !== -1) {
    return { success: false, message: "该激活码已被使用" };
  }

  // 4. 兑换码一次性使用校验
  var usedRedeemCodes = loadUsedRedeemCodes();
  if (usedRedeemCodes.indexOf(decoded.redeemCode) !== -1) {
    return { success: false, message: "该兑换码已被使用" };
  }

  // 5. 设备ID校验
  if (decoded.deviceId !== currentDeviceId) {
    return { success: false, message: "设备ID不匹配" };
  }

  // 6. 激活成功
  var months = parseInt(decoded.months, 10);
  addMonthsToRemaining(months);
  saveUsedCode(inputCode);
  saveUsedRedeemCode(decoded.redeemCode);

  return { success: true, message: "激活成功，有效期延长 " + months + " 个月" };
}
```
