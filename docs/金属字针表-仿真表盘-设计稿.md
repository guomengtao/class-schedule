# 仿真金属字针表 · 设计稿（黑盘金标 + 5 种隐形退出）

> 归属：ev 课程表手环快应用（ev/class-schedule）第三款表盘
> 机型：小米手环 9 标准版 · 跑道屏 192×490
> 关联任务：`evtask-D-evclass-sche-261009-qzwfzj`（实现已入库 commit 90fe8ae）
> 设计定稿依据：用户修订「去掉黄色外圈 + 新增单击直接退出」

## 1. 设计定位

与已交付的两款表盘并列，形成系列辨识度：

| 表盘 | 风格 | 主色 | 时标 |
|---|---|---|---|
| 仿真机械表盘 `watch-face` | 蓝钢棒时标 | 蓝钢 | baton 棒 |
| 课程表盘 `watch-face-class` | 电子 LCD 荧光 | 青绿 | 数字（无指针） |
| **金属字针表 `watch-face-gold`** | **黑盘金标·应用式数字** | **暖金 #E6C24A 系** | **立体金阿拉伯数字** |

核心差异：本款用 **12 枚立体金阿拉伯数字** 替代蓝钢棒时标，盘面改为 **深色钢圈 + 深炭拉丝盘**，让「金数字 + 金针」成为唯一金色焦点，呈现克制的奢华感（即用户要求的「去掉黄色外圈」后的最终形态）。

## 2. 视觉规范（与 `.ux` 实测一致）

### 2.1 表壳同心环（无黄色外圈 · 深色钢圈造厚度）
> Vela 引擎不支持 CSS 渐变，金属厚度用「多层同心圆 + 边线高光」模拟。

| 层 | 尺寸(px) | 位置(left/top) | 颜色 | 说明 |
|---|---|---|---|---|
| case-outer | 184×184 | 4 / 148 | `#1c1f23` + border `#3a3f47` | 钢圈外缘（包边高光） |
| case-mid | 170×170 | 11 / 155 | `#2a2f36` | 中圈亮钢 |
| case-inner | 162×162 | 15 / 159 | `#14171b` | 内圈暗钢 |
| dial | 156×156 | 18 / 162 | `#16191e` | 深炭拉丝盘面 |
| dial-light | 156×78 | 18 / 162 | `#2b3038` op 0.55 | 上半受光（太阳纹明暗） |
| dial-shade | 156×78 | 18 / 240 | `#05070a` op 0.45 | 下半沉影 |
| glare | 58×26 | 34 / 178 | `#ffffff` op 0.10 | 镜面一处高光 |

### 2.2 表盘构件
- **盘心**：`CX=96, CY=240`（屏宽 192 正中，y 避上下弧形危险区）。
- **分钟轨 60 格**：半径 `R_TICK=70`。长刻度（`i%5==0`）2×7 `#8a7330`；短刻度 1×4 `#5c4e22`。
- **金属字 12 枚**：半径 `R_NUM=58`，字号 16px bold。
  - 亮金层 `#f0d678`（宽 26 居中、行高 20 垂直居中）。
  - 暗金倒角层 `#7a5e16`，相对亮金层偏移 **(+1,+1)** 造立体浮雕感。
  - **3 点位跳过**（让位日历窗）。
- **品牌字**：12 点位 `EV` `#e6c24a` 14px；6 点位 `AUTOMATIC` `#caa64a` 11px（长按退出热区②，计时中转为松石绿 `#1f7d5d`）。
- **日历窗**（3 点位）：28×20 `#0e1013` + border `#caa64a`，日期 `dayText` `#f0d678` 14px，取 `new Date().getDate()`。
- **指针**（金针 + 红尖秒针）：
  - 时针 `#e6c24a` 8×40，transform-origin `50% 100%`。
  - 分针 `#e6c24a` 6×58。
  - 秒针杆 `#e6c24a` 2×64 + 红尖 `sec-tip` `#d8483b` 4×14（子元素随父级旋转至针尖）。
  - 中心轴帽 `#e6c24a` 10×10。

### 2.3 走时
- 刷新间隔 `TICK_MS=100ms`（连续扫秒的丝滑感）。
- `hourDeg = (h%12)*30 + m*0.5`（时针随分钟连续推进，非整点跳）。
- `minDeg = m*6 + s*0.1`。
- `secDeg = (s + ms/1000)*6`（毫秒级扫秒）。

### 2.4 几何换算（极坐标 → 元素左上角）
```
x = CX + radius*sin(deg) - w/2
y = CY - radius*cos(deg) - h/2
```
全部盘面坐标在 `buildDial()` 内一次性算好，渲染期只改旋转角度，零重排。

## 3. 五种隐形退出（不画按钮、不占画面）

热区层级：`hit-face` 最底（覆盖中性盘区 156×156，单击直退）→ `hit-center` / `hit-brand` / `hit-crown` 在其上方各管专属手势，互不触发单击。

| # | 途径 | 触发区 | 反馈 | 实现 |
|---|---|---|---|---|
| ⑤ | **单击中性盘区直退** | `hit-face`（left18/top162 156×156） | 无 | `onclick → onFaceTap → doExit` |
| ① | 长按盘心 3 秒 | `hit-center`（52×52） | 中心六微光点每 500ms 亮一颗，6 颗满=3s | `onlongpress onCenterLongPress` |
| ② | 长按 6 点位 AUTOMATIC 2 秒 | `hit-brand`（80×18） | 字样转松石绿 `#1f7d5d` | `onlongpress onBrandLongPress` + `setTimeout 2000` |
| ③ | 双击 3 点位表冠区 | `hit-crown`（42×40） | 无 | `onclick onCrownTap`（两次间隔 <500ms 判定） |
| ④ | 自下往上滑 | 整页 `page` | 无 | `ontouchstart/onTouchEnd` 手写方向判定，`startY-endY >= 40` 退出 |

**防误触**：①/② 在 `ontouchend` 触发 `cancelCountdown()` 立即中止计时（松手即取消）；④ 仅在「上滑位移 ≥40px」时退出；⑤ 单击只在中性区生效，中心/表冠/字样区各有专属处理器拦截，不会误退。

`doExit()` 收尾：`clearCountdown()` → `setDots(0)` 复位微光点 → `brandColor` 复位 → `vibrator.vibrate({mode:'short'})`（无震动模块则静默容错）→ `router.back()` 返回工具页。

## 4. 关键工程决策

1. **去黄圈**：原三层暖金表壳改为深色钢圈（包边高光 `#3a3f47` + 暗钢 `#1c1f23`），金数字/金针成为唯一金色焦点 → 黑盘金标的克制奢华。
2. **单击直退（用户新增）**：最省事的退出方式，中性盘区不与其他手势冲突（中心/表冠/字样各有专属热区）。
3. **无渐变约束**：Vela 引擎不支持 CSS `gradient`，金属立体感用「同心环 + 半色调叠（dial-light / dial-shade / glare）」模拟，已在 `watch-face.ux` 验证可渲染。
4. **`transform: rotate` + `position:absolute`**：引擎支持，指针几何复用 `watch-face.ux` 已验证结构。
5. **根容器必须是 flex 且拿尺寸**：否则内部 absolute 子元素不参与布局 → 整页只剩底色（黑屏）。`.page` 设 `flex:1; flex-direction:column; width/height:100%`。
