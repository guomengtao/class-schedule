# Ev课程表 胶囊屏（192px）专项走查报告

> 走查对象：Ev课程表 v1.5.70（`deviceTypeList = ["watch", "band"]`）
> 重点屏型：**胶囊屏 / pill-shaped，物理宽 192px**（规范：内容区 ≈160px）
> 走查方式：源码静态走查 + 宽度算式推导（**未真机运行**，标注「需真机确认」处以实机为准）
> 判定依据：[Ev课程表_手环字号规范_v1.md](./Ev课程表_手环字号规范_v1.md)（字号档位 40/36/34/32/28/24/20，**禁止低于 20px**；按钮高度 ≥48px；行高 = 1.2 × 字号）
> 姊妹文档：[用户视角功能与排版走查报告.md](./用户视角功能与排版走查报告.md)

## 一、胶囊屏结论速览

| 页面 | 文字是否正常显示 | 是否有遮挡/挤压 | 严重度 |
|:---|:---|:---|:---:|
| 首页 `index` | **不正常**：课程名只能显示 0-1 个字；大量 16-18px 小字 | 有：名字 48px 挤在 ~40px 空间，时间竖排吃半屏 | **P0** |
| 添加课程 `add-course` | 基本正常（标题完好） | 有：时间行超宽 14px；星期按钮 30px 易点错 | **P1** |
| 编辑课程 `detail` | 标题被截断（"编辑课…"） | 有：轮播卡片区超宽 52px、时间步进器超宽 12px | **P0/P1** |
| 总课表 `week-view` | 不正常：课名 20px 且**只显示 1 个字** | 无明显截断，但信息量不足 | **P0** |

**胶囊屏三个最致命的问题：**

1. **首页课程卡看不到课程名**（可用宽度 40px，字号 48px）；
2. **总课表每格 1 个字**（`minimal-char` 默认模板 `charAt(0)`）；
3. **课程管理页 4 个元素挤在一行**，课程名只剩 2 字，删除按钮只有 36×24px（规范要求 ≥48px）。

## 二、先看一张"对不齐"的表：各页面胶囊屏宽度基准不统一

胶囊屏物理宽 192px，但每个页面的左右 padding 都不一样，导致**同一台设备上内容边界来回跳**：

| 页面 | 胶囊屏 padding | 内容区宽 | 代码位置 |
|:---|:---|:---:|:---|
| 首页 `index` | `30px 12px` | **168px** | `index.ux` L896-899 |
| 添加课程 `add-course` | `30px 8px` | **176px** | `add-course.ux` L743-746 |
| 编辑课程 `detail` | `38px 8px 50px 8px` | **176px** | `detail.ux` L998-1001 |
| 总课表 `week-view` | `30px 16px` | **160px** | `week-view.ux` L998-1001 |
| 课程管理 `course-manager` | **无胶囊屏适配**（走默认 `38px 6px`） | **180px** | `course-manager.ux` L294-298 |

> 问题：规范给的是统一的「内容区 160px」，实际代码出现 160/168/176/180 四种。页面之间切换时左右留白不一致，**是"界面混乱"的第一层来源**。

## 三、逐页走查（含算式）

### 3.1 首页 `index` —— 课程名基本看不见（P0）

**① 星期标题被压到极限**

```
内容区 168px
  − nav-btn 36px（左箭头）
  − nav-btn 36px（右箭头）
  − day-nav-circle 36px + margin 2px（"总"按钮）
  = 留给 .day-title 的宽度 = 58px
```

而 `.day-title` 的字号是**内联注入的**（`index.ux` L9）：

```9:9:src/pages/index/index.ux
<text class="day-title" style="font-size: {{ dayTitleSize }}px; color: {{ theme.text }}">{{ dayDisplayText }}</text>
```

`dayTitleSize = baseFontSize`，**默认 48px**，档位最高可到 **76px**：
- 48px：单字占 48px，剩 10px 余量 → 勉强
- **62px / 76px：直接超出 58px → 文字被裁切**（需真机确认裁切方向）

同时 CSS 里的胶囊屏降级 `.day-title { font-size: 26px }`（`index.ux` L919-925）**被内联 48px 完全覆盖**，降级形同虚设。

**② 课程卡：名字可用宽度只剩 40px**

```
页面内容区 168px
  − .class-card-body padding 8px×2 + 10px×2 = 20px
  = 卡片正文宽 148px
  − 右侧 .class-card-meta（flex-shrink:0，竖排"时间+地点"）
       字号是内联的 34px（0.71×48）
       时间 "08:00"  ≈ 5 半角 × 0.55 × 34 ≈ 93px
       地点 "3号楼"  ≈ 3 汉字 × 34 = 102px  ← 取大者
  − .grid-item-name margin-right 6px
  = 课程名可用宽度 ≈ 148 − 102 − 6 = 40px
```

课程名字号 48px → **40px 空间连 1 个字都放不下**（无地点时约 49px，勉强 1 个字）。
结论：**胶囊屏首页每张卡片只能看到 0-1 个字的课程名**，其余被 `text-overflow: ellipsis` 吃掉。用户要看"这节课是什么"必须逐条点进详情。

相关代码：
```1000:1026:src/pages/index/index.ux
  .class-card-body {
    padding: 8px 10px 8px 10px;
    flex-direction: row;
    align-items: center;
  }
  .grid-item-name {
    margin-bottom: 0;
    flex: 1;
    margin-right: 6px;
    lines: 1;
    text-overflow: ellipsis;
  }
  .class-card-meta {
    flex-direction: column;
    flex-shrink: 0;
    align-items: flex-end;
  }
  .grid-item-time {
    font-size: 13px;
    ...
```

**③ 行高与字号打架（文字上下压在一起）**

| 元素 | 内联字号 | 生效行高 | 结果 |
|:---|:---:|:---:|:---|
| 课程名 | 48px | 32px（继承默认 L678） | 字形溢出 16px |
| 时间 | 34px | 28px（L691） | 溢出 6px |
| 地点 | 34px | 28px | 溢出 6px |

胶囊屏卡片是**横向**布局（名字与时间同排），行高问题主要表现为"字被上下切边"；一旦切回纵向（或名字换行），就会与下一行重叠。

**④ 大量 16-18px 小字（低于规范 20px 护栏）**

| 元素 | 字号 | 位置 |
|:---|:---:|:---|
| `.day-nav-text`（总/今/明） | 16px | `index.ux` L932-935 |
| `.status-tag-compact` | 16px | L944-949 |
| `.status-right-compact` | 16px | L959-962 |
| `.quick-add-tag-text`（快捷添加标签） | 16px | L981-983 |
| `.custom-content-text` | 18px | L936-939 |
| `.quick-add-title` | 18px | L971-973 |
| `.status-middle-compact` | 18px | L950-958 |
| `.week-text`（底部课表名） | 18px | L1027-1029 |

规范原话：「**20px 是护栏不是档位：禁止任何文字低于 20px，但日常不用它**」。胶囊屏首页有 **8 处**踩线或越线。

**⑤ 竖向空间紧张（需真机确认）**
胶囊屏高约 490px，减去上下 padding 30px×2 后约 430px。首页最多可同时存在 9 个区块（时钟行 / 星期头 / 自定义内容条 / 状态条 / 钉住条 / 课程列表 / 快捷添加 / 底部按钮 / 课表指示器）。这些区块都用 `padding/margin` 累加，当自定义内容、状态条、快捷添加同时开启时，**留给课程列表的高度可能不足以显示 2 张卡片**（卡片被 48px 名字撑高，单卡约 98px）。

### 3.2 添加课程 `add-course` —— 可用，但控件偏小（P1）

**① 标题正常 ✓**
```
内容区 176px − back-btn 38px = 138px
"添加课程" 4 字 × 28px = 112px ≤ 138px  →  不挤压
```

**② 时间行超出可用宽度**
```
time-box 80px + time-sep（"至"22px + margin 4×2 ≈ 30px）+ time-box 80px
= 190px  >  176px   →  超出 14px
```
`.time-box` 未设 `flex-shrink: 0`，会被压缩到 ≈73px；而盒内有 `padding: 5px`，实际文字空间 ≈63px，"08:00"（24px 字 ≈66px）**临界溢出**，可能出现换行或贴边。

**③ 星期按钮 30×30px，触控面积严重不足（最大的易错点）**
```868:872:src/pages/add-course/add-course.ux
  .weekday-btn {
    width: 30px;
    height: 30px;
    border-radius: 15px;
  }
```
- 规范要求按钮高度 **≥48px** 保证手指点得准；这里是 **30px，只有要求的 62%（面积 39%）**
- 7 个按钮共 210px > 176px → 必须横向滑动才能点到"六""日"
- 用户排课时**极易点错星期**，而这一步错了整门课就放错天

**④ 课程名只显示约 3 个字**
`.course-item` 胶囊屏 80×50px，`.course-name` 22px + `max-lines: 1` + 省略号（L792-795、`add-course.ux` L547-554）→ "大学英语"显示"大学英…"。若预设库里有"大学英语""大学物理""大学化学"，**肉眼无法区分**。

**⑤ 已在胶囊屏适配的部分（做得好的地方）**
- 底部按钮改为 `flex-direction: column` 全宽（L877-896）✓ 不挤压
- 时间微调区 `.adjust-group` 横向 152px ≤ 176px ✓
- 时间微调区整体 `flex-direction: column`（L603-606）✓ 上下排列

### 3.3 编辑课程 `detail` —— 标题被截断、两处横向溢出（P0/P1）

**① 标题"编辑课程"显示不全（截断）**
```
内容区 176px
  − back-btn 40px（L1008-1015）
  − header-trash-btn 40px（默认值 L623-629，胶囊屏未覆盖）
  − .title margin 0 4px ×2 = 8px
  = 标题可用 88px
"编辑课程" 4 字 × 26px = 104px  >  88px  →  截断，显示"编辑课…"
```
`.title` 在胶囊屏有 `lines: 1`（L1022），所以是**截断**而非换行——虽不破版，但标题看不全。

**② 第 1 步轮播区横向溢出 52px**
```
swipe-arrow 36px + course-card 140px + swipe-arrow 36px + card margin 8px×2 = 228px
228px  >  176px   →  溢出 52px
```
`.swiper-wrapper` 是 `justify-content: center` 且子项**都没设** `flex-shrink: 0` → 三个元素一起被压缩，卡片可能被压到 ≈108px；而 `.card-course-name` 是 28px 字，4 个字需要 112px → **课程名截断**（该元素有 `lines: 1`，L1061-1067）。

**③ 第 2 步时间步进器横向溢出 12px**
```
stepper-label 48 + stepper-btn 38 + stepper-val 48 + stepper-btn 38 = 172px
  + .stepper-time padding 8px×2 = 16px
  = 188px  >  176px   →  溢出 12px
```
"小时 / − / 08 / +" 一行正好排不下，会出现轻微挤压/贴边。

**④ 18px 小字**
`.course-index-hint { font-size: 18px }`（L1072-1076，"1 / 8"这行页码提示）低于 20px 护栏。

**⑤ 内联高度覆盖媒体查询**
```39:40:src/pages/detail/detail.ux
<input class="manage-btn" type="button" value="管理" ... style="height: 48px; ..." />
<input class="next-btn" type="button" value="下一步" ... style="height: 48px; ..." />
```
内联 `height: 48px` 会覆盖胶囊屏的 `36px`（L1077-1097）。虽然 48px 更高（触控更好），但这种"内联压过媒体查询"的写法让适配规则不可预测——本次走查已发现 **3 处同类问题**（首页 font-size、详情页 height、详情页字号变量）。

### 3.4 总课表 `week-view` —— 每格只有 1 个字（P0）

**① 网格宽度是符合规范的 ✓**
```
内容区 160px；默认模板 minimal-char 的 cellWidth = 50px
5 列 = 250px > 160px  →  横向滑动，可视 3.2 列
```
正好落在规范要求的「胶囊屏显示 2.5~3.5 列，露半截引导滑动」区间内，**这一点做对了**。

**② 但每格只显示 1 个字（核心问题）**

默认套用 `minimal-char`（`week-view.ux` L294-296），其配置为：

```137:146:src/pages/week-view/week-view.ux
var TEMPLATE_CONFIGS = {
  "minimal-char": {
    ...
    nameDisplay: "char",
    ...
    nameFontSize: 20, nameLineHeight: 28, nameFontWeight: "bold", infoFontSize: 0,
    useColorScheme: true, denseMode: false, cellWidth: 50
  },
```

`nameDisplay: "char"` → `name.charAt(0)`（L544-545）→ **"大学英语"只显示"大"，"高等数学"只显示"高"**。
规范场景 5 明确要求：胶囊屏每格 28px 字、可放 **2 个汉字**。当前是 **20px（护栏档）+ 1 个字**，双重不达标。

**③ 五个模板的课名字号全是 20px**（L137-182）
`minimal-char / minimal-en / standard-block / compact-grid / color-pastel` 无一例外 → 换模板也解决不了"看不清"。

**④ footer 五个模板按钮需滑动**
每个按钮 2 字 × 24px + padding 12 + margin 6 ≈ 66px，5 个共 ≈330px，可视区 160px → **只能看到 2.4 个**，其余要滑。按钮高 40px，低于规范的 48px。

### 3.5 课程管理 `course-manager` —— 一行塞 4 个元素（P1）

**① 该页没有胶囊屏适配**
只有 `circle`（L429）和 `rect`（L497）两套媒体查询，**没有 `@media (shape: capsule)`** → 胶囊屏完全走默认值（`padding: 38px 6px 10px 6px`，内容区 180px）。

**② 标题截断**
```
180px − back-btn 36px − add-btn 56px = 88px 给 .title
"课程管理" 4 字 × 26px = 104px > 88px  →  截断
```

**③ 每行塞 4 个元素，课程名只剩 2 个字**
```
.course-item padding 8px×2 = 16px（L375）
  + item-index 24px + margin 4px（L379-387）
  + edit-btn 36px + margin 4px（L405-415）
  + delete-btn 36px + margin 3px（L417-427）
  = 123px
课程名可用 = 180 − 123 = 57px
24px 字 → 只能显示 2 个汉字（"大学…"）
```

**④ 编辑/删除按钮 36×24px —— 误触风险最高的一处**
```405:427:src/pages/course-manager/course-manager.ux
.edit-btn {
  width: 36px;
  height: 24px;
  ...
}
.delete-btn {
  width: 36px;
  height: 24px;
  ...
}
```
- 规范要求触控高度 **≥48px**，这里是 **24px（一半）**
- "编辑"和"删除"两个按钮**相邻仅 3px**，且删除是**不可撤销**的破坏性操作
- 后果：**用户点"编辑"时很容易点到"删除"**（需真机确认误触率）

**⑤ 18px 小字**：`.back-btn`/`.add-btn`/`.clear-btn`/`.index-text` 全为 18px（L308-336、L353-363、L389-395）→ 低于护栏。

## 六、其他"界面混乱"问题

1. **同一功能在不同页面长得不一样**
   删除的二次确认：`course-manager` 的"清除全部"有文字提示「**再次点击确认**」（L10），但同一页的单条"删除"没有；`detail` 页也没有。用户学到的规则无法复用。

2. **"编辑课程"标题在胶囊屏截断为"编辑课…"**，而这正是用户最需要确认"我在编辑什么"的位置。

3. **字号设置只影响首页**：`store.getBaseFontSize()` 仅被 `index`（L242、L330）与设置页使用；`add-course`、`detail`、`week-view`、`course-manager` 全部使用硬编码字号。用户在设置里调大字号后，**进入添加/编辑页会突然变小**。

4. **`detail.ux` 的字号设置是死代码**：`titleStyle / labelStyle / hintStyle / inputStyle / btnStyle / pickerValueStyle` 在脚本里赋值（L306-315），模板零引用。

5. **胶囊屏 padding 四套值**（12/8/8/16/6），内容边界不齐（见第二节表）。

6. **`course-manager-v2` 是无入口页面**：manifest 注册了，但全项目没有任何跳转指向它（添加页/详情页跳的都是 `/pages/course-manager`）。

7. **`index.ux` 的 `.class-grid` 是悬空样式**（L637-639）：定义了但模板从未使用，卡片间距实际靠 `.class-grid-item` 的 `margin-bottom`。

8. **特殊符号显示风险**（需真机确认）：`week-view` 用 `⇄`（L63）、`detail`/`index` 用 `◀ ▶`、`course-manager-v2` 用 `⏱ 🔤`。手环字体对非基础符号的覆盖不确定，可能出现方框占位，而它们出现在**按钮和标题**上，一旦渲染失败就是"文字被遮挡"的观感。

9. **按钮高度普遍不达 48px**：胶囊屏下 store 相关按钮 40px、模板按钮 40px、星期按钮 30px、课程管理行内按钮 24px、detail 部分按钮 36px。

## 八、修复建议（按收益排序）

### 第一优先：让胶囊屏"看得见字"

1. **首页课程卡改为胶囊屏上下两行布局**（不要名字与时间左右并排）
   ```
   胶囊屏 .class-card-body { flex-direction: column; }
   胶囊屏 .class-card-meta { flex-direction: row; }
   课程名字号收敛到 32px（规范正文基准）
   ```
   改后：名字 32px 在 148px 内可显示 4 个字，时间/地点另起一行——**这是投入最小、观感提升最大的一处**。

2. **把字号从"内联注入"改为"脚本按屏型算好再注入"**
   当前内联 `font-size: {{ displaySize }}px` 击穿了 CSS 里的所有降级。建议在 `class-list.js` 里按 `isCapsule` 计算：
   ```
   胶囊屏：fontSize = 32，metaFontSize = 24，lineHeight = 字号 × 1.2
   方屏：  fontSize = 32（规范值），metaFontSize = 28
   ```
   并**同时内联 line-height**，彻底消除"行高 32 / 字号 48"的错配。

3. **总课表默认模板改为 `standard-block`**，并把五个模板的 `nameFontSize` 统一提到 **28**、`cellWidth` 提到 **60**，让胶囊屏每格可显示 2 个字。

### 第二优先：把触控目标做大

4. **星期按钮放大**：胶囊屏下把 `.weekday-btn` 从 30×30 提到 **44×44**（不再强行 7 个一行，允许横向滚动，但首屏至少露出 4 个）。
5. **课程管理行拆成两行**：第一行"序号 + 课程名（32px）"，第二行"编辑 / 删除"两个大按钮（各 ≥44px 高），彻底解决 36×24px 误触删除的问题。
6. **统一按钮最小高度 44-48px**（模板按钮 40 → 48、detail 部分 36 → 48）。

### 第三优先：统一与清理

7. 统一胶囊屏左右 padding 为 **16px**（内容区 160px），所有页面一致。
8. 删除/清理内联覆盖媒体查询的三处写法（`index` font-size、`detail` height、`detail` 字号变量）。
9. 标题加 `lines: 1 + text-overflow: ellipsis` 并**精简文案**（"编辑课程"→"编辑"、"课程管理"→"课程"），或把图标按钮缩小给标题让位。
10. 把所有 16/18px 文字提到 **20px 起**（合规不越线）。
11. 删除确认统一加「再次点击确认」文案。
12. 让 `getBaseFontSize` 在所有页面生效，或明确废弃该设置并移除，避免"设置无效"的困惑。
