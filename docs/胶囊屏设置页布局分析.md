# 胶囊屏设置页布局分析

## 问题概述

设置页面中，可展开栏目（周课表、工具）在胶囊屏（圆形屏幕，约 208×208 像素）上，由于采用了 `flex-direction: row` 的水平行布局，导致多列元素挤在一行内，视觉上过于拥挤混乱。

## 详细分析

### 1. 周课表栏目

当前 HTML 结构：

```html
<div if="{{ showSchedule }}">
  <div class="row">
    <text class="row-label">隐藏周末</text>
    <input class="toggle-btn" ... />
  </div>
  <div class="divider"></div>
  <div class="row" onclick="openTemplatePicker">
    <text class="row-label">模版选择</text>
    <div class="row-right">
      <text class="row-hint">{{ currentTemplateName }}</text>
      <text class="arrow">›</text>
    </div>
  </div>
</div>
```

**现状：**  
- `.row` 使用 `flex-direction: row; justify-content: space-between`，label 和 right 分别占据左右两侧
- 胶囊屏 `@media (shape: circle)` 仅微调了 padding 和字号（28px/24px），**未改变布局方向**
- `row-label` 字号 30px/28px，`row-hint` 字号 28px/24px，在仅 208px 宽度的胶囊屏上，两端对齐导致文字被挤压

**结果：**  
label 和 hint 在同一行争抢空间，文字长时出现截断或重叠，视觉拥挤。

### 2. 工具栏目

当前 HTML 结构：

```html
<div if="{{ showTools }}">
  <div class="row" onclick="openDeviceInfo">
    <text class="row-label">设备信息</text>
    <div class="row-right">
      <text class="row-hint">调试</text>
      <text class="arrow">›</text>
    </div>
  </div>
  <div class="divider"></div>
  <div class="row" onclick="openVibrationLab">
    <text class="row-label">震动自定义</text>
    <div class="row-right">
      <text class="row-hint">震动方案</text>
      <text class="arrow">›</text>
    </div>
  </div>
  <div class="divider"></div>
  <div class="row" onclick="openTestArea">
    <text class="row-label">测试区</text>
    <div class="row-right">
      <text class="row-hint">实验功能</text>
      <text class="arrow">›</text>
    </div>
  </div>
</div>
```

**问题与周课表完全一致：**  
- 胶囊屏上 `row-label` + `row-hint` + `arrow` 三元素挤在一行
- "震动自定义"（4字）+ "震动方案"（4字）+ "›" 在 208px 宽屏上非常拥挤
- 字号保持 UI 规范（28px-30px），但行布局不匹配胶囊屏宽度

### 3. 测试区找不到

**原因：**  
"测试区" 入口被放置在「工具」可折叠组内部（`<div if="{{ showTools }}">`），默认 `showTools: false`。

用户需要先点开「工具」标题才能看到测试区，但 "工具" 和 "测试区" 的关联不直观。普通用户不会联想到去「工具」里找「测试区」。

## 解决方案

### 方案 A：胶囊屏使用垂直堆叠布局（推荐）

在 `@media (shape: circle)` 中，将 `.row` 从 `flex-direction: row` 改为 `flex-direction: column`，让 label 在上、hint/arrow 在下。

```
[ 隐藏周末                     ]  ← 当前（一行拥挤）
[ 开/关 ]

改为：
[ 隐藏周末            [开/关] ]  ← 胶囊屏垂直堆叠
```

**优点：** 无需改动 HTML 结构，仅通过 CSS `@media` 切换布局  
**缺点：** 每个 row 高度增加，可能需要滚动

### 方案 B：简化胶囊屏 row 内容

在胶囊屏上隐藏 `row-hint`，只保留 label + arrow，减少一行内元素数量。

**优点：** 代码改动最小  
**缺点：** 丢失提示信息

### 方案 C：混合方案（最终采用）

1. 胶囊屏 row 改为垂直堆叠（label 一行，控制/hint 一行）
2. 工具栏目新增独立可见入口（移动到工具栏目外部，作为独立可折叠组或直接可见行）
3. 测试区从工具组中移出，作为独立入口直接可见

## 具体改动

### 样式修改

```css
@media (shape: circle) {
  .row {
    flex-direction: column;
    align-items: flex-start;
  }
  .row-right {
    margin-top: 6px;
  }
}
```

### 结构修改

将「测试区」从「工具」组中移出，放入主页设置组下方（独立可见行），确保用户可直接找到。

### 字号保持

不做字号调整，符合 UI 规范：label 28px，hint 24px（胶囊屏）、30px/28px（方屏）。

## 总结

| 问题 | 原因 | 解决 |
|------|------|------|
| 周课表挤在一行 | row 为水平布局，胶囊屏宽度不足 | 胶囊屏改为垂直堆叠 |
| 工具栏目挤在一行 | 同上 + 三元素挤在 208px 行内 | 同上 |
| 测试区找不到 | 被隐藏在折叠的「工具」组内 | 移出为独立可见入口 |
