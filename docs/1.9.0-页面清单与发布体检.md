规则见 `trae-global-rules.md` §七（正文下限 18px）。1.9.0 **未修**，理由：每处都要重排防止 192×490 溢出，属于独立一轮 UI 工作量，不适合混进版本号跳变这一次。

5. `schedule-panel-simple`：row-time:15
