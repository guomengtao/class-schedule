## 〇、产品定位诊断（决定打法的地基）

先把事实锚定清楚——**这是手环上的快应用，不是手机 App**（包名 `com.application.watch.classschedule`，Vela / 快应用，192×490 胶囊屏）。

从源码确认的卖点：

| 能力 | 用户可感知的价值 |
|---|---|
| 「下一节 / 上课中 / 课间」状态面板 | 当前课名、剩 X 分、本节进度、下一节预告、「X 分后上课」 |
| 多彩课表（一天一屏彩色瓷砖）/ 简易课表 / 周视图总课表 | 抬手扫一眼就看完一天/一周，高饱和色块自带视觉锤 |
| 上课地点、老师、加课自定义 | 找教室不用翻手机 |
| 震动 / 同步通知、消息收件箱 | 上课前提醒，不迟到 |
| 多课表管理、数据备份、首页自定义、多套主题（PRO 付费点） | 大学生双课表、换设备迁移、颜值党换肤 |
| 内置示例课表为「九年级一班」，教室/老师留空避免家长看到陌生占位 | 目标用户含**初高中生 + 家长**，兼大学生 |

**这决定了三件事：**

1. 抖音上「手环课程表」几乎是无人区——先发即品类占位，不用卷红海。
2. 抬手看屏 + 彩色瓷砖 + 早八赶课，画面天生带钩子，几乎不用编剧本。
3. 初高中生 + 大学生是抖音最活跃人群，「早八 / 赶课 / 课表排满」是天然高共鸣母题，完播率有底。

## 一、一句话战略与人设

**战略**：卖的不是「课程表工具」，是「早八还剩 5 分钟、抬手一秒就知道去哪间教室」那种松弛感。工具属性藏在场景里，让评论区搜索和应用商店去承接转化。

**人设（冷启动只做 1 个号，别铺矩阵）**：

- 视角：**学生本人**（真实出镜手腕 + 校园空镜），不做官方蓝 V 说教。抖音上学生信同龄人，不信官号。
- 账号名 / 简介统一一个品牌词：**「Ev课程表」**，人物定位「把课表塞进手腕的人」。
- 企业蓝 V **不排在冷启动期**，用途见 §五搜索收口（品牌词卡位 + 私信承接），不是内容主号。
- 家长视角裂变号：月涨粉 >15% 跑通后再开（孩子迟到/忘带书），且**不诱导付费**。

**品牌词的一个真实的坑**：「Ev」单独搜会跟电动车等大量无关词混淆，新品牌本身没有搜索量。所以：

- 抖音端强化连读锚点「Ev课程表」「手环上的 Ev 课表」；
- 搜索卡位**主攻品类词**：「手环 课程表」「小米手环课表」「抬手看课表」「手环上课提醒」，用品类需求喂品牌，而不是只赌弱品牌词；
- 应用分发端同样把品类词占住（见 §四）。

## 二、内容矩阵四支柱（配比 = 涨粉 40 / 转化 30 / 破圈 15 / 留存 15）

| 支柱 | 配比 | 作用 | 示例选题 |
|---|---|---|---|
| **01 痛点共鸣** | 40% | 踩早八/赶课/找教室，冲完播和涨粉 | 全班掏手机我抬手 1 秒／早八还有 5 分钟我没醒／一周 32 节课的绝望 |
| **02 场景演示** | 30% | 抬手下一节/课间倒计时/彩色瓷砖，种功能 | 抬手 1 秒看下一节／震动提醒再没迟到／我的手环课表长这样 |
| **03 反差猎奇** | 15% | 「手环还能干这个？」的意外感，冲播放 | 手机被没收我照样看课表／把课表塞进手腕是什么体验／同学问我这是不是新表 |
| **04 干货教程** | 15% | 承接搜索长尾，教安装/导入/多课表/PRO | 手环怎么装课程表／大学生两套课表怎么切／PRO 到底值不值得开 |

**04 类权重随阶段上调**：冷启动期做 15% 立人设；进入搜索收口期提到 30%+，把它做成置顶的长尾流量入口（见 §四）。

## 三、视频脚本骨架 + 两条可直接开拍的成品

**算法第一权重是完播率，不是点赞。** 所有设计只服务两件事：别划走、看到底。

### 30 秒骨架

| 时段 | 段落 | 唯一任务 | 硬要求 |
|---|---|---|---|
| 0–3s | 黄金钩子 | 别划走 | 反差/冲突开场；手腕先入镜；悬念不解答；严禁「大家好」 |
| 4–20s | 信息密度 | 完播 + 种草 | 抬手 → 看 → 爽；功能拆成 2–3 个爽点；卡点踩 BGM 鼓点 |
| 21–30s | 收尾留钩 | 换评论和关注 | 一句价值对比；抛争议引评论；下条预告；引搜索不引外链 |

拍摄铁律：9:16 / 真人出镜手腕（完播比纯产品画面高 30%+）/ **全程字幕**（多数人静音刷）/ 用当周上升期 BGM。

### 成品 A｜痛点共鸣型 `22s · 目标完播>40%、涨粉`

- `0–3s`：镜头就是手腕，面无表情抬手 → 屏显「早八 还有 3 分钟 3-301」。口播：**「别人早八在找教室，我根本没醒过。」**
- `4–12s`：快切三个真实场景——被窝里抬手、食堂排队抬手、操场回头抬手，每次屏幕换一节课。字幕踩鼓点：「周一第3节 / 周三第8节 / 周五没课」
- `13–19s`：定格彩色瓷砖总课表，口播：**「一整周，抬手就看完。」**
- `20–22s`：手机与手环同框，手机还停在 loading，口播：「你还在手机里翻？」→ 黑屏留白 + 关注引导

### 成品 B｜转化种草型 `30s · 目标搜索量 + 收藏`

- `0–3s`：手环震动亮屏特写，口播：**「上课前它比我先醒。」**
- `4–18s`：爽点三连——① 震动提醒不迟到 ② 抬手看「下一节+教室」③ 课间倒计时「X 分后上课」，每个配一个校园空镜
- `19–26s`：切多套主题皮肤 + 周视图总课表，字幕：「多课表 / 备份 / 换主题」（**埋 PRO 卖点、不硬推**）
- `27–30s`：口播：**「装法我放主页了，搜『Ev课程表』。」** → 引向搜索，不导外链

## 四、【核心】合规装机闭环——最容易被外行做死的一环

> 常见错误：主页挂链接、评论区发「去 XX 下载」。这在抖音是**找限流**：视频内出现外链/二维码/「去某平台下载」，直接压进低质流量池。
> 更麻烦的是，这是**手环快应用**，用户看完没法「点一下就装」，转化链路天然比 App 长。所以打法必须反过来设计。

**闭环四步：**

1. **抖音只负责种草 + 造品牌词**，不承担下载。视频里绝不出现下载指引，只反复强化唯一品牌词「Ev课程表」，养成「搜这个词」的条件反射。
2. **转化收口到搜索，不是链接。** 用户看完主动搜——抖音站内搜（企业号/品牌词）+ **实际应用分发渠道的搜索框**（按首发渠道替换：手环端应用市场 / 小米穿戴 App 内分发 / 快应用平台）。配套把「手环 课程表」「小米手环课表」等品类词占住；否则抖音替你种草、商店被别人截胡。
   - ⚠️ 待 Tom 确认：Ev 课程表当前**实际首发/上架渠道**（自分发 rpk / 快应用平台 / 手环应用市场），据此把 ASO 关键词落到正确位置。
3. **把「怎么装」单独做成置顶教程**（即 04 类），用搜索流量承接长尾，而不是每条视频都挂导流。这是快应用场景唯一稳的闭环。
4. **企业号 + 私信关键词自动回复**兜底：用户私信「课表」，自动回一段纯文字安装路径（**不带链接、不带外站字样**），接住高意向用户又不触发站外判罚。企业号在冷启动期不开，第 2 月搜索收口阶段才上。

**一句话记住**：内容在抖音，成交在搜索框，交付在应用商店。

## 六、DOU+ 策略：冷启动一分钱别投

前 10 条完播没跑正就投 = 拿钱给算法喂负反馈，越投越窄。

- **起投门槛**：某条**自然流量**跑过完播 35% 才追投。
- **投法**：`100 元/包、多包小额` 测人群，别一大包砸一个；定向「系统智能 + 校园/手环/学习达人相似粉」。
- **优化目标**：选**粉丝增长**，不选播放量。
- **追投判据**：DOU+ 带来的**自然播放外溢 ≥ 1:3** 才继续加，否则停。

## 七、数据复盘：盯 5 个数，别被播放量骗

| 指标 | 及格线 | 说明 / 低于时怎么办 |
|---|---|---|
| 完播率 | >35%（>40% 优秀） | 算法第一权重；<25% 说明中段垮了 |
| 3 秒留存 | >50% | 低于此 = 钩子废了，**换开头重发同一条**，别弃选题 |
| 分享率 | 越高越好 | 分享权重最高；多做「转给室友/同桌」型内容 |
| 每千播涨粉 | >3 | 太低 = 内容没打中人设，人设要更锋利 |
| 主页访问→搜索 | 快应用专属 | **这条最该盯**，是装机的真实转化点 |

## 八、合规红线（踩了不是限流，是封号 + 合规风险）

内置示例是九年级课表，目标用户含初高中生——**未成年人保护是最大雷区**：

1. 严禁诱导未成年人充值 PRO、严禁「不买就落后」式焦虑；
2. 视频/文案/评论区不出现外链、二维码、「去 XX 下载」；
3. 禁绝对化用语：「最全」「第一」「100% 不迟到」；
4. 不露真实校名 / 校徽 / 学生正脸；
5. 不向站外平台导流；BGM 只用平台曲库，不搬影视音。

## 九、两个别照搬带货模板的判断

- **直播不做带货，做「装机答疑直播」。** 没有实物商品，GPM 那套不适用。开播让观众进来问「怎么装、怎么导课表、双课表怎么切」，作用是收口信任 + 涨粉 + 拉搜索，别硬搭带货脚本。
- **冷启动只做 1 个主号，别铺矩阵。** 铺矩阵 = 每个号都喂不饱、算法学不会打标。主号跑到月涨粉 >15% 后，再裂变家长视角号；达人合拍/员工号放到第 3 个月。
