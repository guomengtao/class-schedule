## 一、本轮结论摘要

> **一句话结论**：v1.6.28 是围绕**总课表（week-view）**的一次集中优化——新增「清爽」模板、修复英文表头换行、引入切模板缓存、修复返回图标路径，并把**首页新增了「+」入口直达完整版课程管理页**；同时**detail 编辑页胶囊屏标题截断问题已修复**。但**两个 P0 硬伤依旧原样**：**①时间格式不统一导致冲突检测对所有新添加/编辑课程静默失效（第 2 轮未修）；②首页胶囊屏字号被内联样式覆盖（第 3 轮未修）**。本轮新增的英文模板单字母表头存在「周二/周四同为 T」的二义性。

**最该优先修的 3 件事：**

1. **时间格式统一（第 2 轮挂起未修，P0）**：add-course.ux:440 / detail.ux:547 保存「08:00-08:45」（无空格），database.js:491 `parseTimeRange` 用 `split(" - ")` → 无空格串被当单点时间 → `rangesOverlap` 恒 false → **新添加/编辑的课程永远不会触发冲突提示**。作者上轮刚上线冲突检测，至今对用户实际添加的课程完全不生效
2. **首页胶囊屏字号内联覆盖（第 3 轮挂起未修，P0）**：`day-title` 内联 48px 覆盖胶囊 CSS 26px（标题截断成 1 字）、课程时间内联 34px 覆盖 CSS 20px（「08:00-08:45」溢出卡片），用户仍看不到完整星期与时间
3. **死页/Demo 残留（第 3 轮挂起未修，P1）**：course-manager-v2、test-area、lab-add-course、lab-edit-course 4 页仍 0 引用注册；lab-edit-course 仍是「课程已更新 (Demo)」假操作，误入即困惑

## 六、回归测试建议（按用户操作路径）

**A. 主链路（每次发版必跑，约 8 分钟）**
1. 冷启动 → 首页 → **胶囊屏看星期标题是否完整（当前截断成 1 字）与时间是否溢出卡片（P0-2）**
2. 首页 → 快速添加 → 点标签行末尾「+」→ 确认进入课程管理页（FIX-18）→ 返回
3. 首页 → 添加课程 → 预置课「语文」→ 再加「数学 08:10-08:30」→ **期望提示时间冲突需二次确认**（当前无空格格式检测不到 → P0-1 命中）
4. 开始调到 23:55 → 结束自动跳 23:59（倒挂纠正）→ 确认添加 → 回首页出现
5. 点课程 → 胶囊屏**确认 header 标题「编辑课程」完整不截断（FIX-13）**→ 改时间 → 更新 → 杀进程重进确认保留
6. 点课程 → step3 换星期 → dayConfirmed 二次确认 → 更新 → 该课程出现在新星期
7. 删除课程 → 第一次点不删 → 观察撤销按钮 → 撤销恢复
8. 首页 → 总课表 → 依次切换 6 个模板（极简/清爽/标准/紧凑/英文/跟随系统）→ **确认切换流畅无卡顿（FIX-16 缓存）**、英文模板下确认表头「M/T/W/T/F/S/S」可接受（P2-1）
9. 总课表 → 返回图标可点且能返回首页（FIX-17）

**B. 输入法**
