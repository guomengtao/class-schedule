## 维护规则（QA 侧）

每轮质检结束后按顺序更新本表：

1. **扫 commit**：`git log <上轮HEAD>..HEAD --grep='fix(qa)'` 摘编号 → 标 🟡 已修待验
2. **读 `REPLY.md` 三区登记**，逐条搬运：
   - ① 已处理 → 🟡（有 commit 的填进「修复 commit」列）
   - ② 处理中 → 🟠，备注里写"预计 X"；连续 3 轮没动就在报告里提一句
   - ③ 打算做 → 保持 🔴；③ 不打算做 → ⚪ 已关闭
   - 作者说明同步进「作者备注」列
3. **打开代码复核**（文档会过期，只信代码）→ 真修好了改 🟢，没修实的退回 🔴 并说明为什么
4. 新增缺陷追加行；更新顶部总结数字、「最近更新轮次」、HEAD
5. ⏸ 挂起的条目在末尾「卡住的三件事」里带上"已问 N 轮"
