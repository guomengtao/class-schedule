## 五、回归测试建议（按用户操作路径 · 可执行 checklist）

修复后按此顺序走一遍，每步都要在**真机 9 Pro 和 10 Pro 各走一次**：

1. **启动**：冷启动 → 启动页 → 进首页。✅ 能进；✅ 在首页按返回**能退出应用**（验 P0-8）
2. **加课**：首页 → 加课 → 填名称/时间/老师 → 保存 → **返回首页立刻能看到新课**（验 P0-2，不用重启）
3. **加课竞态**：切到「周三」→ 加课 → 保存 → 确认课落在**周三**（验 P0-4）
4. **编辑**：打开某课 → 记下备注 → 只改时间 → 保存 → 重新打开 ✅ 时间变了 ✅ **备注还在**（验 P0-3）
5. **编辑空值**：打开某课 → 清空名称 → 点更新 → **应该有 toast 提示**，不能毫无反应（验 P2-10）
6. **删课**：打开某课 → 删除 → 首页该课消失（这条本来就是通的，防回归）
7. **课表管理**：建 3 张课表 → 各加不同课 → 删除**中间那张** → 回首页确认**剩下两张的课程没有串**（验 P0-1）
8. **复制课表**：复制一张有课的表 → 成功有 toast；故意制造失败 → **也要有提示，不能卡住**（验 P0-6）
9. **备份恢复**：改主题 → 新建备份 → 改回别的主题 → 恢复备份 → **主题一起回来**（验 P0-5）
10. **激活**：输入正确激活码 → 成功提示；**故意断网/输错** → **必须有失败提示**（验 P0-7）
11. **按钮点名**：振动实验室 → 「模块测试」→ 不能跳砖（验 P0-9）；再把设置/统计/二维码/捐赠等入口逐个点一遍
12. **详情页跨课**：连点两门不同的课 → 第二次打开的必须是**第二次点的那门**（验 P1-6）
13. **显示**：9 Pro / 10 Pro 各看首页、启动页、课表管理、自定义内容 4 个页面 → 无裁切、无溢出、安全区一致（验 P1-1~P1-4）
14. **输入法**：进任意输入框 → 记录「完全唤不起 / 出来但错位 / 能出但打不出字」中的哪一种（定性 P3-7 / P2-2）
