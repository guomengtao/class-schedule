## 一、本轮结论摘要

> **一句话结论**：v1.6.49 是**修复型大版本**——挂起两轮的**最严重 P0「时间格式不统一 → 冲突检测失效」已完整修复**（输出端统一带空格 + 解析端双格式兼容），**上轮新增的英文表头「T 二义性」也已修复**（Mo/Tu/We/Th/Fr/Sa/Su）；同时新增**工具聚合页**、首页**日期行/调休提示/节假日问候/胶囊状态栏两行重构**，settings 与 schedule-manager 大重构，新元素统一 22px。**唯一仍未修的重大问题是首页胶囊屏字号内联覆盖（P0-2，已挂 4 轮）**：commit 声称「fix font size display」，但胶囊档字号始终未降，标题仍被内联 48px 覆盖截断。

**最该优先修的 3 件事：**

1. **首页胶囊屏字号内联覆盖（第 3 轮挂起，P0）**：`day-title` 内联 48px 仍覆盖胶囊 CSS 26px（3 字标题截断成 1 字）、课程时间内联 metaFontSize 34px 覆盖 CSS 20px（「08:00-08:45」约 170px 溢出卡片）。本轮 commit 主题即「fix font size display」，新元素（日期/调休/节假日/状态栏）均用了 22px，但胶囊首页标题与课程时间两处旧内联覆盖被遗漏
2. **死页/Demo 残留（第 3 轮挂起，P1）**：course-manager-v2、test-area、lab-add-course、lab-edit-course 4 页仍 0 引用注册；lab-edit-course 仍是「课程已更新 (Demo)」假操作
3. **图标路径统一改绝对路径 `/common/icons/...`（本轮新增，需真机验证）**：index/week-view/settings/tools 等 7+ 页从相对路径（`../../common` / `../common`）统一改为以 `/` 开头的绝对路径。若平台不支持该写法则图标全部加载失败——低概率但影响面大，建议真机首查

## 六、回归测试建议（按用户操作路径）

**A. 主链路（每次发版必跑，约 10 分钟）**
1. 冷启动 → 首页 → **胶囊屏看星期标题是否完整（当前截断成 1 字）与时间是否溢出卡片（P0-2）**
2. 首页 → 快速添加 → 点标签行末尾「+」→ 确认进入课程管理页 → 返回
3. 首页 → 添加课程 → 预置课「语文」→ 再加「数学 08:10-08:30」→ **期望提示「时间冲突：与《语文》…重叠，再点确认添加」**（FIX-21 验证点，上轮该测试必失败，本轮应通过）
4. 点课程 → 改时间 → 更新 → 与另一课程时间重叠 → **期望同样触发冲突提示**
5. 开始调到 23:55 → 结束自动跳 23:59（倒挂纠正）→ 确认添加 → 回首页出现
6. 点课程 → step3 换星期 → dayConfirmed 二次确认 → 更新 → 该课程出现在新星期
7. 删除课程 → 第一次点不删 → 撤销恢复
8. 首页 → 总课表 → 切英文模板 → **确认表头 Mo/Tu/We/Th/Fr/Sa/Su 无二义（FIX-22）**；依次切 6 模板确认流畅
9. **逐页检查图标：首页/总课表/设置/工具/添加/编辑/课程管理 返回与导航图标是否显示（P2-1 真机重点）**
10. 首页看新增日期行、调休提示（若当天调休）、节假日问候（若节假日）是否显示正常（FIX-24）

**B. 输入法**
11. 添加课程 → 填位置 → 唤起输入法 → 确认键盘水平居中
12. 连敲 12 字符 → 位置 maxlen=10 被挡

**C. 胶囊屏专项（米环 9 / 10）**
13. 首页截图核对标题/时间字号（P0-2）
14. 首页截图核对胶囊状态栏两行布局（accent 竖条 + tag + 时间 + 课程名 是否挤压换行，FIX-24）
15. 总课表截图核对「+」入口可理解性（P2-4）、横滑提示（P2-3）
