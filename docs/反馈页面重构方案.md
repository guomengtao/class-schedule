# 反馈页面重构方案

## 一、当前页面结构

```
反馈
├── 设备信息（当前版本 / 发布渠道 / 设备型号）
├── 扫码反馈（二维码 → app-auth.gudq.com/feedback.html + URL 文字）
├── QQ 群（群号 936886288 + 复制按钮）
└── 常见问题（3 条 FAQ）
```

## 二、新页面结构（2 个部分）

```
反馈
├── 📱 QQ 群
│   ├── 标题：QQ 群
│   ├── 说明：扫码或搜索加群，备注「课程表用户」
│   ├── 二维码（Vela <qrcode> 组件自动生成）
│   │   值：https://qm.qq.com/q/6lmyuev7VY
│   └── 群号：936886288（可复制）
│
└── 📝 提交反馈
│   ├── 标题：提交反馈
│   ├── 说明：手机扫码打开反馈页，可提交问题描述与截图
│   ├── 二维码（Vela <qrcode> 组件自动生成）
│   │   值：https://app-auth.gudq.com/feedback.html
│   └── 网址文字：app-auth.gudq.com/feedback.html
```

## 三、改动清单

| 操作 | 内容 | 理由 |
|------|------|------|
| 删除 | 设备信息 section | 用户不关心，页面更简洁 |
| 删除 | 常见问题 FAQ section | 已有帮助/文档可查，不在此处重复 |
| 修改 | 「扫码反馈」→「提交反馈」 | 标题更明确 |
| 新增 | QQ 群二维码（qrcode 组件） | 原来只有文字+复制按钮，加二维码方便扫码加群 |
| 保留 | 反馈页二维码（qrcode 组件） | 已有，二维码值改为纯链接（去参数） |
| 保留 | QQ 群号 936886288 + 复制按钮 | 保留，放在二维码下方 |

## 四、二维码值

| 用途 | 值 | 生成方式 |
|------|------|------|
| QQ 群加群链接 | `https://qm.qq.com/q/6lmyuev7VY` | `<qrcode>` 组件 |
| 反馈页链接 | `https://app-auth.gudq.com/feedback.html` | `<qrcode>` 组件 |

## 五、文案

| 位置 | 文案 |
|------|------|
| QQ 群 section 标题 | QQ 群 |
| QQ 群 说明文字 | 扫码或搜索加群，备注「课程表用户」 |
| QQ 群号 | 936886288 |
| 提交反馈 section 标题 | 提交反馈 |
| 提交反馈 说明文字 | 手机扫码打开反馈页，可提交问题描述与截图 |
| 反馈网址 | app-auth.gudq.com/feedback.html |

## 六、section 卡片样式（与现有保持一致）

每部分使用 `div.section` 卡片容器：
- 圆角 12px
- 内边距 18px 14px
- 卡片间距 14px
- 标题字号与现有 sec-title 一致
- 说明文字字号与现有 sec-desc 一致

## 七、实施要点

1. 仅改模板 + 脚本（删 device 相关 data 和方法），CSS 不变
2. QQ 群二维码用 `<qrcode>` 组件，值写死 `https://qm.qq.com/q/6lmyuev7VY`
3. 反馈页二维码值改为纯 `https://app-auth.gudq.com/feedback.html`（不再拼参数）
4. 保留 `copyGroup()` 复制群号功能
5. 删除 `buildUrl()` 方法、`device.getInfo()` 调用、`versionName`/`channel`/`deviceModel`/`feedbackUrlShort` 数据字段
