| 项 | 结论 |

| 页面机制 | 快应用 `.ux` 文件放 `src/pages/<名>/<名>.ux`，在 `src/manifest.json` 的 `router.pages` 注册 `"pages/<名>": { "component": "<名>" }` |

## 十、黑屏修复 + 简化重写（2026-10-09 · P2.1）

**现象**：设置 → 表盘目录 → EV指针，打开黑屏（目录页本身正常）。

**排查**（全程静态取证，未启模拟器，遵 §3.8e）：

1. **排除「包内没这个页面」**：解包 `.temp_class-schedule/dist/*.rpk`，其中 manifest 已含 `pages/watch-face-evpointer` → 不是漏注册。
2. **排除 JS 崩溃**：抽出 `<script>` 在 Node 里跑 `onInit` / `onShow` / `tick`，无抛错，`ticks` / `ganZhi` 正常生成。
3. **元素结构对齐 gold**：机械化比对 template 元素，本页是 gold（真机已验证可用的表盘）的**严格子集** + `gan` / `gan-sh` 两类。
4. **锁定嫌疑 = 群组选择器**：`.gan-sh, .gan { }` 是**全仓唯一一处群组（逗号）选择器**
   （其余 60+ 页 0 处：`grep -rnE "^\s*[.#][a-zA-Z0-9_-]+,\s*$" src/` 为空表）。
   快应用 CSS 解析对群组选择器支持差，疑似整张样式表被丢弃 → 根容器失 flex/背景、
   绝对定位子元素全部失样式 → 深色底看上去就是黑屏
   （与 `docs/position-fixed-black-screen-verification.md` 的「根容器塌缩＝只渲染深色背景」形态一致）。

**修复（简化重写，仍为同一文件）**：

| 改动 | 前 → 后 |
|---|---|
| 群组选择器 | `.gan-sh, .gan { }` → 拆成独立 `.gan { }`（**快应用禁用群组选择器**） |
| 刻度 | 60 格（长/短两档）→ **12 格长刻度** |
| 地支 | 双层（亮铜 + 暗影倒角）→ **单层** |
| 半色调叠影 | `.dial-light` / `.dial-shade` / `.glare` 三层 → **全删**，改由表壳同心环颜色层次造金属厚度 |
| 秒针尾 | `.sec-tip` 子元素 → 删 |
| `letter-spacing` | `.brand` 上的 `3px` → 删（gold 全页 0 处，保守不使用） |
| DOM 量 | 约 90 → 约 35 |

**新增三条硬约束**（已写进文件头注释，后续步勿回退）：
① 样式表**禁用群组选择器**（`.a, .b {}`）；
② 根容器必须显式 `width/height:100%` + `flex-direction: column`；
③ **少层少 DOM**。

**验证**：`npm run build:dev` → `build success 5347ms`，产出 `.temp_class-schedule/dist/com.application.watch.classschedule.debug.1.8.55.rpk`，本页零报错（其余告警均为存量他页）。真机观感按 §3.8e **待用户手动核实**。
