# 首页开发需求文档

> 本文档从用户角度描述首页的功能需求和界面要求，不涉及任何技术实现细节。

---

## 一、整体布局

首页采用纵向滚动布局，从上到下依次为以下区域：

```
┌─────────────────────────────────┐
│  ① 时钟区域                      │
├─────────────────────────────────┤
│  ② 日期导航栏                    │
├─────────────────────────────────┤
│  ③ 自定义文字区域（可选）          │
├─────────────────────────────────┤
│  ④ 课程状态栏（可选）             │
├─────────────────────────────────┤
│  ⑤ 已钉页面快捷入口（可选）       │
├─────────────────────────────────┤
│  ⑥ 课程列表（可滚动，主体区域）     │
│     · 课程卡片                    │
│     · 课程卡片                    │
│     · ...                        │
├─────────────────────────────────┤
│  ⑦ 快速添加课程（可折叠）          │
├─────────────────────────────────┤
│  ⑧ 底部操作按钮                   │
├─────────────────────────────────┤
│  ⑨ 课表切换指示器                 │
└─────────────────────────────────┘
```

**屏型适配要求**：
- 胶囊屏（pill-shaped / capsule）：紧凑布局，所有字号和间距缩小，星期显示使用简称（如一、二、三...日）
- 方屏：标准布局，星期显示使用全称（如星期一、星期二...星期日）
- 两种屏型共享同一套功能逻辑，仅布局尺寸和字体大小不同

## 二、各区域详细需求

### ① 时钟区域

**功能需求**：
- 在首页顶部显示当前实时时间
- 时钟每秒更新一次
- 支持通过设置控制显示/隐藏
- 显示格式可配置：年、月、日、时、分、秒，各自可独立开关
- 胶囊屏默认不显示秒，减少宽度占用

**界面要求**：
- 居中显示，单行
- 字体大小：20px
- 行高：28px
- 颜色：使用次要文字颜色（灰色系）
- 与其他区域之间有适当的上下间距

---

### ② 日期导航栏

**功能需求**：
- 左右箭头按钮切换查看不同日期的课程
  - 左箭头（◀）：切换到前一天
  - 右箭头（▶）：切换到后一天
- 中间显示当前查看的日期名称
- 支持"隐藏周末"模式：
  - 开启后，日期列表仅显示周一至周五（5天）
  - 关闭后，日期列表显示周日至周六（7天）
  - 切换隐藏周末设置时，自动定位到合适日期
- 快捷跳转按钮（位于右侧，紧贴标题右侧）：
  - **「总」按钮**：跳转到总览视图（周视图 / 整周课程表）
  - **「今」按钮**（方屏专属）：一键跳回今天
  - **「明」按钮**（方屏专属）：一键跳转到明天
  - 胶囊屏不显示「今」「明」按钮，节省空间
  - 每个按钮可独立在设置中控制显示/隐藏

**界面要求**：

| 元素 | 方屏 | 胶囊屏 |
|------|------|--------|
| 日期标题字号 | 36px-40px | 28px-32px |
| 日期标题样式 | **加粗**、居中、单行 | **加粗**、居中、单行 |
| 日期显示文字 | 完整星期名 | 单字简称 |
| 箭头按钮 | 44×44圆形按钮，字号24px | 36×36圆形按钮，字号20px |
| 快捷按钮 | 44×44圆形按钮，「今」+「明」+「总」 | 仅「总」圆形按钮 |
| 快捷按钮文字 | 20px、加粗 | 18px、加粗 |

- 日期标题字体大小可随用户字号设置动态缩放，范围20px-40px
- 各按钮之间有适当间距

---

### ③ 自定义文字区域

**功能需求**：
- 在首页课程列表上方显示用户自定义的文字
- 支持多条文字轮流切换显示（轮播）
- 轮播间隔可配置（1秒、2秒、3秒、5秒、10秒）
- 单条文字时不轮播，多条时才自动切换
- 可通过首页设置控制显示/隐藏
- 文字内容在独立的编辑页面进行管理（选择预设语句或输入自定义内容）

**界面要求**：
- 左侧有彩色竖线装饰条（4px宽）
- 文字左对齐、单行显示，超出部分显示省略号
- 字体大小：20px
- 行高：28px
- 圆角卡片背景（8px圆角）
- 有适当内边距
- 与上下区域有间距

---

### ④ 课程状态栏

**功能需求**：
- **仅当查看日期为"今天"时才显示**，查看其他日期时自动隐藏
- 实时显示当前课程状态，每分钟自动刷新：
  - **上课中**：显示"上课中"标签 + 当前课程名称 + 剩余分钟数
  - **即将上课**：显示"即将上课"标签 + 下一节课名称 + 距离开课分钟数
  - 无课状态：隐藏状态栏
- 可通过首页设置控制显示/隐藏

**界面要求**：

**方屏**：
- 左侧彩色竖线装饰条（6px宽）
- 状态标签：圆角小标签，白色文字在彩色背景上
- 课程名称：居中，弹性宽度，单行不换行
- 时间信息：右侧，显示分钟数

**胶囊屏**：
- 紧凑单行布局，无装饰条
- 格式：「上课中:语文 剩5min」
- 单行显示，超出省略号截断

| 元素 | 字号 | 行高 |
|------|------|------|
| 标签文字 | 20px | 28px |
| 课程名称 | 20px | 28px |
| 时间信息 | 20px | 28px |

- 圆角卡片背景（8px圆角）
- 有适当内边距

---

### ⑤ 已钉页面快捷入口

**功能需求**：
- 显示用户在首页固定的页面快捷入口列表
- 点击任一标签跳转到对应页面
- 无已钉页面时整个区域自动隐藏
- 可通过首页设置控制整个区域显示/隐藏
- 固定页面的管理在独立的「已钉页面」管理页中进行

**界面要求**：
- 左侧彩色竖线装饰条（4px宽）
- 标签以横向排列，支持自动换行
- 每个标签为椭圆胶囊形（圆角18px）
- 标签文字：20px，单行不换行
- 标签之间有间距
- 圆角卡片背景（8px圆角）

---

### ⑥ 课程列表

#### 6.1 加载状态

**功能需求**：
- 首次进入或切换日期时，显示骨架屏加载动画
- 骨架屏显示3个占位卡片，营造加载中的视觉反馈
- 加载超时（8秒未完成）显示加载失败提示和重试按钮

**界面要求**：
- 骨架卡片：圆角12px，左侧有4px宽的装饰条
- 骨架卡片高度：72px
- 每个骨架卡片内含两条灰色圆角条（模拟课程名称和时间）
- 灰色条宽度随机变化（30%-50%），增加真实感
- 失败提示：居中显示"数据加载失败"文字 + 重试按钮

#### 6.2 空状态

**功能需求**：
- 当天无课程安排时显示空状态提示

**界面要求**：
- 居中显示"今天没有课"文字
- 字体大小：20px，行高：28px
- 颜色：使用弱化文字颜色（浅灰）

#### 6.3 课程卡片

**功能需求**：
- 按课程开始时间从上到下排列
- 每张卡片显示：课程名称、上课时间、上课地点
- 点击卡片进入课程详情页
- **仅查看日期为"今天"时**，卡片底部有进度条显示课程进度：
  - 未开始：无进度条
  - 进行中：蓝色半透明进度条（从0%到100%实时增长）
  - 已结束：灰色半透明满条
- 进度条每分钟自动更新
- 胶囊屏时间只显示开始时间（如 "08:00"），方屏显示完整时间段（如 "08:00 - 08:45"）
- 课程名称、时间、地点字号均支持用户字号设置动态调整

**界面要求**：

| 元素 | 方屏字号 | 胶囊屏字号 | 样式 |
|------|----------|-----------|------|
| 课程名称 | 32px-40px | 24px-32px | **加粗**、单行、超出省略号 |
| 时间 | 26px-34px | 20px-24px | 彩色、单行 |
| 地点 | 26px-34px | 20px-24px | 灰色、单行 |
| 行高 | 字号的 1.2 倍 | 字号的 1.2 倍 | - |

**卡片样式**：
- 圆角：12px
- 左侧彩色竖线装饰条：5px宽、3px圆角
- 卡片内部有适当内边距（上下14px、左右14-16px）
- 卡片之间有10px间距
- 卡片最小高度：60px
- 卡片背景有圆角，与页面背景形成层次感
- 进度条位于卡片底部，左对齐，高度撑满卡片，透明度0.12

**字号缩放规则**：
- 以默认字号48为基准，按比例缩放
- 步进为4px（对齐到4的倍数）
- 最小字号20px，最大字号40px

---

### ⑦ 快速添加课程

**功能需求**：
- 默认收起状态，显示"快速添加"标题和展开箭头（▼）
- 点击标题栏展开/收起
- 展开后自动计算下一个可用时间段：
  - 取当天最后一节课的结束时间 + 10分钟休整
  - 不早于当前时间 + 5分钟
  - 默认每节课45分钟
  - 若已排满24小时则显示"已排满"
- 展开后显示预设课程标签列表（横向滚动）
- 点击课程标签一键添加到当天课程末尾，自动分配计算好的时间段
- 添加成功后自动刷新预设列表和时间段
- 无预设课程时显示提示"暂无已添加课程，请先添加课程"
- 可通过设置控制显示/隐藏

**界面要求**：

| 元素 | 字号 | 样式 |
|------|------|------|
| 标题"快速添加" | 20px | **加粗**、彩色 |
| 时间段文字 | 20px | 灰色、右侧显示 |
| 展开箭头 | 20px | 彩色，▲展开/▼收起 |
| 课程标签文字 | 20px | 单行 |
| 空状态提示 | 20px | 灰色、居中 |

- 整个区域为圆角卡片（10px圆角）
- 标题栏左右布局：左标题、右时间+箭头
- 课程标签为横向排列，可水平滚动
- 标签为圆角胶囊形（20px圆角），有内边距
- 标签间有适当间距

---

### ⑧ 底部操作按钮

**功能需求**：
- **添加课程按钮**：跳转到添加课程页面，自动带入当前查看的日期
- **设置按钮**：跳转到应用设置页面

**界面要求**：

| 元素 | 方屏 | 胶囊屏 |
|------|------|--------|
| 添加按钮文字 | "+ 添加课程" | "+" |
| 设置按钮文字 | "设置" | "设置" |
| 按钮高度 | 44px | 40px |
| 按钮圆角 | 22px | 20px |
| 按钮字号 | 20px | 18px |
| 按钮样式 | **加粗** | **加粗** |

- 两个按钮并排，左右各占一半宽度
- 添加按钮使用主题色填充（彩色背景+白色文字）
- 设置按钮使用浅色背景（卡片色背景+普通文字）
- 按钮文字居中
- 两按钮之间有小间距

---

### ⑨ 课表切换指示器

**功能需求**：
- 显示当前使用的课表名称（如"课程表1"）
- 文字前面显示切换符号「⇄」
- 点击进入课表管理页面，可切换或管理多张课表
- 支持多课表：用户可创建多个课表（按使用场景），每个课表独立存储课程数据

**界面要求**：
- 居中显示
- 字体大小：20px，行高：28px
- 颜色：使用主题色
- 居中有适当的上下内边距（12px）

## 三、首页设置项汇总

以下设置项可在「首页设置」页面中分别控制，所有设置在主页实时生效：

| 序号 | 设置项 | 默认值 | 控制范围 |
|------|--------|--------|----------|
| 1 | 时间显示 | 开启 | 控制 ① 时钟区域的显示/隐藏 |
| 2 | 快速添加 | 开启 | 控制 ⑦ 快速添加区域的显示/隐藏 |
| 3 | 课程提醒（状态栏） | 开启 | 控制 ④ 状态栏的显示/隐藏 |
| 4 | 已钉页面 | 关闭 | 控制 ⑤ 已钉页面的显示/隐藏 |
| 5 | 总览按钮（总） | 开启 | 控制 ② 中「总」按钮的显示/隐藏 |
| 6 | 今天按钮（今） | 开启 | 控制 ② 中「今」按钮的显示/隐藏 |
| 7 | 明天按钮（明） | 开启 | 控制 ② 中「明」按钮的显示/隐藏 |
| 8 | 自定义文字 | 开启 | 控制 ③ 自定义文字的显示/隐藏 |
| 9 | 时间格式 | 时:分 | 控制时钟显示的精度（年/月/日/时/分/秒各自开关） |
| 10 | 隐藏周末 | 关闭 | 日期导航栏是否跳过周六周日 |
| 11 | 字号设置 | 48（基准） | 影响课程名称、时间、地点和日期标题的字号 |

## 四、交互行为要求

### 4.1 页面生命周期
- 首次进入首页：显示骨架屏 → 加载数据 → 渲染课程列表
- 从其他页面返回首页（onShow）：自动刷新课表数据、已钉页面、自定义文字、快速添加预设列表
- 按返回键：退出应用（不是返回上一页）

### 4.2 实时更新
- 时钟每秒更新
- 课程状态每分钟更新
- 课程进度条每分钟更新
- 自定义文字按设定间隔轮播切换

### 4.3 数据联动
- 切换日期后，课程列表和状态栏同步更新
- 切换课表后（从课表管理页返回），课程列表自动刷新
- 隐藏周末设置变更后，日期导航自动调整范围并重新定位

### 4.4 错误处理
- 数据加载失败：显示错误提示和重试按钮
- 加载超时（8秒）：自动显示超时错误，可点击重试

### 4.5 屏型适配
- 应用启动时自动检测屏幕形状（胶囊屏/方屏）
- 根据屏型自动选择字号方案、布局模式
- 胶囊屏整体更紧凑，减少文字显示量，增大触摸区域
- 字号设置在不同屏型下有不同上限，确保不会溢出

## 五、页面间距规范

| 位置 | 间距值 | 说明 |
|------|--------|------|
| 页面顶部内边距 | 44px | 安全区域，避开状态栏 |
| 页面左右内边距 | 8px | 两侧留白 |
| 页面底部内边距 | 8px | 底部留白 |
| 各区域之间 | 4px | 上下区域的间距 |
| 课程卡片之间 | 10px | 卡片列表间距 |

## 六、颜色主题

页面支持深色主题，使用以下色彩角色：

| 角色 | 用途 |
|------|------|
| 背景色 | 页面底色 |
| 卡片色 | 区域背景、按钮背景 |
| 卡片亮色 | 次级区域背景、标签背景 |
| 主题色 | 强调色、图标、按钮、标签文字 |
| 主文字色 | 课程名称、标题等主要文字 |
| 次要文字色 | 时间、辅助信息 |
| 弱化文字色 | 空状态提示、灰色标签 |
