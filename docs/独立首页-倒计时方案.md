# 独立首页方案 · 倒计时（schedule-panel-countdown）

## 1. 页面定位（重新规划）

「倒计时」是**距下一节课的秒级倒计时牌**：上课中显示「正在上课 + 剩余 mm:ss」（等宽大字）；课间显示「距下节课 + mm:ss」+ 下节课课名/时间/地点卡片；无课/结课有对应文案。大字尺寸响应式：基础 52px（192px 胶囊屏可完整容纳 `MM:SS` 五字符不裁切）、`width>=200` 90px、`width>=400` 104px。

作为独立首页的差异化价值：**最强时间紧迫感**——大数字倒计时适合「怕迟到」场景，是 7 页中唯一秒级刷新的首页。保留现有信息结构。

## 2. 现状 vs 独立首页标准

| 维度 | 现状 | 达标 |
|---|---|---|
| 数据自加载 | `database.init` + `getAllCourses` | ✅ |
| 主题适配 | `store.getTheme` 全变量 | ✅ |
| 加载态/空态 | 加载中 + 上课中/课间/结课/无课 | ✅ |
| 屏型适配 | `width >= 200 / >= 400` 断点 | ✅ |
| 生命周期 | 1s 定时器 + `onDestroy` 清理 | ✅ |
| 返回逻辑 | `goBack()` 直接 `router.back()` | ❌ |

**唯一缺口**：返回逻辑（同前 3 页）。

## 3. 改造项

按标准 v1 第 1 条（同第 1 页模式）：`fromPanel`/`isRoot`、返回钮+占位符条件渲染、`goBack` 双模、`onBackPress` 双模、`require utils.js`。

### 3.1 工整化（用户 2026-10-19 追加：截图核对字号 + 界面工整）
- **防溢出**：倒计时大字从基础 72px 降到 52px，断点 96/120 → 90/104px；192px 胶囊屏下 `MM:SS` 五字符约需 156px < 可用 168px，不再被裁切（原 72px 需 216px，明显溢出）。
- **主题纯净化**：`next-info` 卡片底色由硬编码 `rgba(255,255,255,0.05)` 改为内联 `theme.card`，浅色主题下不再出现"灰白叠底"怪异观感；间距收成统一节奏（label 6 / time 16 / name 6 / detail 2）。
- **对齐工整**：卡片内文字保持居中、垂直节奏一致，标题与计时牌层级清晰（time 为唯一视觉焦点）。
