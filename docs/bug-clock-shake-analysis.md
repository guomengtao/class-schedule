# 首页时钟秒数跳动时"时:分"整体晃动分析

## 现象

首页顶部时钟显示 `HH:MM:SS`，每秒更新一次。当秒数变化时（如 `12:30:58` → `12:30:59`），"时"和"分"部分也会跟着轻微左右晃动，视觉上不稳定。

## 根因分析

### 原因：非等宽字体导致字符宽度不同

| 数字 | 在非等宽字体下的宽度 | 说明 |
|------|---------------------|------|
| `1` | 窄 | 约占 0.6em，最窄的数字 |
| `2` ~ `9` | 中等 | 约占 0.9em |
| `0` | 宽 | 约占 1.0em |
| `:` | 窄 | 约占 0.3em |

核心问题在于**每秒秒数变化时，整个文本的渲染宽度也在变化**：

```
12:30:11  →  总宽度约 6.2em  (末尾两个窄字符 1)
12:30:00  →  总宽度约 7.0em  (末尾两个宽字符 0)
12:30:58  →  总宽度约 6.8em  (末尾 5 宽, 8 宽)
12:30:59  →  总宽度约 6.8em  (末尾 5 宽, 9 宽)
12:30:10  →  总宽度约 6.5em  (末尾 1 窄, 0 宽)
```

### 为什么"时"和"分"也会晃动

```
┌─────────────────────────────────────┐
│           flex 容器居中               │
│     ┌──────────────┐                │
│     │  12:30:58    │  ← 宽度 6.8em   │
│     └──────────────┘                │
│          ↓ 下一秒                     │
│        ┌─────────┐                  │
│        │ 12:30:11│  ← 宽度 6.2em    │
│        └─────────┘                  │
└─────────────────────────────────────┘
```

由于 `.clock-row` 使用了 `justify-content: center`，文本在容器中居中显示。当文本总宽度变化时，居中对齐导致整段文本的起始位置发生偏移，因此"时"和"分"部分看起来也在跟着晃动。

### 当前 CSS 分析

```css
.clock-row {
  justify-content: center;   /* 居中 → 宽度变化导致位置偏移 */
  align-items: center;
  padding: 2px 4px;
  margin-bottom: 2px;
}

.clock-text {
  font-size: 18px;
  font-weight: normal;       /* 没有设置等宽字体 */
}
```

## 解决方案

### 方案一：使用等宽字体 `monospace` （推荐）

```css
.clock-text {
  font-size: 18px;
  font-weight: normal;
  font-family: monospace;    /* 每个数字等宽，总宽度不变 */
}
```

**原理**：等宽字体中每个数字占据相同宽度，无论秒数如何变化，`HH:MM:SS` 总宽度始终不变。

**优点**：一行代码解决，性能最优
**缺点**：视觉风格会变为等宽字体风格

### 方案二：使用 `font-variant-numeric: tabular-nums`

```css
.clock-text {
  font-size: 18px;
  font-weight: normal;
  font-variant-numeric: tabular-nums;  /* 数字等宽，其他字符保持原字体 */
}
```

**原理**：`tabular-nums` 让 OpenType 字体使用等宽数字变体，`:` 冒号不受影响。

**注意**：快应用（Vela）可能不支持此 CSS 属性，需要实测。

### 方案三：固定文本容器宽度

```css
.clock-row {
  justify-content: flex-end;  /* 改为右对齐，视觉上更稳定 */
  width: 100px;               /* 固定足够宽度 */
}

.clock-text {
  font-size: 18px;
  font-weight: normal;
  text-align: right;
}
```

**原理**：固定容器宽度 + 右对齐，文本仅在右侧"生长"，左侧"时:分"位置不变。

**缺点**：需要精确宽度值，不同字号下需调整。

### 方案四：零宽空格填充（不推荐）

```html
<!-- 在秒钟前后加零宽空格，但快应用可能不支持 -->
```

不推荐，兼容性差。

## 推荐方案

| 方案 | 兼容性 | 效果 | 实现难度 |
|------|--------|------|----------|
| `font-family: monospace` | ✅ 通用 | 好 | 极简 |
| `tabular-nums` | ❓ 快应用未知 | 最佳 | 简单 |
| 固定宽度 + 右对齐 | ✅ | 可行 | 需要调参 |

**首选方案一**：在 `.clock-text` 中添加 `font-family: monospace`。
