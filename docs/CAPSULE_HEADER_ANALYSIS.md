# 胶囊版 Header 返回按钮 + 汉字标题 尺寸分析

## 1. 胶囊版手表屏幕参数

| 设备 | 屏幕宽度 | 形状 |
|------|----------|------|
| HUAWEI Watch GT 4 (胶囊) | 466px | capsule |
| HUAWEI Watch GT 3 Pro (胶囊) | 454px | capsule |
| Honor Watch 4 Pro | 466px | capsule |
| HUAWEI Watch GT 5 Pro | 466px | capsule |

**取基准宽度:466px**(最常见的最大胶囊屏幕)

## 2. 页面可用宽度计算

```
屏幕宽度:              466px
- 左 padding:           -6px  (全站胶囊版统一 60px 6px 30px 6px)
- 右 padding:           -6px
─────────────────────────────
= 内容区总宽度:         454px
```

但胶囊屏幕左右有圆角,**边缘 10~15px 内容会被圆角裁掉**,所以**实际可视内容宽度 ≈ 430px**。

## 3. Header 布局结构

```
┌─────────────────── 430px 可视区 ──────────────────┐
│                                                     │
│  ┌─────┐   ┌───────────────────────┐               │
│  │返回 │   │  打 赏 支 持  (4个汉字) │               │
│  │按钮 │   └───────────────────────┘               │
│  └─────┘                                           │
│  W_back    margin_title_right = W_back + gap       │
│                                                     │
└─────────────────────────────────────────────────────┘
```

flex-direction: row,标题 text-align:center + margin-right 对称返回按钮宽度,实现视觉居中。

## 4. 变量定义

| 变量 | 含义 | 说明 |
|------|------|------|
| W_back | 返回按钮宽度 | 含圆角点击区 |
| H_back | 返回按钮高度 | 含点击区 |
| F_back | 返回按钮字号 | 箭头字符 ◀ |
| gap | 按钮与标题间距 | margin-left |
| F_title | 标题字号 | 4个汉字等宽 |
| H_title | 标题 line-height | 通常 = F_title 或略大 |
| N | 汉字数量 | 固定 = 4 |

## 5. 约束公式

### 5.1 宽度约束(单行不换行)

```
W_back + gap + (N × F_title) + (W_back + gap) ≤ 可视宽度
2 × W_back + 2 × gap + 4 × F_title ≤ 430px
```

### 5.2 高度约束(header 总高 ≤ 屏幕合理值)

```
header 总高 = max(H_back, H_title)
建议 ≤ 48px(胶囊版垂直空间珍贵)
```

### 5.3 返回按钮最小可点击区

快应用(基于 Web)推荐最小点击区:**48 × 48px**(Apple HIG 标准)
手表端可适当缩小,但不宜低于 **40 × 36px**,否则手指难以点中。

## 6. 场景计算

### 场景 A:返回按钮 48×40,最大化标题

```
W_back = 48px, gap = 8px
2×48 + 2×8 + 4×F ≤ 430
96 + 16 + 4F ≤ 430
4F ≤ 318
F ≤ 79.5px
```
→ **标题最大字号 ≈ 79px**

但 79px 的标题会导致 header 高度 = max(40, 79) = 79px,太高了。

### 场景 B:约束 header 总高 ≤ 48px

```
H_back = 40px, F_title ≤ 48px(line-height)
2×W_back + 2×gap + 4×F_title ≤ 430

如果 F_title = 36px:
2×W_back + 2×gap + 144 ≤ 430
2×(W_back + gap) ≤ 286
W_back + gap ≤ 143px

如果 W_back = 48px: gap ≤ 95px(太宽松)
如果 W_back = 60px: gap ≤ 83px
```
→ **标题字号 36px 时,按钮和间距都很充裕**

### 场景 C:返回按钮放大到 60×48,标题最大化(高 ≤ 48px)

```
W_back = 60px, H_back = 48px, F_back = 28px, gap = 10px
2×60 + 2×10 + 4×F_title ≤ 430
120 + 20 + 4F ≤ 430
4F ≤ 290
F ≤ 72.5px
```
但 F_title 必须 ≤ 48px(高约束),所以 **F_title = 48px**。

### 场景 D:推荐方案(平衡美观和可用性)

```
返回按钮:  52×44px, 字号 26px, gap = 8px
标题字号:  34px  line-height 44px(与按钮同高,视觉对齐)

宽度验算: 2×52 + 2×8 + 4×34 = 104 + 16 + 136 = 256px ≤ 430px ✓
高度验算: max(44, 44) = 44px, header 总高 44px ✓
```

### 场景 E:极限方案(字号最大的可行解)

```
约束 header 高 ≤ 52px, 返回按钮 56×48px, gap = 6px
2×56 + 2×6 + 4×F ≤ 430
112 + 12 + 4F ≤ 430
4F ≤ 306
F ≤ 76.5px

但高约束 F ≤ 52px,所以:
返回按钮:  56×48px, 字号 28px
标题字号:  48px  line-height 52px
header总高: 52px
```

## 7. 汉字宽度系数

CJK 统一汉字通常宽度 = 字号(方形字)。但实际渲染中:
- 黑体/思源黑体:字宽 ≈ 字号 × 1.0
- 宋体:字宽 ≈ 字号 × 1.0
- 因此 **4个汉字总宽度 ≈ 4 × F_title**

保守估算:× 1.05 倍(字间距)

```
保守公式: 2×W_back + 2×gap + 4×F_title×1.05 ≤ 430
```

## 8. 胶囊 vs 圆形 vs 方形屏幕对比

| 屏幕形状 | 宽度 | 页面 padding | 可用内容宽 | header 最大可用宽 |
|----------|------|-------------|-----------|-----------------|
| capsule | 466px | 6px 左右 | 454px | ≈ 430px(圆角扣减) |
| circle  | 466px | 36px 左右 | 394px | ≈ 320px(圆形扣减更多) |
| rect    | 336px | 8px 左右 | 320px | ≈ 320px |
| pill-shaped | 454px | 6px 左右 | 442px | ≈ 416px |

**圆形屏幕**可用宽度只有 ≈ 320px,同样按钮和标题在圆形上更拥挤:
```
圆形约束: 2×W_back + 2×gap + 4×F_title ≤ 320
按钮 48×40, gap=8: 96+16+4F ≤ 320 → 4F ≤ 208 → F ≤ 52px
```
圆形标题最大 ≈ 48px(还要扣字间距)。

## 9. 结论推荐值

### 胶囊版(主力):
| 属性 | 推荐值 | 最大可行值 | 说明 |
|------|--------|-----------|------|
| 返回按钮宽度 | **48~52px** | 56px | 48px 是最小推荐点击区 |
| 返回按钮高度 | **40~44px** | 48px | 与标题 line-height 对齐 |
| 返回按钮字号 | **24~26px** | 28px | 箭头 ◀ 清晰可辨 |
| 标题字号 | **32~34px** | 40px(保守) | 40px 以上可用但偏小 |
| 按钮与标题 gap | **8~10px** | — | 视觉间距 |
| header 总高 | **44~48px** | 52px | 不能太高,挤压内容区 |

### 当前 donate.ux 胶囊版参数:
```
返回按钮: 48×40px, 字号 24px, gap 8px
标题字号: 28px, line-height 40px
验算: 2×48 + 2×8 + 4×28 = 96+16+112 = 224px
剩余空间: 430 - 224 = 206px  ← 非常宽裕,可以放大!
```

### donate.ux 胶囊版可升级到:
```
返回按钮: 52×44px, 字号 26px, gap 8px
标题字号: 34px, line-height 44px
验算: 2×52 + 2×8 + 4×34 = 104+16+136 = 256px ≤ 430px ✓
```

## 10. 注意事项

1. **标题禁止换行** — 必须加 `lines: 1` 或 `white-space: nowrap`,防止窄屏设备折行
2. **标题用 text-align:center + margin-right 对称** — 不要用绝对定位,否则覆盖按钮点击区
3. **返回按钮必须用 flex-shrink:0** — 防止标题过长把按钮压扁
4. **真机测试不同字号** — 快应用渲染引擎的字体宽度可能和 Web 略有差异
5. **胶囊版不是圆形** — 不要照搬圆形的 36px padding,胶囊版只用 6px
