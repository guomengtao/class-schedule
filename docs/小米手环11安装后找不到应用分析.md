# 小米手环11安装快应用后找不到应用/看不到图标 — 原因分析与解决方案

> 针对新发布的小米手环11（含11 Pro）安装快应用后，在设备上找不到应用入口、看不到图标的问题。

---

## 一、问题现象

- 通过工具安装 `.rpk` 包到小米手环11，提示安装成功
- 在手环的应用列表/桌面中**找不到该应用图标**
- 或者能找到图标但**点击白屏/黑屏无响应**

---

## 二、根本原因分析

### 2.1 手环11平台版本更高，`minPlatformVersion` 不匹配

小米手环11搭载 **HyperOS / Vela 新版本**，平台版本号比手环9/10更高。如果 manifest.json 中 `minPlatformVersion` 设置过低（如 `1000`），系统可能认为该应用不兼容当前设备而隐藏。

**检查点**：当前项目 manifest.json 中 `minPlatformVersion` 为 `1000`，手环11的最低平台版本可能是 `1080` 或更高。

### 2.2 `deviceTypeList` 缺少 `band` 类型

手环（Band）和手表（Watch）在快应用框架中是**不同设备类型**。手环11在系统中注册为 `band` 类型，如果 manifest.json 只声明了 `watch`：

```json
"deviceTypeList": ["watch"]     // ❌ 手环11识别不到
```

应同时声明：

```json
"deviceTypeList": ["band", "watch"]   // ✅ 同时支持手环和手表
```

### 2.3 快应用在手环11上的入口机制不同

手环9/10的快应用入口在「更多应用」或「应用列表」中，但手环11可能：
- 将快应用放入**不同的分组目录**（如「工具」或「小程序」）
- 需要用户**手动添加到桌面**才能看到图标
- 通过**负一屏**或**侧滑**才能找到
- 首次安装后不会自动出现在主屏，需要在「全部应用」中搜索

### 2.4 图标资源问题

手环11可能对图标有更严格的要求：
- 图标文件必须在 `src/common/` 路径下
- 图标格式必须为**纯 PNG**，分辨率建议 80×80 或 128×128
- 如果图标路径写错或图标文件过大，系统会跳过显示
- 当前项目 manifest.json 中 `"icon": "logo.png"` 需确保文件确实存在于 `src/` 目录

### 2.5 新屏幕形状不匹配

手环11 Pro 可能使用了新的屏幕形状（非标准的 capsule/rect/circle），如果 `@media (shape: ...)` CSS 查询不匹配，可能导致页面渲染为**空白/黑屏**。

### 2.6 包名冲突或签名问题

如果两端（开发工具和手环）签名不一致，快应用安装后：
- 系统认为应用受损
- 自动隐藏或禁止运行
- 不显示任何提示（静默失败）

### 2.7 存储空间不足

手环11系统分区剩余空间低于 **60MB** 时，快应用运行时可能出现白屏或闪退，系统也可能在安装后不显示入口。

## 三、解决方案

### 方案 3.1：更新 manifest.json 配置

```json
{
  "package": "com.application.watch.classschedule",
  "name": "Ev课程表",
  "versionName": "1.6.5",
  "versionCode": 835,
  "minPlatformVersion": 1050,
  "icon": "logo.png",
  "deviceTypeList": [
    "band",
    "watch"
  ],
  "features": [
    { "name": "system.router" },
    { "name": "system.storage" },
    { "name": "system.prompt" },
    { "name": "system.device" },
    { "name": "system.vibrator" },
    { "name": "system.request" },
    { "name": "system.app" }
  ],
  "permissions": [
    { "name": "hapjs.permission.DEVICE_INFO" }
  ],
  "config": {
    "logLevel": "log",
    "designWidth": "device-width"
  }
}
```

**关键改动**：
| 字段 | 旧值 | 新值 | 原因 |
|------|------|------|------|
| `minPlatformVersion` | `1000` | `1050` | 手环11平台版本更高 |
| `deviceTypeList` | `["watch"]` | `["band", "watch"]` | 手环11识别为 band 类型 |
| `features` | 含 `system.resident` | 移除 `system.resident` | 手环上常驻能力不稳定，建议先禁用 |

### 方案 3.2：验证图标文件

确保 `src/logo.png` 文件存在且：
- 格式为 PNG
- 尺寸 80×80 或 128×128
- 文件大小 < 50KB

### 方案 3.3：添加手环11屏幕形状适配

在手环11未知屏幕形状时，确保有一个**兜底样式**。在 CSS 中不依赖任何 `@media shape` 的样式作为默认值，`@media` 只用于覆盖差异。

```css
/* 默认样式 — 兜底所有未匹配的屏幕形状 */
.header {
  height: 50px;
  padding: 0 12px;
}

/* 矩形屏覆盖 */
@media screen and (shape: rect) {
  .header { height: 60px; padding: 0 16px; }
}

/* 圆形屏覆盖 */
@media screen and (shape: circle) {
  .header { height: 56px; padding-top: 12px; }
}
```

### 方案 3.4：安装后查找入口

安装成功后，在手环11上按以下顺序查找：
1. 打开手环 → 滑到最右 → **「更多」**或**「全部应用」**
2. 在应用列表中查找 **「Ev课程表」**
3. 如果找到，**长按图标** → 选择**「添加到桌面」**或**「置顶」**
4. 如果仍未找到，重启手环后重复以上步骤

### 方案 3.5：重新打包并安装

```
# 1. 清理旧构建
rm -rf .temp_class dist/

# 2. 重新构建（强制 release + JSC）
npx aiot release --enable-jsc

# 3. 检查产物
ls -lh dist/*.rpk

# 4. 解压验证 icon 和 manifest
unzip -l dist/*.rpk | grep -E "logo|manifest"
```

### 方案 3.6：使用设备信息页排查

如果应用能打开但看不到界面，进入「设置 → 设备信息」页面，查看手环11上报的：
- **设备类型**（应为 band）
- **屏幕形状**（可能在现有三种之外）
- **平台版本号**（确认是否 ≥ 1050）

## 四、排查清单

| 检查项 | 当前状态 | 应修改 |
|--------|----------|--------|
| `minPlatformVersion` | `1000` | → `1050` |
| `deviceTypeList` | `["watch"]` | → `["band", "watch"]` |
| `logo.png` 存在 | 需验证 | `src/` 目录下 |
| 兜底 CSS（无 @media 匹配时） | 部分页面有 | 所有页面需确保默认样式合理 |
| `system.resident` 常驻能力 | 已启用 | 手环11暂不建议开启 |
| 安装后重启手环 | — | 有时需重启才能显示 |
