# 新安装用户默认配置参数说明

本文档整理 Ev课程表 应用首次安装后，所有功能的默认配置参数。

---

## 一、课程数据

### 1.1 课程表
| 参数 | 默认值 | 说明 |
|------|--------|------|
| 课程表数量 | 1 个 | 默认名称为 `课程表1` |
| 当前选中课程表 | 第 1 个（索引 0） | - |
| 课程表内课程 | 0 门 | 新安装无预设课程数据 |

### 1.2 预设课程列表（快速添加用）
| 参数 | 默认值 |
|------|--------|
| 预设课程数量 | 12 门 |
| 课程列表 | 语文、数学、英语、物理、化学、政治、音乐、体育、美术、历史、地理、生物 |

## 六、首页设置

存储键 `homepage_settings`，默认值如下：

### 6.1 显示控制

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 快速添加按钮 | `true`（**开启**） | 首页底部快速添加课程入口 |
| 上课提醒区域 | `true`（**开启**） | 首页状态栏上课/下课提示 |
| 时间显示 | `true`（**开启**） | 首页显示当前时间 |
| 钉首页 | `false`（关闭） | 首页已固定页面的快捷入口 |
| 功能实验室 | `false`（关闭） | 首页显示实验性功能区 |
| 自定义文字 | `true`（**开启**） | 首页显示自定义鼓励语句 |

### 6.2 快捷按钮（日期导航栏）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| "总" 按钮 | `true`（**开启**） | 显示全部课程 |
| "今" 按钮 | `false`（关闭） | 显示今日课程 |
| "明" 按钮 | `false`（关闭） | 显示明日课程 |

### 6.3 时间格式

## 八、震动设置

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 震动风格 | `short`（短震） | 存储键 `vibrationStyle` |
| 可选风格 | 短震、长震、双短震、三连震、SOS、心跳 | 6 种可选 |

---

## 九、高级版/会员

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 高级版解锁状态 | `false`（未解锁） | 标准用户，部分功能受限 |

## 十、数据备份

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 备份列表 | 空数组 `[]` | 无历史备份 |

---

## 十一、存储键总览

| 存储键 | 类型 | 默认值 | 用途 |
|--------|------|--------|------|
| `appTheme` | String | `"blue"` | 主题配色 |
| `fontScale` | String | `"0.58333..."` | 字体缩放比例（28px） |
| `userNickname` | String | 随机昵称 | 用户昵称 |
| `hideWeekend` | String | 无存储（默认 `true`） | 隐藏周六日 |
| `scheduleNames` | JSON Array | `["课程表1"]` | 课程表名称列表 |
| `currentScheduleIndex` | String | `"0"` | 当前选中课程表索引 |
| `homepage_settings` | JSON Object | 见第六节 | 首页设置 |
| `remindSettings` | JSON Object | `{"enabled":true,"minutes":5}` | 上课提醒设置 |
| `vibrationStyle` | String | `"short"` | 震动风格 |
| `premium_unlocked` | - | `false`（无存储） | 高级版解锁状态 |
| `course_preset_list` | JSON Array | 12 门预设课程 | 快速添加预设课程 |
| `backup_list` | JSON Array | `[]` | 备份记录列表 |
| `allCourses_0` | JSON Array | 无存储 | 第 1 个课程表的课程数据 |

---

## 十二、默认配置变更记录

### 2026-09-05 更新
- **首页设置精简**：默认仅开启"快速添加"、"上课提醒"、"时间"、"总"按钮，其他关闭
- **字体大小**：默认从 48px 改为 28px
- **昵称**：默认从空字符串改为 20 个学生昵称随机选取
- **首页自定义文字**：默认开启，20 句鼓励语句随机选取
- **周六日**：默认隐藏（不显示）
