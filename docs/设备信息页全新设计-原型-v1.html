全新设计要点（对照四条铁律 + 外壳规范）

现状问题：17 个原始字段一列平铺 = 调试转储；用户最关心的「这是什么设备、什么系统、ID 是多少」被淹没；底部孤零零一个「钉首页」没有视觉归属。
  • 信息架构转储 → 分组：身份卡（型号+品牌+系统）置顶回答「这是什么」；下分 屏幕 / 系统 / 标识 / 调试 / 应用 五组，按用户关心度排序；设备 ID 从列表中段提升为独立「点击复制」按钮。
  • 铁律①宽度加总：行内 k 值 ≤5 字（55px）+ v 值 ≤104px + 内边距 20px = 179px ≤ 192−24 安全区；「分辨率 192 × 490 px」实测 118px 收进。
  • 铁律②弧形区：内容层 top:46 / bottom:44；两屏首末行（返回条 / 复制条、分组行）全在弧线外。
  • 铁律③字号：型号 16（白底深字对比 12.6:1）、正文 11（白字压深绿 ≥9:1）、分组标签 9 配半透明白。全主题 WCAG 达标（深色底方案四主题通用，浅色族不再塌）。
  • 铁律④禁省略：序列号、设备代号等长值整行换行（v 值 line-height 1.35），列表自适应伸高；「未知」兜底保留。
  • 新增应用自报版本：补「Ev课程表 版本号+code」行——排查问题最高频信息，原页面反而没有。
  • 保留「钉首页」功能不变（下一屏尾部，与原逻辑一致）；错误态/加载态沿用现有重试卡样式。
