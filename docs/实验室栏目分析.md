# 实验室栏目分析：为什么有多个 `lab-list.js` 以及入口在哪里

## 概述

项目中存在 **3 份** `lab-list.js` 文件，但只有 **1 份** 被实际使用。另外两份是历史遗留的孤立副本，未被任何页面引用。

---

## 三份 `lab-list.js` 文件对比

| 文件路径 | 是否被引用 | 条目数 | 功能完整度 |
|---|---|---|---|
| [src/pages/home-module-demo/modules/lab-list.js](../src/pages/home-module-demo/modules/lab-list.js) | ✅ 是（被 `test-area` 页面引用） | 37 条 | 完整（增删改查、排序、钉选） |
| [src/pages/index/modules/lab-list.js](../src/pages/index/modules/lab-list.js) | ❌ 否（孤立） | 12 条 | 简化版（仅 `init` + `getItems`） |
| [src/pages/home-pro/modules/lab-list.js](../src/pages/home-pro/modules/lab-list.js) | ❌ 否（孤立） | 12 条 | 简化版（与 index 版完全相同） |

---

## 详细说明

### 1. 活跃版本：`home-module-demo/modules/lab-list.js`

- **引用者**：[test-area.ux](../src/pages/test-area/test-area.ux) 第 70 行：`var labList = require("../home-module-demo/modules/lab-list.js")`
- **条目数**：37 条（包含所有可用的实验室页面）
- **功能**：完整的增删改查、排序、钉选、获取可用页面列表
- **作用**：为"功能实验室"页面提供数据源

### 2. 孤立版本：`index/modules/lab-list.js`

- **未被任何 `.ux` 文件引用**
- **条目数**：12 条（仅早期的基础页面）
- **功能**：仅有 `init` 和 `getItems` 两个方法
- **推测来源**：早期版本的首页模块，后被 `home-module-demo` 版本替代，但文件未清理

### 3. 孤立版本：`home-pro/modules/lab-list.js`

- **未被任何 `.ux` 文件引用**
- **条目数**：12 条
- **功能**：与 `index` 版本完全相同
- **推测来源**：可能是从 `index` 目录复制过来作为 `home-pro` 的模块，但 `home-pro` 的 `index.ux` 并未加载 lab-list 模块（它加载的是 clock、dayNav、statusBar 等模块，没有 lab-list）

---

## 实验室入口分析

"功能实验室"在项目中有 **唯一的入口**：

```
设置页面 (settings.ux)
  └─ 点击 "功能实验室" 行
       └─ openTestArea() → router.push({ uri: "/pages/test-area" })
            └─ test-area.ux（功能实验室页面）
                 └─ 加载 home-module-demo/modules/lab-list.js
```

### 入口路径图

```
用户
  │
  ├─ 首页 (index/index.ux) → 底部 "设置" 按钮
  │     └─ settings.ux → "功能实验室" → test-area.ux
  │
  ├─ 首页 Pro (home-pro/index.ux) → 底部 "设置" 按钮
  │     └─ settings.ux → "功能实验室" → test-area.ux
  │
  └─ 首页模块版 (home-module-demo/index.ux) → 底部 "设置" 按钮
        └─ settings.ux → "功能实验室" → test-area.ux
```

**结论**：无论从哪个首页进入，最终都通过 `设置 → 功能实验室 → test-area.ux` 到达同一个实验室页面。

---

## 建议

1. **清理孤立文件**：删除 `index/modules/lab-list.js` 和 `home-pro/modules/lab-list.js`，它们未被任何页面引用，属于历史遗留代码。
2. **统一文件位置**：将 `lab-list.js` 移至公共目录（如 `src/data/`），避免放在 `home-module-demo` 目录下造成混淆。
3. **保持单一数据源**：确保只有一个 `lab-list.js` 维护实验室页面列表，避免多份拷贝导致不一致。
