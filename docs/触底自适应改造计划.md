## 三、需要额外关注的问题

### 3.1 首页（index.ux）CSS 分布在子模块中

首页不像其他页面 CSS 全部写在一个 `.ux` 文件里，它的样式分散在 `src/pages/index/modules/` 下的多个 JS 文件中（`class-list.js`、`status-bar.js` 等）。改造时需逐个模块排查。

### 3.2 两版共存页面

| 页面 | v1 | v2 | 建议 |
|------|----|----|------|
| 添加课程 | `add-course.ux` | `add-course-v2.ux` | 确认主力版本，另一版可延后或废弃 |
| 课程管理 | `course-manager.ux` | `course-manager-v2.ux` | 同上 |

### 3.3 标准版"可看不可操作"还需要加的页面

当前仅 `homepage-settings` 和 `backup-restore` 做了"可看不可操作"的 premium 门禁（v1.7.82）。以下页面入口暂无门禁：

| 页面 | 入口位置 | 当前行为 | 建议 |
|------|----------|----------|------|
| 统计页 | 首页底部按钮 | 直接进入，标准版可用 | 加门禁：可看，不可操作 |
| 工具箱 | 首页底部按钮 | 同上 | 同上 |

### 3.4 共享 header.css

29 个页面 `@import '../../common/header.css'`。这个共享头部的 CSS 如果还有旧 `@media shape` 写法，会影响所有引用它的页面。改造时需要一并检查。

## 四、改造检查清单（单页面模板）

每改造一个页面，必查：

- [ ] base CSS 以 160px 内容区为基准，无任何 media query 依赖
- [ ] 移除所有 `@media (shape: pill-shaped)` 和 `@media (shape: capsule)` 独立块
- [ ] 保留 `@media (shape: circle)` 仅用于圆方不同构
- [ ] 添加 `@media (width >= 200px)` 断点（手环 10 增量调整）
- [ ] 添加 `@media (width >= 400px)` 断点（Watch 6 增量调整）
- [ ] `overlay-modal` / `overlay-sheet` 定位属性在 inline style 上
- [ ] 无 `lines:` 属性
- [ ] 无 `text-overflow: ellipsis`
- [ ] 在模拟器上手环 9 / 10 Pro / Watch 6 三种形态均验证通过

```
  3. 添加课程 (add-course-v2) ← 先确认主力版本

  5. 首页设置 (homepage-settings)
  6. 周视图 (week-view)
  7. 重置数据 (reset-data)
  
P1 第四轮（高级版功能）：
  8~15 按复杂度从简到难依次
  
P2 第五轮（辅助页面）：
  16~22 批量快速改造
```
