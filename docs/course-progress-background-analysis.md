# 课程名单区域进度背景色分析报告

## 需求

仅针对当天课程名单区域，用背景色微调来直观区分三种状态：

| 状态 | 背景色 | 进度条 |
|------|--------|--------|
| 未开始 | 正常卡片背景 | 无 |
| 进行中 | 蓝色渐变（半透明） | 从左到右按时间比例填充 |
| 已结束 | 红色覆盖（半透明） | 满格 |

## 设计思路

```
未开始（0%）
┌────────────────────────────────────────────┐
│  数学  08:00 - 08:45                      │
│  教室301                                  │
├────────────────────────────────────────────┤
│  英语  08:55 - 09:40                      │
└────────────────────────────────────────────┘

进行中（45%）
┌────────────────────────────────────────────┐
│  ████████████████░░░░░░░░░░░░            │
│  数学  08:00 - 08:45    45%              │
│  教室301                                  │
├────────────────────────────────────────────┤
│  英语  08:55 - 09:40                      │
└────────────────────────────────────────────┘

已结束（100%）
┌────────────────────────────────────────────┐
│  ████████████████████████████████████     │
│  数学  08:00 - 08:45    已结束            │
│  教室301                                  │
├────────────────────────────────────────────┤
│  英语  08:55 - 09:40                      │
└────────────────────────────────────────────┘
```

## 实现方案

### 核心逻辑

```javascript
getCourseProgress(course) {
  // 解析课程时间 "08:00 - 08:45"
  // 计算当前时间在课程中所占的比例 0-100
  // 现在 < 开始时间 → 0（未开始）
  // 现在 >= 结束时间 → 100（已结束）
  // 否则 → (现在-开始) / (结束-开始) * 100（进行中）
}
```

### 三个颜色方案

| 状态 | 进度条颜色 | 视觉 |
|------|-----------|------|
| 未开始 | `transparent` | 正常卡片背景 |
| 进行中 | `rgba(126,200,227,0.2)` | 蓝色半透明渐变 |
| 已结束 | `rgba(231,76,60,0.25)` | 红色半透明覆盖 |

### 技术方案

- 使用 `position: absolute` 的进度背景层 + `position: relative` 的内容层
- 进度背景层 `overflow: hidden` 确保不超出卡片边界
- 文字始终在进度层之上
- 颜色使用 `rgba` 格式内嵌透明度，避免 `opacity` 属性兼容性问题

## Bug 排查：进度条不生效

### 问题1：快应用不支持 `opacity` 内联样式

**现象**：进度条 `div` 设置了 `opacity: 0.2`，但快应用内联样式不支持 `opacity` 属性。

**修复**：将 `opacity` 合并到 `background-color`，使用 `rgba` 格式：

```html
<!-- 修复前 -->
style="background-color: #7ec8e3; opacity: 0.2"

<!-- 修复后 -->
style="background-color: rgba(126,200,227,0.2)"
```

### 问题2：Reactivity 不触发

**现象**：`currentClasses` 中的课程对象来自数据库，没有 `progress`/`progressColor` 属性。后续 `updateClassProgress()` 添加这些属性时，快应用响应式系统不检测新增属性。

**修复**：在 `loadDayClasses()` 中创建新对象，预初始化 `progress` 和 `progressColor` 属性：

```javascript
// 修复前：直接使用数据库返回的原始对象
this.currentClasses = dayData ? dayData.classes : []

// 修复后：克隆对象并预初始化进度属性
var classes = []
for (var j = 0; j < rawClasses.length; j++) {
  var src = rawClasses[j]
  classes.push({
    id: src.id, name: src.name, time: src.time, location: src.location,
    progress: 0,
    progressColor: "transparent"
  })
}
this.currentClasses = classes
```

### 问题3：忘删 `progressOpacity` 残留

**修复**：移除所有 `progressOpacity` 引用，颜色统一用 `rgba` 格式。

### 问题4：进度条右边和底部漏边（未铺满）

**现象**：进度背景色右边和底部与卡片边缘之间有缝隙，没有完全铺满。

**根因**：`.class-card` 有 `padding: 14px`，`.progress-bg` 用 `position: absolute; left: 0; top: 0` 定位，但绝对定位默认相对于父元素的 **padding box**（而非 border box），所以进度条被限制在 padding 区域内，右边和底部留下 14px 空隙。

```
修复前：
┌──────────────────────────────────────┐
│ ← 14px padding                       │
│   ┌──────────────────────────────┐   │
│   │ ████████████░░░░░░░░░░░░░░░  │   │ ← 进度条右边有缝
│   │ 数学  08:00 - 08:45          │   │
│   │ 教室301                      │   │
│   └──────────────────────────────┘   │
│                      14px padding →  │
└──────────────────────────────────────┘
```

**修复**：将 `padding` 从 `.class-card` 移到 `.class-content`，进度条直接铺满整个卡片：

```css
/* 修复前 */
.class-card  { padding: 14px; }
.progress-bg { left: 0; top: 0; }
.class-content { /* no padding */ }

/* 修复后 */
.class-card  { /* no padding */ }
.progress-bg { left: 0; top: 0; border-radius: 10px; }  /* 同卡片圆角 */
.class-content { padding: 14px; }
```

修复后进度条从卡片边缘开始，完全铺满：

```
修复后：
┌──────────────────────────────────────┐
│ ████████████████████████████████████ │ ← 进度条贴边铺满
│   数学  08:00 - 08:45                │
│   教室301                            │
└──────────────────────────────────────┘
```

## 配色方案：跟随主题

### 设计原则

进度背景色 = 当前主题的 `accent` 色 + 透明度，切换主题自动适配。

| 主题 | 进行中（ongoing） | 已完成（done） |
|------|-------------------|----------------|
| 深空蓝 | `rgba(126,200,227,0.2)` | `rgba(74,138,154,0.25)` |
| 翡翠绿 | `rgba(126,200,160,0.2)` | `rgba(74,138,106,0.25)` |
| 珊瑚红 | `rgba(227,126,126,0.2)` | `rgba(154,74,74,0.25)` |

| 深空灰 | `rgba(136,136,153,0.2)` | `rgba(85,85,102,0.25)` |
| 暗紫魅影 | `rgba(176,126,200,0.2)` | `rgba(106,74,122,0.25)` |
| 晨光白 | `rgba(74,144,217,0.2)` | `rgba(42,90,138,0.25)` |
| 暖阳米 | `rgba(196,168,130,0.2)` | `rgba(138,106,74,0.25)` |

| 琥珀金 | `rgba(212,160,96,0.2)` | `rgba(138,106,58,0.25)` |

### 代码实现

```javascript
// store.js - 每个主题新增两个字段
progressOngoing: 'rgba(126,200,227,0.2)',
progressDone: 'rgba(74,138,154,0.25)'

// index.ux - 使用主题色
var ongoing = theme.progressOngoing || "rgba(126,200,227,0.2)"
var done = theme.progressDone || "rgba(74,138,154,0.25)"
course.progressColor = progress >= 100 ? done : ongoing
```

## 注意事项

1. 仅对当天课程生效，不涉及其他日期
2. 进度背景半透明，文字始终可读
3. 未开始的课程无任何进度背景，保持原样
4. 已结束的课程显示红色半透明覆盖，明确区分
5. 进度每 30 秒自动刷新，无需手动操作
