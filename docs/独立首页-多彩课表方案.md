# 独立首页方案 · 多彩课表（schedule-panel-colorful）

> 系列：7 个课表首页独立化改造（umbrella: evtask-D-evclass-sche-261019-wxfkmx）
> 「独立首页标准 v1」见 `docs/独立首页-当前进度方案.md` 附节，本页直接引用。

## 1. 页面定位（重新规划）

「多彩课表」是**一周全览色块矩阵**：7 列 × N 行格子矩阵（沿用 open-vela 官方 calendar 样例的 rows×7 渲染机制），有课格按科目分配官方色板五色，点击格进课程管理；左右滑动切换周（数据源固定当前生效方案，滑动仅重载）。

作为独立首页的差异化价值：**唯一的全周视角**——其余 6 页全是「今天」，只有它回答「这周每天都有什么课」。保留官方矩阵渲染机制与屏型收敛（胶囊 178px 窄矩阵）。

## 2. 现状 vs 独立首页标准

| 维度 | 现状 | 达标 |
|---|---|---|
| 数据自加载 | `getAllCourses`（database） | ✅ |
| 主题适配 | **全部硬编码白色**：标题/星期头/分隔线/空格文字全是 `#fff` 或 white，浅色主题下整页刺眼且文字不可读 | ❌ 重灾区 |
| 空态 | **无任何空态**——整周无课时渲染一张空矩阵，用户不知道是没数据还是没课 | ❌ |
| 屏型适配 | pill 形专属收敛（178px 矩阵 + 12px 格字）已做 | ✅ |
| 生命周期 | 无定时器 | ✅ |
| 返回逻辑 | `backClick()` 直接 `router.back()`（官方原为 `app.terminate()`，曾被改过一次） | ❌ |
| 附带缺陷 | 模板星期头把「一」标了 `weekend` 类（官方样例笔误，与矩阵列逻辑 一~五工作日 不一致） | ❌ 顺手修 |

**四类缺口**：主题硬编码（标准 v1 第 3 条重灾区）、空态缺失（第 4 条）、返回逻辑（第 1 条）、星期头笔误。

## 3. 改造项

1. **主题化（核心）**：`require store` + `onInit` 走 `store.getTheme`；文字颜色全部改**行内响应式绑定**（`.ux` 的 CSS 类吃不到 theme 变量，而格子色是 JS 塞进 className 的快照字符串、对主题切换不响应，故改 `cell.colorKey` 方案：空格存 `text`/`textSecondary` 键，绑定 `theme[cell.colorKey]` 保持响应式；有课格固定白字——彩色底上白字两种主题都可读）。
2. **空态**：`buildScheduleMatrix` 统计全周是否有课，无课时渲染「本周暂无课程」提示（矩阵保留，视觉不突兀）。
3. **返回逻辑**（标准 v1 第 1 条）：`fromPanel`/`isRoot`、返回条 `if="{{ !isRoot }}"`、`backClick` 双模、`onBackPress` 双模。
4. **星期头笔误**：「一」的 `weekend` 类随颜色重绑一并修正为工作日色。

不动官方矩阵渲染机制、色板五色、pill 收敛 CSS（那是 2026-10-14/17 两轮已验收的注入成果）。

## 4. 验收口径

- 单测 33/33 不回归。
- vela-loop root 模式截图：无返回条、标题/星期头随主题着色、空格文字可读、有课格色块白字正常、无课周出现空态提示。
