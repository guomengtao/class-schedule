# 独立首页方案 · 多彩课表（schedule-panel-colorful）—— 单日视图重构

> 系列：7 个课表首页独立化改造（umbrella: evtask-D-evclass-sche-261019-wxfkmx；本页后续优化：evtask-D-evclass-sche-261019-sqbnbs）
> 「独立首页标准 v1」见 `docs/独立首页-当前进度方案.md` 附节，本页直接引用。

## 1. 页面定位（重新规划 · v2）

原 v1 方案把多彩课表做成「整周 5×7 矩阵 + 科目配色格」。在 192–390px 的表盘上，7 列塞进 50px 格，课程名必须压成两字、行高随课程数动态收敛，信息密度过高且阅读负担重，**不符合「独立首页一眼可读」的定位**。

v2 改为 **「只显示一天」的单日视图**：
- 默认显示**今天**；左右滑动切到上一天 / 下一天（prevDay / nextDay，仅在周一↔周日边界内 clamp）。
- 当天课程以**彩色卡片列表**纵向铺开：每张卡用该科目的稳定配色填充（多彩身份保留），白字显示课名 + 时间（+ 地点）。
- 空天显示「今天暂无课程 / 星期X 暂无课程」空态。
- 标题下方一行显示当前天（选中今天时为「今天 · 星期一」，否则「星期一」）。

差异化价值：**每天一屏、彩色可辨、滑动翻日**——比整周矩阵更适合「今天上啥 / 翻翻明天」的场景，也避免小屏上的密集矩阵。

## 2. 现状 vs 独立首页标准（v2 改造后）

| 维度 | v2 实现 | 达标 |
|---|---|---|
| 数据自加载 | `database.init` + `getAllCourses`（当前方案） | ✅ |
| 主题适配 | `store.getTheme` 全变量 + 卡片色为科目色（与主题无关，浅/深色均白字可读） | ✅ |
| 加载态/空态 | 无 loading（数据同步取，极轻）；空天有空态文案 | ✅ |
| 屏型适配 | `width >= 200 / >= 400` 断点放大字号与卡片间距 | ✅ |
| 生命周期 | `onShow` 刷新主题；无定时器（非秒级页） | ✅ |
| 返回逻辑 | 双模 `backClick`/`onBackPress` + `fromPanel`/`isRoot` | ✅ |
| 单日聚焦 | 默认今天 + 滑动切天 + 科目稳定配色 | ✅（本版核心改造） |

## 3. 改造项（相对 v1 矩阵版）

- **结构替换**：删除 5×7 `list` 矩阵与 `initList`/`updateListRows`/`buildScheduleMatrix`/`prevWeek`/`nextWeek`；改为 `dayClasses` 数组 + `renderDay(matrix)` + `reloadDay()`。
- **单日数据**：`dayCursor`（0–6 星期索引，默认 `new Date().getDay()`）→ 取 `matrix[DAY_NAMES[dayCursor]]` → 按时间升序 → 映射为 `{name, time, location, id, color}`。
- **多彩配色**：`PALETTE = [#ff6b6b, #51cf66, rgb(51,154,240), #3b82f6, #f00]`，`self._subjectColors` 按科目名稳定分配（跨实例一致）。
- **滑动切天**：模板 `@swipe="handleSwipe"` → `nextDay`/`prevDay`（clamp 0–6）→ `reloadDay`。
- **模板重写**：`back-header`（返回钮 + 居中标题/星期两行 + 占位）+ `empty-hint` + `scroll` 内 `course-card`（科目色底、白字）。
- 双模返回、`isRoot` 条件渲染、`store.getTheme` 主题适配沿用 v1。
