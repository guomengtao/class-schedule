## 一、结论先说

`watch-face-metal` 目前**不是产品页，是一张调试现场**：5 种「找圆心」辅助线、5 个预设时刻按钮、停止/继续开关、硬编码旧版本号 `v1.8.88`，以及一套**已被实拍证伪的走针方案**（`@keyframes` + 负 `animation-delay` 数据绑定）。

本次重构不复用它的任何走针逻辑，而是**整页重写**，走 `watch-face-evpointer` 已验证通过的那条路线：**60/120 档字面量旋转类 + class 绑定**。视觉上保留并强化「仿古金属」定位（黄铜表壳、罗马数字、铜锈色调），清掉全部调试残留。

## 三、重构目标

### 3.1 视觉
- 184px 黄铜表壳，四层同心色阶造出「厚边 + 内圈倒角 + 做旧盘面」的层次，**不用渐变**（Vela 渐变不稳）。
- 12 个**罗马数字**时标（I–XII，IV 用钟表惯例的 IIII 或 IV，本页取 IV），黄铜色。
- 12 个整点刻度线，绕盘心均匀分布，静态字面量旋转。
- 4 颗表壳铆钉（斜 45° 位置），强化金属装配感。
- 三针：时针/分针做旧黄铜，秒针氧化铜（细针），盘心铜轴。
- 底部：日期 + 大号数字时间 + 「轻触返回」。

### 3.2 交互（与系列其它表盘一致）
- **点击任意位置** → 回表盘目录（`/pages/watch-face-list`）。
- **上滑**（≥40px）→ `/pages/watch-face-evpointer`（环上的上一个）。
- **下滑**（≥40px）→ `/pages/watch-face`（经典表盘，环上收尾回绕）。
- 滑动后抑制当次 click，避免「滑一下顺带退出」。

### 3.3 性能与稳定
- 无 `@keyframes`、无动态 `transform` 值、无群组选择器。
- 静态元素控制在 ~40 个（对比：evpointer 已验收量级 ~37 个）。
- 定时器 1000ms（远高于手册要求的 ≥200ms），`onShow/onHide/onDestroy` 完整启停。

## 四、技术路线（照抄 evpointer 的已验证写法）

### 4.1 三条铁律（复述，避免下次再踩）

1. **禁动态 transform**：`transform: rotate({{deg}}deg)` 会整页黑屏。只允许**字面量** transform。
2. **禁 `@keyframes` 承载当前时刻**：动画合成不可靠（角度漂、针消失、画面冻结）。
3. **引擎旋转轴 = 元素顶部中点**，`transform-origin` 不按 CSS 语义生效。
   4 色标定针实测：`top` 对齐盘心的元素，`rotate(90)` 得到的是盘心**上方 79px** 的横线。

### 4.2 定稿写法

```html
<!-- 针顶压在盘心 (92,92)，向下延伸 -->
<div class="hand hour {{hourCls}}"></div>
```
```css
.hand { position: absolute; }
.hour { left: 89.5px; top: 92px; width: 5px; height: 38px; }
/* 120 档：rotate(180 + 3N)，180° 把「向下」翻成「向上」 */
.r0  { transform: rotate(180deg); }
.r1  { transform: rotate(183deg); }
...
.r119{ transform: rotate(537deg); }
```
```js
this.secondCls = "r" + (Math.round(sec * 6 / 3) % 120)   // 3° 一档
```

### 4.3 本页相比 evpointer 的两点升级

| 项 | evpointer（已验收） | 本页（金属） | 理由 |
|---|---|---|---|
| 角度档位 | 60 档（6°） | **120 档（3°）** | 时针 6° 档 = 每 12 分钟跳一格；3° 档 = 每 6 分钟，机械表观感更接近连续 |
| 表盘结构 | 三层同心环 + 地支 | 四层同心环（多一道内圈倒角）+ 罗马数字 + 铆钉 | 强化「金属厚度」，与青铜指针盘区分 |

### 4.4 刻度定位公式（静态，字面量旋转）

外端定在半径 `R`、角度 `θ`（0=12 点，顺时针）的刻度线：

```
left = 92 + R·sin(θ) - w/2
top  = 92 - R·cos(θ)
transform: rotate(θ)          ← 轴在顶部中点，旋转后自然沿半径向内延伸
```

罗马数字（20×16 文本框居中于该点）：

```
left = 92 + R·sin(θ) - 10
top  = 92 - R·cos(θ) - 8
```

## 九、验收标准

1. **构建**：`aiot release --enable-jsc` 无 error（群组选择器 0、动态 transform 0）。
2. **出画**：192×490 冷启截图非黑、非白。
3. **盘面元素**：OCR 能识别罗马数字/日期/时间；像素扫描确认盘心铜轴、四层环存在。
4. **角度定量**：抓帧记录时刻，理论值 = 时 `(h+m/60+s/3600)×30`、分 `(m+s/60)×6`、秒 `s×6`，实测极坐标峰值需落在 ±3° 内。
5. **走时**：间隔 10s 连采 3 帧，秒针应每帧 +60°（允许固定截图时延）。
6. **交互**：点击返回目录（手测）；上下滑切盘（手测，本轮至少静态核对路由目标）。
