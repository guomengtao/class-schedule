## 一、背景与目标

Ev课程表 已内置 3 款表盘（基础盘 / 课程表盘 LCD 绿荧光 / 金属字针表 金盘），
入口均在「工具」栏目。现需新增一款**面向中学生**的表盘，要求：

- 视觉方向：**潮酷运动科技**（深色底 + 电光强调色，大号数字 + 进度环）。
- 入口：**仅工具栏目新增一行**（设置页不动）。
- 数据：**纯时间 + 日期**（进度环显示秒数推进，不依赖任何传感器权限）。
- 复用现有「隐形多手势退出」方案，符合胶囊屏 UI 规范。

目标：为中学生提供一款「像缩小版智能手表」的潮酷表盘，贴合 2025 表盘榜单
「运动功能数字」红黑科技感（年度人气款），男生女生都易接受。

## 三、设计方案（潮酷运动科技 + DESIGN.md 设计系统）

### 3.1 设计系统（落地为项目根 DESIGN.md）
采用品牌设计技能 9 节格式，定义一套可被后续表盘复用的 token：

| 角色 | Token | 值 | 说明 |
|------|-------|-----|------|
| 背景底 | `--bg` | `#0A0E16` | 深墨近黑 |
| 表层 | `--surface` | `#111824` | 卡片/环底 |
| 强调主色（电光青） | `--accent` | `#25E8D8` | 时间数字、进度环亮段、发光 |
| 强调副色（品红） | `--accent-2` | `#FF2E6E` | 冒号闪烁、高亮点缀 |
| 主文字 | `--text` | `#EAF6FF` | 高对比 |
| 次文字 | `--text-muted` | `#5C6B82` | 日期/周几 |
| 环轨道 | `--ring-track` | `rgba(46,230,214,0.10)` | 进度环底色 |
| 发光 | `--glow` | 同 accent，opacity 0.12~0.5 叠层 | 霓虹辉光 |

字体：快应用引擎字体有限，统一 `font-weight: bold`；时间用最大号，体现「硬核仪表盘」。

### 3.2 布局（192×490，中心 96,240）
- **进度环**：半径 R≈84 的 60 点阵环，当前秒数之前的点亮（accent），其余暗（track），
  形成「随秒推进的数据环」——纯时间驱动，零权限。
- **时间 hero**：居中 `HH:MM`（约 54px 粗体，accent 发光）；冒号品红闪烁；`:SS` 小字（22px）。
- **日期行**：`10-09 周五` 22px `--text-muted`，置于时间下方。
- **品牌标**：底部小字 `EV`（兼作退出热区②，长按 2 秒退出）。
- 视觉：中心受光叠层 + 边缘霓虹辉光，营造夜间运动仪表盘质感。

### 3.3 退出手势（沿用金盘，全部隐形）
① 长按中心 3 秒（六连珠进度反馈）→ 退出
② 长按底部 `EV` 字样 2 秒（转品红反馈）→ 退出
③ 双击右上表冠区（间隔 <500ms）→ 退出
④ 自下往上滑（touchstart/touchend 手写方向判定，位移 ≥40px）→ 退出
⑤ 单击中性盘区 → 退出（最省事）
松手即取消计时，防误触；退出带短震动 `vibrator.vibrate`。

## 五、验收标准（测试纪律 L0–L3）

- **L0 静态**：`manifest.json` 注册正确；页面可经 `router.push` 进入，无白/黑屏。
- **L1 走时**：时间 `HH:MM:SS` 实时刷新；冒号按秒闪烁；进度环随秒推进。
- **L2 手势**：四种隐形退出均可触发；松手取消计时不误退；退出有震动。
- **L3 模拟器实跑**：用 vela CLI 显式型号（手环 10 Pro / 9）跑通，截屏确认
  顶部/底部未被半圆遮挡，进度环完整可见。
- 回归：工具栏目原 3 个表盘入口不受影响。

## 六、风险与对策

| 风险 | 对策 |
|------|------|
| 54px 时间宽度超 192 屏宽 | 实测 `HH:MM` 粗体≈150px，居中留白；超宽则降 48px |
| 进度环 60 点阵过密显脏 | 点径 2px、间距 adequate；暗段 opacity 0.10 弱化 |
| Vela 无 SVG/conic-gradient | 用 60 个绝对定位 div 点阵模拟进度环，规避矢量限制 |
| 与金盘手势热区冲突误退 | 热区坐标独立，单击中性区与专属手势分层（沿用金盘已验证方案） |
| 真机性能/耗电 | 刷新用 setInterval 1s（非逐帧），进度环仅改 opacity，开销低 |
