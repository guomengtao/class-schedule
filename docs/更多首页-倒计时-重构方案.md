# 倒计时 栏目 · 重构方案（更多首页 · countdown）

> 定位：**课程的仪表盘**——课名是整屏最大字，时钟可小可无。
> 判据来自 `docs/表盘盘点与升级方案.md` §九：课名最大 → 此页归「更多首页」；若改成时钟最大，应移出本栏目。

## 0 · 共同约束（七份方案共用，写死勿破）
- 画布 **192×490**，页边距 12，卡片圆角 12。
- 色板：主 `#7ec8e3` / 正文 `#f2fbff` / 次 `#8fa6b5` / 卡底 `#16213e` / 分隔 `#0f3460`。
- **禁区**：带文字的 `transform`（必白屏）、`<scroll>+scrolltop`（引擎不认）、
  `@keyframes` 承载读数（会冻结）。动画只许 `opacity`。
- 数据只走 `require("../../data/store.js")`，分钟级刷新，禁止秒级轮询（除秒相关页）。
- 每个栏目**必须**有一个 120px 高的顶部返回热区，页面根节点不挂 onclick（防 drag 被当点击）。

## 1 · 现状实测
- 文件 `src/pages/schedule-panel-countdown/schedule-panel-countdown.ux`，**199 行**，最大字号 **104px**，已接 store。
- 结构判定（待核对）：104px 是“距上课还有 X 分钟”的大数字。

## 2 · 问题
- 104px 已接近屏宽一半，**再加一位数就会超 192**（3 位数在 104px 下约 180px，4 位数必溢）。
- 倒计时最需要“这是到哪节课”，但大数字占满后课名无处安放。


## 3 · 新结构
| 区 | 内容 | 字号/尺寸 |
|---|---|---|
| A 课名 | 单行省略 | 24px |
| B 大数字 | **最多 3 位**，超时改文案 | 96px |
| C 单位/文案 | `分钟后上课` | 20px |
| D 时间 | `08:00 – 09:35` | 18px |

A 130–158、B 175–275、C 282–306、D 320–342。
**溢出规则**：≥100 分钟时 B 显示 `99+`，C 改为 `分钟后上课`；已上课时 B 显示 `--`。

## 4 · 数据
`store` 取下一节课 `start`，`diff = start - now`；`diff ≤ 0` 时切“上课中”态（B 显示剩余分钟）。

## 5 · 分档实施与回退
| 档 | 内容 | 风险 | 回退 |
|---|---|---|---|
| P0 | 96px + 3 位溢出规则 | 低 | 降到 88px |
| P1 | 上课中/未开始双态 | 中 | 只做未开始 |
| P2 | 秒级刷新（仅上课中） | 中（耗电） | 保持分钟级 |

## 6 · 验收
1. 单测：9 / 99 / 999 / ≥100 分钟四档字号与文案。
2. 实拍：`99+` 不超宽。
3. 分钟级刷新，不引入秒定时器（P2 除外）。
