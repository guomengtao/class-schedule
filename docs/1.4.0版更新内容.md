# 1.4.0版 更新内容

## 概述

v1.4.0 是一个里程碑版本，主要对 README 文档进行了全面重写，同时包含 v1.3.x 系列累积的功能更新。

---

## README 文档全面重写

### 新增版本徽章
- Version 徽章：显示当前版本号 1.4.0
- Platform 徽章：标识 Xiaomi Quick App 平台
- Device 徽章：标识支持 watch 和 band 双设备

### 应用概览重写
从原来的 8 项功能介绍扩展到 **12 项**核心功能：
1. 按天查看课程，支持左右滑动切换日期，默认隐藏周末仅显示周一至周五
2. 快速添加课程（一键添加 + 完整表单 + 预设课程列表三种方式）
3. 实时上课状态感知（正在上课/即将上课/休息中），首页状态栏动态显示
4. 上课前震动提醒，6 种震动模式可选，提前 1-30 分钟可调
5. 多课程表管理，支持创建、切换、复制、重命名、删除
6. 周视图总览，矩阵表格一目了然整周课程分布
7. 9 套主题配色，深空蓝、翡翠绿、珊瑚红、暗夜黑等自由切换
8. 5 档字体大小（28px/36px/48px/62px/76px），全局动态适配
9. 个性化昵称，新用户安装自动随机分配 20 个趣味昵称
10. 首页自定义鼓励语，20 句励志语句随机显示在首页
11. 数据备份与恢复，支持导出/导入课程数据，跨设备迁移
12. 高级版功能，解锁更多主题配色、高级功能，支持激活码激活

### 新增 3 个页面详细介绍

#### 高级版激活页（`pages/activation`）
- 激活码输入：输入 16 位激活码解锁高级版
- 高级功能预览：展示解锁后可用的功能列表
  - 全部 9 套主题配色
  - 高级震动模式
  - 数据备份与恢复
  - 课程表管理
  - 数据重置
  - 功能实验室
- 激活状态持久化：通过 `premium_activation` 存储键保存激活状态
- 非高级用户访问受限页面时自动弹出升级提示弹窗

#### 数据备份与恢复（`pages/backup-restore`）
- 创建备份：将当前所有课程表数据打包为 JSON 备份文件
- 备份列表：展示所有历史备份，带时间戳和课程数量摘要
- 恢复备份：选择任意备份恢复课程数据
- 删除备份：长按或滑动删除历史备份
- 预览备份：点击备份可预览其中包含的课程表和数据概览
- 非高级用户进入页面自动弹出升级提示

#### 功能实验室（`pages/lab`）
- Debug 模块：开发者调试工具
- 钉首页开关：控制首页"钉首页"功能区域的显示
- 实验性功能可能随时调整或移除

### 核心亮点新增 3 个章节

#### 多主题配色系统
- 9 套精心设计的主题配色：深空蓝、翡翠绿、珊瑚红、暗夜黑、暗紫魅影、晨光白、暖阳米、墨绿护眼、琥珀金
- 深空蓝为基础免费主题，其余 8 套为高级版主题
- 全局统一响应，切换主题后所有页面即时生效
- 适合 OLED 屏幕手表的深色主题，护眼且省电

#### 数据备份与恢复
- 一键备份所有课程表数据为 JSON 文件
- 支持多版本备份管理，带时间戳和课程数量摘要
- 备份预览功能，恢复前可查看数据概览
- 跨设备数据迁移，换手表无缝衔接

#### 高级版功能体系
- 激活码激活机制，支持 16 位激活码
- 高级功能：全部主题配色、高级震动模式、数据备份恢复、课程表管理、数据重置、功能实验室
- 非高级用户访问受限页面时自动弹出底部升级提示弹窗
- 激活状态持久化存储，卸载重装后可重新激活

### 数据架构更新
存储层级从 7 个键扩展到 **12 个键**，新增：
- `appTheme` — 主题配色
- `hideWeekend` — 隐藏周六日
- `homepage_settings` — 首页设置
- `premium_activation` — 高级版激活状态
- `backup_list` — 备份记录列表
- `course_preset_list` — 预设课程列表

### 项目结构更新
新增 7 个组件/页面目录：
- `components/unlock-dialog/` — 升级弹窗组件
- `pages/activation/` — 高级版激活
- `pages/backup-restore/` — 数据备份与恢复
- `pages/lab/` — 功能实验室
- `pages/reset-data/` — 数据重置
- `pages/vibration-lab/` — 震动实验室
- `pages/chinese-input/` — 中文输入

### 技术栈更新
- 数据存储：从 "SQLite + Storage" 更新为 "SQLite + @system.storage"
- 新增"版本管理"条目：语义化版本 + 自动增量构建号
- 目标设备：从 "智能手表（watch）" 扩展为 "智能手表（watch）、手环（band）"

## v1.3.x 系列累积功能更新

### 课程表管理页
- 新增进入页面即检查高级版状态，非高级用户自动弹出升级弹窗
- 每次页面显示（onShow）也会检查并弹出

### 设置页
- 主题配色区域点击时检查高级版状态，非高级用户从底部弹出升级弹窗
- 弹窗"暂不需要"按钮仅关闭弹窗，留在设置页面
- 弹窗"立即解锁"按钮跳转到激活页面
- 点击弹窗外空白区域也可关闭弹窗

### 新用户默认配置优化
- 字体大小默认值从 48px 改为 **28px**
- 昵称默认从空字符串改为 **20 个学生昵称随机选取**
- 首页自定义文字默认开启，**20 句鼓励语句随机选取**
- 周六日默认隐藏（不显示），仅显示周一至周五
- 首页设置默认仅开启：快速添加、上课提醒、时间显示、总按钮、自定义文字
- 首页设置默认关闭：钉首页、今按钮、明按钮、功能实验室

### 文档
- 新增 `docs/默认配置参数说明.md`，完整记录所有默认配置参数
