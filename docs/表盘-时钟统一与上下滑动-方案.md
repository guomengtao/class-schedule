## 二、侦察结论（2026-10-10 实测）

| 维度 | 经典表盘 `watch-face.ux`（59 行）| 课程表盘 `watch-face-class.ux`（592 行）|
|---|---|---|
| 时钟字号 | **48px** | 44px(数字) / 36px(冒号) / 18px(秒) |
| 时钟颜色 | **`#e8e4da` 米白** | `#7dffb0` 青绿荧光 |
| 时钟位置 | **flex 水平垂直居中** | 绝对定位 `left:8px top:78px` |
| 页面底色 | `#1a1a2e` | `#0a0e12` |
| 其他内容 | 仅时钟 + 返回 | 状态条 / 课程卡 / 进度条 / 时间轴 / 隐形热区 |

**基准方（经典表盘）时钟样式原文：**
```css
.clock { font-size: 48px; color: #e8e4da; font-weight: bold; letter-spacing: 4px; }
```
```css
.page { flex-direction: column; justify-content: center; align-items: center; }
```

**既有手势冲突（必须处理）：**
`watch-face-class.ux` 已用 `ontouchstart` / `ontouchend` 实现「**自下往上滑 → 退出回目录**」（文件头注释第 9 行）。
新增「上滑切表盘」会与它**抢同一个手势**，必须二选一。

**平台约束：**
Vela **不支持 `onswipe` / `onSwipe`**（同注释第 9 行注明），只能手算 touch 方向。

## 四、待你定夺项（方案里唯一不确定的地方）

**课程表盘的时钟「居中」做不到照搬。**
经典表盘是全屏只有时钟，所以能"画面正中"。课程表盘是整屏 LCD 布局（上方状态条、下方课程卡+进度条+时间轴），时钟挪到画面正中会**直接压住课程卡片**。

三选一：

| 选项 | 说明 |
|---|---|
| **A（推荐）** | 字号/颜色/字距统一为 `48px / #e8e4da / 4px`，**位置保持** `left:8 top:78`。视觉一致、不破坏布局 |
| B | 时钟行在**原区域内水平居中**（`clock-row` 加 `justify-content:center`），位置不变但更"整齐" |
| C | 真按"画面正中"挪——需重新排布下方所有元素，**工作量翻倍且大概率变丑** |

## 五、路由与返回栈设计

```
表盘目录 --push--> 经典表盘A --(上滑 replace)--> 课程表盘B
                     ↑                              |
                     └-------- (下滑 replace) -------┘
```
- 互切用 **`router.replace`**（不堆栈）；栈里始终只有「目录 → 当前表盘」两层。
- 「返回」按钮 `router.back()` → **直接回表盘目录**，语义正确。

## 十、扩展：五个表盘全部加入上下滑动（2026-10-10 08:40）

用户追加需求：**五个表盘全部**加入上下滑动切换（原方案只覆盖前两个）。

### 切换环（按「表盘目录」watch-face-list 的列示顺序）
```
① 经典 watch-face            上滑↑ → ⑤        下滑↓ → ②
② 课程 watch-face-class      上滑↑ → ①        下滑↓ → ③
③ 金属字针 watch-face-gold   上滑↑ → ②        下滑↓ → ④
④ EV指针 watch-face-evpointer 上滑↑ → ③       下滑↓ → ⑤
⑤ 仿古金属 watch-face-metal  上滑↑ → ④        下滑↓ → ①（环回）
```
**统一规则：上滑 = 上一页（序号 −1），下滑 = 下一页（序号 +1），首尾相接成环。**

### 各页改造前的手势现状（实测）
| 页面 | 改造前 |
|---|---|
| watch-face | 上轮已加，**仅下滑** |
| watch-face-class | 上轮已加，**仅上滑**（原「上滑=退出回目录」已被取代）|
| watch-face-gold | **无任何手势**，只有返回按钮 |
| watch-face-evpointer | **无任何手势**，只有返回按钮 |
| watch-face-metal | **无任何手势**，`onFaceTap` = `router.back()` |

⇒ 后三页加滑动**零冲突**；`metal` 底部「停止 / 12:00 / 返回」等按钮不受影响——切换阈值 40px，点击位移为 0，不会误触。

### 实现方式（含取舍）
各页**内联**同一套 `onTouchStart` / `onTouchEnd`，**未抽公共模块**。
理由：表盘页有**黑屏前科**（见 `docs/表盘开发黑屏记录与防黑屏.md`），Vela 对跨模块 `require` 的行为未经验证，**优先选零新文件的最低风险路线**。
代价：5 份重复代码，将来调阈值要改 5 处——**已记录为已知债**。

## 十一、经典表盘重做：极简大数字 + 去返回按钮（2026-10-10 08:45）

**用户要求**：重新设置经典表盘，"体现经典即可"；**去掉里面的返回按钮**；界面工整、简单。
**用户裁定**：形态 = **纯大数字（极简）**；退出 = **长按 + 双击都要**。

### 设计
- **全屏只有一个元素**：`HH:MM` —— 68px / 米白 `#e8e4da` / `letter-spacing: 2px` / flex 水平垂直居中。
- **秒被去掉**（"纯大数字"）；底色保持 `#1a1a2e`，与其他表盘一致。
- **返回按钮删除**，`goBack()` 方法一并移除。

### 退出（两条，全部隐形，不占画面）
| 途径 | 实现 | 反馈 |
|---|---|---|
| 长按 2 秒 | `onlongpress` → `setTimeout(2000)`；`ontouchend` 里 `clearPress()` 做到**松手即中止** | 满 2 秒震动一下 → `router.back()` |
| 双击 | `onclick` → 两次间隔 <500ms 触发 | 震动一下 → `router.back()`（与长按共用 `exit()`）|

四类事件挂在同一个 `.page` 上：`ontouchstart` / `ontouchend` / `onlongpress` / `onclick`。
**不冲突的理由**：滑动切页要求 Y 位移 ≥40px，而长按与双击的位移都是 0。

### ⚠️ 副作用（已知照会）
经典表盘时钟由 **48px → 68px**，课程表盘**仍是 48px** ⇒ §三 建立的「两页时钟规格统一」**已被本次重做打破**。若仍要统一，需另行决定跟哪一边。
