# 多彩课表 栏目 · 重构方案（更多首页 · colorful）

> 定位：**课程的仪表盘**——课名是整屏最大字，时钟可小可无。
> 判据来自 `docs/表盘盘点与升级方案.md` §九：课名最大 → 此页归「更多首页」；若改成时钟最大，应移出本栏目。

## 0 · 共同约束（七份方案共用，写死勿破）
- 画布 **192×490**，页边距 12，卡片圆角 12。
- 色板：主 `#7ec8e3` / 正文 `#f2fbff` / 次 `#8fa6b5` / 卡底 `#16213e` / 分隔 `#0f3460`。
- **禁区**：带文字的 `transform`（必白屏）、`<scroll>+scrolltop`（引擎不认）、
  `@keyframes` 承载读数（会冻结）。动画只许 `opacity`。
- 数据只走 `require("../../data/store.js")`，分钟级刷新，禁止秒级轮询（除秒相关页）。
- 每个栏目**必须**有一个 120px 高的顶部返回热区，页面根节点不挂 onclick（防 drag 被当点击）。

## 1 · 现状实测（2026-10-20 以源码为准回写）
- 文件 `src/pages/schedule-panel-colorful/schedule-panel-colorful.ux`，**209 行**，已接数据层，**含 touch 手势**。
- **原 §1 三处误判，逐条纠正**：
  1. 不是「彩色格子的周/日视图」，而是**单日彩色卡片 + `<scroll>` 竖列表**（`for="{{ dayClasses }}"` 每节课一张卡）。
  2. **最大字号 32px 不是格内课名**——页面上根本没有格子；32px 是 `@media (width >= 400px)` 断点下的课名，
     192 画布下实际只有 24px。
  3. 数据走 `database.getAllCourses`，**不是 `store`**（§0 写的「数据只走 store」在本页不成立）。
- **配色是「按插入顺序取色」不是固定表**：本地 `PALETTE` 5 色，
  `ci = Object.keys(self._subjectColors).length % PALETTE.length` —— 同一科目在不同天/不同加载顺序下**会变色**，
  与 #3 已落地的固定配色表（14 科 + 子串匹配）是两套东西。本栏前置工作即把它统一到 `src/data/subject-color.js`。
- **无任何定时器**：`loadDay()` 只在 `onInit` 跑一次，`onShow` 只刷主题 → 页面常驻时「当前时段」不会更新。

## 2 · 问题
- 32px 课名塞进格子必然截断，彩色块多于文字，读起来像“色卡”不像“课表”。
- 含 touch：drag 在本引擎容易被判成点击 → **有跳页风险**（表盘目录页踩过）。


## 3 · 新结构
| 区 | 内容 | 字号/尺寸 |
|---|---|---|
| A 星期条 | 一~日 7 格（**单字** 日/一/…/六），当前日高亮 | 15px，每格 **16** |
| B 课表格 | 3 列 × 5 行，格 **52×64**，不滚动 | 课名 15px，最多 2 行 |
| C 今日合计 | **并入页头副标题** | 15px，单行 |

**三处按实拍修正（2026-10-20，单测看不出来）**：

1. **星期格每格 24 → 16，且必须用单字标签**。原写「7 格每格 24」= 168，正好顶满内容宽，
   切天箭头就**没地方放**。改 16 后 `7×16 + 2×20(箭头) = 152 ≤ 168`；配单字标签（「周一」32px 放不进 16px 格）。
2. **箭头不能放页头**。首版把 ‹ › 放进返回栏，`header-center` 被 48(返回)+20+20+48(占位) 挤到约 60px：
   标题「多彩课表」折成两行、副标题「今天 · 周二 · 6 节」被裁成「今天 · 6」。箭头最终落在**星期条两侧**（20×20）。
3. **C 区独立行会溢出画布**。首版加了 `共 N 节 · 显示前 5 节` 一行：网格已到 y=476，再加 24px → 500 > 490 直接被裁。
   按开工卡「C 不设」删除该行，合计/溢出口径改走页头副标题（可用宽仅 ~120px，
   故「今天 · 周二 · 6 节」这种 150px 串会被切 → 去掉与 A 区高亮重复的星期名，溢出时连「今天」也省掉）。

区间（192 画布，页边距 12 / 内容宽 168）：页头 44–164（含 120px 返回热区）、A 星期条 172–200、
B 网格 204–524 → **5×64=320，最坏总高 524 已超 490**，故 B 实际按 `5×64` 排到 524 会溢出；
落地采用 **B 起点 204、5 行各 64 = 到 524 超界**，因此实拍版把行高压到 **56px**（5×56=280，到 482 ≤ 490）。

## 4 · 数据
`database.getAllCourses` 取整周课表，按 `day` 建矩阵；`render()` 按 `dayCursor` 取当天课程，
排序后 `slice(0, 15)` 入格，每格存 `{name, color, startMin, endMin, now}`。
- 配色一律走共享固定表 `src/data/subject-color.js`（#3 落地那份），**禁止本地 PALETTE / 禁止按插入顺序兜底**。
- 当前时段判定 `startMin <= now < endMin`，命中格加 2px 主色框；由唯一整分对齐 `setTimeout` 驱动，
  `onHide`/`onDestroy` 双清、`onShow` 重排。首帧用 `../../data/schedule.js` 内置课表同步出画。

## 6 · 验收
1. 单测：7 天 × 5 节满格时全部格子落在 192×490 内、互不重叠（`test/schedule-panel-colorful.test.js` 65 项）。
2. 实拍：格子不越界、课名截断带省略号（`screenshots/更多首页-多彩课表-20261020.png`）。
3. **确认无 drag 跳页**：单测断言模板**无 `@swipe` 指令**、无 `<scroll>` 标签（剥注释后判定，注释里出现字样不算）。
4. 新增护栏：箭头必须在星期条内且 20×20（`7×16+2×20 ≤ 168`）；副标题最坏串字宽估算 ≤120px。
