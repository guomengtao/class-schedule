# 简易课表（schedule-panel-simple）重设计方案

> **版本**：v2.0（2026-10-15）
> **目标**：重新设计「课程面板 → 简易课表」页面，从无结构的平铺列表改为按天分组、含时间地点、高亮今日的清晰课表视图。

---

## 一、现状分析

### 1.1 页面位置

```
设置 → 课程面板 → 简易课表
                → 当前进度
                → 剩余课程
                → 科目色卡
                → 倒计时
                → 智能切换
                → 多彩课表
```

路由：`/pages/schedule-panel-simple`，文件：`src/pages/schedule-panel-simple/schedule-panel-simple.ux`

### 1.2 当前实现

```
┌──────────────────────────────┐
│  ← 简易课表                   │  ← 标题行 + 返回（app.terminate）
├──────────────────────────────┤
│  [icon] 周一 数学             │
│  [icon] 周一 英语             │
│  [icon] 周一 物理             │
│  [icon] 周二 语文             │
│  [icon] 周二 数学             │
│  [icon] 周三 化学             │
│  ...                         │  ← 所有课程全部平铺，不分天
└──────────────────────────────┘
```

**问题**：
| 问题 | 详情 |
|:--|------|
| 无天分组 | 25 门课全部平铺，周一/周二混在一起无法区分 |
| 无时间 | 不知道每节课几点上、几点下 |
| 无地点 | 不知道在哪间教室 |
| 无今日高亮 | 看不出今天是周几、哪些是今天的课 |
| 无交互 | 点击跳课程表管理，而非课程详情 |
| 返回退出 App | `app.terminate()` 来自官方模板，不应退出 |

### 1.3 数据源

```javascript
// database.getAllCourses(callback) 返回：
[
  { day: "星期一", classes: [{ id, name, time, teacher, location, notes }, ...] },
  { day: "星期二", classes: [...] },
  ...
]
```

数据结构已包含 `day`、`name`、`time`、`location` 全部字段，当前只用了 `day` + `name`。

## 二、设计目标

> **「简易课表」= 一眼看清本周所有课程，按天组织，今日突出。**

| 维度 | 当前 | 目标 |
|------|------|------|
| 组织结构 | 平铺列表 | 按天分组，每天一个 section |
| 单条信息 | 周X 课程名 | 课程名 + 时间 + 地点 |
| 今日标识 | 无 | 今日 section 用 accent 色标记 |
| 点击行为 | 跳课程表管理 | 跳课程详情页（或保留管理入口） |
| 返回行为 | app.terminate | router.back() |
| 适配 | 仅 pill-shaped 缩窄 | 触底自适应（base=手环9） |
| CSS 框架 | 官方 settings less + 原子类 | 项目统一触底自适应 CSS |

## 三、新设计方案

### 3.1 页面布局

```
┌──────────────────────────────┐
│  ← 返回    简易课表            │  ← 统一 back-header
├──────────────────────────────┤
│  星期一               4 门课  │  ← day-section（今日 accent 色）
│  ┌──────────────────────────┐│
│  │ 数学  08:00-08:45  301   ││  ← 课程行：名称 + 时间 + 地点
│  ├──────────────────────────┤│
│  │ 英语  08:55-09:40  205   ││
│  ├──────────────────────────┤│
│  │ 物理  10:00-10:45  实B   ││
│  ├──────────────────────────┤│
│  │ 化学  10:55-11:40  实A   ││
│  └──────────────────────────┘│
├──────────────────────────────┤
│  星期二               4 门课  │
│  ┌──────────────────────────┐│
│  │ 语文  08:00-08:45  205   ││
│  │ 数学  08:55-09:40  301   ││
│  │ 历史  10:00-10:45  102   ││
│  │ 物理  10:55-11:40  实B   ││
│  └──────────────────────────┘│
├──────────────────────────────┤
│       ...（滚动查看更多天）     │
└──────────────────────────────┘
```

### 3.2 设计要点

#### 3.2.1 按天分组

- 每一天一个 section，包含：
  - **天标题**：星期名 + 课程数量
  - **课程列表**：该天所有课程按时间排序

#### 3.2.2 今日高亮

- 今天的 section 天标题用 `theme.accent` 色
- 其他天用 `theme.text` 色
- section 之间用分隔线区分

#### 3.2.3 课程行信息

每行展示：**课程名（bold） + 时间（accent 色） + 地点（muted 色）**

- 胶囊屏 198px 宽：单行紧凑，地点超长时换到第二行
- 方屏 400px 宽：同行展示

#### 3.2.4 点击行为

- 点击课程行 → 跳转该课程的详情页 `/pages/detail`
- 参数传递：`courseId` + `day`

#### 3.2.5 返回行为

- 返回按钮 → `router.back()` 回到课程面板目录

### 3.3 空状态

- 无课表数据时：显示「暂无课程数据」
- 某天无课时：不显示该天的 section

## 四、CSS 适配方案（触底自适应）

按照项目规则 §10 的标准四层结构：

```css
/* ================================================================
   BASE CSS = 手环 9 基准（160px 内容区）
   手环 9 默认命中，弹性 flex + % 撑满
   ================================================================ */

/* page / back-header / scroll / section-header / course-row 的 base 值 */

/* ================================================================
   宽度断点：width >= 200px（胶囊屏大号）
   在 base 基础上增量调整
   ================================================================ */
@media (width >= 200px) {
  /* 字号 / padding 微增 */
}

/* ================================================================
   宽度断点：width >= 400px（方屏 Watch 6）
   字号更大、间距更大
   ================================================================ */
@media (width >= 400px) {
  /* 进一步放大 */
}

/* ================================================================
   圆形表盘：唯一保留的 shape 查询
   ================================================================ */
@media (shape: circle) {
  /* 圆屏特定调整 */
}
```

**禁止**：`@media (shape: pill-shaped)`、`lines:` 属性、`text-overflow: ellipsis`

## 五、代码改动清单

| 文件 | 改动内容 |
|------|---------|
| `schedule-panel-simple.ux` | **全部重写**：模板、脚本、样式 |
| `index.less` | 可删除或大幅简化（不再使用官方 less） |

### 5.1 改动范围

- **模板**：`<list>` + `<list-item>` → `<scroll>` + `<div>` 分组结构
- **脚本**：数据库查询逻辑不变，新增按天分组、今日判断、详情跳转
- **样式**：从 `@import "./index.less"` + 原子类 → 触底自适应四层 CSS
- **返回**：`app.terminate()` → `router.back()`

### 5.2 不改变的部分

- `schedule-panel/data.js`：目录页数据源不变（路径 `schedule-panel-simple` 保留）
- `manifest.json`：路由注册不变
- 数据库读取方式不变（`database.getAllCourses`）

## 六、兼容性检查清单

实施时逐项验证：

- [ ] **触底自适应**：base = 手环 9，用 `width >= 200px` / `width >= 400px` / `shape: circle`
- [ ] **禁止 `lines:`**：无文本截断属性
- [ ] **禁止 `text-overflow: ellipsis`**：无省略号
- [ ] **禁止 `@media (shape: pill-shaped)`**：移除现有 pill-shaped 查询
- [ ] **overlay 定位 inline**：如有弹窗，定位写在 inline style
- [ ] **文字不截断**：胶囊屏 198px/24px 字号下所有文字完整可见
- [ ] **构建验证**：`npm run release` RPK ≤ 1MB

## 七、与同系列面板的一致性

参考同目录下已完成的 panel 页面，保持风格统一：

| 面板 | 风格 |
|------|------|
| `schedule-panel-progress` | 统一 back-header + 触底自适应 CSS |
| `schedule-panel-dual-mode` | 同上 |
| `schedule-panel-colorful` | 官方 calendar 模板 |

新版 `schedule-panel-simple` 应与 progress/dual-mode 保持相同的 back-header 结构（返回按钮 + 居中标题 + 占位对称），CSS 采用触底自适应四层结构。
