## 1. 页面定位（重新规划）

「智能切换」是**当前进度 + 倒计时两页的合体态**：顶部模式徽标（「上课中 · 进度」/「课间 · 倒计时」），上课中渲染进度卡（课名 + 时间 + 进度条 + 已过/剩余），课间渲染倒计时卡（大字 mm:ss + 下节课信息），结课/无课渲染 🎉 完结态。

作为独立首页的差异化价值：**一页覆盖全天**——不用用户自己判断此刻该看进度还是倒计时，页面按时间自动切换形态，是 7 页中最「智能」的默认首页候选。保留现有信息结构。

## 2. 现状 vs 独立首页标准

| 维度 | 现状 | 达标 |
|---|---|---|
| 数据自加载 | `database.init` + `getAllCourses` | ✅ |
| 主题适配 | `store.getTheme` 全变量 | ✅ |
| 加载态/空态 | 加载中 + 三形态 + 结课/无课文案 | ✅ |
| 屏型适配 | `width >= 200 / >= 400` 断点 | ✅ |
| 生命周期 | 10s 定时器 + `onDestroy` 清理 | ✅ |
| 返回逻辑 | `goBack()` 直接 `router.back()` | ❌ |

**唯一缺口**：返回逻辑（同前 4 页）。

## 3. 改造项

按标准 v1 第 1 条（同第 1 页模式）：`fromPanel`/`isRoot`、返回钮+占位符条件渲染、`goBack` 双模、`onBackPress` 双模、`require utils.js`。
