# 添加课程栏目开发需求文档

> 本文档从用户角度描述"添加课程"栏目的功能需求和界面要求，不涉及任何技术实现细节。

---

## 一、栏目概述

"添加课程"栏目包含两个页面：
- **添加课程页**：用户选择课程、设置时间和地点，将课程添加到指定日期的课表中
- **课程管理页**：管理预设课程库（添加、编辑、删除课程名称），供添加课程页使用

两个页面关系：添加课程页横向滚动选择课程 → 点击「管理」进入课程管理页 → 管理完成后返回添加课程页

### 2.1 顶栏

**功能需求**：
- 左侧返回按钮（◀），点击返回上一页
- 居中显示页面标题「添加课程」

**界面要求**：

| 元素 | 方屏 | 胶囊屏 |
|------|------|--------|
| 返回按钮 | 52×52 圆形，字号28px | 38×30 圆角，字号20px |
| 标题字号 | 30px，加粗 | 28px |
| 页面内边距 | 上下30px，左右16px | 上下30px，左右8px |

### 2.2 选择课程

**功能需求**：
- 横向可滚动展示预设课程列表，每门课程为一个卡片
- 点击课程卡片选中该课程，选中卡片高亮显示（边框变色）
- 选中课程后，自动填入该课程关联的默认时间、默认位置
- 列表末尾固定显示一个「+」卡片，点击跳转到课程管理页新增课程
- 右侧「管理」按钮，点击跳转到课程管理页编辑课程库
- 从课程管理页返回后，课程列表自动刷新
- 首次使用时，系统提供12门默认课程（语文、数学、英语、物理、化学、生物、历史、地理、政治、音乐、美术、体育）
- 课程列表按上课时间排序

**界面要求**：

| 元素 | 方屏 | 胶囊屏 |
|------|------|--------|
| 章节标题 | 26px，加粗 | 24px |
| 课程卡片尺寸 | 100×64px | 88×56px |
| 课程卡片圆角 | 14px | 10px |
| 课程名称字号 | 26px，加粗，居中 | 24px，加粗，居中 |
| 光标间间距 | 10px | 6px |
| 选中卡片边框 | 2px实线边框（主题色） | 同方屏 |
| 「+」卡片 | 同尺寸，背景浅色 | 同方屏 |
| 「+」字号 | 40px，加粗 | 34px |
| 管理按钮 | 60×40，圆角12px，字号22px | 48×30，圆角8px，字号22px |
| 滚动区域高度 | 72px | 60px |

- 课程名称单行显示，超出用省略号，不可换行

### 2.3 上课时间

**功能需求**：
- 显示两个时间选择框：「开始时间」和「结束时间」
- 中间用「至」字分隔
- 点击开始时间框，弹出时间调节面板，默认选中开始时间
- 点击结束时间框，弹出时间调节面板，默认选中结束时间
- 时间调节面板包含：
  - **时**：左侧「-」按钮 + 当前数值 + 右侧「+」按钮，范围为 00-23，循环
  - **分**：左侧「-」按钮 + 当前数值 + 右侧「+」按钮，步进5分钟（0→5→10...55），循环
  - **确定**按钮：点击确认当前调节的时间，面板收起
- 选中课程后，自动填入该课程的默认时间段
- 确认时间后，「开始」和「结束」显示框立即更新

**界面要求**：

| 元素 | 方屏 | 胶囊屏 |
|------|------|--------|
| 章节标题 | 26px，加粗 | 24px |
| 时间显示框尺寸 | 150×70px | 自适应宽度（平分） |
| 时间显示框圆角 | 14px | 10px |
| 时间数值字号 | 32px，加粗 | 24px |
| 开始/结束标签字号 | 20px | 20px |
| 「至」分隔字号 | 26px，加粗 | 20px |
| 「至」左右间距 | 12px | 2px |
| 调节面板按钮 | 44×44，圆角10px，字号24px | 44×44，圆角10px，字号24px |
| 调节面板数值 | 30px，加粗，宽52px | 24px，宽40px |
| 时/分标签 | 24px，宽40px | 22px，宽32px |
| 确定按钮 | 100×44，圆角10px，字号24px | 88×44，圆角10px，字号22px |

- 调节面板带圆角卡片背景，内容居中
- 各组之间有小间距

### 2.6 底部操作栏

**功能需求**：
- **取消按钮**：点击返回上一页，不保存任何内容
- **确认添加按钮**：点击保存课程到当前课表
  - 保存前校验：未选择课程 → 提示「请先选择课程」
  - 保存前校验：未设置时间 → 提示「请先设置时间」
  - 保存成功后提示「课程已添加」，自动返回上一页
  - 保存失败提示「保存失败，请重试」
  - 保存中防止重复点击（isSaving 锁定）

**界面要求**：

| 元素 | 方屏（横向排列） | 胶囊屏（纵向排列） |
|------|------|------|
| 取消按钮 | flex占1份，高48px | 全宽，高44px |
| 确认按钮 | flex占2份，高48px | 全宽，高48px |
| 按钮圆角 | 14px | 10px |
| 按钮字号 | 26px，加粗 | 24px，加粗 |
| 按钮间距 | 12px | 上下8px |

- 取消按钮：浅灰色背景 + 灰色文字
- 确认按钮：主题色背景 + 白色文字
- 取消在上，确认在下（胶囊屏纵向时）

## 三、课程管理页

### 整体布局

```
┌─────────────────────────────────┐
│  ◀ 返回      课程管理   [+ 添加] │    ← 顶栏
├─────────────────────────────────┤
│  清除全部                  [清除]│    ← 清空操作行
├─────────────────────────────────┤
│  ① 语文             [编辑][删除] │
│  ② 数学             [编辑][删除] │    ← 课程列表（可滚动）
│  ③ 英语             [编辑][删除] │
│  ...                            │
├─────────────────────────────────┤
│         暂无课程（空状态）         │
└─────────────────────────────────┘
```

### 3.1 顶栏

**功能需求**：
- 左侧返回按钮（◀），点击返回上一页
- 中部显示页面标题「课程管理」
- 右侧「+ 添加」按钮，点击跳转到文字输入页面新增课程

**界面要求**：

| 元素 | 方屏 | 胶囊屏/圆形屏 |
|------|------|------|
| 返回按钮 | 48×40，圆角20px，字号22px | 44×40，圆角20px，字号22px |
| 标题 | 28px，加粗，居中 | 26px |
| 添加按钮 | 80×40，圆角20px，字号22px | 64×40，圆角20px，字号22px |

### 3.2 清除全部

**功能需求**：
- 仅课程列表不为空时显示
- 首次点击「清除」按钮，变为确认模式：按钮变为红色「确认」，左侧提示「再次点击确认」
- 在确认模式下再次点击「确认」，清空所有课程
- 5秒超时自动取消确认模式，恢复初始状态

**界面要求**：

| 元素 | 规格 |
|------|------|
| 提示文字 | 20px，红色文字 |
| 清除按钮（普通） | 64×40，圆角20px，字号22px |
| 清除按钮（确认） | 同尺寸，红色背景 + 白色文字 |

### 3.3 课程列表

**功能需求**：
- 每门课程显示：序号（圆形编号）、课程名称、编辑按钮、删除按钮
- 课程列表按上课时间排序
- **编辑按钮**：点击跳转到文字输入页面，预填当前课程名称，输入完成后更新课程名称
  - 重名检测：新名称与列表内其他课程重名时提示「名称已存在」，不保存
  - 名称未变化时不做任何操作
  - 更新成功提示「已更新」
- **删除按钮**：需要二次确认
  - 首次点击「删除」，按钮变为「确认」（红色），5秒超时自动恢复
  - 在确认模式下再次点击「确认」，删除该课程
  - 删除成功提示「课程已删除」
- **添加课程**：点击顶栏「+ 添加」，输入新课程名称
  - 空名称不做任何操作
  - 重名检测：提示「名称已存在」
  - 添加成功后自动按时间排序，提示「已添加」
- 新添加的课程默认时间段为 08:00-08:45

**界面要求**：

| 元素 | 方屏 | 胶囊屏/圆形屏 |
|------|------|------|
| 卡片圆角 | 10px | 14px |
| 卡片内边距 | 10px | 10-12px |
| 序号圆标 | 30×30，圆形，白色数字20px | 30×30 同 |
| 课程名称 | 28px，加粗，单行省略号 | 28px |
| 编辑按钮 | 56×40，圆角20px，字号22px | 56×40 同 |
| 删除按钮 | 56×40，圆角20px，字号22px | 56×40 同 |
| 卡片间距 | 8px | 8px |
| 卡片内布局 | 横向排列 | 纵向排列（名称上方，操作按钮下方） |

- 编辑按钮：主题色背景 + 白色文字
- 删除按钮（普通）：浅红背景 + 红文字
- 删除按钮（确认）：红色背景 + 白文字
- 课程名称单行，超出省略号

### 3.4 空状态

**功能需求**：
- 课程列表为空时显示「暂无课程」提示

**界面要求**：
- 居中显示，上下内边距40px

## 七、交互规范

### 7.1 时间调节步进
- **时**：每次 ±1，范围 0-23，循环（23 → + → 0，0 → - → 23）
- **分**：每次 ±5，范围 0-55，循环（55 → + → 0，0 → - → 55）

### 7.2 确认/删除二次防误触
- 首次点击显示确认状态，按钮文字和颜色变化
- 5秒内未再次点击自动取消确认状态
- 确认状态下再次点击才执行实际操作

### 7.3 保存防重复
- 保存操作中（isSaving=true），重复点击无响应
- 保存完成或失败后恢复可点击状态

### 7.4 Toast提示汇总

| 场景 | 提示文字 |
|------|----------|
| 未选择课程 | 请先选择课程 |
| 未设置时间 | 请先设置时间 |
| 保存成功 | 课程已添加 |
| 保存失败 | 保存失败，请重试 |
| 编辑-名称重复 | 名称已存在 |
| 编辑-名称未变 | （无提示，静默跳过） |
| 编辑成功 | 已更新 |
| 删除成功 | 课程已删除 |
| 添加成功 | 已添加 |
| 清空成功 | 所有课程已清除 |
