## 一、总体结论

| 指标 | 数值 |
|------|------|
| 页面总数 | 33 |
| 已有 @media (shape: capsule) 适配 | 31（含 1 个故意缺失的测试页） |
| 完全缺失胶囊屏适配 | **1**（lab-settings） |
| 适配不完整（padding/字号未对齐规范） | **31** |
| 违规使用 transform:scale() | **1**（donate） |
| 需要实质性优化 | **32** |

**核心问题**：所有已适配页面的 `padding-top` 都是 **44px**，但规范 v1.1 明确要求 **30px** 半圆避让（将内容推到 y=120 以下，即半圆底边 y=96 以下 24px 的安全区）。44px 只够放头部返回按钮，下方列表项顶部仍在半圆覆盖区域内，**有被遮挡的风险**。

## 四、统一修改模板

对每个需要 padding-top 修正的页面，在 `@media (shape: capsule)` 块中将：

```css
/* 修改前 */
.page-root {
  padding: 44px 10px 12px 10px;
}

/* 修改后 */
.page-root {
  padding: 30px 10px 30px 10px;
}
```

> **注意**：改为 30px 后，头部返回按钮区域需要重新规划。如果头部用绝对定位（`position: absolute; top: 20px`），则正文从 `padding-top: 30px` 开始，头部浮在 padding 区内。参考规范 v1.1 §7 头部处理方案。
