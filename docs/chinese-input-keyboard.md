# 中文输入键盘说明

## 概述

`chinese-input.ux` 页面使用**内联精简键盘**，是一个完全自定义的轻量级中文输入方案，**并非 QuickApp 框架内置功能**。

## 它是框架默认支持的吗？

**不是。** QuickApp 框架本身不提供中文输入法组件。原来的 `InputMethod` 组件是一个第三方组件，包含三种屏幕类型（圆形屏 circle、方形屏 rect、胶囊屏 pill-shaped）的完整键盘布局，使用了大量 PNG 图片作为按键，编译后体积高达 **1.3MB**，导致手环内存不足崩溃。

现在的内联精简键盘是在 `chinese-input.ux` 页面内**直接使用 `<text>` 和 `<div>` 等基础元素手工构建**的，完全不依赖任何外部键盘组件。

## 架构说明

```
chinese-input.ux
├── 模板层 (template)
│   ├── 显示区域：已输入的文字
│   ├── 拼音行：显示当前输入的拼音（如 ni'hao）
│   ├── 候选词行：可横向滚动的候选字/词
│   └── 键盘区：纯文字按键，无图片
│
├── 逻辑层 (script)
│   ├── 按键处理：字母/数字/符号/删除/空格
│   ├── 模式切换：中文 ↔ 英文 ↔ 数字符号
│   └── 候选词管理：调用 SimpleInputMethod 查字
│
└── 引擎层 (SimpleInputMethod)
    ├── dic.js ── 拼音→汉字 映射（3000+ 词）
    ├── pinyin_syllables.js ── 合法音节表
    └── dicUtil.js ── 分词、多拼、简拼匹配
```

## 键盘布局

### 中文/英文模式（字母键盘）
```
Q  W  E  R  T  Y  U  I  O  P
 A  S  D  F  G  H  J  K  L
  Z  X  C  V  B  N  M  [Del]
[123]  [      空格      ]  [中/EN]
```

### 数字符号模式
```
1  2  3  4  5  6  7  8  9  0
-  /  :  ;  (  )  $  &  @  "
.  ,  ?  !  '         [Del]
[ABC]  [      空格      ]  [中/EN]
```

## 体积对比

| 指标 | 原来（InputMethod 组件） | 现在（内联精简键盘） | 减少 |
|------|--------------------------|---------------------|------|
| 键盘组件源文件 | 846 行 (40KB) | 无（内联在页面中） | - |
| 图片资源 | 156KB（50+ 张 PNG） | **0** | **-100%** |
| 屏幕类型支持 | 3 种（circle/rect/pill） | 1 种（rect） | 够用 |
| 编译后 JS | **1,324,572 字节 (1.3MB)** | **532,942 字节 (533KB)** | **-60%** |
| 整体 RPK 包 | ~360KB+ | **308KB** | **-15%+** |

## 轻量化的关键点

1. **零图片**：所有按键都是 `<text>` 元素，不依赖任何 PNG 图片资源
2. **单一布局**：只保留 rect 方形屏键盘，去掉 circle 和 pill-shaped 布局
3. **无组件嵌套**：键盘直接写在页面模板中，省去组件通信开销
4. **复用引擎**：继续使用 `dicUtil.js` 的 `SimpleInputMethod` 拼音引擎，汉字转换能力不变
5. **懒初始化**：字典（拼音→汉字映射表）只在首次弹出键盘时才初始化，不影响页面加载速度

## 功能完整性

精简后的键盘保留了所有核心功能：

- ✅ 中文拼音输入 + 候选词选择
- ✅ 多拼/简拼/混合输入支持
- ✅ 英文输入
- ✅ 数字符号输入
- ✅ 拼音分词显示（如 `ni'hao`）
- ✅ 震动反馈
- ✅ 中/英模式一键切换
- ✅ 删除、空格、确认

唯一牺牲的是圆形屏和胶囊屏的键盘布局（本应用实际只使用方形屏布局，所以无影响）。
