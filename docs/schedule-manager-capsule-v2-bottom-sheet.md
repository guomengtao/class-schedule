# Schedule Manager V2: Bottom Sheet (胶囊屏全场景方案)

## 背景

inline 展开在 198px 宽胶囊屏上是死路。名字、勾选框、门数、箭头、6 个按钮挤在一行，无论怎么调都至少牺牲一头。**V2 换思路：列表极简 + 底部操作面板（Bottom Sheet）**。

## 设计目标

1. 名字占用整行宽度，24px 字号，不再被挤
2. 门数在 sheet 内清晰展示，不需要隐藏
3. 按钮热区 ≥44px，不自缩
4. 列表页只有两个动作：切换当前课表、打开操作面板
5. 一屏完整呈现 4 个课表项

## 布局

### 列表页（折叠态）

```
[返回]   课程表管理
──────────────────────
│ ● 高等数学         ⋯ │  ← 整行点击=切当前；⋯点击=开面板
│ ○ 英语四级         ⋯ │
│ ○ 物理实验班       ⋯ │
│ ○ 编程入门         ⋯ │
──────────────────────
[ + 新增课程表 ]
[ 固定到首页 ]
```

- 当前课表用色点 + 加粗高亮
- 名字获得 ~110px 宽度（4-5 个字完整显示，更长则末尾省略）
- 无展开、无内嵌按钮、无门数挤位

### 操作面板（点 ⋯ 弹出）

```
──────────────
   高等数学
  12 门课程       ← 门数在此显示，20px
──────────────
┌───────┬───────┐
│ 重命名 │  复制 │
├───────┼───────┤
│  导出  │  总览 │
├───────┼───────┤
│  统计  │  删除 │
└───────┴───────┘
   [ 取消 ]
──────────────
```

每个按钮 52px 高、22px 字号，热区完全不缩。

## 关键数值对比

| | 旧方案（inline 展开） | 新方案（Bottom Sheet） |
|---|---|---|
| 列表一屏可见项 | 2~3 项 | **4 项** |
| 名字可用宽度 | ~50px（1~2 字） | **~110px（4~5 字）** |
| 名字字号 | 22px | **24px** |
| 展开后要滚动 | 是 | **否**（sheet 独立层） |
| 按钮热区 | 44×44 | **52×48** |
| 一屏可见所有操作 | 否（需滚动） | **是**（6 个按钮一屏） |
| 操作的点击次数 | 1 次（箭头展开） | **1 次（⋯ 打开面板）** |

## 代码变更范围

| 区域 | 变更 |
|------|------|
| 模板 `<div class="item">` | 替换为 `item-main` + `more-hit` 极简行 |
| 模板新增 | `<div class="overlay-sheet">` 底部面板 |
| 私有数据 | `expandedIndex` 删除，新增 `sheetIndex/sheetName/sheetCount` |
| 方法 | 删除 `expandItem/collapseAll`，新增 `openSheet/closeSheet/sheet*` 6 个方法 |
| 基础 CSS | 删除旧 `.item/.actions/.expand-*` 等，新增 `.item-main/.sheet-*` |
| 胶囊 @media | 大幅精简，只保留 item/sheet/add-btn/pin-link |
| 圆形 @media | 同步删除 item/actions 过期规则 |

## 唯一代价

多一次点击打开操作面板。在胶囊屏这么窄的屏幕上，这一次点击用空间换来了名字完整、热区达标、操作一屏可见，是值得的。
