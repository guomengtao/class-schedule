# 打赏页面技术方案

## 一、需求概述

在实验室中增加一个精美的打赏页面，展示三个二维码，用户扫码即可打赏：

| 平台 | 链接类型 | 链接 |
|------|----------|------|
| 微信 | `wxp://` 收款协议串 | `wxp://f2f0i7FYfQ5xBhxQtXDwsQpkyGZLB7UsjrRjsrXn02Qx8NQHjn8WlZEnozT2BURX_JRy` |
| 支付宝 | `https://` 收款链接 | `https://qr.alipay.com/fkx11582syvbdeymczggr3c` |
| 爱发电 | `https://` 主页链接 | `https://ifdian.net/a/peipeijin/plan` |

## 二、技术分析

### 2.1 QRCode 组件

Vela 快应用内置 `<qrcode>` 组件，直接传入 `value` 属性即可渲染二维码，无需打包任何图片资源。

```html
<qrcode value="{{ qrText }}"
  style="color: #000000; background-color: #ffffff; width: 180px; height: 180px;">
</qrcode>
```

### 2.2 链接兼容性

- **微信 wxp:// 协议**：`wxp://` 是微信个人收款协议串，传入 `<qrcode>` 生成二维码。手机扫码后微信自动唤起转账页面。
- **支付宝 https://**：`qr.alipay.com` 是支付宝官方收款码链接，传入 `<qrcode>` 生成二维码。支付宝扫码后直接唤起转账。
- **爱发电 https://**：`ifdian.net` 是爱发电创作者平台，传入 `<qrcode>` 生成二维码。浏览器扫码后打开主页。

> 注意：wxp:// 协议串较长（约80字符），需确保 `<qrcode>` 组件支持。根据 Vela 文档，qrcode 组件对内容长度无硬性限制，但二维码内容越长，生成的码点越密集，手机扫码识别需要更近的距离和更好的光线条件。

## 三、页面设计

### 3.1 布局结构

```
┌──────────────────────────────┐
│         ◀ 返回    打赏支持    │  头部导航
├──────────────────────────────┤
│  [ 微信 ] [ 支付宝 ] [ 爱发电 ] │  Tab 切换
├──────────────────────────────┤
│                              │
│       ┌──────────────┐       │
│       │              │       │
│       │   QR Code    │       │  二维码区域
│       │              │       │  (白底黑色二维码)
│       │              │       │
│       └──────────────┘       │
│                              │
│      请用手机扫码打赏         │  提示文字
│                              │
│   ❤️ 感谢您的支持 ❤️         │  感谢语
│                              │
└──────────────────────────────┘
```

### 3.2 配色方案

- 微信 Tab：绿色系 `#07C160`
- 支付宝 Tab：蓝色系 `#1677FF`
- 爱发电 Tab：橙色系 `#FF6B35`
- 背景：延续主题色暗色风格
- 二维码：白色背景 + 黑色二维码

### 3.3 交互逻辑

1. 默认展示微信二维码
2. 点击 Tab 切换不同平台的二维码
3. 二维码使用 `<qrcode>` 组件动态渲染，传入对应链接
4. 三个二维码内容直接硬编码，无需从数据库读取

### 3.4 适配方案

- 圆屏：左右 padding 增大，二维码居中
- 方屏/胶囊屏：紧凑布局，二维码适当缩小

## 五、风险与注意事项

1. **wxp:// 协议串长度**：约80字符，二维码会较密集，建议在页面说明中提示用户"请靠近扫描"
2. **支付宝/微信跳转**：需要用户手机已安装对应 App 才能扫码唤起
3. **爱发电**：纯网页链接，任何浏览器扫码均可打开
4. **无需网络请求**：所有链接均为静态字符串，页面加载零延迟
5. **无需权限**：不涉及任何敏感权限，符合快应用安全规范
6. **RPK 体积影响**：零（无图片资源，纯文本链接）
