# 首页课程表切换模块功能需求分析

## 一、功能定位

课程表切换模块位于首页最底部，用于在不同课程表之间切换（如「课程表1」「课程表2」），以及跳转到课程表管理页面。

**使用场景**：用户有两套课程表（单周/双周课程不同），通过底部的课程表名称切换，快速查看不同课程表的安排。

## 二、界面布局格式要求

课程表切换位于首页最底部，占一行高度，居中显示。

```
┌──────────────────────────────┐
│  ┌──────────────┐ ┌────────┐ │
│  │ + 添加课程   │ │  设置  │ │  ← 底部按钮
│  └──────────────┘ └────────┘ │
├──────────────────────────────┤
│        ⇄ 课程表1             │  ← 课程表切换
└──────────────────────────────┘
```

- 居中显示
- 格式：`⇄ 课程表名称`
- 文字使用主题色

## 三、用户视角的功能描述

### 3.1 查看当前课程表

底部显示当前使用的课程表名称，如「⇄ 课程表1」。

### 3.2 切换课程表

用户点击课程表名称，跳转到课程表管理页面，可以：
- 选择切换到其他课程表（如「课程表2」）
- 重命名课程表
- 导入/导出课程表数据

切换后返回首页，课程列表、状态栏、快速添加等全部刷新为新课程表的数据。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 点击课程表名称 | 跳转到课程表管理页面 |
| 在管理页切换课程表后返回 | 首页所有数据刷新 |
| 在管理页重命名课程表后返回 | 首页显示新名称 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 只有一个课程表 | 显示「⇄ 课程表1」 |
| 有多个课程表 | 显示当前激活的课程表名称 |
| 课程表名称为空 | 显示默认名称「课程表N」 |
| 切换课程表后 | 课程列表、状态栏、快速添加全部刷新 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 课程表管理页 | 点击跳转到管理页，切换/重命名课程表 |
| 课程列表 | 切换课程表后课程列表刷新 |
| 状态栏 | 切换课程表后状态栏刷新 |
| 快速添加 | 快速添加的课程数据跟随课程表变化 |
| 周视图 | 周视图也使用当前课程表数据 |
