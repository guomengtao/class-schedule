# 首页快速添加功能需求分析

## 一、功能定位

「快速添加」是首页底部的一个快捷操作区域，让用户无需进入完整的添加课程流程，一键就能把常用课程添加到当天课表中。

**使用场景**：用户打开首页，发现今天漏了一节语文课，不想走繁琐的添加流程，直接在快速添加区域点一下「语文」，课程就自动加到当天了。

## 二、界面布局格式要求

### 2.1 总体结构

快速添加区域在首页底部，占两行高度（展开状态），结构如下：

```
┌──────────────────────────────────────┐
│  快速添加                    09:00 ▲ │  ← 第1行：标题栏（始终显示）
├──────────────────────────────────────┤
│ [语文] [数学] [英语] [物理] [化学] →│  ← 第2行：课程标签行（展开后显示）
└──────────────────────────────────────┘
```

### 2.2 第1行：标题栏

- 左侧显示「快速添加」文字
- 右侧显示：自动计算的时间 + 展开/收起箭头（▼收起 / ▲展开）
- 点击整行切换展开/收起状态
- 收起时不显示时间，仅显示「快速添加 ▼」

### 2.3 第2行：课程标签行

- 仅在展开后显示，高度为一行
- 课程名以**标签（pill/胶囊）**形式横向排列
- 每个标签显示一个课程名，点击即添加
- 课程数量较多时，整行支持**左右滑动**浏览
- 标签之间保持均匀间距

### 2.4 两种状态对比

**默认收起（1行）**：
```
┌──────────────────────────────────────┐
│  快速添加                          ▼ │
└──────────────────────────────────────┘
```

**点击展开（2行）**：
```
┌──────────────────────────────────────┐
│  快速添加               09:00-09:45 ▲│
├──────────────────────────────────────┤
│ [语文] [数学] [英语] [物理] [化学] →│
└──────────────────────────────────────┘
```

## 三、用户视角的功能描述

### 3.1 默认状态（收起）

用户进入首页，看到底部有一行「快速添加 ▼」标题栏，只占一行高度，不挤占课程列表空间。

### 3.2 点击展开

用户点击标题栏后，下方多出一行课程标签，自动计算的时间也显示在标题栏右侧。12 门课程以标签形式横向排列，屏幕显示不下的可以左右滑动查看。

### 3.3 点击添加

用户点击某个课程标签（比如「语文」），该课程立即添加到当天课表中，时间就是标题栏右侧显示的时间段。添加成功后，用户会看到「已添加」的提示，课程出现在上方的课程列表中。

### 3.4 再次收起

用户再次点击标题栏，课程标签行收起，回到只有一行标题栏的简洁状态。

## 四、课程列表来源

快速添加里显示的课程名，来自「课程管理」页面。

### 4.1 默认课程

首次使用时，系统预置了 12 门常见课程：

> 语文、数学、英语、物理、化学、政治、音乐、体育、美术、历史、地理、生物

### 4.2 用户可自定义

用户可以在「课程管理」页面：

- **添加**新课程（比如「自习」、「班会」）
- **删除**不需要的课程（比如不学「物理」，就删掉）
- **重命名**课程（比如把「美术」改成「书法」）

课程管理页面的任何改动，都会自动同步到首页快速添加区域。

### 4.3 空状态

如果用户在课程管理页面删光了所有课程，快速添加展开后会显示提示：「暂无已添加课程，请先添加课程」。

## 五、自动时间计算规则

每次用户展开快速添加面板时，系统会自动计算一个新课程应该安排在什么时间。

### 5.1 计算逻辑

| 情况 | 开始时间 |
|------|----------|
| 今天已有课程 | 最后一节课结束后 + 10 分钟休息 |
| 今天还没有课程 | 默认早上 08:00 开始 |
| 计算出的时间已过 | 从当前时间 + 5 分钟开始 |

每节课默认时长：**45 分钟**。

### 5.2 举例

- 今天最后一节课是 16:15 结束 → 新课程安排在 16:25 - 17:10
- 今天还没排课 → 新课程安排在 08:00 - 08:45
- 现在是 10:30，最后课是 10:00 结束 → 新课程安排在 10:35 - 11:20

### 5.3 已排满状态

如果当天课程已经排到很晚，计算出的开始时间超过了 24:00（即当天已无可用时间），面板会显示：「今天课程已排满」，此时无法再添加课程。

## 六、显隐控制

用户可以在「设置」页面中控制快速添加区域是否显示在首页。

- **显示**（默认）：首页底部显示快速添加区域
- **隐藏**：首页不显示快速添加，节省屏幕空间

这个开关位于：设置 → 首页设置 → 快速添加栏目

## 七、交互行为总结

| 操作 | 结果 |
|------|------|
| 点击「快速添加」标题栏 | 展开/收起面板，标题栏从一行变为两行（或反之） |
| 展开时点击课程标签 | 课程添加到当天课表，显示成功提示 |
| 课程标签行左右滑动 | 浏览屏幕显示不下的更多课程 |
| 添加成功后 | 课程列表自动刷新，显示新课程 |
| 时间自动重算 | 每次展开面板时重新计算下一个可用时间 |
| 切换日期 | 课程列表和时间都针对当前查看的日期 |

## 八、功能演变历史

### 第一版：三个固定按钮

最早只有「数学」「英语」「科学」三个固定按钮，课程名和时间都是写死的，用户无法修改。

**问题**：如果用户不学这三门课，或者学了更多课程，快速添加就没用了。

### 第二版：动态课程名

改为从用户已添加的课程中自动提取所有课程名，用户添加过什么课程，快速添加就显示什么。

**改进**：课程名不再是固定的，而是跟着用户的实际课程走。

### 第三版：与课程管理联动

课程来源改为从「课程管理」页面读取，用户可以在课程管理里统一维护课程列表，快速添加自动同步。同时增加了折叠功能，默认收起，点击展开。

**改进**：用户可以自主管理课程列表，不再依赖已添加过的课程。

### 第四版（当前）：横向标签布局

折叠面板改为两行布局：
- 第1行：标题栏 + 自动计算的时间
- 第2行：课程标签横向排列，支持左右滑动浏览

点击标签即添加课程，展开时自动显示计算出的时间，收起时只占一行高度。

## 九、已知问题（从用户角度）

| 问题 | 用户看到的现象 |
|------|---------------|
| 添加后课程没出现 | 提示"已添加"但课表里看不到，需要刷新或切换页面才出现 |
| 课程被覆盖 | 之前添加的课程莫名消失，被新课程替换了 |
| 重置后课程列表为空 | 点了"恢复默认数据"后，快速添加里没有课程可选了 |
| 添加失败无提示 | 课程没保存成功，但用户看到的是"已添加"提示 |

## 十、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 没有任何课程 | 显示"暂无已添加课程，请先添加课程" |
| 当天已排满 | 显示"今天课程已排满"，不可点击添加 |
| 用户关闭了快速添加 | 首页不显示快速添加区域 |
| 页面加载中 | 快速添加区域不显示（等待数据加载完成） |
| 切换课程表 | 快速添加读取当前课程表的数据 |
| 非当天日期 | 仍然可以添加课程到该日期 |

## 十一、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 课程管理 | 课程管理是快速添加的**数据源**，管理页增删改的课程会同步到快速添加 |
| 添加课程（完整流程） | 快速添加是**快捷方式**，跳过选课、调时间、填地点等步骤，适合快速补录 |
| 首页设置 | 控制快速添加的**显示/隐藏** |
| 课程详情/编辑 | 通过快速添加添加的课程，点击后一样可以进入详情页编辑时间、地点等 |
