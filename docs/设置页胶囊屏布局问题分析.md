# 设置页胶囊屏布局问题分析

## 概述

设置页 (`settings.ux`) 在胶囊屏设备上存在三个问题：
1. **周课表** 展开后里面的栏目挤在一行
2. **工具** 栏目展开后同样挤在一行
3. **测试区** 在设置页中找不到入口

> 设备类型：watch / band（胶囊屏典型宽度约 300px）

---

## 问题一：周课表展开后栏目挤在一行

### 涉及代码

文件: [settings.ux](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/pages/settings/settings.ux#L91-L116)

```html
<div class="group">
  <div class="group-title-row" onclick="toggleSchedule">
    <text class="group-title">周课表</text>
    <div class="row-right">
      <text class="arrow">{{ showSchedule ? 'v' : '›' }}</text>
    </div>
  </div>
  <div if="{{ showSchedule }}">
    <!-- 第1行：隐藏周末 + 开关按钮 -->
    <div class="row">
      <text class="row-label">隐藏周末</text>
      <input class="toggle-btn" type="button" value="{{ hideWeekend ? '开' : '关' }}" ... />
    </div>
    <div class="divider"></div>
    <!-- 第2行：模版选择 + 提示 + 箭头 -->
    <div class="row" onclick="openTemplatePicker">
      <text class="row-label">模版选择</text>
      <div class="row-right">
        <text class="row-hint">{{ currentTemplateName }}</text>
        <text class="arrow">›</text>
      </div>
    </div>
  </div>
</div>
```

### 根因分析

`.row` 的 CSS 样式将所有子元素强制排列在**同一行**：

```css
.row {
  flex-direction: row;              /* ← 强制水平排列 */
  justify-content: space-between;    /* ← 两端对齐，内容被推到两端 */
  align-items: center;
  padding: 12px 0;
}
```

在胶囊屏上（`@media (shape: capsule)`），字体反而**放大**了：

```css
@media (shape: capsule), (shape: pill-shaped) {
  .row-label {
    font-size: 32px;     /* ← 比默认 30px 还大 */
    line-height: 44px;
  }
  .row-hint {
    display: none;       /* ← hint 隐藏，但 label+arrow 仍在一行 */
  }
  .toggle-btn {
    width: 52px;         /* ← 开关按钮 52px */
  }
}
```

### 宽度计算

| 层级 | 水平方向 | 占用 |
|------|---------|------|
| 设备屏幕宽度 | — | ~300px |
| `.settings-page` padding | `30px 16px 30px 16px` | -32px |
| `.group` padding | `18px 14px` | -28px |
| **`.row` 可用宽度** | | **~240px** |

**第1行「隐藏周末」+ 开关按钮：**

| 元素 | 宽度 |
|------|------|
| `.row-label` "隐藏周末" (4个中文字×32px) | ~128px |
| `.toggle-btn` 52px | 52px |
| **合计** | **~180px** |

180px < 240px，但是 `.justify-content: space-between` 将它们推到**两端**，中间仅有 **60px** 间隙，视觉上非常拥挤。

**第2行「模版选择」+ 箭头：**

| 元素 | 宽度 |
|------|------|
| `.row-label` "模版选择" (4个中文字×32px) | ~128px |
| `.arrow` "›" (32px字体) | ~32px |
| `.row-hint` (display:none) | 0 |
| **合计** | **~160px** |

160px < 240px，同样因为 `space-between` 导致元素被推到两端，中间 80px 空隙显得空旷但元素本身紧贴边缘不自然。

### 小结

核心问题：**`.row` 的 `flex-direction: row` + `justify-content: space-between`** 将所有内容强制水平排列。胶囊屏本身宽度就有限，加上胶囊媒体查询反而增大了 `.row-label` 字体（32px），导致内容在狭窄空间内被挤压，视觉上"挤在一行"。

## 问题二：工具栏目同样挤在一行

### 涉及代码

文件: [settings.ux](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/pages/settings/settings.ux#L132-L165)

```html
<div class="group">
  <div class="group-title-row" onclick="toggleTools">
    <text class="group-title">工具</text>
    <div class="row-right">
      <text class="arrow">{{ showTools ? 'v' : '›' }}</text>
    </div>
  </div>
  <div if="{{ showTools }}">
    <div class="row" onclick="openDeviceInfo">
      <text class="row-label">设备信息</text>
      <div class="row-right">
        <text class="row-hint">调试</text>
        <text class="arrow">›</text>
      </div>
    </div>
    <!-- 震动自定义 / 测试区 结构相同 -->
  </div>
</div>
```

### 根因分析

与问题一**完全相同**。工具栏目的三个子项（设备信息、震动自定义、测试区）都使用 `.row` 类，继承了相同的布局问题：

- `flex-direction: row` 强制水平排列
- `justify-content: space-between` 两端对齐
- 胶囊屏 `.row-label` 32px 字体过大
- `.row-hint` 虽然隐藏，但 label + arrow 依然挤在一行

**具体每个子项的宽度占用（胶囊屏）：**

| 子项 | row-label | hint | arrow | 合计 |
|------|-----------|------|-------|------|
| 设备信息 | 4字×32px = ~128px | 隐藏 | ~32px | **~160px** |
| 震动自定义 | 5字×32px = ~160px | 隐藏 | ~32px | **~192px** |
| 测试区 | 3字×32px = ~96px | 隐藏 | ~32px | **~128px** |

"震动自定义" (5个字) 占用 192px，在 240px 可用宽度内只剩下 **48px** 间隙，最为拥挤。

### 小结

两个可展开栏目的根因一致：**通用的 `.row` 样式没有针对胶囊屏做垂直布局适配**。

## 问题三：测试区找不到

### 涉及代码

测试区入口定义在 [settings.ux](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/pages/settings/settings.ux#L156-L163)：

```html
<div class="row" onclick="openTestArea">
  <text class="row-label">测试区</text>
  <div class="row-right">
    <text class="row-hint">实验功能</text>
    <text class="arrow">›</text>
  </div>
</div>
```

### 根因分析

测试区入口**确实存在于代码中**，但它被深埋在两层折叠之下：

```
设置页面
  └── group: 工具 (showTools 默认 false)
        ├── row: 设备信息
        ├── row: 震动自定义
        └── row: 测试区 ← 藏在最底部
```

| 问题 | 说明 |
|------|------|
| **默认隐藏** | `showTools` 初始值为 `false`，"工具"组默认折叠 |
| **层级太深** | 测试区是"工具"的**孙节点**，不是独立的 group |
| **位置靠后** | 即使展开，也在"设备信息"和"震动自定义"之后 |
| **名称混淆** | 用户期望看到独立的"测试区"栏目，而非混在"工具"里 |

### 对比：用户期望 vs 实际

| 用户期望 | 实际 |
|---------|------|
| 设置页中有独立的「测试区」组 | 测试区藏在「工具」折叠组的底部 |
| 一眼能看到测试区入口 | 需要先展开「工具」才能看到 |
| 测试区有自己的独立入口 | 测试区是工具组的子项之一 |

### 小结

测试区入口代码存在，但因**被嵌套在可折叠的「工具」组内且默认隐藏**，导致用户找不到。应该将测试区提升为设置页中独立可见的 group，或至少将其从折叠状态中移出。

---

## 总结

| 问题 | 根本原因 | 影响范围 |
|------|---------|---------|
| 周课表栏目挤在一行 | `.row` 强制 `flex-direction: row` + `space-between`，胶囊屏字体过大 | 周课表展开后的 2 个子项 |
| 工具栏目挤在一行 | 同上，通用 `.row` 样式未做胶囊屏适配 | 工具展开后的 3 个子项 |
| 测试区找不到 | 入口藏在「工具」折叠组内部，默认不可见 | 整个测试区功能不可访问 |

### 建议修复方向

1. **胶囊屏 `.row` 垂直布局**：在 `@media (shape: capsule)` 中为可展开组内的 `.row` 改为 `flex-direction: column; align-items: flex-start;`，让 label 和控件**上下排列**而非左右排列
2. **减小胶囊屏字体**：将胶囊屏 `.row-label` 从 32px 降为 26px，为内容腾出空间
3. **测试区独立化**：将「测试区」从「工具」折叠组中移出，作为设置页中**独立的、始终可见的** group 或 row
