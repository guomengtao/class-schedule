## 三、核心几何：12 时位怎么「按屏幕比例」分配

### 3.1 三个候选方案比选

| 方案 | 做法 | 结论 |
|---|---|---|
| **A 全出血射线-矩形** | 时位 = 射线与**屏幕矩形**的交点（方表公式的推广）：`R(θ)=min((W/2−m)/\|cosθ\|, (H/2−m)/\|sinθ\|)` | ✌ **否决**。指针是定长直杆：长度必须 ≤ 0.92·(W/2) 否则 3 点方向穿出屏幕（192 屏最多 ~86px），而在 12 点方向只能覆盖 86/235 = **37%** 的距离，盘面上下各空 150px+；且 1/2/4/5 点方向的指针会越过边线上的标记继续穿出屏幕 |
| **B 比例封顶椭圆（推荐）** | 时位 = 椭园：`a=min(0.44W, 0.42H)`，`b=min(0.42H, 1.35a)`，长宽比**跟随屏幕比例但封顶 1.35** | ✅ 方形屏上自然收敛为**正圆**（Watch S4：a=b=195.7）；手环长屏收敛为 1.35 的竖椭圆；12 时位永远在屏内且指针长度有解 |
| C 正圆 | 固定圆，与圆表相同 | ✌ 违背「按屏幕比例」需求，且浪费长屏 |

**为什么封顶 1.35**：指针定长 `L=0.72·√(a·b)`。不封顶时 192×490 的椭圆 b=205.8，12 点方向指针只有 √(84.5·205.8)·0.72=71px，覆盖 34%，上方空 135px；封顶到 1.35 后覆盖率提升到 62%，上方留白由品牌铭文 + 日期窗接管（见 4.4）。这是「指针定长」与「屏幕比例」之间唯一自洽的折衷，**不是偷懒，是几何必然**。

### 3.2 公式（全部运行时按真实屏幕计算）

```
中心：cx = W/2, cy = H/2
椭圆：a = min(0.44·W, 0.42·H);  b = min(0.42·H, 1.35·a)     // 长宽比 = min(W:H, 1.35)
第 k 时位（k=0..11，θ=30k°，自 12 点顺时针）：
    x_k = cx + a·sinθ        y_k = cy − b·cosθ
    标记朝向 = 径向 θ     → 复用 120 档 .rN：rotate(180+θ)，即 class 取 .r(θ/3)
指针基长：L0 = √(a·b)
    时针 0.42·L0   分针 0.72·L0   秒针 0.78·L0（配重尾 0.22·L0）
阿拉伯数字（11 个，3 点让位日期窗）：半径 0.70·(a, b)
日期窗：中心 (0.66a, 0)，尺寸 22×16
印刷分钟轨（铁路双线）：同心椭圆 (a+4, b+4) 与 (a+6, b+6)，1px
```

> 12 点时位落在**上顶点**、3/9 落在**左右顶点**，斜位时标沿椭圆切线方向自然偏转——和真椭圆盘表（tonneau）一致，不是「圆刻度环塞进屏幕」。

## 四、「无框」如何做出仿真感（没有框，细节全部靠印刷与材质）

无框表的可信度 = ** El 盘面材质 60% + 指针层次 25% + 印刷信息 15%**。逐条落地：

1. **盘面 = 屏幕底色，无任何外轮廓**。底色 `#17191d` 上叠 6 条全宽横带（高 H/6、灰阶 ±2、alpha 0.02~0.05）模拟纵向拉丝；B 阶段可选 24 条旭放射线（每 15° 一条，动态 class 绑 `.rN`，出屏即自然截断，无裁切风险）。
2. **印刷分钟轨（铁路双椭圆线）是唯一「盘的边界」**——不是框，是印在盘上的刻度轨，真实机械表都有。外线略亮（受光）、内线略暗。
3. **三层指针**（沿用圆表已验收结构）：底层同形暗影偏移 1px → 主针（2px 银白 / 时针加宽 3px）→ 左缘 1px 高光。秒针橙色 + 配重尾。**不用嵌套子 div、不用动态 transform**（启动即退红线）。
4. **时标**：12 个 2×9 金属条（整点加宽到 2.5），外端贴椭圆轨、内端贴夜光点（2×2 `#b9cfc2`）。
5. **日期窗凹槽**：框上缘 1px 亮线 + 窗内上缘 1px 暗线（圆表同款，凹槽感的关键）。
6. **中轴三层**：暗底 + 银环 + 高光点。
7. **印刷铭文**（贴文字，非元素）：`EV`（16px）/ `AUTOMATIC`（9px）/ `36 JEWELS`（9px）/ 底部操作提示。位置 `y = cy − b − 26` 与 `cy + b + 26`。
8. **1.35 封顶后的上下留白**由品牌铭文（上）+ 36 JEWELS + 日期+星期小字（下）填满，不空。

## 六、多机型适配机制（运行时计算，不写死）

```js
device.getInfo({
  success(ret) { applyGeometry(ret.screenWidth || 192, ret.screenHeight || 490) },
  fail()      { applyGeometry(192, 490) }        // 兜底：手环基准
})
function applyGeometry(W, H) {
  // 计算 a/b/cx/cy/L0，写入 this.geo，模板用 {{m1x}}px / {{hLen}}px 等逐项绑定
}
```

- 计算一次（`onInit`），屏幕不会变；`onShow` 不重算。
- **12 个时标 = 24 个坐标绑定 + 12 个 `.rN` class 绑定；11 个数字 = 22 个坐标绑定；指针长度 4 个绑定**——全部是 dynamic inline `left/top/width`（已验证可用），**没有一个 vw、一个动态 transform、一个 scale**。
- 指针旋转**继续用 120 档字面量 `.rN = rotate(180+3N)`**（N=0..119，覆盖 180°..537°）。时标是静止件，但朝向 θ 也走同一套阶梯（N=θ/3），与本页指针共用一套 CSS。

## 七、Vela 红线规避清单（抄错即启动即退 / 不出画）

| 红线 | 本方案对策 |
|---|---|
| 旋转父元素内嵌套子 div | 指针三层是**兄弟**平级，不嵌套 |
| 祖先 transform + 子孙 rotate | 全页无任何 `transform: scale()`；椭圆轨/日期窗只改 left/top/width/height |
| 动态 transform | 旋转只走 `.rN` 静态 class 动态绑定 |
| `vw` 单位不生效 | 全部运行时算 px |
| 群组选择器 | 每个元素独立 class |
| 秒针配重尾 | 与主针同一元素的延伸（伪元素不可用 → 用绝对定位子 div **平级**方案需验证，或尾针与主针合并为一个 L 形元素） |

> ⚠️ 秒针配重尾若做不成平级，就接受「针杆穿心 + 尾部省略」——圆表当初正是删掉嵌套尾针才恢复出画的。

## 九、验收标准

1. **无框**：盘内、盘外无任何闭合轮廓线（分钟轨是双线刻度轨，不算框；盘面与屏幕底色连续无边）；
2. **比例分配**：五机型的 12 时位坐标与 §3.3 表一致（误差 ≤2px）；
3. **仿真**：三针角度误差 ≤1°（像素扫描）；三层针高光可见；日期窗有凹槽感；
4. **无出界**：任何时标/文字距屏边 ≥8px；
5. **稳定性**：构建无 error；冷启出画（不黑不退）；稳态 1 次/秒重绘（不闪）；
6. **交互**：点空白返回、长按面板、主题持久化。
