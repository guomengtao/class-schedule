# 首页日期导航栏模块功能需求分析

## 一、功能定位

日期导航栏是首页的核心导航控件，让用户在不同日期之间切换课表，以及快速跳转到今天、明天和周视图。

**使用场景**：用户想查看明天的课程安排，点击右箭头切换到明天；想回到今天，点击「今」按钮。

## 二、界面布局格式要求

导航栏位于时钟下方，占一行高度，包含左右箭头、日期文字和快捷按钮。

```
┌──────────────────────────────┐
│  ◀      星期一      ▶        │
│       [总] [今] [明]          │
└──────────────────────────────┘
```

- **左箭头 ◀**：切换到前一天
- **日期文字**：居中显示，如「星期一」
- **右箭头 ▶**：切换到后一天
- **快捷按钮**：总（周视图）、今（今天）、明（明天）

## 三、用户视角的功能描述

### 3.1 基本导航

用户点击左右箭头，在星期日~星期六之间循环切换。当前日期显示的课程列表会随之更新。

### 3.2 快捷跳转

- **总**：跳转到周视图页面，显示整周课程概览
- **今**：一键跳回今天，高亮显示（如果当前已是今天则无变化）
- **明**：一键跳转到明天

### 3.3 隐藏周末

用户可以在设置中选择「隐藏周末」，此时导航栏只显示星期一~星期五，星期日和星期六被隐藏。

### 3.4 快捷按钮显隐控制

用户可以在设置中分别控制「总」「今」「明」三个快捷按钮的显示/隐藏。不需要的按钮可以关掉，保持导航栏简洁。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 点击 ◀ | 切换到前一天，课程列表刷新 |
| 点击 ▶ | 切换到后一天，课程列表刷新 |
| 点击「总」 | 跳转到周视图页面 |
| 点击「今」 | 跳回今天，课程列表刷新 |
| 点击「明」 | 跳转到明天，课程列表刷新 |
| 隐藏周末后 | 循环范围缩小为星期一~星期五 |
| 关闭某快捷按钮 | 对应按钮从导航栏消失 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 在星期日点击 ◀ | 切换到星期六 |
| 在星期六点击 ▶ | 切换到星期日 |
| 隐藏周末时在星期日 | 自动显示为星期一 |
| 隐藏周末时从星期五点 ▶ | 回到星期一 |
| 当前已是今天点击「今」 | 无变化 |
| 所有快捷按钮都关闭 | 只显示左右箭头和日期文字 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 课程列表 | 导航栏切换日期后，课程列表自动刷新 |
| 状态栏 | 导航栏切换日期后，状态栏自动更新 |
| 快速添加 | 快速添加读取当前日期的课程，跟随导航栏切换 |
| 设置页 | 控制隐藏周末和快捷按钮显隐 |
| 周视图 | 「总」按钮跳转到周视图 |
