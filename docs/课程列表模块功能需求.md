# 首页课程列表模块功能需求分析

## 一、功能定位

课程列表是首页的核心模块，以卡片网格形式展示当前日期的所有课程，每张卡片包含课程名、时间、教师、地点等信息。

**使用场景**：用户打开首页，看到今天的课程以卡片形式排列，点击某张卡片进入课程详情页查看和编辑。

## 二、界面布局格式要求

课程列表位于页面中部，占据主要空间，可垂直滚动。课程卡片以两列网格排列。

```
┌──────────────────────────────┐
│ ┌─────────┐ ┌─────────┐     │
│ │ ░░░░░░░░ │ │ 英语    │     │  ← 进度条（上课中课程）
│ │ 数学    │ │ 08:55   │     │
│ │ 08:00   │ │ 张老师  │     │
│ │ 李老师  │ │ 205教室 │     │
│ │ 301教室 │ │         │     │
│ └─────────┘ └─────────┘     │
│ ┌─────────┐ ┌─────────┐     │
│ │ 物理    │ │         │     │
│ │ 10:00   │ │         │     │
│ └─────────┘ └─────────┘     │
└──────────────────────────────┘
```

- 两列网格布局，卡片宽度各占约 48%
- 每张卡片包含：课程名（粗体）、时间（主题色）、教师（次要色）、地点（浅色）
- 如果是今天，正在上课的卡片底部有进度条，已结束的卡片有完成标记

## 三、用户视角的功能描述

### 3.1 课程卡片展示

每张卡片显示：
- **课程名称**：如「数学」，最多显示两行
- **时间**：如「08:00 - 08:45」
- **教师**：如「李老师」（有则显示，无则不显示）
- **地点**：如「301教室」（有则显示，无则不显示）

### 3.2 进度条

如果是今天，卡片上会显示进度条：
- **未开始**：无进度条
- **进行中**：底部有半透明进度条，实时更新
- **已结束**：底部有淡色完成标记

切换到非今天日期时，不显示进度条。

### 3.3 点击卡片

用户点击任意课程卡片，跳转到课程详情页，可以查看和编辑该课程的完整信息。

### 3.4 空状态

当天没有课程时，显示「今天没有课」的提示文字。

### 3.5 加载状态

首次加载数据时，显示「加载中...」提示。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 点击课程卡片 | 跳转到课程详情页 |
| 上下滑动 | 滚动查看更多课程 |
| 切换日期 | 课程列表自动刷新为该日期的课程 |
| 添加/删除课程后返回 | 课程列表自动刷新 |
| 快速添加课程后 | 课程列表自动刷新并显示新课程 |
| 切换课程表 | 课程列表刷新为新课程表的数据 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 当天没有课 | 显示「今天没有课」 |
| 数据加载中 | 显示「加载中...」 |
| 课程时间冲突 | 按开始时间排序，两列网格显示 |
| 单数课程 | 最后一格为空 |
| 课程名很长 | 最多显示两行，超出省略号 |
| 不是今天 | 不显示进度条 |
| 课程非常少 | 一列或两列显示，下方留空 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 日期导航栏 | 切换日期后课程列表自动刷新 |
| 课程详情页 | 点击卡片跳转到详情页 |
| 快速添加 | 添加课程后课程列表自动刷新 |
| 添加课程 | 完整添加课程后返回，课程列表自动刷新 |
| 课程表切换 | 切换课程表后列表刷新 |
| 状态栏 | 状态栏和课程列表共享课程数据 |
