## 规范检查要点

每个页面整改时需逐一核对：

1. **标题** → 36px（页面大标题）
2. **正文标签** → 32px（列表项名称、主要按钮文字）
3. **辅助说明** → 28px（次要文字、描述、副标题）
4. **次要辅助** → 24px（脚注、时间单元、小标签）
5. **底线** → 20px（极小辅助文字）
6. **特大** → 40px（突出数字/状态）
7. **禁止使用中间值**（如 15px、13px、11px 等非 4 倍数）
8. **禁止缩放**（不使用 transform: scale）
9. **留白** → 内边距/外边距增大，圆角 12px，行间距 14px+
10. **精简文字** → 返回 `◀`、描述缩短、去掉冗余说明
