# 胶囊屏 打赏V2 文字缺失分析

## 一、基础参数

```
胶囊屏: 192px × 490px
页面 content 宽度 = 192 - 8(page左) - 8(page右) = 176px
header 有效宽度  = 176 - 6(header左) - 6(header右) = 164px
```

```
┌──────────── 192px ────────────┐
│ ┌─ page padding: 8px ──────┐ │
│ │ ┌─ header padding: 6px ─┐│ │
│ │ │    ← 164px 可用 →     ││ │
│ │ │ [40] [  flex:1  ] [40]││ │
│ │ │ ←btn  title    spacer ││ │
│ │ └───────────────────────┘│ │
│ └──────────────────────────┘│
└──────────────────────────────┘
```

## 二、标题 "打赏支持" — 缺 1 字

### 可用宽度

```
title 可用 = 164 - 40(back-btn) - 40(spacer) - 4×2(margin) 
          = 164 - 40 - 40 - 8 
          = 76px
```

### 所需宽度

```
"打赏支持" 4个中文字, 字号 26px
每个字约 = 字号 × 1.0 = 26px
所需宽度 = 4 × 26 = 104px
```

### 结论

```
104px > 76px  ❌ 装不下!
76 / 26 = 2.92  → 只能显示 3 个字
用户看到: "打赏支"  ← 缺 "持"
```

## 三、"支付宝/爱发电" tab — 各缺 1 字

### 可用宽度

```
tab-bar 宽度 = 176px (page content)
单个 tab   = (176 - 2×6) / 3    (3个tab, 各 margin 0 2px)
          = (176 - 12) / 3
          = 164 / 3
          = 54.67px
```

### 所需宽度

```
"支付宝" 3个字, 字号 22px
所需宽度 = 3 × 22 = 66px

"爱发电" 3个字, 字号 22px
所需宽度 = 3 × 22 = 66px
```

### 结论

```
66px > 54.67px  ❌ 装不下!
54.67 / 22 = 2.48  → 只能显示 2 个字
用户看到: "支付"  ← 缺 "宝"
用户看到: "爱发"  ← 缺 "电"

"微信" 2个字: 2 × 22 = 44px < 54.67px ✅ 完整
```

## 五、能否在当前布局下保持字号？

### 标题: 若要装下 4 个字

```
可用: 76px
需要: 4 × font-size ≤ 76
     font-size ≤ 76 / 4 = 19px

胶囊规范: 标题 ≥ 26px
19px < 26px  → ❌ 不可行
```

### Tab: 若要装下 3 个字

```
可用: 54.67px
需要: 3 × font-size ≤ 54.67
     font-size ≤ 54.67 / 3 = 18.22px

胶囊规范: 按钮 ≥ 22px
18.22px < 22px  → ❌ 不可行
```

### 如果不考虑 header-spacer (去掉40px占位)

```
标题可用: 76 + 40 = 116px
需要: 4 × 26 = 104px
104px < 116px  → ✅ 可以!
```

### 但要同时解决 tab 问题

```
3 个 tab 各含 3 个字, 字号 22px
3 × 22 = 66px 每个 tab 需要
66 × 3 = 198px 总宽度需要
可用: 176px
198px > 176px  → ❌ 不可行!

即使去掉所有 margin:
176 / 3 = 58.67px 每个
58.67 / 3 = 19.56px 最大字号
19.56 < 22px  → ❌ 仍不可行
```

## 六、最终结论

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│   192px 胶囊屏 + 当前三栏布局 + 胶囊规范字号          │
│                                                      │
│   ├─ 标题 "打赏支持" 4字 × 26px = 104px              │
│   │  可用 76px → 只能 3 字 → 缺少 "持"              │
│   │                                                  │
│   ├─ Tab "支付宝" 3字 × 22px = 66px                 │
│   │  可用 54.67px → 只能 2 字 → 缺少 "宝"           │
│   │                                                  │
│   └─ Tab "爱发电" 3字 × 22px = 66px                 │
│      可用 54.67px → 只能 2 字 → 缺少 "电"           │
│                                                      │
│   ═══════════════════════════════════════════════    │
│   当前布局 + 胶囊规范字号 = 无法同时满足              │
│                                                      │
│   必须改变布局方案，可选:                             │
│   ① 去掉 header-spacer, 标题可放 4 字               │
│   ② Tab 改为 2 栏 (合并微信/支付宝)                  │
│   ③ Tab 字号降至 18px (规范妥协)                    │
│   ④ 标题和 tab 分别降字号到能装下的尺寸              │
│   ⑤ 采用不同布局 (如 tab 竖向排列)                  │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### 各方案可行性

| 方案 | 标题4字 | Tab3字 | 字号规范 | 用户体验 |
|------|---------|--------|----------|----------|
| ① 去掉spacer | ✅ 26px | ❌ 54px不够 | 标题达标 | Tab模糊 |
| ② Tab改2栏 | ✅ 26px | ✅ 每栏83px | 全部达标 | 需合并平台 |
| ③ Tab降18px | ✅ 26px | ✅ 54px | ❌ 不达标 | 字小勉强 |
| ④ 全降字号 | 19px 4字 | 18px 3字 | ❌ 不达标 | 字太小 |
| ⑤ Tab竖向 | ✅ 26px | ✅ 176px | 全部达标 | 占空间多 |

**推荐方案②**: 去掉 spacer 解决标题，tab 改为 2 栏（每个 83px 宽，3字 66px 够用），三个平台怎么办 — 微信/支付宝合并一个入口？或者只保留 2 个 tab。

**推荐方案①+③组合**: 去掉 spacer + tab 统一改为图标或2字简称（如"微信/支付宝/爱发电"→ "微信/付宝/发电"），但会改变含义。
