# 动画表盘重构方案（时间走动画 + 转盘 + 修饰）

> 页面：`src/pages/watch-face-animated/watch-face-animated.ux`
> 屏幕：192 × 490（慢应用面板固定竖屏）
> 日期：2026-10-20 · 状态：**方案定稿 → 已落地 v1**
> 前序：`横屏表盘-重构方案.md`（§三 的 10 组实验是本文的约束来源）

---

## 一、结论先行

动画表盘原来只有「5 根均衡器柱 + 静态 HH:MM」，柱子只是装饰、时间跟动画无关。
本次重构把动画拆成**三层，各层用各层能承受的马达**：

| 层 | 承担什么 | 马达 | 为什么不用更强的 |
|---|---|---|---|
| L1 秒环转盘 | 显示"现在是第几秒" | **类交换 / 数据绑定位移** | 不用 `@keyframes` 承载读数——金属表盘实测：动画合成不可靠，针角与盘面时间对不上、周期性冻结 12s |
| L2 时间读数 | HH / MM 大字 | **整分脏检查重绘** | 不做逐帧补间——读数优先准确 |
| L3 修饰 | 呼吸光晕、品牌、日期 | **`@keyframes` 字面量 opacity/scale** | 本页 5 柱 demo 已实测不黑屏（`nz=20000`），可放心用 |

一句话：**动画只负责"动"，数字只负责"准"，两者解耦**。任何一层挂掉，另一层仍是可用的表盘。

## 二、三条已验证的动画马达（选型地基）

| 马达 | 机制 | 实证出处 | 适用 |
|---|---|---|---|
| **M1 类交换** | CSS 里预置字面量 `.r0…​.r119 { transform: rotate(Ndeg) }`，每秒只改 class 名 | `watch-face-metal` 三针 120 档（3°一档）实机通过 | 指针、转盘、刻度盘 |
| **M2 分帧推位移** | `overflow:hidden` 裁切窗 + 竖向数字带 + JS 分帧改 `top` | `watch-face-flip` v4、`watch-face-pickdate` v2 实拍通过 | 数字滚动、翻页 |
| **M3 keyframes 修饰** | 字面量 `transform/opacity` + `animation-*` | 本页均衡器 demo（本轮实测出画） | 呼吸、律动、扫光（**只做装饰**） |

### 明确禁用（都踩过）

| 禁 | 后果 | 出处 |
|---|---|---|
| `transform: rotate({{deg}}deg)` 数据绑定 | 整页黑屏 | `watch-face-metal` 头注释 ① |
| `<scroll>` + `scrolltop` | 定位完全不生效，只剩标点 | `watch-face-flip` v1 日志 `domUpdate type:0 is error, kid:19999` |
| 用 `@keyframes` 承载当前时刻 | 画面冻结 12s（10 帧 md5 全同） | `watch-face-metal` 头注释 ② |
| 带文字的节点做 `transform` | 除「整页铺满 + origin 居中」外全白屏 | `横屏表盘-重构方案.md` §三 实验 4–10 |

## 三、本次设计（192×490）

### 版式

| 元素 | 位置 | 规格 |
|---|---|---|
| 呼吸光晕圈 | left 26 / top 26 | 140×140，`border-radius:70px`，`@keyframes` 只改 `opacity` + `scale` |
| 60 格秒环 | 圆心 (96,96)，半径 66 | 每格 5×5（5 的倍数处 7×7 更亮），6° 一格，`for` 生成、**静态不动** |
| 秒游标 | 半径 66 上按当前秒定位 | 14×14，强调色，每秒跳一格（一档 6°） |
| 环心秒数 | 环内居中，top 76 | 36px 两位数 + 10px `SEC` |
| `HH` | top 186，整宽居中 | **96px**（line-height 100） |
| `MM` | top 290 | **96px** |
| 日期 | top 404 | 14px |
| 提示 | top 432 | 11px |

区间校验：光晕 26~166、`HH` 186~286、`MM` 290~390、日期 404~419、提示 432~443，全部落在 490 内且互不重叠。
（v1 稿曾用 88px / date 380，实拍发现底部空 80px 一片死白，故下移并放大到 96px。）

### 秒环坐标怎么算（不碰 transform）

刻度不做旋转，直接按极坐标算出 `left/top` 逐格摆放：

```
θ = i × 6°
left = 96 + 66·sin(θ) − size/2
top  = 96 − 66·cos(θ) − size/2
```

`left/top` 是**数据绑定**（与 flip 推 `top` 同一条已验证通道），不涉及 `transform`。
60 个点只在 `onInit` 生成一次，此后**永不重绘**；每秒只动游标一个节点的两个值。

### 走时纪律

- **整秒对齐**：`setTimeout(1000 − now%1000)` 起 `setInterval(1000)`，不跳秒、不长跑漂移。
- **分级脏检查**：秒 → 每拍写（秒数 + 游标）；分 → 只在 `HH:MM` 变化时写；日期 → 只在跨日时写。
- **单一定时器**：全页只有 1 个 `setInterval`，`onHide`/`onDestroy` 双清（含对齐用的 `alignTimer`）。
- **显式分支赋值**：`setDigit(i, c)` 用 if/else，不用 `this['h'+i]`（动态属性名不保证被 Vela 观测）。

### 为什么游标"跳"而不是"扫"

扫秒需要 60×N 帧/分钟的位移推送（M2），而秒环的位移是**圆弧**，推 `left/top` 得同时改两个值、还要算中间角度——收益（视觉更顺滑）与风险（每帧两处绑定 + 圆整误差）不成正比。
**v1 采用 6° 跳格（石英表手感）**，配合常亮的呼吸光晕，画面任何时刻都有东西在动。

### v3 补充：三级游标拖尾（静帧也看得出转向）

单点跳格有个弱点——**静帧看不出盘是在顺时针转还是逆时针转**。v3 在游标后面补两级渐隐：

| 元素 | 角度 | 尺寸 | 颜色 |
|---|---|---|---|
| `.cur`（当前秒） | sec × 6° | 14×14 | `#7ec8e3` |
| `.cur2`（前一秒） | (sec−1) × 6° | 12×12 | `#3d7f95` |
| `.cur3`（前两秒） | (sec−2) × 6° | 10×10 | `#274b5c` |

实现仍是**纯数据绑定 `left/top`**（`posOf(deg, size)` 一个函数算三档），不新增 `transform`、不新增 `@keyframes`、不新增定时器；
每秒写入字段从 3 个变成 7 个（`secText` + 三档 × 2 坐标），仍是同一拍里一次性推完。
回绕用 `(sec + 59) % 60` / `(sec + 58) % 60`，0 秒时拖尾落在 59 秒位置，不会越界。

### v4 补充：分钟个位数字带上滚（P3 已落地）

MM 从"整块换字"改成"十位换字 + 个位滚动"，这是全页第一个非环形的动效，也是 M2 在本页的第一次使用：

| 项 | 取值 |
|---|---|
| 裁切窗 `.mmWin` | 55×100，`overflow: hidden`，`position: relative` |
| 数字带 `.mmStrip` | `position: absolute`，`top: {{ mmTop }}px`，内 11 格（`0..9` + 副本 `0`） |
| 单格 `.mmDig` | 55×100，`font-size: 96px`，`line-height: 100px` |
| 帧间隔 | 60ms / 格（跨 1 格 = 1 帧，跨 9 格 = 9 帧 ≈ 540ms） |
| 位移公式 | `mmTop = -mmIdx × 100` |

三个必须写对的细节：

1. **数字带必须显式给高度 + 列向排布**（`.mmStrip { height: 1100px; flex-direction: column }`）。
   只给 `position: absolute` 时 11 格会在同一行横排，实拍表现是"窗里只有一个数字、其余挤在右边"——本轮踩了两次。
2. **`9 → 0` 走副本格**：`target = (one === 0 && from === 9) ? 10 : one`，滚到索引 10（即副本 0），
   滚完立刻把 `mmIdx/mmTop` 复位成 `0/0`，避免下一轮从 10 越界。
3. **方向由差值符号决定**（`dir = target >= from ? 1 : -1`），所以 `58 → 59` 下滚、`59 → 00`（经副本）仍是下滚，
   不会出现"跳回上一个数字"的错觉。

失败语义：`rollTo` 的定时器句柄存在 `this.rollTimer`，`stop()` 里与心跳一起清；滚动中若又来一次 `setMinute`
（快速跨分钟），先 `clearTimeout` 再重算 `from`，**不会出现两条数字带同时推 top**。

## 四、分档与回退

| 档 | 内容 | 风险 | 回退 |
|---|---|---|---|
| **P0** | 60 格秒环 + 秒游标 + 环心秒数 | 低 | 删游标，退纯秒数 |
| **P1** | 呼吸光晕（`@keyframes` infinite） | 中（infinite 有黑屏前科） | 删 `.halo` 整层，其余不受影响 |
| **P2** | HH/MM 88px 大字 + 脏检查走时 | 低 | 换回 64px 单行 |
| **P3** | 分钟个位用 M2 数字带上滚（v4 已做，60ms/格） | 中 | 保持纯换字 |
| P4（未做） | 环内扫光弧（M1 类交换 60 档） | 中 | 秒游标已能表达进度，可不加 |

**预算**：同屏 `@keyframes` 规则 ≤ 2 条；每秒变更的绑定值 ≤ 4 个（秒数 + 游标 left/top + 可选的分钟位）。
P3 只在**跨分钟那一秒**额外产生 1 条 `setTimeout` 链（≤ 9 帧），平时零开销。

## 六、风险登记

| 风险 | 说明 | 处置 |
|---|---|---|
| infinite 动画长时间冻结 | 金属表盘实测 12s 冻结，本页只在光晕上用了 infinite | 光晕是纯装饰，冻结时不影响读数；连续 8 帧全同即判失败并删该层 |
| 60 个 `for` 节点的首帧开销 | 首次渲染 60 个绝对定位小盒 | 静态不重绘，实测冷启未变慢（见 §七） |
| 圆整误差 | `sin/cos` 结果取 1 位小数，环可能轻微不圆 | 半径 66、误差 < 0.2px，肉眼不可见；单测校验极值在 ±0.5 内 |
| 名不副实 | 页面名/目录文案是"动画表盘"，v1 实际是"秒环 + 跳秒" | 若要更强动效，按 P3/P4 加档，不改名 |
