# 添加课程页面 — 全新界面实现方案

## 一、设计目标

彻底重构"添加课程"页面，解决以下现有问题：

| 问题 | 现状 | 目标 |
|------|------|------|
| 四步向导 | 分4步操作，反复前进/后退 | 单页布局，一目了然 |
| 文字被挤压 | 28处 line-height 缺失 | 所有文本规范 line-height |
| 时间输入困难 | +/- stepper 逐次点击 | 滚轮或直接输入 |
| 课程选择效率低 | 卡片左右翻找 | 列表直接点选 |
| 胶囊屏适配差 | padding 120px 过大 | 紧凑布局 30px 上下 |

---

## 二、设计规范（摘录自 ui 规则文件）

### 2.1 屏幕基准

| 屏幕形态 | 宽度 | 可用内容宽度 |
|---------|------|-------------|
| 胶囊屏 (capsule) | 466px | ≈ 430px（圆角扣除） |
| 方屏 (rect) | 336px | ≈ 320px |
| 圆形屏 (circle) | 466px | ≈ 320px（圆形裁切更多） |

默认优先适配胶囊版（466px），其次方屏版。

### 2.2 排版规范

| font-size | line-height | 公式 |
|-----------|------------|------|
| 20px | 28px | fs + 8 |
| 24px | 32px | fs + 8 |
| 28px | 38px | fs + 10 |
| 32px | 42px | fs + 10 |
| 36px | 46px | fs + 10 |
| 40px | 50px | fs + 10 |
| 48px | 56px | fs + 8 |

**规则**: `line-height = font-size + 8~12px`，最小行高不小于字号 + 8px。

### 2.3 文本溢出保护

所有动态文本必须设置：
```css
max-lines: 1;
text-overflow: ellipsis;
```

### 2.4 点击区规范

- 按钮最小尺寸：40×36px（手表端）
- 推荐按钮高度：44~48px
- 按钮圆角：12~14px
- 返回按钮：52×44px，圆角 26px

### 2.5 间距规范

| 区域 | 胶囊版 | 方屏版 |
|------|--------|--------|
| 页面上下 padding | 30px | 16px |
| 页面左右 padding | 16px | 8px |
| 卡片 padding | 14px | 10px |
| 区块间距 (margin-bottom) | 14px | 10px |

## 五、交互流程

### 5.1 页面加载

1. 读取本地存储中的课程预设列表 → 渲染网格
2. 读取 `add_course_day` → 选中当天星期
3. 默认选中第一个课程

### 5.2 选择课程

- 点击课程卡片 → 高亮选中（蓝色边框）
- 自动填入该课程默认时间
- 如果课程有默认位置，填入位置栏

### 5.3 调整时间

**方案 A（推荐）：点击弹出浮层**
- 点击"开始时间"区域 → 弹出时分选择浮层
- 浮层样式：居中，半透明遮罩
- 小时列（0-23）上下滚选，分钟列（00/15/30/45）快捷选择
- 点击"结束时间"同理
- 自动校验：结束时间不得早于开始时间

**方案 B（备选）：在时间卡片内嵌入 +/- 按钮**
- 小时与分钟旁边各一组 +/- 按钮
- 字号 22px，按钮 36×36px
- 比现有 stepper 更紧凑

### 5.4 输入位置

- 点击位置输入框 → 跳转中文输入页面
- 返回后自动填入

### 5.5 选择星期

- 7个圆形按钮，选中高亮
- 默认选中当天
- 仅允许单选

### 5.6 确认添加

- 校验课程名非空
- 校验时间非空
- 校验结束时间 > 开始时间
- 保存至数据库，弹出 toast "已添加"
- 返回上一页并刷新列表

## 六、与旧版对比

| 维度 | 旧版（4步向导） | 新版（单页布局） |
|------|----------------|-----------------|
| 操作步骤 | 4步，需反复前进后退 | 1页，一次性完成 |
| 课程选择 | 左右翻找卡片，效率低 | 网格列表，一眼可见 6-9 门 |
| 时间设置 | 按 +/- 逐次调节，慢 | 点击弹出滚轮选择 |
| 星期选择 | 默认当天，无法修改 | 7按钮自由选择 |
| text line-height | 10处缺失 | **0处缺失** |
| 文字溢出保护 | 3处缺失 | **全覆盖** |
| 底部按钮高度 | 48px 统一 | 48px 统一 |
| 胶囊版总高度 | ~600px（需滚动） | ~520px（一屏内） |
