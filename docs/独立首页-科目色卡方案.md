# 独立首页方案 · 科目色卡（schedule-panel-subject-color）

> 系列：7 个课表首页独立化改造（umbrella: evtask-D-evclass-sche-261019-wxfkmx）
> 「独立首页标准 v1」见 `docs/独立首页-当前进度方案.md` 附节，本页直接引用。

## 1. 页面定位（重新规划）

「科目色卡」是**今日课程的科目色标清单**：每节课一张卡片，左侧 8px 科目色条（按科目名映射 14 学科色板，未匹配取灰），右侧课名 + 时间 + 地点。

作为独立首页的差异化价值：**用颜色扫一眼今天的课**——色相即科目身份，比纯文字清单更快定位。保留现有信息结构。

## 2. 现状 vs 独立首页标准

| 维度 | 现状 | 达标 |
|---|---|---|
| 数据自加载 | `database.init` + `getAllCourses` | ✅ |
| 主题适配 | 文字色全走 theme 变量 | ⚠️ 卡片底色**硬编码** `rgba(255,255,255,0.05)`（CSS 类内联不了 theme），浅色主题下白叠加近乎隐形，卡片失去边界 |
| 加载态/空态 | 加载中 + 「今天没有课」 | ✅ |
| 屏型适配 | `width >= 200` 断点 | ✅ |
| 生命周期 | 无定时器（静态清单） | ✅ |
| 返回逻辑 | `goBack()` 直接 `router.back()` | ❌ |

**两处缺口**：返回逻辑（同前两页）；卡片底色硬编码（标准 v1 第 3 条「禁止硬编码颜色」）。

## 3. 改造项

1. **root 判定 + 双模返回**（标准 v1 第 1 条，同第 1/2 页）：`fromPanel`/`isRoot`、返回钮条件渲染、`goBack` 双模、`onBackPress` 双模、`require utils.js`。
2. **卡片底色主题化**：`.course-card` 的 CSS 硬编码 `rgba(255,255,255,0.05)` 移除，改模板行内 `style="background-color: {{ theme.card }}"`，与全局卡片体系一致（深浅主题都有清晰边界）。
