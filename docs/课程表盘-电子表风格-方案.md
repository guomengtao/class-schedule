## 一、目标与边界

**要做的**：在「工具」栏目新增**第二款表盘** —— 电子表风格（数码管/LCD），把**真实课表数据**融进盘面：不只是显示时间，还要显示「现在在上什么课 / 下节是什么课 / 还有多久」。

**明确的边界（不做）**：
- ❌ 不做指针/机械风格（上一款 `watch-face` 已经是，本款刻意做成电子表形成对比）
- ❌ 不修改、不写入课表数据（**只读**）
- ❌ 不改动现有机械表盘页面（独立新页面，互不干扰）
- ❌ 不做设置项/自定义配色开关（首版固定一套风格，如需再议）

---

## 二、侦察结论（已实测确认）

| 项 | 结论 |
|---|---|
| 课表存储 | `@system.storage`，key = **`course_preset_list`**，值为 **JSON 数组** |
| 课程字段 | `{ id, name, time: "8:00 - 9:40", ... }`（`time` 分隔符为 ` - `，解析需 trim） |
| 当前课判定 | 现成逻辑在 `week-view.ux:802 detectCurrentCourse()`：把 `HH:MM` 转分钟与 `now` 比较，可照搬 |
| 按星期分组 | `week-view.ux:543` 起 `allCourses[dayName]` 的组装方式可参考 |
| 读取范式 | `course-manager-v2.ux:138 loadCourses()`：`storage.get` + `JSON.parse` + 失败回落默认课表 |
| 引擎能力 | `transform` / `position:absolute` 多页面已在用（loading-lab 等），Vela 支持 |
| 屏幕 | 池内 `xiaomi_band` = 小米手环 9 标准版 192×490 ✅ |

## 四、盘面设计（192×490 纵向分区）

```
y  40- 66  顶部状态条：10-08 周四 · 今日 5 节
y  74-150  巨型电子时间  HH:MM（字号 ~62px）
           冒号每秒闪烁；右侧小字 :SS
y 158-186  AM/PM + 当前时段标签（上课中 / 课间 / 放学）
y 194-252  课程主卡片：
           ┌ 进行中 ┐ 高等数学
           08:00 - 09:40 · 剩余 23 分钟
y 258-276  课程进度条（当前课已过百分比）
           —— 课间时改显示：下一节 数据结构 · 还有 12 分钟
y 286-430  今日课程时间轴（接下来 3 节，当前项高亮）
           ① 高等数学   08:00
           ② 数据结构   10:00   ← 高亮
           ③ 大学英语   14:00
y 440-470  底部：今日进度 / 放学倒计时
y 470-490  安全区留白（不放内容）
```

**视觉风格（默认方案）**：深色炭黑底 + **青绿荧光**（#7dffb0 系）+ 等宽数字感，模拟 LCD 背光；与上一款「银白机械」形成明确对比。

> 备选（你说一声就换）：琥珀橙（#ffb347，老式 LED 味）／跟随 App 现有主题色。

## 六、风险与回滚

| 风险 | 应对 |
|---|---|
| 课表为空 / 无课 | 显示「今日无课」，不崩溃（storage 失败也有默认回落，照抄 course-manager-v2 范式） |
| `time` 字段格式不一（`8:00-9:40` vs `8:00 - 9:40`） | 解析前统一按 `[-–—]` 切分并 trim |
| 每分钟重算课程，性能 | 定时器 1s 只更新时间；课程判定放到「分钟变化」时才算 |
| 模拟器环境抽风（今晚连环故障） | S3 用全新实例首装；若再遇僵死则**诚实降级**为「构建+逻辑校验通过，实拍待办」，不谎报 |
| 回滚 | 删 `watch-face-class/` 目录 + revert manifest 与 tools 两处即可，零残留 |
