# 首页自定义内容栏模块功能需求分析

## 一、功能定位

自定义内容栏是首页的一个可编辑文本区域，用户可以自由输入文字内容（如励志名言、今日目标、备忘提醒等），显示在课程列表上方。

**使用场景**：用户想在课表上方放一句「今天要加油！」或者「下午3点有班会」，打开自定义内容功能输入文字，即可一直显示在首页。

## 二、界面布局格式要求

自定义内容栏位于日期导航栏下方、状态栏上方，占一行高度，左侧有彩色竖条装饰。

```
┌──────────────────────────────┐
│  ◀      星期一      ▶        │  ← 日期导航栏
├──────────────────────────────┤
│ ▎ 今天要加油！               │  ← 自定义内容栏
├──────────────────────────────┤
│ [上课中] 数学      15min     │  ← 状态栏
├──────────────────────────────┤
│  ...                         │
└──────────────────────────────┘
```

- 左侧：彩色竖条装饰（与主题色一致）
- 右侧：用户输入的文字，单行显示，超出省略号截断

## 三、用户视角的功能描述

### 3.1 开启功能

用户在设置中开启「自定义内容」开关，并输入想显示的文字，首页即显示该内容。

### 3.2 关闭功能

用户在设置中关闭开关，首页的自定义内容栏隐藏。

### 3.3 修改内容

用户随时可以在设置中修改文字内容，首页实时更新。

### 3.4 空内容

如果用户开启了功能但没有输入文字，首页不显示该栏。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 在设置中开启并输入文字 | 首页显示自定义内容栏 |
| 在设置中修改文字 | 首页内容实时更新 |
| 在设置中关闭开关 | 首页自定义内容栏消失 |
| 开启但未输入文字 | 首页不显示该栏 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 文字过长 | 单行显示，超出部分用省略号截断 |
| 文字为空 | 即使开关开启也不显示 |
| 切换日期 | 自定义内容不变（不随日期变化） |
| 切换课程表 | 自定义内容不变 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 设置页 | 在设置中控制开关和编辑文字内容 |
| 状态栏 | 自定义内容栏在状态栏上方显示 |
| 其他模块 | 无依赖关系，完全独立 |
