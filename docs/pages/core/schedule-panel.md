## 0. 目录页 `pages/schedule-panel` ——「更多首页」栏目索引

> 源码：`src/pages/schedule-panel/schedule-panel.ux` ｜ 数据源：同目录 `data.js` 的 `tabsData`
> **已按 `ev-six` 六位准则重排（2026-10-25，evtask-D-evclass-sche-261025-5aqmfh）。**

职责单一：把 `tabsData` 一章一组的 8 个栏目**展平成一条竖向列表**，点任意行 `router.push` 到对应页并带 `params.fromPanel='1'`（目标页据此判定自己不是 root 页）。不折叠、不分组、不解释。

### 0.1 界面结构

| 区块 | 内容 | 说明 |
|---|---|---|
| 头部 | 返回键 30 + 标题「栏目」28px + 等宽占位 30 | 3 元素骨架；标题 2 字 = 75px，可用宽 108px，余 33px |
| 栏目卡 | 单张 card，内 8 行 × 44px，无分隔线无箭头 | 整块成组；可点性靠 card 底色，不靠符号 |

标题由「更多首页」改为「栏目」是**删字不缩字号**：4 字 @28 实宽 149px，头部可用宽只有 108px（192 − 12×2 − 30 − 30），原样必折行裁字。

### 0.2 三处硬预算修复（重排前后对照）

| 项 | 重排前 | 重排后 | 判据 |
|---|---|---|---|
| 标题宽 | 「更多首页」4 字 = 149px vs 可用 116px ❌ 折行 | 「栏目」2 字 = 75px vs 108px ✅ | 手册 §4.1（1 汉字 ≈ 1.33 × 字号） |
| 条目宽 | 页面 8 + 卡片 14 ⇒ 内宽 148px < 4 字 149px ❌ 贴边裁字 | 页面 12 + 卡片 8 ⇒ 内宽 152px ✅ 余 3px | 手册认可「贴边」配置 |
| 整页高 | 8×50 + 头部 + 留白 = 518px > 490 ❌ 末项被切 | 8×44 + 其余 = **468px** ✅ 一屏放下 | 行 padding 6→3，44px 恰是触控最小热区 |

468px 的算式：页面顶 44 + 头部 30 + 头部下距 10 + 卡片纵向 padding 10×2 + 8 行 × 44 + 页底 12。

### 0.4 简易课表 `schedule-panel-simple`（同日重排，evtask-D-evclass-sche-261025-veq7rw）

今日课程列表页，5 行固定、不滚动、分钟级刷新。**这是本组里违规最重的一页**：字号 20/18/22px、5 处 `if`、`ellipsis`、`·`、8px 状态点，五条红线同时踩。

| # | 改前 | 改后 | 依据 |
|---|---|---|---|
| 字号 | 课名 20/22、时间 18/20、日期 22 | 课名 28、时间与日期 24（行高 38/34） | 红线 2：只认 44/30/28/24 |
| 行结构 | 上下两行（课名 + 时间），行高 52 | **单行左右两列**，行高 56 | 见下方「为什么必须改单行」 |
| 状态表达 | 8px 三色圆点（灰/主色/白） | 行底色 + 字色：当前课 `progressOngoing` 淡底 + accent 字，已过课 `textMuted` 字，未到课 `text` 字 | 红线 9：状态靠底色；8px 在 15mm 屏上不可辨 |
| 日期标题 | 「今天 · 周日」 | 「今天 周日」 | 红线 4：禁 `·` |
| 超宽处理 | `text-overflow: ellipsis` | 去掉，自然裁切不出现「…」 | 红线 8：禁省略号 |
| 条件渲染 | 5 处 `if="{{ }}"` | `display` 绑定 | 事故案例 11：多兄弟节点 `if` 会整页白屏 |
| 时间格式 | `08:00`（5 字符） | `8:00`（4 字符，省 13px 给课名） | 位置预算 |

**为什么必须从两行改单行**：四档字号下两行结构行高 = 38 + 34 = **72px**，5 行 360px；加上头部与日期行，末行底边会到 y≈478，而胶囊屏在 **y>438 后可见宽度已不足 168px**（圆心 490−96，半径 96），末行会被圆弧实切。改单行 56px×5=280px 后整页 430px，末行底边 y≈410，安全。

**代价（已知取舍）**：单行里课名可用宽 ≈91px ≈ **2.4 汉字 @28px**。默认 12 门课名全是 2 字（语文/数学/英语…）完全够用；自定义 3 字以上课名（如「自习课」）会被裁掉最后一两字。这是 192px 宽的物理上限——想装 4 字课名只能回到两行结构，那就必然丢掉第 5 节课，取舍后选保留完整 5 行。

**验收**：`test/schedule-panel-simple.test.js` 47 项 + 聚合套件 55 项全绿；模拟器截图确认单行左右两列、行高 56、时间右对齐、已过课灰字；当前课高亮态由单测断言 `isCurrent` + 模板 `progressOngoing` 绑定覆盖（设备当日课程恰好全部已上完，未截到高亮态）。

**头部标题兼状态位**：192px 一行只放得下一句话，而本页需要「节次 / 课名 / 剩余 / 进度 / 下节 / 时钟」六段信息。把节次挪进头部标题（`第3节` / `课间` / `今天`，@28 最坏 102px ≤ 头部可用 108px），正文才腾出一行。页面身份由「更多首页」入口与返回键提供。

**上下对称占位**：内容块在「头部以下、时钟以上」这段安全区里垂直居中，时钟仍贴安全区底部。只放一个占位会让内容全挤在上半屏、中间空出一大片（首版截图就是这个效果）。

**最坏栈高 404px ≤ 440px**：`44(顶) + 40(头) + 12+120(两行课名) + 10+34 + 14+10(条) + 18+68(两行下一节) + 34(钟) = 404`。课名两行（3 字以上）时仍不进圆弧。

**验收**：`test/schedule-panel-progress.test.js` 92 项 + 聚合套件 55 项全绿；其中新增 ev-six 硬指标断言——字号只出现 44/28/24、无 `text-overflow`、无 `·`、无 `if=`、页面左右 padding 12、底部留白 ≥50、**按 CSS 数值累加的最坏栈高 ≤440**。模拟器（emulator-13000）截图确认「第4节 / 物理 / 剩 42 分 / 进度条约 28% / 下节 17:20 自习课 / 16:28」六段完整无裁字。

> 截图用的是临时注入的「周日 5 节课」演示数据（物理 16:10-17:10 覆盖截图时刻），拍完已 `git checkout` 还原 `src/data/schedule.js`，仓库里的内置课表不含周日。

| 定时器 | `setInterval(… , 10000)` 常驻轮询 | 对齐「下一个整分」的单发 `setTimeout` | 方案 §0 禁秒级轮询；跨节次才需要重算 |
| 垂直布局 | 卡片 `flex:1` 撑满、内容顶到胶囊下沿 | 上下各一颗 `flex:1` 的 `.spacer` 居中，最坏栈高 320 | 内容底 ≤440（y>440 后右缘 x<180） |

**代价（如实记）**：课间态大数字从 72px 降到 44px，视觉冲击损失最大——四档上限 44 不可破；补偿是「状态词 + 大数字 + 下节课名 + 时间」四行节奏，一眼能读出「还有多久」和「上什么」。

**验收**：`test/schedule-panel-dual-mode.test.js` **85 项全绿**，含 ev-six 硬指标（字号只出现 44/28/30/24 / 无 12~23px / 无 `·›→` / 无 ellipsis / 无 `if=` / 5 处 display 逐条断言 / 左右 padding 12 / 标签居中）与三态判定（上课中进度 67%、课间 01:00、有课上完=下课/明天见、今天没课=无课/今天没有课）+ 字宽护栏 + **最坏栈高 320 ≤ 440**。模拟器 `emulator-13000` 实拍：智能 / 上课中 / 历史 / 到 18:30 / 已过 64 分 / 还剩 26 分。

> **两个阻塞的根因（都是静默失败，不报错）**
> 1. **`database.init(cb)` 在 `onInit` 里同步调 → 回调永不触发**。探针走 `0→1→2→L→T` 就断了，页面永远停在「加载中」。修法：先 `self.apply(内置课表)` 铺第一帧，再把 `database.init` 挪进 `store.getTheme` 的**回调里**（同 countdown 页的成熟写法）。storage 全挂时也能出画面。
> 2. **同一 `style` 里两个 `{{ }}` 绑定 + `if=` 混用 → 整页只渲染标题**。修法：一个节点只放一组绑定；`display` 给外层容器，配色/字号给内层或同层的另一属性（本项目 remaining/countdown 已稳态）。
> 3. 附带一条：**`<text>` 不吃 `align-self: center`**，居中只能 `width: 100% + text-align: center`；首版状态标签就是被它顶到左边。
> 4. 附带二条：字宽口径 0.5em/半角**偏乐观**，真机数字接近 0.63em（24px 下 13 字符就吃掉 168px）。本页单测已改用 0.63em 并留一条「整段时间必超宽」的回归哨兵。

## 1. 功能说明

面板（Schedule Panel）是课程表在锁屏、负一屏或主页卡片区域的紧凑展示组件。相比完整"表盘"，面板更强调**一屏多看**与**快速信息密度**，通常作为手环多表盘体系里的"信息聚合"入口。所有面板共享课表数据源，差异在**信息密度、进度表达与配色策略**。

## 2. 变体清单

| 末段 | 名称 | 差异点（概览） |
|---|---|---|
| `schedule-panel` | 面板·基础 | 默认：当日节次网格（**实际为目录页，见 §0**） |
| `schedule-panel-simple` | 面板·简约 | 今日课程单行列表，5 行固定不滚动（见 §0.4） |
| `schedule-panel-progress` | 面板·进度 | 三态页 + 节进度条（见 §0.5） |
| `schedule-panel-remaining` | 面板·剩余 | 剩余节数 + 总时长 + 前 4 节（见 §0.6） |
| `schedule-panel-subject-color` | 面板·科目色 | 当前科目色条 + 2×3 色块网格 + 图例（见 §0.7） |
| `schedule-panel-countdown` | 面板·倒数日 | 距下课/距上课三态 + 明日首节（见 §0.8） |
| `schedule-panel-dual-mode` | 面板·智能切换 | 按当前时刻自适应 上课中/课间/结束 三态（见 §0.9；原表写的「双周」名不副实） |
| `schedule-panel-colorful` | 面板·多彩 | 高饱和配色主题 |

## 3. 实现要点

- **复用表盘渲染层**：面板与表盘共享底层课表切片与配色方案，仅在布局模板上分叉。
- **双周模式**：~~原计划给 `schedule-panel-dual-mode` 读"单双周"标记做高亮~~ —— 实读源码后确认该页是**时间态自适应**（上课中/课间/结束），与本条无关，已按实况改写在 §0.9；真要单双周需另开页面与数据字段。
- **进度/剩余语义**：`progress`/`remaining` 依赖当前时间相对节次的时间窗计算，需处理"无课日""已结束"边界态。
- **胶囊屏安全区**：同表盘，所有面板须避让圆角。
