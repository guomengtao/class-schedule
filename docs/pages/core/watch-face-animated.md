# watch-face-animated · 动画表盘

> 角标精确命中，不走组级回退。上级目录见 [watch-face.md](./watch-face.md)。
> 双屏适配全过程与预算推导见 `docs/WatchFace-动画表盘-双屏适配方案.md`。

## 定位

秒环 + 呼吸光晕 + 大字时间的动效表盘。三层结构：

| 层 | 内容 | 实现 |
|---|---|---|
| L1 | 60 格秒环 + 三级游标（当前 + 前 1 秒 + 前 2 秒拖尾） | 极坐标算 `left/top`，走**数据绑定** |
| L2 | HH / MM 100px 大字，分钟个位走上滚数字带 | 整分脏检查 + `mmStrip` 位移 |
| L3 | 呼吸光晕（140/168 双圆挖出光带） | 全页唯一 `@keyframes`，只动 opacity |

## 与其他表盘的本质差异

**本页几何不在 CSS 里。** 60 格坐标由 `buildDots()` 用 `CX/CY/R` 常量算出，游标每秒由 `placeCur()` 现算。所以：

- 不能走 `transform: scale()`（会把 60 个绑定坐标一起放大，圆心跟着偏）
- 不能只改 CSS（改 CSS 对 60 格完全无效）
- 宽屏适配必须**改 JS 常量 + CSS 单类双改**

## 双屏参数

| 元素 | 192×490 | 336×480 |
|---|---|---|
| `CX / CY / R` | 96 / 96 / 66 | **168 / 112 / 80** |
| `ROW`（分钟滚动行高） | 100 | **104** |
| `.halo` / `.haloIn` | 26,26·140 / 36,36·120 | 84,28·168 / 96,40·144（光带 12px） |
| 品牌 EV | top 6 / 12px | top 4 / 18px |
| 秒数 / SEC | 70·40px / 120·10px | 87·44px / 141·16px |
| HH | 内联 top 186 / 96px lh100 | 绑定 dgTop 196 / 100px lh104 |
| MM 十位 / 窗 | 42,290·55 / 95,290·55×100 | 110,300·58 / 168,300·58×104 |
| 日期 / 返回 | 400·24px / 434·24px | 406·24px / 440·24px |

纵向：环 28–196 → HH 196–300 → MM 300–404 → date 406–436 → hint 440–470（底余 10px）。

## 三个必须记住的坑

1. **`.dg` 的 top 曾经写在内联 style 里**（`style="top: 186px"`）。内联优先级高于 class，不改绑定的话 `.w-dg { top: … }` 完全不生效。现已改成 `style="top: {{ dgTop }}px"`。
2. **`rollTo()` 的步长必须等于行高**。原代码 `mmTop = -mmIdx * 100` 把行高写成字面量；改字号→改行高却不同步步长，数字带会滚半格。现已改用 `ROW` 常量。
3. **`mmWin` 窗高 = `mmDig` 高 = `ROW` 三者必须一致**，任一不同都会裁掉数字上下沿（与 gold 的「字号变了 height 没变」同一个病）。

## 生命周期

- `fitScreen()` 从 `onInit` 调 —— 本仓 `watch-face-functional` 已实测 `onReady` 可能不触发
- `onReady` 与 `onShow` 都调 `start()`，所以计时有两道兜底；但**屏宽判定只有 `onInit` 这一道**
- 页内 `require("@system.device")`，不用顶部 `import`（同模块 import/require 并存会静默失效）

## 硬约束（改本文件前必读，源自头注释）

① 禁 transform 数据绑定；② 禁 scroll+scrolltop；③ 禁群组/后代选择器；④ `.page` 只 100%/relative；⑤ keyframes 只放字面量、只挂纯色无文字节点。

## 遗留

分钟个位上滚无法用静态截图验证（需盯跨分钟瞬间）；已靠三点一致（窗高/字高/步长 = 104）控制。低端设备持续动效掉帧问题另见主文档性能段。
