# watch-face-class · 表盘·课程（LCD 电子表）

> 页路径：`src/pages/watch-face-class/watch-face-class.ux`
> 变体名：课程表盘 —— LCD 背光风格，全页只为「今天上什么课」服务
> 方案：`docs/WatchFace-课程表盘-双屏适配方案.md`

## 形态

**本仓唯一没有几何图形的一块**：没有表壳、表圈、刻度、指针、圆环。整页是 9 个绝对定位的文字块
+ 1 个带边框卡片 + 1 条进度条 + 3 个隐形热区，靠 `#0a0e12` 炭黑底 + `#7dffb0` 青绿荧光模拟 LCD 背光。

| 块 | 类名 | 内容 | 192 y 范围 |
|---|---|---|---|
| 状态条左 | `.status-left` | `10-26 周一` | 46–66 |
| 状态条右 | `.status-right` | `今日 6 节` / `今日无课` | 46–66 |
| 大字时间 | `.clock-row` | `07:56` + 冒号（每秒闪）+ `:16` | 78–142 |
| 时段标签 | `.phase-tag` | 上课中 / 课间 / 放学 / 自由时间 / 「星期X课表」 | 168–190 |

## 三处 JS ↔ CSS 双控（改一处漏一处不会报错）

```js
let BAR_MAX = 156   // 必须 = .bar-track width，否则满格时溢出或不满
let TL_TOP = 286    // 时间轴首行 y
let TL_GAP = 42     // 行距，≈ .tl-row height + 2
```

`fitScreen()` 在 `w >= 300` 时整组改成 `292 / 280 / 44`，192 屏不进入该分支
→ **192 是结构性零回归**，不是「改完再对齐」。

**历史坑**：原代码把行距写成 `TL_TOP + i * 42` 两处字面量（第 289、357 行，fallback 分支与正常分支
各一处）。改成常量时必须两处同时改，漏一处的症状是「今天有课和今天无课的行距不一致」——
只有周末才看得出来，极难发现。

## 数据依赖

```js
const database = require("../../data/database.js")
```

`getAllCourses()` 返回**排课数组** `[{ day: "星期一", classes: [...] }]`，不是以星期名为 key 的对象。
旧实现按 `all["星期一"]` 取值必然 `undefined`，盘面会恒显「今日无课」——已按数组形态修正。

今天无课时回退到「本周内最近一个有课日」，`fallbackLabel` 记来源（如「星期一课表」），
`phase-tag` 显示它、`.foot` 显示「今日无课 · 显示星期一课表」。
**fallback 状态只列课表、不算实时进度**——时间基准是另一天，算「上课中/还剩几分钟」必然是错的。

## 交互（四条，全部隐形）

| 方式 | 实现 | 反馈 |
|---|---|---|
| 长按时间区 2s | `.hit-clock` + `onlongpress` | 进度条从 0 推到满（20 步 × 100ms） |
| 长按卡片区 2s | `.hit-card` + `onlongpress` | 卡片边框转亮绿 `#7dffb0` |
| 双击右下角 | `.hit-corner`，两次间隔 < 500ms | 震动 + 退到目录 |
| 下往上滑 ≥ 40px | `ontouchstart`/`ontouchend` 判方向 | 上滑→经典表盘，下滑→金色表盘 |

退出统一走 `router.replace({ uri: "/pages/watch-face-list" })`——幂等，连触两次也只停在目录；
用 `back` 会退过头导致黑屏。

**三个热区是透明 `div`，宽屏必须与可见块同步放大**：错位的症状是「点了没反应」，比视觉错位更难查。

## 已知问题

- **192 屏状态条右段的「节」字在修复前被裁**：`.status-right` 原 `left:124 width:56`，15px 字号下
  「今日 4 节」需约 68px，实测只渲染 3 个字符簇。已改为 `left:112 width:68`——右端点仍是 180，
  `text-align:right` 保证文字贴同一右端点，只是不再裁字。
- 课程卡片 82px 高装三行（34+22+22=78），余量仅 4px，宽屏字号的上下沿几乎贴框。
- 本盘 192 基线字号未做「≥24px」提升：课程表版面密集，整体提字号会挤爆，且原 13–16px 在 192 上可读。
