## 2. 走针机制（**不要改**）

页面头部注释里写死的三条引擎坑，2026-10-19 标定得出，动了会黑屏或错位：

1. **不用** `transform: rotate({{deg}}deg)` 数据绑定 —— 整页黑屏；
2. **不用** `@keyframes` 承载当前时刻 —— 指针角度与盘面时间对不上、周期性整根消失；
3. 引擎旋转轴实测为 **元素顶部中点**，`transform-origin` 不按 CSS 语义生效。故三针一律「顶部中点压在盘心 (92,92) + 向下延伸」，`rotate(180+θ)` 即指向 θ。

角度走 **60 档字面量类 `.r0…​.r59`**（内部 `rotate(180 + 6N)`，6° 一档）。JS 里 `stepClass(deg)` 只负责算 class 名，不写 transform 值。

## 3. 几何（192 基线，全部相对 `.dial-wrap`）

`.dial-wrap` 定位 `left:4px; top:153px`，尺寸 184×184。盘内 32 个节点坐标全部落在这个 184 坐标系里：

| 层 | 节点 | 尺寸 / 位置 |
|---|---|---|
| 壳 | `.ring-outer` | 184×184 @0,0　r92 |
| 壳 | `.ring-mid` | 168×168 @8,8　r84 |
| 面 | `.dial-face` | 148×148 @18,18　r74 |
| 刻度 | `.tick` ×12 | 2×10，`left/top` 内联 + 字面量 `rotate(0…330deg)` |
| 地支 | `.gan` ×12 | 20×20 / 14px |
| 针 | `.hour` 5×48　`.minute` 4×66　`.second` 2×80 | 全部 `top:92px`，left 89.5 / 90 / 91 |
| 心 | `.hub` 16×16@84 | `.ev` 铭文 10px @62,96 |

**盘心 = (92, 92)**。

## 4. 布局铁律

`.page` **只给** `width/height:100%` + `flex-direction:column`。**绝不加** `justify-content` / `align-items` —— 加了会与 absolute 子元素共同触发黑屏。宽屏适配也没有碰 `.page`。

## 5. 双屏适配（2026-10-26）

走 **父级 scale** 路线，与方形机械表盘（vibrate）同族，与字体表盘（font）相反。

**为什么不是逐节点改**：32 个节点 × left/top 两个值 = 64 个数，圆心/半径/刻度角的比例关系必然算崩。`transform: scale(1.5)` 一次放大整个 `.dial-wrap`，**32 个盘内节点一个都没改**，几何天然正确。

| 宽屏类 | 作用 |
|---|---|
| `.w-dial` | **唯一带 transform 的类**：`scale(1.5)` + `left:30px; top:78px` |
| `.w-brand` / `.w-bsub` | 品牌区重排，补 `width:100%`（原 192px 定宽会让文字中心停在 96） |
| `.w-date` / `.w-time` / `.w-back` | 底部三行重排，`width:100%` + 字号 24 / 52 / 24 |

**盘径与盘心**：184 × 1.5 = 276，`(336−276)/2 = 30` → 盘心 `(30+138, 78+138) = (168, 216)`。实测 277 / (168,216)。

**关键结论：父级 scale 不影响子元素的旋转轴**。三针 `top:92px` 的"顶部中点"轴在放大后仍是盘心，07:04 / 07:13 两次实拍指位与盘面时间一致。

### 探针写法（照抄，别改）

```js
onInit() {
  this.fitScreen()   // 必须 onInit，不能 onReady
  ...
}
// fitScreen 里用 require("@system.device")，不用顶部 import
```

两条都是踩过坑的：`watch-face-functional` 实测 `onReady` 不触发；顶部 `import` 与页内 `require` 同模块并存时 import 绑定取不到、调用静默抛错被 catch 吞。

## 6. 已知问题

1. **`.w-time` 只能到 52px**。56px 时时间 ink 底沿 444 与"轻触返回"顶沿 442 相连（实测扫成 67px 一段），视觉贴住。要再放大只能压缩盘体或砍掉返回提示。
2. **`轻触返回` 与时间的间距只有 8px**。屏底余量只剩 8px（472/480），没有继续下移的空间。
3. **地支「巳」放大后字形接近「己」**。12px 时看不出，21px（scale 1.5）时明显。属字体渲染，盘内铭文，未处理。
4. **192 屏 `.date-line` 13→24、`.back` 12→24** 是本次有意改动（可读下限），不是回归。实测 24px 不截断（日期 x37–154 / 192 宽），不溢出（返回底 470 / 490 高）。
5. **触摸滑动切表盘依赖 Y 位移 40px 阈值**，与屏宽无关，未改。验收时用 `tap` 而非 `drag`，否则会切到 gold / metal。
