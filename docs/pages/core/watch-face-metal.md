## 2. 走针机制（**不要改**）

与 `watch-face-evpointer` 同源，2026-10-19 标定：

1. **不用** `transform: rotate({{deg}}deg)` 数据绑定 —— 整页黑屏；
2. **不用** `@keyframes` 承载当前时刻 —— 针角与盘面时间不符、粗针周期性整根消失；
3. 引擎旋转轴 = **元素顶部中点**，`transform-origin` 不按 CSS 语义生效 → 三针「顶部中点压盘心 (92,92) + 向下延伸」，`rotate(180+θ)` 即指向 θ。

角度走 **120 档字面量类 `.r0…​.r119`**（`rotate(180 + 3N)`，3° 一档，比 evpointer 的 6° 更细）。`stepClass(deg)` 只算 class 名。

## 4. 布局铁律

`.page` **只给** `position:relative` + `width/height:100%`，子元素全部 absolute 手写坐标，**不叠 flex 居中**（会与 absolute 共同触发黑屏）。宽屏适配也没有碰 `.page`。

## 5. 双屏适配（2026-10-26）

走 **父级 `transform: scale(1.5)`** 路线（同 evpointer）：36 个盘内节点零改动，圆心/半径/刻度角/针长比例天然正确。

| 元素 | 192×490 | 336×480 |
|---|---|---|
| `.brand` | top 48 / 22px | `.w-brand` top 18 / 28px / w100% |
| `.brand-sub` | top 74 / 11px | `.w-sub` top 46 / 24px / w100% |
| `.dial-wrap` | left 4 / top 153 | `.w-dial` left 30 / top 78 / **scale(1.5)** → 盘径 276 |
| `.date-line` | **24px @352**（原 13px@360） | `.w-date` top 360 / 24px |
| `.time-line` | top 386 / 34px | `.w-time` top 388 / 52px |
| `.back` | **24px @444 / #9a8f72**（原 12px / #6f6650） | `.w-back` top 446 / 24px |

**盘心 = (30 + 92×1.5, 78 + 92×1.5) = (168, 216)**，与 evpointer 实测完全一致。

192 屏的两处字号提升按「可读文字 ≥24px」裁定执行，其余像素零变化。

## 6. 三个坑（本页实测）

1. **点 entry 直挂本页可行**（与 `watch-face-functional` 不同）：push rpk → `unzip -o` → **再推 manifest** → `vapp`，顺序反了会被包内默认 entry 冲回 `pages/index`。
2. **首次 `vapp` 可能白屏全黑**（截图 353 字节）：`am stop` 后重拉、等 20s 即正常。单次黑屏不构成"页面崩了"的证据。
3. **看图定针位不可靠**：336 屏三针在放大图中极易把罗马数字 II/III + 刻度读成"右上有一根针"。**定针位要用像素角度直方图**——从盘心沿半径 14…78 采样，按黄/红分档统计角度峰值。实测 07:19 时：分针 116°、时针 216°、秒针 222°，与理论值 114° / 219.7° / 222° 吻合。
