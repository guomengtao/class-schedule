## 1. 职责

拟真方表（Tank / Reverso 观感）：方形表壳、四边不等亮、45° 错位倒角、铁路分钟轨、表冠表耳、三针 + 日期窗。附带原「震动表盘」的震动提醒功能（默认开、每 30s 一次），入口收在长按面板里 —— 表面上不出现任何按钮，按钮是拟真杀手。

不支持自定义背景图、不支持主题色跟随（方表拟真靠固定配色）。

## 2. 盘面几何（改动前必看）

全部 absolute 定位，192×490 基准：

| 元素 | 192×490 | 336×480 | 说明 |
|---|---|---|---|
| 盘容器 `.dial-wrap` | 172×172 @ (10, 112) | 288×288 @ (24, 96) | 宽屏 `transform: scale(1.674)` |
| 表壳四级内缩 | 16 | 26.8 | `case-outer 172 → dial-face 140`，靠错位同心方框造倒角 |
| 刻度方框半径 `r` | 65 | 108.8 | `r = 86 − 21`，不是盘半宽 |
| 盘心 | (96, 198) | (168, 240) | |
| `.brand` / `.brand-sub` | top 52 / 69 · 10px / 8px | top 22 / 46 · 14px / 10px | 装饰铭文，小于 24 是刻意的质感 |
| `.date-line` | top 326 · 24px | top 392 · 24px | |
| `.hint` | top 358 · 24px | top 424 · 24px | |
| `.panel` | 宽 240 · 24px | 宽 284 · 28px | |

**刻度是「贴在半径 65 的方框边界上」，不是圆环。** 公式 `R(θ) = 65 / max(|sinθ|, |cosθ|)`：

| 时点 | θ | R | 相对盘心 | 模板实测 |
|---|---|---|---|---|
| 12 | 0° | 65 | (0, −65) | `left:85 top:21` ✅ |
| 1 | 30° | 75.1 | (37.5, −65) | `left:122.5 top:21` ✅ 差 1 = tick 宽 2 的外端对齐 |
| 2 | 60° | 130 | (65, −37.5) | `left:150 top:48.5` ✅ |

所以 12/3/6/9 落在四边中点，1/2/10/11 自然落到角部呈 45° 斜向。**不能改成圆刻度**，一改立刻变成「圆表塞进方框」。

**走针**：禁动态 transform，用 120 档字面量 `.rN { transform: rotate(180 + 3N)deg }`。引擎轴是元素顶部中点，所以针必须「顶部中点压在盘心、向下延伸」。120 档只含角度，与盘径无关 —— 双屏不用改任何一档。

## 3. 双屏适配的实现

### 3.1 盘内：整体缩放，140 个节点零改动

```css
.w-dial { transform: scale(1.674); }
```

宽屏只给 `.dial-wrap` 挂 `w-dial` 并用 style 绑定位置：

```js
self.dialCls = "w-dial"
self.dialStyle = "left:24px;top:96px;"
```

成立依据（192×490 实机探针）：父级 `scale` 会带动绝对定位子块，且子块的 `left/top` 按同一比例缩放 → 刻度方框半径、表壳四级内缩、字号、指针全部自动等比，方表比例天然不变。

`transform-origin` **实测默认是左上角（0 0），不是中心** → 视觉左上 = 布局左上，`left/top` 直接写目标位置，不用算中心补偿量。

### 3.2 盘外：能进缩放层的就进，剩下用单类 + style

- **表冠（crown + 3 条齿纹）已移进 `.dial-wrap`**，坐标改成相对盘左上（`180−10=170`、`187−112=75`）→ 随盘缩放，宽屏不用另算
- **表耳**留在外面，用 `w-lug` + `w-lugt` / `w-lugb` 两个单类
- **品牌行 / 日期行 / 提示行**的 `width` 一律 `100%`（原来是 192px 死值），靠 `text-align: center` 自动居中 → 省掉宽度分支
- **位置类走 `style` 绑定**（探针已验证 `left/top` 可绑），**样式类走单类选择器**

192 屏 `fitScreen` 里 `w < 300` 直接 `return`，8 个字段全留空串 → 零回归。

## 4. 三个 Vela 渲染限制（踩过，别再踩）

1. **不支持后代选择器。** `.w-page .dial-wrap { ... }` 会退化成 `.dial-wrap { ... }` —— 宽屏样式被套到**所有屏**上（192 屏盘心从 96 跑到 167）。首版就是这么错的，而且很难看出来（画面"看起来只是变大了"）。所有宽屏规则必须用**单类选择器**。
2. **纯动态 class 不行。** `class="{{ pageCls }}"` 会让 `.page` 的 `position: relative` / `100%` 全部丢失 → 子元素失去定位基准、页面白屏。必须**混写**：`class="page {{ pageCls }}"`。项目内 `class="hand hour {{hourCls}}"` 有大量成功先例。
3. **同步 `device.getInfo()` 取不到正确宽度。** 同步形式在 192 屏上读到的 `screenWidth` ≥300（会把小屏误判成宽屏）。必须用异步回调：

```js
device.getInfo({ success: function (d) { /* d.screenWidth */ } })
```

## 5. 已知问题

1. **面板未实机截图验证。** 面板改动只有字号（15/22/18/13 → 24；宽屏 28）与宽度（240 → 284）。模拟器 shell 没有 `input` 命令，`adb shell input swipe` 报 `input: command not found`，长按门槛 600ms 无法在模拟器触发，所以长按面板只做了尺寸推算（24px × 最长 8 字 = 192 < 240；高度约 200 < 480）。真机需补一张。
2. **hint 文案被 24px 下限倒逼缩短。** 原文「长按设置 · 轻触返回」9 字 × 24 = 216 > 192 宽会截断，改为「长按设置 · 返回」7 字 = 168。
3. **表耳颜色刻意很暗**（`#363c43` 压在 `#0b0d10` 上），远看只是轮廓。这是原设计（模拟表壳阴影侧的表耳），不是漏改。
4. **宽屏底部间距压缩。** 192 屏盘底到日期行间距 42px，按同比例放大到 70 会爆屏（384+70 > 480），宽屏硬排 8px。视觉上比小屏紧，属取舍。
