# watch-face-random · 表盘·无框机械

> 页路径：`src/pages/watch-face-random/watch-face-random.ux`
> 变体名：无框机械表盘（由「随机表盘」重写而来，随机跳字与换色面板已取消）
> 方案：`docs/WatchFace-无框机械表盘-双屏适配方案.md`

## 形态

不画表壳、表圈、表耳、盘面轮廓线 —— 整个屏幕即盘面（底色 `#17191d` + 6 条纵向拉丝带），
盘的「边」只由 48 根印刷分钟刻度 + 12 根整点时标暗示。

| 组成 | 数量 | 说明 |
|---|---|---|
| 纵向拉丝带 | 6 | 百分比定位，静态，`opacity` 0.008 / 0.020 交替 |
| 分钟刻度 `.mt` | 48 | 每 5 分让位整点时标；`.rN` 字面量旋转对齐径向 |
| 整点时标 `.hm` | 12 | 金属条，外端贴椭圆轨 |
| 夜光点 `.lume` | 11 | 3 点让位日期窗 |
| 阿拉伯数字 `.num` | 11 | 3/6/9/12 用 `.num-big` 加大 |
| 日期窗 `.dw` | 1 | 凹槽三层：框上缘亮线 + 窗内上缘暗线 + 天数 |
| 三针 | 3+1 | 时针/分针各带阴影 + 左缘高光；秒针另配重尾（`+60` 档 = 反向） |
| 中轴 `.hub` | 3 层 | base / ring / dot |

## 自适应机制（与其余表盘最大的差异）

**位置全部由 JS 按真实屏宽高算出，不走 CSS 字面量。**

```js
onInit() {
  this.build(192, 490)                       // 先出基线图，避免首帧空
  device.getInfo({ success: (ret) =>        // 异步取真实尺寸后重建
    this.build(ret.screenWidth, ret.screenHeight)
  })
}

build(W, H) {
  var wide = W > 300
  var S = wide ? 1.75 : 1                    // 尺寸因子
  var a = Math.min(0.44 * W, 0.42 * H)       // 横径半轴
  if (wide) { b = 172; cy = 46 + b }         // 宽屏：纵径半轴固定 + 盘心上移
  else      { b = Math.min(0.42 * H, 1.35 * a); cy = H / 2 }
}
```

- `S` 是**尺寸因子**，不是缩放：192 屏 `S=1` 时所有 `* S` 项与原式字面等价，故零回归。
- 宽屏必须把盘心上移（`cy = 46 + b` 而非 `H/2`）：顶部只放 2 行铭文、底部要放 3 行，对半分会把底部挤爆。
- 三针长度由 `L0 = √(a·b)` 推出，随盘自动变化，无需单独适配。

## 踩过的坑

1. **`cy = H/2` 在宽屏上必错**：盘中线不能固定居中，上下内容行数不对称时会把一侧挤爆（详见方案 §2）。
2. **改 CSS 宽度必须同步改 JS 的 `DLW`**：`dlL = cx - DLW/2`，只改 CSS 到 180 而 `DLW` 仍 90，容器会从 `left 51` 溢出到 231（屏宽 192），文字被右边缘裁掉。判据是量 ink 的 x 中心是否等于 `cx`。
3. **内联 `width` 优先级高于 class**：三针宽度原为内联 `width:6px`，宽屏类改不动，必须改成 `width:{{hw}}px` 绑定。
4. **顶部 46px 放两行必然压盘沿 1–3px**：20px + 10px 的 ink 高合计 42，加间隙已超 46。机械表铭文压在盘缘是正常做法，不视为缺陷。

## 已知问题

- 336 屏「36 JEWELS」10px（盘内铭文口径，豁免 24px 下限）。
- 192 屏返回提示 `backT = H-30 = 460`，24px 文字占 460–488，距屏底仅 2px（完整不裁，但偏贴边）。
- `onReady` 在本仓曾出现不触发（见 `watch-face-functional.md`）；本页计时由 `onShow → refresh` 兜住，`build` 挂在 `onInit`，不受影响。
