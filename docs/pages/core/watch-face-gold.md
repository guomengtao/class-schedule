> 168px 银钢表壳（不是 184，留出表耳才有"实物表"轮廓）+ 8 层错位同心圆造金属厚度 + 48 分钟刻度 + 12 整点刻度 + 阿拉伯时标 + 日期窗 + 4 螺钉双高光 + 三层立体三针 + 上下表耳。

## 2. 仿真三条铁律（**设计约束，不是建议**）

1. **单一主光源在左上**：所有亮面在左上、暗面在右下，一处反向就"假"。
2. **没有渐变，用「错位双圆」造月牙**：亮圆在下、暗圆向右下偏 1–3px，露出的未重叠月牙就是高光带；层层递进即有倒角和厚度。
3. **细节密度 = 像不像**：刻度、螺钉、日期窗、机芯小字决定"真"。

改颜色/坐标前先看这三条，否则表壳会瞬间变"塑料"。

## 3. 走针机制（**不要改**）

与 evpointer/metal 同源，120 档 `.rN`（`rotate(180+3N)`，3°/档），引擎轴 = 元素顶部中点，三针「顶部中点压盘心 (84,84) + 向下延伸」。

**本页独有**：每根针由**三层**组成（暗影右下偏 2px / 主针 / 左缘高光），三层共用同一个档位 class，靠固定 left/top 偏移造立体，不额外算角度。

`syncHands()` 带**脏值判断**（值没变就不赋值）——Vela 每次赋值都跑一轮全树 diff + 整屏重绘，同一帧内多次赋值不合并，6 次/秒的重绘正是"整页闪"的来源。这块别优化掉。

## 5. 双屏适配（2026-10-26）

**取 `scale(1.35)`，不是前几块的 1.5**——这是本页最大的差异点。

1.5 试算直接爆版：`盘 252 + 表耳上凸 33 + 下凸 33 = 318`，再加品牌两行 70 与底部三行 100 ≈ 500 > 480。
1.35 时盘 226.8、整块含表耳 262，480 内放得下，且「盘 227 + 表耳」的视觉体量与前两块 276 的盘相当。

| 元素 | 192×490 | 336×480 |
|---|---|---|
| `.brand` | 50 / 11px / h14 | `.w-brand` **6 / 24px / h28** |
| `.brand-sub` | 68 / 10px / h14 | `.w-sub` **34 / 22px / h26** |
| `.lug` 尺寸 | 84×26 @left 54 | `.w-lug` **113×35 @left 111** |
| `.lug-top` | 96 | `.w-lug-top` **60** |
| `.dial-wrap` | 12 / 118 | `.w-dial` **54.6 / 88 / scale(1.35)** |
| `.lug-bottom` | 282 | `.w-lug-bottom` **306** |
| `.date-line` | **24px @306**（原 13px@314） | `.w-date` 342 / 24px |
| `.time-line` | 334 / 32px（未动） | `.w-time` 372 / 48px |
| `.back` | **24px @396 / #8d949c**（原 12px / #4f565d） | `.w-back` 426 / 24px |

盘心 = (54.6 + 113.4, 88 + 113.4) = **(168, 201.4)** —— 注意 y 与 evpointer/metal 的 216 不同（盘小 + 表耳占位），验收取心别照抄。

### 表耳为什么单独三个类

`.lug` 在容器外，只 scale 表壳会让表耳留在原地彻底错位。没走「把 lug 移进容器 + 负 top 相对化」是因为**负 top 在 Vela 上未验证**，而三条 CSS（`.w-lug` 管尺寸+left、`.w-lug-top` / `.w-lug-bottom` 各管一个 top）零结构风险。

## 6. 坑：宽屏改字号必须同时覆盖 height

**首版只改了 `font-size` 没改 `height`，两行品牌字被裁掉上下沿。** 本页基线 `.brand`/`.brand-sub` 的 `height` 只有 **14px**（11/10px 字号时的尺寸），字号提到 24/22px 后文字溢出盒子被 Vela 裁切。

金属/指针两块没踩到，只是因为它们基线 `height` 是 26/22px 恰好够。

**通用规则：宽屏 `font-size` 与 `height` 必须成对给出。**

## 7. 亚像素代价（1.35 非整数倍）

`.mtick` 1×4 → 1.35×5.4、`.tick` 2×9 → 2.7×12.15、`.screw` 7 → 9.45、秒针宽 2 → 2.7。实测 336 屏上分刻度仍是细线、螺钉仍有高光，**没有糊成一片**；秒针 2.7px 也清晰可见（橙色高对比）。

1.35 是妥协：整数倍只有 1（等于没放大）和 2（溢出屏高 130px）。
