# 首页时钟模块功能需求分析

## 一、功能定位

时钟模块是首页顶部的时间显示区域，用于实时展示当前时间，帮助用户在查看课表时快速了解现在几点。

**使用场景**：用户打开首页，一眼看到当前时间，方便判断距离下一节课还有多久。

## 二、界面布局格式要求

时钟位于首页最顶部，占一行高度，居中显示。

```
┌──────────────────────────────┐
│          14:35               │  ← 时钟行
├──────────────────────────────┤
│  ◀      星期一      ▶        │  ← 日期导航栏
│       [总] [今] [明]          │
├──────────────────────────────┤
│  ...                         │
└──────────────────────────────┘
```

## 三、用户视角的功能描述

### 3.1 正常显示

用户进入首页，顶部显示当前时间，格式为 `HH:MM`（如 `14:35`），每秒更新一次。

### 3.2 显示格式

用户可以设置时间的显示格式：

| 设置项 | 说明 |
|--------|------|
| 年月日 | 选择是否显示日期（如 `2025:09:04:14:35`） |
| 时 | 默认显示，不可关闭 |
| 分 | 默认显示，不可关闭 |
| 秒 | 可选择显示/隐藏 |

默认格式：`HH:MM`（例如 `14:35`）
含秒格式：`HH:MM:SS`（例如 `14:35:22`）
含日期格式：`YYYY:MM:DD:HH:MM`（例如 `2025:09:04:14:35`）

### 3.3 显隐控制

用户可以在设置中关闭时钟显示，关闭后首页顶部不再显示时钟行，节省屏幕空间。

## 四、交互行为

| 操作 | 结果 |
|------|------|
| 进入首页 | 时钟立即显示当前时间 |
| 每秒自动更新 | 时间数字实时刷新 |
| 在设置中关闭时钟 | 时钟行消失，下方内容上移 |
| 在设置中开启秒显示 | 时间格式变为 `HH:MM:SS` |
| 切换页面后返回 | 时钟继续实时显示 |

## 五、功能边界条件

| 场景 | 预期行为 |
|------|----------|
| 首页加载中 | 时钟显示空或 "00:00" |
| 时钟关闭 | 整行不显示 |
| 跨越午夜 | 时间自动更新为第二天 |
| 跨越整点 | 小时数字自动变化 |

## 六、与其他功能的关系

| 功能 | 关系 |
|------|------|
| 设置页 | 在设置中控制时钟的显隐和时间格式 |
| 状态栏 | 状态栏也依赖当前时间判断上课状态，但独立工作 |
| 课程进度条 | 进度条依赖当前时间计算进度，但独立工作 |
