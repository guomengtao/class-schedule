## 一、改造内容（src/pages/activation/activation.ux）

按《激活主页面拆分方案》§五执行，唯一改动点：

1. **「购买兑换码」文字入口 → 首屏购买卡**：标题「购买兑换码」+「爱发电购买」+ afdianUrl 二维码（老版步骤 1 原样上浮），位于状态卡正下方、首屏内完整可见
2. **入口行理顺**：「输入激活码」（主按钮，→ code 页）、「激活步骤指南」（→ guide 页）、「激活历史 · 设备信息」（弱化，→ info 页）
3. **删除「获取设备 ID」入口**：deviceId 只在 guide/code/info 页需要，主页不展示

## 二、技术实现（与老版单页一致，未改口径）

- `AFDIAN_REDIRECT_URL = https://app-auth.gudq.com/go/ev-timetable?deviceId=`（带跟踪跳转，勿改直链）
- afdianUrl 拼接链：`deviceId + 设备信息参数（m/p/o/v/t/s/w/h/a/l）+ &c=渠道`——自老版 updateQrText 中原样搬入
- deviceId 获取链：`@system.device.getDeviceId` → 空/NA/unknown/null → 回落 `utils/device-uuid.js` 本地 UUID
- 二维码未生成时展示「正在生成二维码...」（老版诚实加载态）
