## 六、踩坑记录（本次新增）

1. **vela-loop 不支持嵌套页**：`--page activation/activation-info` 会把 jsc 路径拼成 `pages/activation/activation-info/activation/activation-info.jsc`，报「找不到产物」。已在脚本内修复（页名取 basename）。
2. **nsh 参数拆分**：`adb shell "dd if=... of=... bs=... count=1"` 整串传会 `too many arguments`；拆成独立 argv 才行。`am stop <pkg>` 同理。这个 bug 的表现是「vapp 进程在但 nz=0 全黑」，极易误判成页面写坏。
3. **黑屏 ≠ 包坏**：本次 info 页 3 次冷启失败全是设备侧黑屏，包和 jsc 都没问题（设备侧文件已确认存在）。
4. **模拟器 AVD 锁**：同名 AVD 已被孤儿实例占用时，`vela up` 会等 serial 超时（180s），必须先 reap/down + kill 孤儿 qemu 再 up。
5. 入口行高度预算（band9 192×490，pill padding 30 上下 → 可用 430）：header 44 + 状态卡 ≈78 + 3×(52+8)=180 + 次级行 44 + spacer 12 ≈ 358px，首屏放得下；若后续再加入口行，先把 min-height 压到 44 再谈加行。
