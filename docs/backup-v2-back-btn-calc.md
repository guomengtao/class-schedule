# 备份V2 返回按钮尺寸计算

> 目标：保持页面标题「备份V2」（4个字符）不换行，计算返回按钮最大允许尺寸，与当前尺寸对比。

---

## 1. 页面布局结构

```
┌──────────────────────────────────────────────┐
│  .header (flex-direction: row, align: center) │
│  ┌─────────┬────────────────────┬──────────┐ │
│  │ 返回按钮 │  标题 (flex: 1)    │ 占位符    │ │
│  └─────────┴────────────────────┴──────────┘ │
└──────────────────────────────────────────────┘
```

标题使用 `flex: 1` + `text-align: center`，剩余空间全部给标题。

---

## 2. 各断点计算

### 2.1 基础参数

| 参数     | 说明                       |
| ------ | ------------------------ |
| 标题文字   | 「备份V2」，4 个字符             |
| 单字符宽   | 约等于 `font-size`（中文字符为方形） |
| 标题最小宽度 | 4 × 单字符宽                 |

### 2.2 Base 层（手环 9，page = 192px）

| 项目                | 值                        |
| ----------------- | ------------------------ |
| page 宽度           | **192px**                |
| header padding 左右 | 8px + 8px = **16px**     |
| header 内部可用宽度     | 192 − 16 = **176px**     |
| 标题字号              | **24px**                 |
| 单字符宽度             | ≈ **24px**               |
| 标题最小宽度（4 字符）      | 4 × 24 = **96px**        |
| 占位符宽度             | **36px**                 |
|                   |                          |
| **返回按钮最大宽度**      | 176 − 96 − 36 = **44px** |
| **当前宽度**          | **72px**                 |
| **超出**            | 72 − 44 = **+28px ❌**    |

> 结论：Base 层当前 72px 的返回按钮太大，标题「备份V2」只有 176 − 72 − 36 = 68px 的空间，实际需要 96px，差 28px，**标题会被压缩或截断**。

### 2.3 width ≥ 200px 层（胶囊屏 / 手环 10）

| 项目                | 值                         |
| ----------------- | ------------------------- |
| 假设设备宽度            | **200px**（断点最小值）          |
| header padding 左右 | 10px + 10px = **20px**    |
| header 内部可用宽度     | 200 − 20 = **180px**      |
| 标题字号              | **26px**                  |
| 单字符宽度             | ≈ **26px**                |
| 标题最小宽度（4 字符）      | 4 × 26 = **104px**        |
| 占位符宽度             | **40px**                  |
|                   |                           |
| **返回按钮最大宽度**      | 180 − 104 − 40 = **36px** |
| **当前宽度**          | **80px**                  |
| **超出**            | 80 − 36 = **+44px ❌**     |

### 2.4 width ≥ 400px 层（Watch 6 / 方屏）

| 项目                | 值                          |
| ----------------- | -------------------------- |
| 假设设备宽度            | **400px**（断点最小值）           |
| header padding 左右 | 12px + 12px = **24px**     |
| header 内部可用宽度     | 400 − 24 = **376px**       |
| 标题字号              | **28px**                   |
| 单字符宽度             | ≈ **28px**                 |
| 标题最小宽度（4 字符）      | 4 × 28 = **112px**         |
| 占位符宽度             | **40px**（继承自 200px 断点）     |
|                   |                            |
| **返回按钮最大宽度**      | 376 − 112 − 40 = **224px** |
| **当前宽度**          | **80px**                   |
| **余量**            | 224 − 80 = **+144px ✅**    |

> 400px+ 空间充足，无问题。

---

## 3. 总览对比表

| 断点           | 可用宽   | 标题需   | 占位符  | 按钮最大      | 按钮当前 | 差值     | 状态   |
| ------------ | ----- | ----- | ---- | --------- | ---- | ------ | ---- |
| Base (192px) | 176px | 96px  | 36px | **44px**  | 72px | +28px  | ❌ 太大 |
| ≥200px       | 180px | 104px | 40px | **36px**  | 80px | +44px  | ❌ 太大 |
| ≥400px       | 376px | 112px | 40px | **224px** | 80px | −144px | ✅ 充裕 |

---

## 4. 建议

### 建议值（标题不截断）

| 断点           | 推荐返回按钮                      |
| ------------ | --------------------------- |
| Base (192px) | **44px**（当前 72px → 缩小 28px） |
| ≥200px       | **36px**（当前 80px → 缩小 44px） |
| ≥400px       | 保持 80px 或更大均可（空间充裕）         |

### 注意

- 以上计算假设占位符保持当前宽度。如果占位符也缩小，返回按钮可以稍大一些。
- 如果标题文字可能变长（例如从「备份V2」变为「数据备份V2」6 字符），需要相应缩小按钮或换行。
- 按照触底自适应铁律（Section 6），**禁止 title 截断**，必须保证完整可见。
