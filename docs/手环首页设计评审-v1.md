# 手环端「Ev 课程表」首页 · 设计评审 v1

- **对象**：`src/pages/index/index.ux`（1648 行）+ `src/pages/index/modules/*`（9 个模块）
- **设备**：小米手环 9 标准版，**192×490 胶囊屏**（AVD `xiaomi_band`）
- **主题**：**暖阳米**（设备当前主题）
- **取证方式**：`vela` 独立无头实例 + `/dev/fb0` 直读截图（NuttX guest 无 `screencap`）+ 模拟器控制台点击
- **实拍图**：`screenshots/手环首页-9标准版-*.png`（6 张）
- **结论**：**不改功能，只重排优先级** —— 首页现在把 81% 的垂直空间花在"边框"上，真正的主角（今天有什么课）只剩 47px，连一张课程卡都放不下

---

## 0. 一句话诊断

> 这一屏不是"信息太多"，而是**把 8 个区块按"谁先实现谁先占位"的顺序摞起来**，
> 结果在 490px 的高度里，**固定栏吃掉 81%，课程列表只分到 11%（47px，不足一张卡）**；
> 更糟的是**状态条和假期卡在同一屏上互相打脸**。

---

## 1. 垂直空间预算：实测像素（这是本轮最硬的证据）

数据来源：`screenshots/手环首页-9标准版-有课态.png` 逐行扫描（背景色差 > 30 判为内容块）。

| 区块 | y 区间 | 高度 | 占可用区 |
|---|---|---|---|
| 日期行 `10-10` | 30–60 | 30px | 7.0% |
| 导航行 `← 周六 →` | 60–108 | 48px | 11.2% |
| 自定义内容条 `未来可期，…` | 121–160 | 39px | 9.1% |
| **调休条（折成 3 行）** | 171–255 | **84px** | **19.5%** |
| **课程列表（`flex:1`）** | 259–306 | **47px** | **10.9%** |
| 快速添加 | 306–356 | 50px | 11.6% |
| 底部按钮 `＋` `设置` | 356–408 | 52px | 12.1% |
| 课表切换 `⇄ 课程表1` | 415–460 | 45px | 10.5% |

- 可用区 = 490 − 60（胶囊屏 `.schedule-page` padding `30px 16px`）= **430px**
- **固定栏合计 348px = 80.9%**
- **课程列表 47px = 10.9%** —— 而 `.class-grid-item { min-height: 60px }`
  → **列表连一张完整的课程卡都放不下**，截图里「化学」卡的时间、教室被直接切掉。

对照：手环 9 Pro / 10 Pro 是 336×480 方屏，同样的 348px 固定栏占比会降到 72% —— 也就是说
**这套布局在宽屏上勉强能看，在 9 标准版上直接崩**。这才是这一页真正的问题。

## 2. 诊断清单 H1–H12

| # | 发现 | 证据 | 为什么致命 |
|---|---|---|---|
| **H1** | **状态条与假期卡互相打脸** | 今天 10-05 是国庆假期，`status-bar.js` 无任何假期判断（只比 `currentDay` 与日期、再查 `schedule`），仍渲染「**即将上课** 语文 147m后」；而正下方的假期卡写着「国庆假期 / 国庆快乐，祝…」 | 同一屏两句话直接矛盾。用户信哪个？这是**正确性 bug**，不是审美问题 |
| **H2** | **垂直预算崩坏** | 见 §1：固定栏 81%，课程列表 47px | 首页的主体（今天有什么课）被挤成一条缝 |
| **H3** | **调休条折成 3 行、词被劈开** | `workday-tip-bar` 内 "?" 按钮是 inline 兄弟节点，文字区只剩 ≈98px；「今天调休，按星期三课表」11 字 × 18px = 198px → 3 行，且「**课**」「**表**」被拆到两行 | 屏幕最贵的一条竖线被浪费 84px，还读不通 |
| **H4** | **「今天」是硬编码的字面量** | 模板 `:67` 写死「**今天**调休，按{{ overrideDayName }}课表」 | 翻到 10-10 时页面顶部明明写着 `10-10 周六`，下面却说「今天调休」——**而且在真今天（10-05）那天它反而是错的** |
| **H5** | **没有任何"你在看哪天"的锚点** | `10-05`（date-row）与 `周一`（day-title）两行说同一件事，却都**不区分今天/非今天**；`isTodayDate` 算出来了但界面没用到日期行 | 前后翻日子后，用户不知道自己还在不在今天 |
| **H6** | **自定义内容条被省略号截断** | `未来可期，…`（`lines:1; text-overflow: ellipsis`） | 用户自己写的话，首页显示不全，还要占 39px 固定高度 |
| **H7** | **"今天没有课"空态下方 100px 纯空白** | 无课态实测：文字块 y=190–208（19px），下一个块在 y=310 | 最该说话的空白被浪费 |
| **H8** | **教室名在全部 4 个主题下都不可读** | `grid-item-location` 用 `textMuted` on `card`：深空蓝 **2.18:1** / 翡翠绿 **2.05:1** / 晨光白 **2.32:1** / 暖阳米 3.42:1 | 全主题低于 3:1。深色主题下教室名基本看不清，**这是唯一一个"所有主题都不合格"的项** |
| **H9** | **状态胶囊 `color: theme.bg on accent`，浅色主题崩** | 暖阳米 **2.00:1**、晨光白 **2.93:1**（深空蓝 9.14 / 翡翠绿 7.35 正常）——与欢迎页同一个根因：`THEMES` 缺 `onAccent` | 全页最想被看见的「即将上课」，在最亮的主题下最看不清（实拍图可见：米色底 + 米色字） |
| **H10** | **`cardLight` 与 `bg` 几乎同色，次级面片边界消失** | 暖阳米 `#f0ece4` vs `#f5f0e8` 逐通道差 **(5,4,4)**；晨光白 (8,8,8) | 自定义内容条 / 分组的边界事实上不存在（与手机端设置页 `CARD2` vs `CANVAS` 差 (1,6,9) 同一种病） |
| **H11** | **首屏不完整：状态条与自定义内容条"迟到"** | 同一日期 10-05，进入后 1.5s 的截图**两条都没有**，稍后截图两条都在（`screenshots/手环首页-9标准版-首屏异步缺失对比.png` vs `…今天假期态.png`）；`status-bar` / `customContent` 都是 `defer: true`，且 `updateStatus()` 在 `schedule` 未就绪时直接 `showStatusBar=false`，随后**只靠 60s 定时器**才可能补上 | 首页首帧是"残缺版"，内容会跳进来 |
| **H12** | **三个"加课"入口** | 快速添加（`＋` / `管理`）+ 底部 `＋ 添加课程` + 长按课程卡进编辑器 | 同一个目的三条路，还要各占固定高度（50 + 52px） |

## 3. 设计原则 P1–P5

| # | 原则 | 说明 |
|---|---|---|
| **P1** | **先给"现在"，再给"今天"，最后给"操作"** | 490px 的屏只有三档优先级；现在这一屏的排序是「日期 → 导航 → 自定文案 → 调休 → **课程** → 加课 → 设置 → 切表」，课程排第 5 |
| **P2** | **固定栏要有个预算** | 建议**固定栏 ≤ 35%**（≈150px），课程列表 ≥ 55%（≈240px） |
| **P3** | **一句话只说一遍** | 日期/星期/假期/调休都是"今天是什么日子"，应合成一处 |
| **P4** | **低频操作降级为图标，不占独立行** | 加课 / 设置 / 切课表都是低频，可以并排成一排图标 |
| **P5** | **状态要么准，要么不显示** | 假期说「即将上课」比不说更糟（H1） |

## 4. 方案：方向 A「一屏一课表」（推荐）

### 4.1 重排后的垂直预算

| 区块 | 现状 | 方向 A | 变化 |
|---|---|---|---|
| 日期行 | 30 | **0**（并入导航行） | −30 |
| 导航行 | 48 | **40**（`10-05 周一` 一行 + 两侧箭头） | −8 |
| 自定义内容条 | 39 | **0**（并入空态副文案 / 底部小字） | −39 |
| 调休条 | 84 | **0**（并入状态条） | −84 |
| 状态条 | 50 | **52**（唯一"现在"信息，假期/调休也走这里） | +2 |
| 假期卡 | 74(被裁) | **0**（并入状态条） | −74 |
| **课程列表** | **47** | **≈262** | **+215** |
| 快速添加 | 50 | **0**（改为列表末尾一行 / 长按卡片） | −50 |
| 底部按钮 | 52 | **0**（并入底栏） | −52 |
| 课表切换 | 45 | **0**（并入底栏） | −45 |
| **底栏（一排三图标）** | — | **44** | +44 |
| **固定栏合计** | **348（81%）** | **≈136（32%）** | **−212** |

课程列表从 **47px → ≈262px**，能完整放 **3–4 张课程卡**。

### 4.2 决策 D1–D10

| # | 决策 | 解决的问题 |
|---|---|---|
| **D1** | **日期行与星期标题合并成一行**：`10-05 周一`，左右箭头分列两端 | H2、H5 |
| **D2** | **日期行区分今天/非今天**：今天用 `accent` 色 + 显示 `今天`；非今天用 `textSecondary` + 显示 `10-05 周一` | H5 |
| **D3** | **删掉独立的自定义内容条**：用户自定文案降级为①空态副文案，或②底栏上方 11px 弱色单行 | H6、H2 |
| **D4** | **状态条成为唯一"现在"出口，且必须感知假期**：假期 → `国庆假期 · 今天无课`（tag 用 `WARN` 色，不写「即将上课」）；调休 → `调休 · 上周三课表`；正常 → `即将上课 语文 08:00（147m后）` / `上课中 语文 还剩 22min` | **H1（正确性）**、H3 |
| **D5** | **调休条并入状态条**，文案压缩到 ≤9 字（`调休 · 上周三课表`），**不再折行**、不再需要 "?" 按钮 | H3、H2 |
| **D6** | **课程列表拿到剩余全部空间**（`flex:1`，目标 ≥240px） | H2 |
| **D7** | **底部三件套 → 一排三枚 44×44 图标**：`＋`（添加课程）/ `⚙`（设置）/ `⇄`（切换课表），带 1px 分隔 | H2、H12 |
| **D8** | **删掉「快速添加」固定条**：改为列表末尾一行 `＋ 快速添加`，或长按课程卡弹出 | H2、H12 |
| **D9** | **修对比度**：① `grid-item-location` 的 `textMuted` → `textSecondary`；② `THEMES` 增 `onAccent`，浅色两族状态胶囊改深字 | H8、H9 |
| **D10** | **首屏完整**：`status-bar` / `customContent` 不再 `defer`，或在就绪前**不渲染空位**；`updateStatus()` 在 `schedule` 就绪后主动重算一次（不等 60s 定时器） | H11 |

### 4.3 备选方向

| 方向 | 做法 | 代价 |
|---|---|---|
| **B 状态条吃掉首屏** | 状态条放到屏幕上 1/3，课程列表从中间开始 | 与"列表可滚动"的心智冲突 |
| **C 左右滑动切日期** | 去掉 `← →` 两个 48px 圆，改整页横滑 | 手环横滑与系统手势冲突，风险高 |

## 7. 验收标准（可执行判据）

| # | 判据 | 判定方式 |
|---|---|---|
| 1 | 课程列表实测高度 ≥ 240px | 像素扫描内容块 |

## 8. 与现有代码的关系（落地前须知）

- `.schedule-page` 胶囊屏 padding 已是 `30px 16px 30px 16px`，横向只剩 160px —— **任何"并排两个 44px 圆 + 一行字"都要先算宽度**
- `applyFontSizes()`：`display = min(norm,40)`、`meta = max(norm-6,20)`、`dayTitle = min(norm+4,40)` —— 字号是**按用户基准字号算出来的**，方案里的 px 只是暖阳米+默认基准下的实测值
- `isCapsule` 由 `device.getInfo` **异步**回填，首帧一律按"非胶囊"渲染 → D10 必须处理这个时间差
- 本机 `homepage_settings` 里 `showDayNavZong/Jin/Ming` 三项被关闭（代码默认 `true`，`app-defaults.js:43–45`）→ 截图里没有「总/今/明」。**D2 的"今天高亮"正好补上这个缺口**

## 9. 未验（环境/时间依赖，诚实标注）

- **「上课中」态**：需要真实时间落在课程区间内，本轮为 05:30 左右，只能拿到「即将上课」
- **深色三族实拍**：本轮设备主题是暖阳米，深色三族的结论来自 `THEMES` 源码值 + WCAG 计算，**不是实拍**
- **Pinned 页条 / 工作日的班次切换**：本机未配置 pinned 页
- **快速添加展开后的真实交互**（课程名为空时只显示「暂无课程 管理」）
