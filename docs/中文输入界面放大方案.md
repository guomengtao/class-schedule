# 中文输入界面放大方案

## 1. 问题分析

用户反馈在手环上输入中文时字体太小，难以看清。当前 `chinese-input.ux` 页面的字体基准值如下：

| 元素 | 默认字号 | 胶囊屏 | 方屏 | 说明 |
|------|:--------:|:------:|:----:|------|
| 显示区文字 | 17px | 14px | 14px | 输入内容展示 |
| 拼音行 | 14px | 12px | 12px | 当前拼音 |
| 候选词 | 16px | 13px | 13px | 候选字/词 |
| 键盘按键 | 15px | 12px | 12px | QWERTY 字母 |
| 功能键 | 12px | 10px | 10px | 123/空格/中/EN |
| 删除键 | 11px | 10px | 10px | Del |

**根本原因**：这些字号是针对手机屏幕设计的，在手环 1.3~1.6 英寸的小屏幕上，12-15px 的字号肉眼几乎无法辨认。

---

## 2. 现有字体系统

### 2.1 设置页字体档位

设置页（`settings.ux`）已实现 5 档字体大小：

```javascript
var sizeLevels = [28, 36, 48, 62, 76]
```

### 2.2 store.js 字体计算逻辑

`getFontSizes()` 将 `baseFontSize`（默认 48）按比例映射到各 UI 元素：

```javascript
var r = size / 48  // 比例因子
display:   Math.round(17 * r)   // 显示区
candidate: Math.round(16 * r)   // 候选词
pinyin:    Math.round(14 * r)   // 拼音
key:       Math.round(15 * r)   // 键盘按键
```

以 `baseFontSize = 76`（最大档）为例，各元素字号：
- display: 27px, candidate: 25px, pinyin: 22px, key: 24px

仍然偏小，且键盘按键尺寸（width/height）未同步放大。

## 3. 设计方案

### 3.1 总体架构

```
┌─────────────────────────────────┐
│  返回          标题        确认  │  ← 顶部栏
├─────────────────────────────────┤
│        [ 输入内容显示区 ]        │  ← 动态字号
├─────────────────────────────────┤
│  拼音: ni hao                   │  ← 动态字号
├─────────────────────────────────┤
│  你好  你  尼  拟  逆  泥  ...  │  ← 候选词滚动行
├─────────────────────────────────┤
│  Q  W  E  R  T  Y  U  I  O  P  │
│   A  S  D  F  G  H  J  K  L    │  ← 键盘区（100%宽）
│    Z  X  C  V  B  N  M   Del   │
│  123      空格     中/EN  放大  │  ← 底部功能栏
├─────────────────────────────────┤
│  [ A- ]  [ 字体大小: 48 ] [ A+ ]│  ← 新增：字体快速调节条
└─────────────────────────────────┘
```

### 3.2 方案一：输入页底部独立字体快速调节（推荐）

在键盘下方新增一行字体调节栏，独立于全局设置，仅在当前输入页面生效。

#### 3.2.1 数据结构

```javascript
// chinese-input.ux 新增 private 属性
inputFontLevel: 48,        // 当前输入页字体档位
inputFontLevels: [28, 36, 48, 62, 76],  // 可选档位
inputFontScale: 1.0,       // 当前缩放比例
```

#### 3.2.2 模板

```html
<!-- 字体快速调节栏：键盘下方 -->
<div class="font-size-bar" style="background-color: {{ theme.card }}">
  <text class="font-size-btn" onclick="decreaseInputFont"
        style="background-color: {{ theme.btnSecondary }}; color: {{ theme.text }}">A-</text>

  <text class="font-size-label" style="color: {{ theme.text }}">
    字体: {{ inputFontScale === 1.0 ? '标准' : (inputFontScale === 1.29 ? '大' : (inputFontScale === 1.58 ? '特大' : '最大')) }}
  </text>

  <text class="font-size-btn" onclick="increaseInputFont"
        style="background-color: {{ theme.btnSecondary }}; color: {{ theme.text }}">A+</text>
</div>
```

#### 3.2.3 逻辑

```javascript
// 字体缩放档位映射
var fontScaleMap = {
  28: 0.58,  // 小
  36: 0.75,  // 中小
  48: 1.0,   // 标准
  62: 1.29,  // 大
  76: 1.58   // 特大
}

decreaseInputFont() {
  var levels = this.inputFontLevels
  for (var i = levels.length - 1; i >= 0; i--) {
    if (levels[i] < this.inputFontLevel) {
      this.inputFontLevel = levels[i]
      this.inputFontScale = fontScaleMap[this.inputFontLevel] || 1.0
      this.applyInputFontScale()
      return
    }
  }
},

increaseInputFont() {
  var levels = this.inputFontLevels
  for (var i = 0; i < levels.length; i++) {
    if (levels[i] > this.inputFontLevel) {
      this.inputFontLevel = levels[i]
      this.inputFontScale = fontScaleMap[this.inputFontLevel] || 1.0
      this.applyInputFontScale()
      return
    }
  }
},

applyInputFontScale() {
  var s = this.inputFontScale
  // 综合全局设置和本地缩放
  this.displayStyle  = "font-size: " + Math.round(17 * this.baseFontRatio * s) + "px"
  this.candidateStyle = "font-size: " + Math.round(16 * this.baseFontRatio * s) + "px"
  this.pinyinStyle    = "font-size: " + Math.round(14 * this.baseFontRatio * s) + "px"
  this.keyStyle       = "font-size: " + Math.round(15 * this.baseFontRatio * s) + "px"
}
```

### 3.3 方案二：直接使用设置页字体大小

将全局 `baseFontSize` 直接应用到输入页，无需额外控件。

#### 3.3.1 实现

```javascript
onInit() {
  var self = this
  store.getBaseFontSize(function(size) {
    self.baseFontSize = size
    self.baseFontRatio = size / 48
    self.applyAllSizes()
  })
}
```

#### 3.3.2 优缺点

| 方案 | 优点 | 缺点 |
|------|------|------|
| 方案一（独立调节） | 灵活，输入场景可独立放大，不影响其他页面 | 增加 UI 元素 |
| 方案二（跟随全局） | 简单，无需额外 UI | 输入页和主页共用同一字号，主页可能不需要太大 |
| 混合方案（推荐） | 灵活，默认跟随全局，可独立微调 | 稍微复杂 |

### 3.4 方案三：键盘 100% 宽屏 + 按键放大

当前键盘按键为固定宽高，需要改为百分比宽度自适应并放大触摸区域。

#### 3.4.1 键盘布局优化

```css
/* 键盘 100% 宽度 */
.keyboard {
  width: 100%;
  flex-direction: column;
  margin-top: 4px;
  padding: 0 2px;
}

/* 按键行：弹性分布 */
.key-row {
  flex-direction: row;
  justify-content: space-between;
  width: 100%;
  margin-bottom: 4px;
}

/* 按键：百分比宽度，放大触摸区域 */
.key-btn {
  flex: 1;
  max-width: 36px;
  height: 44px;          /* 从 36px 放大到 44px */
  border-radius: 8px;
  font-size: 18px;       /* 从 15px 放大到 18px */
  font-weight: bold;
  text-align: center;
  margin: 0 2px;
}

/* 功能键：稍宽 */
.key-func {
  flex: 1.2;
  max-width: 48px;
  height: 44px;
  font-size: 14px;
}

/* 空格键：弹性填充 */
.key-space {
  flex: 2;
  height: 44px;
  font-size: 15px;
}

/* 删除键 */
.key-del {
  flex: 1.2;
  max-width: 44px;
  height: 44px;
  font-size: 13px;
}
```

#### 3.4.2 候选词区域放大

```css
.candidate-row {
  height: 44px;          /* 从 36px 放大到 44px */
  margin-bottom: 4px;
  padding-left: 4px;
  padding-right: 4px;
}

.candidate-item {
  font-size: 20px;       /* 从 16px 放大到 20px */
  padding: 6px 14px;
  margin-right: 6px;
  border-radius: 8px;
}
```

### 3.5 不同屏幕类型适配

```css
/* 圆形屏：留出安全边距，内容居中 */
@media (shape: circle) {
  .input-page {
    padding: 44px 36px 44px 36px;
  }
  .key-btn {
    flex: 1;
    max-width: 32px;
    height: 40px;
    font-size: 16px;
  }
}

/* 胶囊屏：紧凑布局 */
@media (shape: capsule) {
  .key-btn {
    flex: 1;
    max-width: 28px;
    height: 34px;
    font-size: 14px;
    margin: 0 1px;
  }
  .candidate-row {
    height: 34px;
  }
  .candidate-item {
    font-size: 16px;
    padding: 4px 8px;
  }
}

/* 方屏：充分利用宽度 */
@media (shape: rect) {
  .key-btn {
    flex: 1;
    max-width: 34px;
    height: 38px;
    font-size: 16px;
  }
}
```

## 4. 推荐实施路线

### 阶段一：快速见效（1-2天）

1. 在 `chinese-input.ux` 底部添加字体快速调节栏（A-/A+ 按钮）
2. 默认跟随全局 `baseFontSize`，允许独立微调
3. 键盘按键、候选词、拼音、显示区同步放大

### 阶段二：深度优化（3-5天）

4. 键盘按键改为 100% 宽度自适应布局
5. 按键触摸区域放大（height 36→44px）
6. 候选词高度和字号加大
7. 不同屏幕类型（circle/capsule/rect）分别适配

### 阶段三：体验完善（1-2天）

8. 输入页字体设置持久化到 storage
9. 页面进入时恢复上次字体大小
10. 添加"重置为默认"按钮
