# 中文输入界面放大方案

## 1. 问题分析

用户反馈在手环上输入中文时字体太小，难以看清。当前 `chinese-input.ux` 页面的字体基准值如下：

| 元素 | 默认字号 | 胶囊屏 | 方屏 | 说明 |
|------|:--------:|:------:|:----:|------|
| 显示区文字 | 17px | 14px | 14px | 输入内容展示 |
| 拼音行 | 14px | 12px | 12px | 当前拼音 |
| 候选词 | 16px | 13px | 13px | 候选字/词 |
| 键盘按键 | 15px | 12px | 12px | QWERTY 字母 |
| 功能键 | 12px | 10px | 10px | 123/空格/中/EN |
| 删除键 | 11px | 10px | 10px | Del |

**根本原因**：这些字号是针对手机屏幕设计的，在手环 1.3~1.6 英寸的小屏幕上，12-15px 的字号肉眼几乎无法辨认。

---

## 2. 现有字体系统

### 2.1 设置页字体档位

设置页（`settings.ux`）已实现 5 档字体大小：

```javascript
var sizeLevels = [28, 36, 48, 62, 76]
```

### 2.2 store.js 字体计算逻辑

`getFontSizes()` 将 `baseFontSize`（默认 48）按比例映射到各 UI 元素：

```javascript
var r = size / 48  // 比例因子
display:   Math.round(17 * r)   // 显示区
candidate: Math.round(16 * r)   // 候选词
pinyin:    Math.round(14 * r)   // 拼音
key:       Math.round(15 * r)   // 键盘按键
```

以 `baseFontSize = 76`（最大档）为例，各元素字号：
- display: 27px, candidate: 25px, pinyin: 22px, key: 24px

仍然偏小，且键盘按键尺寸（width/height）未同步放大。

### 3.2 方案一：输入页底部独立字体快速调节（推荐）

在键盘下方新增一行字体调节栏，独立于全局设置，仅在当前输入页面生效。

#### 3.2.1 数据结构

```javascript
// chinese-input.ux 新增 private 属性
inputFontLevel: 48,        // 当前输入页字体档位
inputFontLevels: [28, 36, 48, 62, 76],  // 可选档位
inputFontScale: 1.0,       // 当前缩放比例
```

#### 3.2.2 模板

```html
<!-- 字体快速调节栏：键盘下方 -->
<div class="font-size-bar" style="background-color: {{ theme.card }}">
  <text class="font-size-btn" onclick="decreaseInputFont"
        style="background-color: {{ theme.btnSecondary }}; color: {{ theme.text }}">A-</text>

  <text class="font-size-label" style="color: {{ theme.text }}">
    字体: {{ inputFontScale === 1.0 ? '标准' : (inputFontScale === 1.29 ? '大' : (inputFontScale === 1.58 ? '特大' : '最大')) }}
  </text>

  <text class="font-size-btn" onclick="increaseInputFont"
        style="background-color: {{ theme.btnSecondary }}; color: {{ theme.text }}">A+</text>
</div>
```

#### 3.2.3 逻辑

```javascript
// 字体缩放档位映射
var fontScaleMap = {
  28: 0.58,  // 小
  36: 0.75,  // 中小
  48: 1.0,   // 标准
  62: 1.29,  // 大
  76: 1.58   // 特大
}

decreaseInputFont() {
  var levels = this.inputFontLevels
  for (var i = levels.length - 1; i >= 0; i--) {
    if (levels[i] < this.inputFontLevel) {
      this.inputFontLevel = levels[i]
      this.inputFontScale = fontScaleMap[this.inputFontLevel] || 1.0
      this.applyInputFontScale()
      return
    }
  }
},

increaseInputFont() {
  var levels = this.inputFontLevels
  for (var i = 0; i < levels.length; i++) {
    if (levels[i] > this.inputFontLevel) {
      this.inputFontLevel = levels[i]
      this.inputFontScale = fontScaleMap[this.inputFontLevel] || 1.0
      this.applyInputFontScale()
      return
    }
  }
},

applyInputFontScale() {
  var s = this.inputFontScale
  // 综合全局设置和本地缩放
  this.displayStyle  = "font-size: " + Math.round(17 * this.baseFontRatio * s) + "px"
  this.candidateStyle = "font-size: " + Math.round(16 * this.baseFontRatio * s) + "px"
  this.pinyinStyle    = "font-size: " + Math.round(14 * this.baseFontRatio * s) + "px"
  this.keyStyle       = "font-size: " + Math.round(15 * this.baseFontRatio * s) + "px"
}
```

### 3.3 方案二：直接使用设置页字体大小

将全局 `baseFontSize` 直接应用到输入页，无需额外控件。

#### 3.3.1 实现

```javascript
onInit() {
  var self = this
  store.getBaseFontSize(function(size) {
    self.baseFontSize = size
    self.baseFontRatio = size / 48
    self.applyAllSizes()
  })
}
```

#### 3.3.2 优缺点

| 方案 | 优点 | 缺点 |
|------|------|------|
| 方案一（独立调节） | 灵活，输入场景可独立放大，不影响其他页面 | 增加 UI 元素 |
| 方案二（跟随全局） | 简单，无需额外 UI | 输入页和主页共用同一字号，主页可能不需要太大 |
| 混合方案（推荐） | 灵活，默认跟随全局，可独立微调 | 稍微复杂 |

### 3.6 方案四：9键输入法（T9 中文输入）

9键输入法是手环等小屏设备上中文输入的最佳方案。每个按键更大、更容易点击，且用户对手机上的 9 键输入早已形成肌肉记忆。

#### 3.6.1 为什么 9 键比全键盘更适合手环

| 对比维度 | 全键盘 QWERTY | 9键 T9 |
|----------|:------------:|:------:|
| 单键宽度 | 26-30px | 56-64px |
| 单键高度 | 30-36px | 50-60px |
| 触摸面积 | 约 780px² | 约 3360px²（**4.3倍**） |
| 误触概率 | 高（手指覆盖 2-3 键） | 低（一键一目了然） |
| 中文输入效率 | 需逐字母输入拼音 | 多字母合并，按键次数少 |
| 学习成本 | 需熟悉键盘布局 | 手机用户零学习成本 |

#### 3.6.2 9键键盘布局（含切换键）

├──────────────────────────────────┤

#### 3.6.4 9键中文输入算法

9键输入中文的核心是 T9 分词：用户按数字键序列（如 `64426`），系统匹配所有可能的拼音组合（`ni hao`、`oh ian` 等），再查找对应的汉字。

```javascript
// T9 数字序列到拼音的映射
var t9ToPinyin = {
  '2': '[abc]',  '3': '[def]',   '4': '[ghi]',
  '5': '[jkl]',  '6': '[mno]',   '7': '[pqrs]',
  '8': '[tuv]',  '9': '[wxyz]'
}

// 将用户输入的数字序列转为拼音候选
function getPinyinCandidates(digitSequence) {
  // digitSequence 如 "64426"
  // 构建正则匹配所有可能的拼音组合
  var pattern = ''
  for (var i = 0; i < digitSequence.length; i++) {
    pattern += t9ToPinyin[digitSequence[i]]
  }
  // 在拼音字典中查找匹配
  return matchPinyin(pattern)
}

// 根据拼音获取汉字候选
function getHanziCandidates(pinyinList) {
  var result = []
  for (var i = 0; i < pinyinList.length; i++) {
    var hanzi = SimpleInputMethod.getHanzi(pinyinList[i], 'cn')
    result = result.concat(hanzi.chars)
  }
  return result
}
```

#### 3.6.8 9键英文输入

9键同样支持英文输入（类似老式手机 T9 英文输入）：

```javascript
// 英文模式下按一次 "2" 显示 "a"，再按一次变 "b"，再按变 "c"
// 或者长按切换
enT9Buffer: '',       // 当前按键缓冲区
enT9LastKey: '',      // 上一次按键
enT9LastTime: 0,      // 上一次按键时间

onT9KeyEnglish(key) {
  var now = Date.now()
  if (key === this.enT9LastKey && (now - this.enT9LastTime) < 800) {
    // 同一按键快速连按，循环字母
    var letters = t9Keys[key]
    var idx = this.enT9Buffer.length
    this.enT9Buffer = letters[idx % letters.length]
  } else {
    // 新按键，确认上一个字母
    this.inputValue += this.enT9Buffer
    this.enT9Buffer = t9Keys[key][0]
  }
  this.enT9LastKey = key
  this.enT9LastTime = now
}
```

#### 3.6.9 代码量估算

9键输入法不需要新建页面，而是在现有 `chinese-input.ux` 中增加 9键模式，与全键盘共存。以下为增量代码估算：

**核心逻辑增量（约 120 行）**：

| 模块 | 代码量 | 说明 |
|------|:------|------|
| `t9Keys` 映射表 | 10 行 | 数字→字母映射，数据结构 |
| `t9ToPinyin` 正则 | 10 行 | 数字序列→拼音匹配 |

| 项目 | 现有 `chinese-input.ux` | 9键增量 | 增幅 |

|------|:------|:------|:------|
| 在 `chinese-input.ux` 内共存 | ~270 行增量 | 低，一处修改 | 一键切换，流畅 |
| 新建 `t9-input.ux` 独立页面 | ~500 行（全量） | 高，两处同步 | 需跳转页面，割裂 |

**推荐**：在现有 `chinese-input.ux` 内共存，通过 `keyboardMode` 状态切换，不新建页面。

## 4. 9键 vs 全键盘 方案对比

| 维度 | 全键盘 QWERTY | 9键 T9 | 推荐 |
|------|:----------:|:----:|:----:|
| 按键大小 | 26-30px | 56-64px | ⭐ **9键胜** |
| 单键触摸面积 | ~780px² | ~3360px² | ⭐ **9键胜（4.3倍）** |
| 误触率 | 高 | 低 | ⭐ **9键胜** |
| 中文输入速度 | 需逐字母 | 数字序列，更快 | ⭐ **9键胜** |
| 英文输入速度 | 直接 | 需 T9 连按 | 全键盘胜 |
| 符号输入 | 方便 | 需切换 | 全键盘胜 |
| 用户习惯 | 电脑用户 | 手机用户（大多数） | ⭐ **9键胜** |
| 界面空间 | 需 10 列 | 仅需 4 列 | ⭐ **9键胜** |

**结论：手环设备上，9键输入法为主，全键盘作为备选。提供一键切换。**
