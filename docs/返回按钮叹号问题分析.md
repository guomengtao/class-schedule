# 返回按钮叹号问题分析

## 问题描述

部分页面的返回按钮图标显示为"叹号"（错误标记），本质原因是页面使用了 `{{ iconTheme }}` 变量拼接图标路径，但 `iconTheme` 变量从未被设置，初始值为 `undefined`，导致图标 src 变成：

```
../../common/icons/undefined/icon_back.png
```

该路径不存在，系统显示默认错误占位符（叹号/问号图标）。

## 正确实现模式

正常页面需同时满足以下三点：

1. **private 中声明默认值**：
   ```
   iconTheme: "dark"
   ```

2. **定义 `updateIconSrc` 方法**：
   ```
   updateIconSrc: function(themeName) {
     this.iconTheme = (themeName === 'light' || themeName === 'warm') ? 'light' : 'dark'
   }
   ```

3. **在 `onInit` / `onShow` 中调用该方法**：
   ```
   store.getTheme(function(t, themeName) {
     self.theme = t
     self.updateIconSrc(themeName)
   })
   ```

## 修复建议

每个问题页面需要添加：

1. 在 `private: { }` 块中新增：
   ```
   iconTheme: "dark",
   ```

2. 新增方法：
   ```
   updateIconSrc: function(themeName) {
     this.iconTheme = (themeName === 'light' || themeName === 'warm') ? 'light' : 'dark'
   },
   ```

3. 修改 `onInit` 和 `onShow` 中的 `store.getTheme` 回调，从：
   ```
   store.getTheme(function(t) { self.theme = t })
   ```
   改为：
   ```
   store.getTheme(function(t, themeName) {
     self.theme = t
     self.updateIconSrc(themeName)
   })
   ```
