## 一、设备唯一标识 / 设备信息 ⭐（你重点问的）

### 官方接口：`system.device`
| 接口 | 返回 | 用途 |
|---|---|---|
| `device.getDeviceId()` | `deviceId` — 设备唯一标识 | **唯一识别一台设备** |
| `device.getSerial()` | `serial` — 设备序列号 | 设备序列号（更"硬"的标识） |
| `device.getInfo()` | brand/manufacturer/model/product/osType/osVersion*/language/region/APILevel/**screenWidth/screenHeight/screenDensity/screenShape/deviceType** | 设备画像 + 屏幕自适应依据 |
| `device.getTotalStorage()` / `getAvailableStorage()` | 容量 Byte | 存储检测 |
| `device.getSystemUptime()` | 毫秒 | 运行时长 |

**权限（必须配置，否则失败）** —— `manifest.json`：
```json
{
  "permissions": [
    { "name": "hapjs.permission.DEVICE_INFO" }
  ]
}
```

**调用写法：**
```js
import device from '@system.device'
device.getDeviceId({
  success: (data) => console.log(`deviceId: ${data.deviceId}`),
  fail: (data, code) => console.log(`fail, code = ${code}`)
})
```

📄 完整文档：`vela-quickapp-docs/features/basic/device_dev.md`（另有一份 `base/device.md`）

### 示例里已有的真实用法
| 文件 | 做了什么 |
|---|---|
| `packages_apps/wearable/fistPower/src/app.ux` | `onCreate` 里 `device.getInfo()` → 存入 `global.deviceInfo`，供全 app 用 |
| `packages_apps/wearable/calendar/src/app.ux` | 同上模式 |
| `packages_apps/wearable/multi-screen-calculator/src/app.ux` + `pages/index/index.ux` | 全局 + 页面级两次取设备信息 |
| `packages_apps/wearable/woodenFish/src/pages/home/index.ux` | 取设备信息 |
| `packages_apps/wearable/vela-sample/src/interface/basic/device/index.ux` | **设备接口的官方示例页（最完整）** |

### ⚠️ 坑（文档没明说，但必须知道）
- `deviceId` 是**设备级**标识，不是用户账号 ID。换设备就变，恢复出厂/重装可能变。
- 想要"稳定绑定用户"：`deviceId` → 首次启动时经 `system.storage` 落本地 + 上报服务端换取自己的账号 token，别把它当账号用。
- 请求 `DEVICE_INFO` 属于敏感权限，应用商店审核可能要求说明用途。

## 三、多屏自适应（圆屏 / 方屏 / 胶囊屏）⭐

### 1) 运行时拿屏幕特征
```js
device.getInfo({ success: (res) => {
  res.screenShape   // 'rect' 方屏 | 'circle' 圆屏 | 'pill-shaped' 胶囊屏
  res.deviceType    // 'watch' | 'band' | 'smartspeaker'
  res.screenWidth; res.screenHeight; res.screenDensity  // DPR
}})
```

### 2) 样式层用媒体查询（官方主推做法）
```css
/* 官方示例：vela-sample/src/framework/style/media-query/index.ux */
@media (shape: circle)      { /* 圆屏 */ }
@media (shape: pill-shaped) { /* 胶囊屏（小米手环9/10） */ }
@media (device-type: watch) and (shape: circle) { /* 组合查询 */ }
@media (shape: circle) or (shape: pill-shaped)  { /* 或查询 */ }
```
实际工程用例：`wearable/fistPower/src/app.ux`、`pages/result/result.ux`、`pages/loading/loading.ux` 等 5+ 处。

### 3) 官方设备尺寸参考（文档 `guide/design/multi-screens.md`）
| 设备 | 形状 | 分辨率 | DPR |
|---|---|---|---|
| 小米手环9 / 手环10 | **胶囊形** | 192×490 / 212×520 | 2.0 |
| 小米手环8 Pro / 9 Pro | 矩形 | 336×480 | 2.1 |
| Watch S1 Pro / S3 / S4 | 圆形 | 466×466 / 480×480 | 2.0 |
| REDMI Watch 5 | 矩形 | 432×514 | 2.0 |

推荐长宽比：圆屏 1（466×466）、矩形 0.7（336×480）、胶囊 0.39（192×490）。

## 四、CSS 安全属性 / 安全区 ⚠️

**实测结论：示例代码里没有任何 `env(safe-area-inset-*)` / `constant()` 用法（grep 结果为 0）。** 官方也没提供安全区 CSS 变量。

官方替代方案是「**设计层安全区**」：
- 圆屏/胶囊屏边缘是弧形，主体内容必须避开边缘 → 官方给的安全区图示：`guide/design/multi-screens.md`（图 `multi-safe-area.png`）
- 落地手段 = `padding` + `@media (shape: ...)`，官方工具链的"全局规范"里建议值：**上下 padding 50px、左右 36px**（见 `tools/dev/official-site-tutorial.md`）

> 所以别找 `env()` 了，找不到的。要安全区就用「媒体查询 + 固定 padding」自己封装。

## 八、缺口与注意事项

- ❌ **没有 npm UI 组件库**（如 Vue 的 Element 那种），也没有第三方 UI 库可用——Vela 平台约束里明确"禁止第三方库"，只能用官方组件 + 自封装。
- ❌ **没有安全区 CSS 变量**，靠 media query + padding 自己实现。
- ⚠️ `deviceId` 需 `DEVICE_INFO` 权限，且是设备级、非用户级，别当账号用。
- ⚠️ `crypto` 示例只演示 API，密钥管理/存储方案要自己设计。
- ⚠️ 图标全是 png，无高清矢量；换分辨率屏幕需自行准备多套或改用 `chart`/`qrcode` 这类矢量渲染组件。
- 📌 完整 API 目录见 `vela-quickapp-docs/features/`（basic/data/network/other/security/system 六大类）与 `vela-quickapp-docs/components/`。
