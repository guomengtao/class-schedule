# 胶囊屏首页文字显示不全 - 问题分析与解决方案

> 胶囊屏宽度约 **120px**，去除左右 padding (16px×2) 后，实际可用宽度仅 **88px**。  
> 以下所有方案均基于这个物理约束，在不破坏 UI 规范的前提下进行优化。

---

## 一、四大问题及其根因

| 编号 | 问题描述 | 根因 | 涉及文件 |
|------|----------|------|----------|
| A | 周几只显示"星" | `dayTitleSize=48px`，两个汉字 ≈ 96px 超宽 | `index-full.ux` + `modules/day-nav.js` |
| B | 上课提醒课程名不显示 | status-bar 布局 `[accent][tag][name(flex:1)][time]` 挤压课程名 | `index-full.ux` + `modules/status-bar.js` |
| C | 课程时间显示不全 | 时间格式 `08:00-08:45` (11字符) 超出卡片可用宽度 | `index-full.ux` CSS + `modules/class-list.js` |
| D | "添加课程"少一字 | `"+ 添加课程"` (6字符) + 双按钮平分 88px | `index-full.ux` CSS |

---

## 二、逐项解决方案

### 问题 A：周几只显示"星"

**当前代码**：[day-nav.js](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/pages/index-full/modules/day-nav.js#L8-L13)

```js
var dayShortMap = {
  "星期日": "周日", "星期一": "周一", "星期二": "周二", "星期三": "周三",
  "星期四": "周四", "星期五": "周五", "星期六": "周六"
}
// 胶囊屏 dayDisplayText = "周一" (2字符) → 48px字号下宽度 ≈ 96px，超出 88px 可用空间
```

**当前 Header 布局**（胶囊屏 88px 可用宽度）：

```
[◀ 48px] [周一 flex:1 → 0px!] [总48] [今48] [明48] [▶ 48px]
                         ↑ 被挤压到几乎不可见
```

**根本问题**：Header 放了太多元素（导航按钮 + 日期文字 + 3个快捷跳转按钮），120px 宽屏幕无法同时容纳。

**解决方案（按优先级排列）**：

#### 方案 A1（推荐）：胶囊屏上日期文字改为单字缩写

```css
/* index-full.ux capsule media query 新增 */
@media (shape: capsule), (shape: pill-shaped) {
  .day-title {
    font-size: 26px;       /* 从 48px 降到 26px，单字约 26px 宽 */
    max-width: 30px;       /* 限制最大宽度 */
    lines: 1;
    text-overflow: ellipsis;
  }
}
```

同时在 `day-nav.js` 中：

```js
// 新增：胶囊屏上用单字
var daySingleMap = {
  "星期日": "日", "星期一": "一", "星期二": "二", "星期三": "三",
  "星期四": "四", "星期五": "五", "星期六": "六"
}

// updateDayDisplay 中：
instance.dayDisplayText = isCapsule
  ? (daySingleMap[instance.currentDay] || instance.currentDay)
  : instance.currentDay
```

**优点**：单字仅 26px 宽，足够在 88px 的 header 中显示  
**缺点**：用户需要习惯"一~日"表示星期

#### 方案 A2：胶囊屏 Header 精简 — 隐藏快捷跳转按钮

```ux
<!-- 胶囊屏上隐藏 总/今/明 按钮，用 swipe 手势替代 -->
<div class="day-nav-btns" if="{{ !isCapsule && showDayNavZong }}">
  ...
</div>
```

**优点**：释放约 144px 空间（3个48px按钮），日期文字可以使用"周一"  
**缺点**：失去快捷跳转功能（但可通过左右箭头和 swipe 实现）

#### 方案 A3（组合推荐）：**单字缩写 + 缩小导航按钮**

```css
@media (shape: capsule), (shape: pill-shaped) {
  .nav-btn {
    width: 36px;           /* 从 48px 缩小到 36px */
    height: 36px;
    border-radius: 18px;
    font-size: 18px;
    line-height: 36px;
  }
  .day-nav-circle {
    width: 36px;           /* 从 48px 缩小到 36px */
    height: 36px;
    border-radius: 18px;
    margin-left: 2px;
  }
  .day-nav-text {
    font-size: 16px;       /* 从 20px 缩小到 16px */
    line-height: 24px;
  }
  .day-title {
    font-size: 22px;       /* 单字 22px，约 22px 宽 */
    font-weight: bold;
    text-align: center;
    flex-shrink: 0;        /* 不被挤压 */
    width: 30px;
  }
}
```

**布局效果**（胶囊屏）：

```
[◀ 36] [一 30] [总36] [今36] [明36] [▶ 36]  = 210px，仍超 88px
→ 需要隐藏"总/今/明"或用更激进的图标方案
```

**最终推荐：A1 单字 + A2 隐藏快捷按钮的组合**

```ux
<!-- index-full.ux header 修改 -->
<div class="header">
  <input class="nav-btn" type="button" value="&#9664;" onclick="prevDay" ... />
  <text class="day-title" style="font-size: {{ dayTitleSize }}px; color: {{ theme.text }}">{{ dayDisplayText }}</text>
  <!-- 胶囊屏不显示 总/今/明，方屏/圆屏保留 -->
  <div class="day-nav-btns" if="{{ !isCapsule }}">
    <div class="day-nav-circle" onclick="goToWeekView" if="{{ showDayNavZong }}" ...>
      <text class="day-nav-text" ...>总</text>
    </div>
    <div class="day-nav-circle" onclick="goToToday" if="{{ showDayNavJin }}" ...>
      <text class="day-nav-text" ...>今</text>
    </div>
    <div class="day-nav-circle" onclick="goToTomorrow" if="{{ showDayNavMing }}" ...>
      <text class="day-nav-text" ...>明</text>
    </div>
  </div>
  <input class="nav-btn" type="button" value="&#9654;" onclick="nextDay" ... />
</div>
```

**最终布局**（胶囊屏 88px 可用）：

```
[◀ 36] [一 22] [flex space] [▶ 36]  = 94px，基本够用
```

### 问题 B：状态栏课程名不显示

**当前代码**：[status-bar.js](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/pages/index-full/modules/status-bar.js#L67-L82)

```js
self.statusTag = "上课中"        // 3字符, 20px字号 ≈ 60px
self.statusMainText = current.name  // 课程名, flex:1 被挤压
self.statusTimeText = "45min"      // 时间文本
```

**当前布局**（胶囊屏 88px → 减去 padding 8px×2 和 accent 12px → 约 60px 可用）：

```
[accent 12px] [上课中 60px] [课程名 flex:1→0] [45min 40px]
                                ↑ 课程名为0，不可见！
```

**根本问题**：`statusTag` + `statusTimeText` 固定宽度占比过大，`flex:1` 的课程名被挤压到不可见。

**解决方案**：

#### 方案 B1（推荐）：胶囊屏 status-bar 改为纵向两行布局

```css
@media (shape: capsule), (shape: pill-shaped) {
  .status-bar {
    flex-direction: column;    /* 纵向排列 */
    padding: 6px 8px;
    align-items: flex-start;
  }
  .status-bar .left-accent {
    display: none;              /* 隐藏左侧 accent 节省空间 */
  }
  /* 第一行：状态标签 + 剩余时间 */
  .status-bar-row1 {
    flex-direction: row;
    align-items: center;
    width: 100%;
    margin-bottom: 2px;
  }
  /* 第二行：课程名（独占整行） */
  .status-bar-row2 {
    flex-direction: row;
    width: 100%;
  }
  .status-tag {
    font-size: 16px;            /* 从 20 缩小 */
    padding: 1px 6px;
    line-height: 22px;
    margin-right: 4px;
  }
  .status-middle {
    font-size: 18px;            /* 课程名稍大 */
    font-weight: bold;
    line-height: 24px;
    lines: 1;
    text-overflow: ellipsis;
    width: 100%;
  }
  .status-right {
    font-size: 16px;
    line-height: 22px;
  }
}
```

对应的模板修改：

```ux
<div class="status-bar" if="{{ showStatusBar }}" style="background-color: {{ theme.cardLight }}">
  <div class="left-accent left-accent-6" style="background-color: {{ theme.accent }}"></div>
  <!-- 胶囊屏：纵向两行布局 -->
  <div if="{{ isCapsule }}" style="flex-direction: column; flex: 1;">
    <div style="flex-direction: row; align-items: center;">
      <text class="status-tag" ...>{{ statusTag }}</text>
      <text class="status-right" if="{{ statusTimeText }}" ...>{{ statusTimeText }}</text>
    </div>
    <text class="status-middle" ...>{{ statusMainText }}</text>
  </div>
  <!-- 方屏/圆屏：横向一行布局（保持不变） -->
  <block if="{{ !isCapsule }}">
    <text class="status-tag" ...>{{ statusTag }}</text>
    <text class="status-middle" ...>{{ statusMainText }}</text>
    <text class="status-right" if="{{ statusTimeText }}" ...>{{ statusTimeText }}</text>
  </block>
</div>
```

**布局效果**（胶囊屏）：

```
┌──────────────────┐
│ 上课中    45min   │  ← 第一行
│ 高等数学          │  ← 第二行，课程名完整显示
└──────────────────┘
```

#### 方案 B2：缩写 statusTag + 省略课程名

```js
// status-bar.js 胶囊屏缩写
if (isCapsule) {
  self.statusTag = current ? "课中" : "将上"   // 2字符
  self.statusTimeText = Math.ceil(...) + "'"   // 用 ' 代替 min
}
```

**不推荐**：仍然只有约 40px 给课程名，大部分课程名仍需截断。

### 问题 C：课程时间显示不全

**当前代码**：[class-list.js](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/pages/index-full/modules/class-list.js#L52-L60)

```js
classes.push({
  name: src.name,
  time: src.time,     // 格式: "08:00-08:45" (11字符)
  ...
})
```

**当前布局**（胶囊屏 88px - padding 14px×2 - accent 5px - margin 14px = 约 41px 可用）：

```
[accent 5px] [padding 14px] [课程名] [时间 08:00-08:45] [padding 14px]
                                 约41px  ← 时间文本约 110px，远超出
```

**解决方案**：

#### 方案 C1（推荐）：胶囊屏时间格式缩短

在 `class-list.js` 中，根据屏幕类型生成不同的时间格式：

```js
// class-list.js 新增
var isCapsule = false
var device = require("@system.device")
device.getInfo({
  success: function(data) {
    var shape = data.screenShape || ""
    isCapsule = (shape === "capsule" || shape === "pill-shaped")
  }
})

function shortenTime(timeStr) {
  // "08:00-08:45" → "08-08:45"（省略第一个冒号和分钟）
  // 如果还是太长 → "08-45"（只保留开始小时和结束时间）
  var parts = timeStr.split("-")
  if (parts.length < 2) return timeStr
  var start = parts[0].trim()   // "08:00"
  var end = parts[1].trim()     // "08:45"
  var startHour = start.split(":")[0]  // "08"
  return startHour + "-" + end  // "08-08:45"
}
```

同时在 CSS 中限制时间文本宽度：

```css
@media (shape: capsule), (shape: pill-shaped) {
  .grid-item-time {
    font-size: 16px;          /* 从 20 缩小 */
    margin-right: 8px;        /* 从 14px 缩小 */
    max-width: 72px;          /* 限制最大宽度 */
    lines: 1;
    text-overflow: ellipsis;
  }
  .class-card-body {
    padding: 10px 8px 10px 10px;  /* 从 14px 16px 14px 14px 缩小 */
  }
}
```

**效果**：`08-08:45` (8字符，16px字号 ≈ 72px) 勉强够用。

#### 方案 C2：胶囊屏课程卡片纵向布局

```css
@media (shape: capsule), (shape: pill-shaped) {
  .class-card-meta {
    flex-direction: column;    /* 时间在上，地点在下 */
    align-items: flex-start;
  }
  .grid-item-time {
    font-size: 14px;           /* 进一步缩小 */
    margin-right: 0;
    margin-bottom: 2px;
  }
  .grid-item-location {
    font-size: 14px;
  }
  .class-card-body {
    padding: 8px;
  }
}
```

#### 方案 C3：时间用 24h 简短格式

```js
// "08:00-08:45" → "08:00" (只显示开始时间)
function capsuleTime(timeStr) {
  return timeStr.split("-")[0].trim()
}
```

### 问题 D："添加课程"少一字

**当前代码**：[index-full.ux](file:///Users/Banner/Documents/guomengtao/tom/class/class/src/pages/index-full/index-full.ux#L108)

```ux
<input class="add-btn" type="button" value="+ 添加课程" ... />
<input class="style-btn" type="button" value="设置" ... />
```

**当前 CSS（胶囊屏）**：

```css
.add-btn, .style-btn {
  height: 48px;
  border-radius: 24px;
  font-size: 24px;      /* "+ 添加课程" 6字符 ≈ 120px ÷ 2(按钮) ≈ 60px/按钮，放不下 */
  line-height: 48px;
}
```

**说明**：两个按钮平分 88px，每个约 44px。"+ 添加课程" 24px字号下 ≈ 120px，  
只能显示约 44/24 ≈ 1.8 个字符，实际显示约 "+ 添" 或 "+ 添加"。

**解决方案**：

#### 方案 D1（推荐）：胶囊屏按钮文字缩写 + 缩小字号

```css
@media (shape: capsule), (shape: pill-shaped) {
  .add-btn, .style-btn {
    height: 44px;
    border-radius: 22px;
    font-size: 18px;           /* 从 24px 缩小 */
    line-height: 44px;
    flex: 1;
  }
}
```

模板中胶囊屏使用更短文字：

```ux
<!-- 胶囊屏：+加课 / 设置 -->
<input class="add-btn" type="button" value="{{ isCapsule ? '+加课' : '+ 添加课程' }}" ... />
<input class="style-btn" type="button" value="设置" ... />
```

**效果**：`+加课` (3字符) × 18px ≈ 54px，两个按钮 44px + 44px = 88px，  
54px < 44px 需要用 ellipsis... 仍然危险。

#### 方案 D2（推荐）：胶囊屏按钮用图标代替文字

```ux
<input class="add-btn" type="button" value="{{ isCapsule ? '+' : '+ 添加课程' }}" ... />
```

CSS 对胶囊屏的 `+` 按钮做特殊样式：

```css
.add-btn {
  flex: 1;
  ...
}
.style-btn {
  flex: 1;
  ...
}

@media (shape: capsule), (shape: pill-shaped) {
  .add-btn {
    flex: 0 0 44px;            /* 固定 44px 宽 */
    width: 44px;
    font-size: 28px;           /* 大号 + 图标 */
    border-radius: 22px;
    margin-right: 4px;
  }
  .style-btn {
    flex: 1;
    font-size: 18px;           /* "设置" 2字符 × 18px = 36px，在 ~40px 空间内 OK */
  }
}
```

**布局效果**（胶囊屏 88px）：

```
[ + 44px ] [ 设置 40px ]  = 88px ✅
```
