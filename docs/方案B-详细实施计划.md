## 五、支付方案设计

### 5.1 支付方式

小米快应用支持以下支付方式：

| 方式 | 可行性 | 说明 |
|------|--------|------|
| 小米支付SDK | 推荐 | 快应用原生支持，需接入小米支付 |
| 米币支付 | 备选 | 学生用户有米币充值习惯 |
| 微信/支付宝 | 需评估 | 快应用内跳转H5支付 |

推荐：优先使用小米支付SDK，1-2元小额支付体验最流畅。

### 5.2 激活码方案（备选）

考虑到快应用支付接入可能有门槛，备选方案：

```
用户通过其他渠道（如微信小程序/H5页面）支付后获得激活码，
在快应用「激活码」页面输入激活码解锁高级功能。
```

**优点**：不依赖快应用支付SDK，开发简单
**缺点**：用户需要跳转外部支付，流程稍长

### 5.3 激活状态存储

```
存储键：premium_unlocked
存储值：true | false（或存储激活时间戳）
```

- 激活后写入本地存储
- 每次启动检查激活状态
- 激活码方案：存储激活码 + 本地校验
- 重复激活：同一设备已激活，再次输入激活码提示"已解锁"

## 六、交互设计原则

### 6.1 无骚扰原则

```
❌ 禁止：
  - 首页顶部常驻VIP横幅
  - 课程列表插入VIP角标
  - 底部常驻解锁提示条
  - 弹窗广告
  - 启动页广告

✅ 允许：
  - 用户点击高级功能入口时弹出一次解锁提示
  - 设置页底部「高级功能」入口（可选）
  - 关于页面展示高级功能预览
```

### 6.2 文案规范

| 场景 | 文案 | 禁止 |
|------|------|------|
| 功能名称 | 「高级解锁」 | 「VIP会员」「Pro版」「付费版」 |
| 价格描述 | 「一次性解锁，永久使用」 | 「订阅」「月费」「续费」 |
| 按钮文案 | 「立即解锁」 | 「立即购买」「去付费」 |
| 取消按钮 | 「暂不」 | 「残忍拒绝」「继续免费」 |

### 6.3 弹窗组件

统一使用一个 `unlock-dialog` 组件，传入参数区分不同场景：

```javascript
// 调用方式
this.$app.showUnlockDialog({
  feature: 'schedule',  // 'schedule' | 'homepage' | 'theme'
  onSuccess: function() {
    // 解锁成功后的回调：执行原本要做的操作
  }
})
```

弹窗组件 `unlock-dialog.ux`：
- 标题：根据 `feature` 参数显示不同标题
- 内容：固定展示三项高级功能列表
- 按钮：「立即解锁」+「暂不」
- 解锁成功后回调 `onSuccess`

## 七、技术实现要点

### 7.1 状态管理（store.js 新增）

```javascript
// 检查是否已解锁高级功能
isPremiumUnlocked: function(callback) {
  storage.get({
    key: 'premium_unlocked',
    success: function(data) {
      callback(data === 'true')
    },
    fail: function() {
      callback(false)
    }
  })
},

// 设置解锁状态
setPremiumUnlocked: function(callback) {
  storage.set({
    key: 'premium_unlocked',
    value: 'true',
    success: function() { if (callback) callback(true) },
    fail: function() { if (callback) callback(false) }
  })
}
```

### 7.2 拦截点改造

| 文件 | 拦截位置 | 拦截条件 |
|------|----------|----------|
| `schedule-manager.ux` | `addSchedule()` 方法 | 免费用户，`list.length >= 1` 时弹窗 |
| `homepage-settings.ux` | 所有开关 `onclick` / 输入框 `onclick` | 免费用户，弹窗拦截 |
| `settings.ux` | 主题切换点击 | 免费用户点击非默认主题，弹窗拦截 |

### 7.3 拦截示例代码

```javascript
// schedule-manager.ux - addSchedule 方法改造
addSchedule() {
  var self = this
  store.isPremiumUnlocked(function(unlocked) {
    if (unlocked) {
      self.doAddSchedule()
    } else {
      // 第一套课表免费，只有已有1套及以上时拦截
      if (self.list.length >= 1) {
        self.showUnlockDialog('schedule')
      } else {
        self.doAddSchedule()
      }
    }
  })
},

doAddSchedule() {
  var name = "课程表" + (this.list.length + 1)
  database.addSchedule(name, function() {
    this.loadData()
  })
}
```

## 十一、风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 小米支付SDK接入困难 | 无法收费 | 先用激活码方案过渡 |
| 用户破解/绕过激活 | 收入损失 | 简单校验即可，1-2元产品破解成本>购买成本 |

| 用户对"付费"反感 | 卸载/差评 | 基础功能完全免费，仅增值功能收费，日常无骚扰 |
