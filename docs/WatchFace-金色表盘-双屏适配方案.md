## §2 判断：仍走父级 scale，但**不能取 1.5**

105 个盘内节点有严格的八层同心 / 半径 44 时标 / 半径 71 螺钉关系，逐节点改必崩，scale 是唯一选项。

但 1.5 试算直接爆版：

```
盘 168×1.5 = 252；表耳上凸 22×1.5 = 33、下凸 33 → 整块 252+66 = 318
+ 品牌两行 70 + 底部三行 100 + 必要间距 ≈ 500 > 480
```

**1.35 是能同时装下「带表耳的整块 + 品牌 + 三行文本」的上限**：

```
盘 226.8；表耳上凸 29.7、下凸 5.4 → 整块 262
+ 品牌 58 + 三行 98 + 间距 22 ≈ 440 ≤ 480 ✓
```

且盘 227 + 表耳 60 = **整块 287**，与前两块表盘 276 的视觉体量相当。

## §3 宽屏几何（scale 1.35）

- 盘 168 × 1.35 = **226.8**，`left = (336 − 226.8)/2 = 54.6`
- 盘心 = (54.6 + 113.4, 88 + 113.4) = **(168, 201.4)**
- 表耳 84×1.35 = **113.4×35.1**，`left = (336 − 113)/2 = 111.5`

### 表耳为什么要单独三个类

`.lug` 在 `.dial-wrap` **之外**（page 坐标系，`left:54; top:96/282`）。只 scale 表壳会让表耳留在原位置、彻底错位。

两条路：
1. **把 lug 移进 `.dial-wrap` 用负 top 相对化** —— 结构改动 + 依赖「Vela 支持负 top」这一未验证前提，风险高；
2. **给 lug 写 `.w-lug`（尺寸+left）/ `.w-lug-top` / `.w-lug-bottom`（各自的 top）三个单类** —— 只 3 条 CSS，数值按 1.35 手算，零结构风险。

**取方案 2**。

## §5 亚像素清单（scale 1.35 的代价）

| 元素 | 原尺寸 | ×1.35 | 判断 |
|---|---|---|---|
| `.mtick` | 1×4 | 1.35×5.4 | 50% 灰度细线，视觉仍是一条细线 |
| `.tick` | 2×9 | 2.7×12.15 | 可 |
| `.num` | 11px | 14.85px | 盘内铭文，可豁免 24px 下限；evpointer 地支 14→21、metal 罗马 12→18 均实测正常 |
| `.screw` | 7×7 | 9.45×9.45 | 可 |
| 针宽 | 7/5/2 | 9.45/6.75/2.7 | 秒针 2.7px 是最细的一处，若糊则单改 `.second` 宽 |

**1.35 不是整数倍**，是这块表盘的妥协：整数倍只有 1 和 2，1 等于没放大，2 会溢出屏高 130px。

## §6 绑定与探针

7 处混写：`brandCls / subCls / lugCls / lugTopCls / lugBottomCls / dialCls / dateCls / timeCls / backCls`（9 值，7 个节点因为 lug 一节点挂两值需分开）。

实际挂法：
- `.brand {{brandCls}}`、`.brand-sub {{subCls}}`
- `.lug.lug-top` → `class="lug lug-top {{lugTopCls}}"`，其中 `lugTopCls = "w-lug w-lug-top"`（两值合一）
- `.lug.lug-bottom` → `lugBottomCls = "w-lug w-lug-bottom"`
- `.dial-wrap {{dialCls}}`、`.date-line {{dateCls}}`、`.time-line {{timeCls}}`、`.back {{backCls}}`

`fitScreen` 从 `onInit` 调（本仓 `onReady` 不可靠已两次实证），页内 `require("@system.device")`，异步 `getInfo`，`w < 300` return。

### 落地偏差 1 处（关键教训）

**首版 `.w-brand` / `.w-sub` 只写了 `top` + `width` + `font-size`，漏了 `height` → 两行品牌字被裁掉上下沿。**

原因：本页基线 `.brand` / `.brand-sub` 的 `height` 只有 **14px**（字号 11/10px 时的尺寸），而宽屏字号提到 24/22px 后文字溢出盒子，Vela 按盒子裁切。金属/指针那两块没踩到，是因为它们基线 `height` 分别是 26 / 22px，恰好够。

**结论：宽屏改字号时，`height` 必须同步覆盖，不能只改 `font-size`。**

修正值：`.w-brand` top 6 / h28 / 24px；`.w-sub` top 34 / h26 / 22px（两盒 6–34、34–60，正好接上 `.w-lug-top` 的 60）。
