# 图标规范（PNG 资源）

> 适用范围：`src/common/icons/` 下所有 PNG 图标。新增图标前先读本篇，不符合规格的图不要入库。

## 一、硬性规格

| 项 | 值 | 说明 |
|---|---|---|
| 画布尺寸 | **32 × 32 px** | 全仓 10 个存量图标统一为 32×32，不要出 48/64 大图再缩放 |
| 色彩模式 | **8-bit RGBA**（PNG color type 6） | 必须带 alpha 通道，透明底 |
| 位深 | 8 bit/通道 | 不接受 16 bit、不接受索引色（color type 3） |
| 背景 | **完全透明** | alpha=0 处 RGB 也置 0，不留白底/黑底 |
| 图形风格 | **单色实心**，无描边、无渐变、无阴影、无圆角容器 | 手环屏幕小，多色会脏 |
| 抗锯齿 | 4×4 超采样（16 级 alpha） | 手写锯齿边手感极差 |
| 文件名 | `icon_<英文小写下划线>.png` | 例：`icon_week.png`、`icon_gear.png` |
| 目录 | `src/common/icons/dark/` 与 `src/common/icons/light/` **成对存在** | 缺一套会有一侧主题显示空白 |

## 二、颜色（两套主题固定值）

| 主题 | 目录 | 前景色 RGB | 十六进制 |
|---|---|---|---|
| 深色 | `dark/` | `(200, 200, 200)` | `#C8C8C8` |
| 浅色 | `light/` | `(60, 60, 60)` | `#3C3C3C` |

两套图形**几何完全一致，只换颜色**，不要为浅色主题单独调整笔画粗细。

## 三、视觉安全区（32×32 内的可用范围）

- 图形外接框控制在 **4 ~ 28 px**（即四周各留 2px 以上空白），给圆角裁切留余量。
- 线宽/笔画最小 **1.5 px**，低于 1.5px 在手环上会断线。
- 同屏并排的图标，视觉重量要接近：实心面积约占画布 25%~35%。

## 四、来源规定（重要）

**只允许两种来源，其余一律不收：**

1. **本仓脚本数学渲染生成（首选）**
   在 `scripts/gen-icons.py` 内用几何函数描述图形，脚本负责超采样、编码 PNG、双主题落盘。
   优点：可复现、可微调参数、无版权风险、几何必然对称。
   ```bash
   python3 scripts/gen-icons.py     # 重新生成 icon_week / icon_gear 两套四文件
   ```

2. **手绘/矢量工具导出（次选，需评审）**
   Figma / Sketch / Illustrator 画好后按「一、硬性规格」导出 32×32 RGBA，并保证双主题成对。
   提交时必须说明工具与源文件位置；**不接受**网上下载的第三方图标、不接受带图标的整套 UI 包截取。

**明确禁止：**
- 从 iconfont / flaticon 等站点直接下载（授权链不清、尺寸与配色不可控）。
- 用 emoji 或系统字体渲染后截图裁切（边缘发灰、有色偏）。
- 直接把 SVG 丢进项目（Vela 快应用 `image` 组件不支持 SVG，必须转 PNG）。

## 五、新增图标流程

1. 在 `scripts/gen-icons.py` 里加一个 `xxx_inside(x, y) -> bool` 几何函数（坐标系 32×32 浮点，原点左上）。
2. 在文件末尾的双主题循环里加一行 `write_png(...)`。
3. 跑 `python3 scripts/gen-icons.py`，四个文件（dark/light × 新图标）应同时更新。
4. 用 `sips -z 192 192 <png> --out /tmp/preview.png` 放大 6 倍目视检查，确认无断线、无偏色、对称。
5. 页面模板引用方式：
   ```xml
   <image class="xxx-icon" src="/common/icons/{{ iconTheme }}/icon_xxx.png"></image>
   ```
   `iconTheme` 由脚本按主题下发（`dark` / `light`），**不要硬编码目录名**。
6. 样式里显式给宽高（24px 图标位就写 `width:24px; height:24px`），不要依赖图片原始 32px 尺寸。
