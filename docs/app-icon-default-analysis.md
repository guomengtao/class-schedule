# 应用图标始终显示默认图标问题分析报告

## 问题概述

应用（Ev课程表）安装到手环/手表设备后，桌面图标始终显示为系统默认图标（通常是一个灰色或白色的通用图标），而非自定义的应用图标。

## 问题诊断

### 诊断结果总览

通过检查项目文件，发现以下 **4个核心问题**，按影响程度从高到低排列：

| 优先级 | 问题 | 严重程度 | 状态 |
|--------|------|----------|------|
| P0 | 图标文件是项目模板默认图标，从未替换 | 🔴 致命 | 需修复 |
| P1 | 图标尺寸不符合快应用规范 | 🔴 致命 | 需修复 |
| P2 | 图标路径非标准位置 | 🟡 中等 | 建议修复 |
| P3 | 存在重复图标文件 | 🟢 轻微 | 建议清理 |

## 问题1：图标文件是项目模板默认图标（P0 - 致命）

### 现状

```bash
$ ls -la src/logo.png src/common/logo.png
-rw-r--r--  3899 Aug 23 09:51 src/common/logo.png
-rw-r--r--  3899 Aug 23 10:47 src/logo.png

$ md5 src/logo.png src/common/logo.png
MD5 (src/logo.png) = 823bb83b6c03181342d787e3a546d744
MD5 (src/common/logo.png) = 823bb83b6c03181342d787e3a546d744
```

### 分析

两个 `logo.png` 文件的 **MD5 哈希值完全相同**，且文件大小仅有 **3899 字节**。这明显是 `aiot-toolkit` 创建项目时自动生成的**模板默认图标**，从未被替换为自定义的应用图标。

快应用构建工具在打包时，会直接将 `manifest.json` 中 `icon` 字段指向的图片文件复制到最终的 `.rpk` 安装包中。由于该文件始终是模板默认图标，设备安装后自然显示的是默认图标。

### 影响

- 用户安装后看到的是通用图标，无法区分本应用和其他应用
- 品牌识别度为零
- 在手表/手环的小屏幕上，图标是用户识别应用的唯一视觉标识

## 问题2：图标尺寸不符合快应用规范（P0 - 致命）

### 现状

```bash
$ file src/common/logo.png
src/common/logo.png: PNG image data, 128 x 128, 8-bit/color RGBA, non-interlaced
```

### 分析

当前图标尺寸为 **128×128** 像素。根据快应用（Quick App）官方规范：

| 平台 | 要求尺寸 | 当前尺寸 | 是否合规 |
|------|----------|----------|----------|
| 快应用通用规范 | **192×192** | 128×128 | ❌ 不合规 |
| 华为手表 (HarmonyOS) | 192×192 | 128×128 | ❌ 不合规 |
| OPPO 手表 | 192×192 | 128×128 | ❌ 不合规 |
| 小米手表 | 192×192 | 128×128 | ❌ 不合规 |
| 最佳实践（高分屏） | 512×512 | 128×128 | ❌ 不合规 |

**快应用联盟官方规范**明确要求：`manifest.json` 中的 `icon` 字段指向的图片必须是 **192×192 像素**的 PNG 格式图片。

当设备系统检测到图标尺寸不符合规范时，行为因厂商而异：
- **华为手表**：回退到系统默认图标（灰色通用图标）
- **OPPO手表**：可能拉伸显示，但会严重模糊
- **小米手表**：回退到系统默认图标

### 影响

- 这是导致"安装后始终显示默认图标"的**最直接原因**
- 即使替换了自定义图标，如果尺寸不达标，仍可能显示默认图标

## 问题3：图标路径非标准位置（P2 - 中等）

### 现状

```json
// manifest.json
{
  "icon": "common/logo.png"
}
```

### 分析

在当前项目中，图标文件位于 `src/common/logo.png`。虽然 `manifest.json` 中 `icon` 字段的路径是相对于 `src/` 目录的，`common/logo.png` 是一个有效的路径，但快应用的标准实践是：

**标准位置**：`src/logo.png`（即 manifest.json 中 `"icon": "logo.png"`）

`aiot-toolkit` 创建项目时，默认会在 `src/` 根目录下生成 `logo.png`，并在 `manifest.json` 中写入 `"icon": "logo.png"`。

当前项目将图标放在 `src/common/` 子目录下，虽然不是错误，但：
1. 与 `aiot-toolkit` 默认模板不一致
2. 构建工具可能在特定情况下无法正确识别非标准路径
3. 增加了维护者的困惑（存在两个 logo.png）

### 影响

- 中等影响，路径本身是有效的，但属于非标准实践
- 如果构建工具版本升级，可能导致路径解析失败

## 问题4：存在重复的图标文件（P3 - 轻微）

### 现状

项目中存在两个完全相同的 `logo.png` 文件：

```
src/logo.png          (128×128, 3899 bytes)
src/common/logo.png   (128×128, 3899 bytes)
```

### 分析

- `src/logo.png`：`aiot-toolkit` 创建项目时生成的默认位置
- `src/common/logo.png`：手动创建或移动的副本，被 `manifest.json` 引用

两个文件完全相同，存在冗余。`src/logo.png` 未被引用，属于无效文件。

### 影响

- 轻微影响，主要造成维护困惑
- 如果开发者误修改了 `src/logo.png` 而忘记修改 `src/common/logo.png`，会导致图标不更新

---

## 修复方案

### 方案一：完整修复（推荐）

#### 步骤1：设计/准备自定义图标

准备一个符合以下要求的图标文件：

```
格式：PNG（支持透明背景）
尺寸：192×192 像素（推荐同时准备 512×512 用于高分屏）
命名：logo.png
内容：体现"Ev课程表"品牌特征（如课程表、书本、时钟等元素）
```

#### 步骤2：替换图标文件

```bash
# 将自定义图标放到标准位置
cp /path/to/your-custom-icon.png src/logo.png

# 同步更新 common 目录下的文件
cp src/logo.png src/common/logo.png
```

#### 步骤3：修改 manifest.json

将 `icon` 路径改为标准位置：

```json
{
  "icon": "logo.png"
}
```

#### 步骤4：清理冗余文件

```bash
# 删除 common 目录下的旧图标（可选，保留作为备份也可）
rm src/common/logo.png
```

#### 步骤5：重新构建

```bash
npm run build
# 或
npm run release
```

#### 步骤6：验证

1. 将生成的 `.rpk` 包安装到手表/手环
2. 检查桌面图标是否显示为自定义图标
3. 如果仍显示默认图标，检查构建日志中是否有图标相关警告

### 方案二：最小改动修复

如果不想移动文件，只需：

1. 准备 **192×192** 的自定义图标
2. 替换 `src/common/logo.png`（保持 manifest.json 中的路径不变）
3. 同时替换 `src/logo.png`（保持一致性）
4. 重新构建

```bash
cp /path/to/your-custom-192x192-icon.png src/common/logo.png
cp /path/to/your-custom-192x192-icon.png src/logo.png
npm run build
```

## 图标设计建议

### 尺寸规格

| 用途 | 尺寸 | 说明 |
|------|------|------|
| 快应用规范要求 | 192×192 | 必须满足 |
| 高清屏适配 | 512×512 | 强烈推荐 |
| 手表桌面 | 192×192 | 系统会自动缩放 |

### 设计要求

1. **简洁明了**：手表/手环屏幕小，图标应简洁，避免过多细节
2. **圆形适配**：部分手表系统会将图标裁剪为圆形，核心元素应在中心区域
3. **深色背景适配**：手表多为深色背景，图标应有足够的对比度
4. **透明背景**：使用 PNG 透明背景，避免白边
5. **品牌一致性**：延续"Ev课程表"的品牌风格

### 设计元素建议

- 课程表/日历图标
- 书本/学习相关元素
- "Ev" 字母标识
- 时钟/时间元素
- 蓝绿色调（与应用内主题色 #7ec8e3 保持一致）

## 常见问题 FAQ

### Q1: 为什么替换了图标文件，安装后还是默认图标？

**A**: 检查以下几点：
1. 图标尺寸是否为 **192×192**（不是 128×128 或其他尺寸）
2. 文件格式是否为 PNG
3. 是否重新执行了构建命令（`npm run build`）
4. 是否正确卸载了旧版本再安装新版本（部分手表会缓存旧图标）

### Q2: 可以用 JPG 格式的图标吗？

**A**: 不可以。快应用规范要求图标必须是 **PNG 格式**，且建议使用透明背景。

### Q3: 512×512 的图标会不会太大？

**A**: 不会。构建工具会自动处理图标。使用 512×512 可以确保在高分屏手表上显示清晰。同时建议保留 192×192 版本以确保兼容性。

### Q4: 为什么 `src/` 目录下有两个 logo.png？

**A**: `src/logo.png` 是 `aiot-toolkit` 默认生成的；`src/common/logo.png` 是手动添加的。建议统一使用 `src/logo.png`（标准位置），删除 `src/common/logo.png`。
