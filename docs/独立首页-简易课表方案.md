# 独立首页方案 · 简易课表（schedule-panel-simple）

> 系列：7 个课表首页独立化改造（umbrella: evtask-D-evclass-sche-261019-wxfkmx）
> 「独立首页标准 v1」见 `docs/独立首页-当前进度方案.md` 附节，本页直接引用。

## 1. 页面定位（重新规划）

「简易课表」是**按天分组的纵向课表清单**：只保留有课的星期，每组显示「星期 X · N 门课」头 + 当天课程（课名/时间/地点，按时间升序），点击进详情。信息密度低、一眼扫完，是 7 页中最轻量的「今天/本周有什么课」速览。

作为独立首页的差异化价值：**极简、零认知负担**——适合「不想看格子，只想快速知道今天上啥」场景。保留现有 daySections 分组模型。

## 2. 现状 vs 独立首页标准

| 维度 | 现状 | 达标 |
|---|---|---|
| 数据自加载 | `database.init` + `getAllCourses`（当前方案） | ✅ |
| 主题适配 | `store.getTheme` 全变量 + `iconTheme` 图标主题 | ✅ |
| 加载态/空态 | `isLoading` 加载中 + `daySections.length===0` 暂无课程 | ✅ |
| 屏型适配 | `width >= 200 / >= 400` 断点 + `shape: circle` | ✅ |
| 生命周期 | `onShow` 刷新主题 | ✅ |
| 返回逻辑 | `goBack()` 直接 `router.back()` | ❌ |

**唯一缺口**：返回逻辑（同前 6 页）。`goBack()` 写死 `router.back()`，作为 root 冷启动首页时栈内无上级，后退会异常/空白。

## 3. 改造项

按标准 v1 第 1 条（同第 1 页模式）：
- `private` 增加 `fromPanel: ""`、`isRoot: false`。
- `onInit` 开头做 root 判定：`fromPanel === '1' ? '1' : ''`；`isRoot = fromPanel !== '1'`。
- 模板：`back-btn-wrapper` 与 `header-placeholder` 两个元素包 `if="{{ !isRoot }}"`（root 时无返回钮，标题仍靠 `flex:1 + text-align:center` 居中，无需改布局）。
- `goBack()` 双模：`fromPanel==='1' → router.back()`，否则 `utils.exitApp()`。
- 新增 `onBackPress()` 双模：`fromPanel==='1' → return false`（交系统默认后退）；否则 `return utils.exitApp() === true`。
- 引入 `const utils = require("../../data/utils.js")`。

其余（daySections 分组、主题绑定、加载/空态、屏型断点）维持现状，不改动。

## 4. 验收口径

- 单测 33/33 不回归（含「简易课表」分组用例）。
- vela-loop root 模式截图：无返回钮、标题「简易课表」居中、有课/空态渲染正常。
- 被「更多首页」push（带 `fromPanel`）时：返回钮可见、点击回到目录页、硬件后退键回目录。
- root 冷启动（设为首页）：无返回钮、硬件后退键退出应用。
