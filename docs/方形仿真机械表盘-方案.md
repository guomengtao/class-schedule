# 方形仿真机械表盘方案（watch-face-vibrate 改造）

> 目标：把「震动表盘」（现在是大号数字钟 + 震动开关）改为**方形仿真机械表盘**。
> 两条硬要求：① 方形就是方形，不是圆表塞进方框，盘内不许出现任何圆形表盘轮廓；② 仿真度要在
> `watch-face-gold`（圆表）之上再深一档 —— 让人第一眼分不出是实物表还是屏幕。

---

## 一、结论先行

| 问题 | 结论 |
|------|------|
| 方表能不能做 | 能。走针引擎（120 档 `.rN` + 顶部中点轴）与方形几何**完全解耦**，原样复用 |
| 会不会又踩引擎红线 | 不新增结构风险：仍是一层 absolute 子元素、无嵌套旋转、无动态 transform、无 vw |
| 和圆表的关系 | 只借用「走针 + 光影方法论」，几何、刻度、表壳全部重写，不复用任何圆角/半径 |
| 震动功能 | 全保留（30s 默认开），但从表盘上撤掉按钮，收进长按面板，避免破坏拟真 |
| 工作量 | 一次性重写页面（约 900 行），A/B 两阶段实拍验收，预计 2 轮截图调参 |

## 二、为什么「方形」比「圆形」更难，但更容易骗过眼睛

圆表靠**同心圆半径**解决一切：刻度沿半径、光影靠月牙、表壳靠圆环。方表没有半径，
所有"像不像"的活都压在**直角转折**和**四边光影**上，一旦四边亮度一样，立刻退化成"电子屏画了个方框"。

所以方表的三条命门（本方案的全部设计都围绕它们）：

1. **四边不能等亮**。主光源仍在左上：上边最亮、左边次亮、右边中等、下边最暗（背光）。
   `border-color` 四条边分别给色，是方表最廉价也最有效的立体手段。
2. **必须有一圈"倒角"**。方表表壳不是一块平板，是外框 → 45° 倒角 → 盘面边框 → 盘面，四级下沉。
   每一级都用「错位同心方框」造，高光只出现在左上两条边。
3. **必须有方表专属零件**。方表没有"圆弧"，靠 **表冠（3 点位圆柱 + 齿纹）**、**直线表耳**、
   **铁路分钟轨（chemin de fer）**、**双线框** 这些零件立住"这是块真表"。

## 三、几何定义（192×490 基准，与圆表同画布）

### 3.1 表体尺寸

| 元素 | 规格 | 说明 |
|------|------|------|
| 表壳外框 | **172 × 172**，`left:10, top:114`，圆角 **9px** | 不是 0：微圆角是"cushion case"，完全直角像贴纸 |
| 盘面 | 140 × 140（inset 16），圆角 3px | 方表盘面几乎直角，只留 3px 防锯齿 |
| 表耳 | 上 76×28 / 下 76×28，圆角 5px | 直线表耳，比圆表更窄更"硬" |
| 表冠 | 6 × 18，3 点位，凸出壳外 3px | 带 3 条横向齿纹（1px 暗线） |
| 分钟轨 | 半宽 **65**，刻度长 4 | 沿方形边界走，见 3.2 |
| 中心 | **(86, 86)** | 172/2 |
| 时针 / 分针 / 秒针 | 36 / 58 / 68 | 分针够到分钟轨内缘，秒针略过轨 |

### 3.2 方表刻度怎么摆（本方案唯一的数学）

圆表刻度：`P = C + (sinθ, -cosθ) × r`。
方表**不能**用固定 r，否则刻度在角上会缩进盘内、四边留白。改用**射线与方形边界求交**：

```
half = 65
R(θ) = half / max(|sinθ|, |cosθ|)        // 边中点 = 65，角上 = 91.9
P_out = C + (sinθ, -cosθ) × R(θ)         // 刻度外端（贴边）
P_in  = C + (sinθ, -cosθ) × (R(θ) - 4)   // 刻度内端
```

效果与真方表一致：12/3/6/9 落在四条边的中点，1、2 这类刻度自然落到**角部**并呈 45° 斜向，
角部刻度间距自动变密 —— 这正是 Cartier Tank / JLC Reverso 那种"真方表"的观感，
而不是"把圆刻度环套进方框"的假货。

- 60 个分钟刻度：外端 `R(θ)`、长 4、宽 1（暗档 `#6f767e`）
- 12 个整点刻度：外端 `R(θ)`、长 9、宽 2（亮档 `#e8eef4`）；12/3/6/9 加宽到 3
- 11 个阿拉伯数字（3 点让给日期窗）：沿射线内缩到 `R(θ) - 17`，字号 11（12/6/9 用 13 加粗）
- 刻度一律 `transform: rotate(θ)`，轴心即顶部中点 → 天然"朝心"

### 3.3 方表的四级下沉（错位方框）

每层都比外层向右下偏 1–2px，左上露出**L 形高光带**（圆表是月牙，方表是直角折线，更硬朗）：

```
① case-outer  172   圆角 9   #6f767e   基体（拉丝面）
② case-shade  168   偏移 +2 #545b62   暗面
③ bezel-hi    165   偏移 +3.5 #d3dae1  倒角抛光（最亮）
④ bezel-lo    159   偏移 +5  #6a7178  倒角下凹
⑤ bezel-in    154   偏移 +6  #b6bdc3  内斜面二次迎光
⑥ dial-rim    144   inset 14 #12161a  盘框（下沉）
⑦ dial-face   140   inset 16 #1b2027  盘面
⑧ dial-tex    128   inset 22 #1e222a  机刻纹区（中心略亮）
```

### 3.4 三针（沿用圆表标定，仅改长度与针形）

- 每针 3 层：暗影（右下 +2px）+ 主针 + 左缘 1–2px 高光；三层共用同一档位 class。
- 时针/分针改**剑形**：主针矩形 + 针尖 2px 收窄块（在针头叠一个窄块，不加旋转），
  方表配剑形针才不显得"电子"。
- 秒针：橙 `#e8722c`，宽 2，末端 3×3 小方块配重（贴在针尾，不旋转、不嵌套）。
- 中轴：暗底 16 → 亮环 12 → 铆钉 6（三层，铆钉偏左上 0.5px 造高光）。

## 四、深度仿真：比圆表多做的 9 件事

按"一眼真假"的贡献度排序，前 5 条必做：

1. **铁路分钟轨**：分钟轨外侧再压一条 1px 亮线（半宽 69），与刻度形成内外双线 ——
   真表叫 chemin de fer，是"专业表"的强信号。
2. **四边异亮**：表壳用 `border-top/left/right/bottom` 四色而非单一 `background-color`，
   上 `#aeb6bd`、左 `#8f979e`、右 `#646b72`、下 `#4a5057`。方表立体感的 70% 来自这里。
3. **表冠齿纹**：3 点位凸出 3px 的圆柱 + 3 条 1px 暗横线 + 左缘 1px 亮线。
   方表没有表冠就是"方框"，加上立刻成表。
4. **日期窗凹槽**：金属框（27×19）+ 内井（23×15）+ 上缘 1px 暗线 + 左缘 1px 亮线，
   日期字下沉 1px，制造"开窗"而非"贴纸"。
5. **蓝宝石反光带**：盘面左上 45° 两条窄亮条（`rgba(255,255,255,.06)`，4px / 2px），
   只覆盖盘面 55% 长度，止于盘心 —— 大片灰块会读成污渍。
6. **拉丝纹理**：表壳上边压 10 条 1px 横线（`rgba(255,255,255,.035)`，间隔 2px），
   左侧压 8 条 1px 竖线。只在迎光侧，暗侧不加（真表拉丝也只在受光处可见）。
7. **时标夜光点**：每个整点刻度内端 2×2 浅绿点 `#cfe3d6`，低亮度下一眼"机械表"。
8. **印刷铭文**：`EV` + `AUTOMATIC`（12 点下）+ `SQUARE · 36 JEWELS`（6 点上），
   字号 5–6px、字距 1px、颜色 `#5c636b`。字太小看不清没关系，密度本身就是真实感。
9. **秒针走法**：机械表是扫秒，但 Vela 每次赋值 = 一轮全树 diff + 整屏重绘。
   **默认 1Hz（与圆表一致，稳）**，秒针常量 `TICK_MS` 可调；若实拍确认 500ms 不闪再放开，
   绝不为了"扫秒"回到整页闪。

## 五、功能与交互（震动不能丢）

原页面的「震动 30秒 开/关」「换色」「返回」三个按钮全部**从表盘上撤掉**（按钮是拟真杀手）。

| 操作 | 行为 |
|------|------|
| 单击盘面 | 返回表盘目录（与机械表盘一致） |
| 长按 ≥600ms | 打开设置面板（震动开关 + 倒计时 + 盘面主题 + 关闭） |
| 上滑 / 下滑 | 切到课程表盘 / EV 指针（沿用 gold 的环） |
| 震动 | 逻辑原样保留：默认开、每 30s 一次、开关各震一下回执 |

面板规格：240 宽、深色半透明遮罩、无圆角大块（方表风格用 4px 小圆角）；
按钮点击必须 `suppressTap` 挡住整页返回，沿用旧页套路。

盘面主题（黑钢 / 象牙白 / 深蓝）：**B 阶段可选**，用 3 个容器 class 切盘面与刻度色。
A 阶段先做单色（黑钢），避免一次引入 3 套配色把调参复杂化。

## 七、引擎红线（沿用已标定结论，逐条遵守）

1. 禁 `transform: rotate({{deg}})` 动态绑定 → 只用 120 档字面量 `.rN`。
2. 引擎旋转轴 = **元素顶部中点**，`transform-origin` 不生效 → 针必须"顶部中点压在盘心、向下延伸"，
   档位值 `rotate(180 + 3N)`。
3. 禁"旋转父元素内嵌子 div"→ 应用启动即退。
4. 禁"祖先有 transform + 子孙有 rotate"→ 启动即退（整表 scale 放大这条路已判死）。
5. `vw` 不生效（实测 25vw = 25px）；`transform: scale` 轴心在左上角，不用。
6. 禁群组选择器 `.a, .b {}`；`.page` 只给 `position:relative` + 100% 尺寸，不叠 flex 居中。
7. 每秒只写变化字段（脏值判断），否则回到 6 次/秒重绘 = 整页闪。

## 八、分期与验收

### 阶段 A（骨架，先看"方不方、真不真"）
表壳 8 层 + 四边异亮 + 表耳 + 表冠 + 分钟轨/整点刻度/数字 + 日期窗 + 三针 + 中轴 + 底部信息。
验收：模拟器实拍，盘内**无任何圆形轮廓**，四边亮度可辨，12/3/6/9 落在边中点。

### 阶段 B（密度）
铁路双线、拉丝、夜光点、铭文、剑形针尖、日期窗凹槽、蓝宝石反光、设置面板 + 震动接线。
验收：同尺寸截图与圆表并排，方表细节密度不低于圆表。

### 阶段 C（实拍调参，1–2 轮）
- 刻度是否压到数字、角部刻度是否过密、表冠是否被裁剪（若裁剪改内嵌凹槽）、
  分针是否够到分钟轨、铭文是否与刻度打架。

### 硬验收
`aiot release --enable-jsc` 无 error；10 Pro 冷启 ≤ 15s 出画；连续 3 张间隔 1s 截图，
秒针每张不同、其余像素稳定（证明无整页闪）；震动 30s 实测触发一次。

### 11.2 实拍验收（小米手环 192×490，emulator-11000）
- **三针角度（像素扫描，非目测）**：分针理论 133.0°、实测 129–131°；时针理论 221.1°、实测 216–221°；秒针与截图时刻 31s 对应 186° 命中。三针全部正确。

### 11.3 与方案的偏差
1. **夜光点取消独立 12 元素后又加回**：先按 §4.7 做 12 个 2×2 点，坐标贴整点刻度内端，最终保留。
2. **螺钉只在四角、无齿纹**：方表表圈螺钉做在内凹槽位（inset 7），未做中央螺钉。
3. **剑形针尖未做**：三针保持圆表的矩形三层结构（暗影/主针/左缘高光），避免叠在旋转父元素内的独立块。
4. **底部 32px 时间大字删除**，只留 13px 日期 + 10px 操作提示（方案 §5 的判断：大字是「电子屏」破绽）。
