# 当前进度 栏目 · 重构方案（更多首页 · progress）

> 定位：**课程的仪表盘**——课名是整屏最大字，时钟可小可无。
> 判据来自 `docs/表盘盘点与升级方案.md` §九：课名最大 → 此页归「更多首页」；若改成时钟最大，应移出本栏目。

## 0 · 共同约束（七份方案共用，写死勿破）
- 画布 **192×490**，页边距 12，卡片圆角 12。
- 色板：主 `#7ec8e3` / 正文 `#f2fbff` / 次 `#8fa6b5` / 卡底 `#16213e` / 分隔 `#0f3460`。
- **禁区**：带文字的 `transform`（必白屏）、`<scroll>+scrolltop`（引擎不认）、
  `@keyframes` 承载读数（会冻结）。动画只许 `opacity`。
- 数据只走 `require("../../data/store.js")`，分钟级刷新，禁止秒级轮询（除秒相关页）。
- 每个栏目**必须**有一个 120px 高的顶部返回热区，页面根节点不挂 onclick（防 drag 被当点击）。

## 1 · 现状实测
- 文件 `src/pages/schedule-panel-progress/schedule-panel-progress.ux`，**217 行**，最大字号 **48px**，已接 store。
- 结构判定（待核对）：时间 + 当前课 + 进度条，48px 给的是时钟或课名之一。

## 2 · 问题
- 48px 撑不住“课名为王”，但也不够大到当时钟，属于两头不靠。
- 进度条若不是 `width` 绑定而是写死，跨节时会失真。
- 无「下一节」提示，用户看完本页还得再翻。

## 3 · 新结构
| 区 | 内容 | 字号/尺寸 |
|---|---|---|
| 顶部 12–120 | 返回热区（隐形） | — |
| A 课名 | 两行，超长省略 | 56px / 行高 62 |
| B 状态行 | `第3节 · 剩 25 分` | 20px `#8fa6b5` |
| C 进度条 | 168×10，圆角 5 | `width:{{pct}}%` |
| D 下一节 | `下一节 09:55 大学物理` | 18px |
| E 时钟 | 右下角小字 | 16px |

区间：A 130–260、B 266–288、C 300–310、D 330–352、E 460–476。全部 ≤490 且不重叠。

## 4 · 数据
`store` 取：当前课 `name/start/end/room`、剩余分钟（`end - now`）、下一节。
三态：**上课中** / **课间**（显示距下一节）/ **已放学**（显示明日首节）。

## 5 · 分档实施与回退
| 档 | 内容 | 风险 | 回退 |
|---|---|---|---|
| P0 | 课名升 56px + 时钟降角标 | 低 | 保留原 48px 版 |
| P1 | 进度条改 `width` 绑定 | 低 | 退回写死宽度 |
| P2 | 三态文案 | 中（时段边界） | 只保留上课中 |

## 6 · 验收
1. 单测：三态各一条用例、进度百分比 0/50/100 边界、跨节不跳字。
2. 实拍 192×490，课名不溢出（长课名两行截断）。
3. 连拍 3 帧无白屏；`emu-start.sh status` 先看 `guest存活`。
