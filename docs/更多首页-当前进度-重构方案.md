# 当前进度 栏目 · 重构方案（更多首页 · progress）

> 定位：**课程的仪表盘**——课名是整屏最大字，时钟可小可无。
> 判据来自 `docs/表盘盘点与升级方案.md` §九：课名最大 → 此页归「更多首页」；若改成时钟最大，应移出本栏目。

## 0 · 共同约束（七份方案共用，写死勿破）
- 画布 **192×490**，页边距 12，卡片圆角 12。
- 色板：主 `#7ec8e3` / 正文 `#f2fbff` / 次 `#8fa6b5` / 卡底 `#16213e` / 分隔 `#0f3460`。
- **禁区**：带文字的 `transform`（必白屏）、`<scroll>+scrolltop`（引擎不认）、
  `@keyframes` 承载读数（会冻结）。动画只许 `opacity`。
- 数据只走 `require("../../data/store.js")`，分钟级刷新，禁止秒级轮询（除秒相关页）。
- 每个栏目**必须**有一个 120px 高的顶部返回热区，页面根节点不挂 onclick（防 drag 被当点击）。

## 1 · 现状实测（2026-10-20 以源码为准回写）
- 文件 `src/pages/schedule-panel-progress/schedule-panel-progress.ux`，**217 行**，已接 store。
- **最大字号 48px 是空态 emoji ⏳**（`.no-class-icon`），课名只有 **34px**（≥200 断点 40px）。
  原 §1「48px 给的是时钟或课名之一」是误判——页面上根本没有 48px 文字，也没有时钟。
- 结构判定（原「待核对」→ 现已核对）：**单张卡片**（课名 / 时间 / 地点 / 进度条 / 已过·剩余两行）。
  §3 的 **D 下一节、E 时钟在源码里不存在**，属新增；三态也没有——正文只有「加载中 / 空态 / 卡片」三分支。
- **进度条已经是 `width: {{ progressPercent }}%` 绑定**（不是写死）：§5 的 P1 现状已达标，本次不重做。
- **定时器是 `setInterval(..., 10000)`**：10 秒轮询，既不是整分对齐也违反 §0「分钟级刷新」，
  且只在 `onDestroy` 清、**没有 `onHide`**——后台仍在空转（本次一并改掉）。
- **无首帧兜底**：`isLoading` 要等 `database` 回调才置 false，storage 慢就停在「加载中…」。

## 2 · 问题
- 48px 撑不住“课名为王”，但也不够大到当时钟，属于两头不靠。
- 进度条若不是 `width` 绑定而是写死，跨节时会失真。
- 无「下一节」提示，用户看完本页还得再翻。

## 3 · 新结构
| 区 | 内容 | 字号/尺寸 |
|---|---|---|
| 顶部 12–120 | 返回热区（隐形） | — |
| A 课名 | 两行，超长省略 | 56px / 行高 62 / **自然高度** |
| B 状态行 | `第3节 · 剩 25 分` | 20px `#8fa6b5` |
| C 进度条 | 168×10，圆角 5 | `width:{{progressPercent}}%` |
| D 下一节 | `下节 10:55 化学`（label + 定长时间 + 弹性课名） | 16 + 18px |
| E 时钟 | 右下角小字 | 16px |

**三处按实拍修正（2026-10-20）**：
1. **A 不写死 `height:124`**。方案原按「两行占满 124」算，但单行课名（2 字科目 / 放学 / 没课）
   只占 62，下面会空一大块。改自然高度：1 行贴紧 B，2 行自动撑到 124；最坏总高 246 < 434 不溢出。
2. **D 不能用「下一节 09:55 大学物理」整串**：18px 下估算 168.4px > 内容宽 168，必截断。
   改三段式：label「下节」16px（32）+ 时间 18px（49.5）+ 课名 `flex:1` 省略，
   课名可用宽 74.5 ≥ 4 个全角字（「大学物理」正好放得下）。
3. **E 时钟贴底不能用 `margin-top: auto`**：本引擎不生效，实测时钟卡在内容下方而非屏幕底部。
   改 `.spacer { flex: 1 }` 撑开。

区间（192 画布，页边距 12 / 内容宽 168）：A 起 98（页头 44+40 后 +14），B 紧随 A +16，
C 条 +12，D 行 +20，E 贴底。全部 ≤490 且不重叠。

## 4 · 数据
`store` 取：当前课 `name/start/end/room`、剩余分钟（`end - now`）、下一节。
**四态**（原三态 + 空态），已全部落地：
| 态 | A 课名 | B 状态行 | C 进度 | D 下一节 |
|---|---|---|---|---|
| 上课中 | 当前课名（主色） | `第3节 · 剩 25 分` | 本节已过 % | 本节之后那节 |
| 课间 | **下节课名**（主色） | `距上课 10 分` | 课间已过 % | 空（A 已是下节，不重复） |
| 已放学 | `放学`（次色） | `今天的课上完了` | 100% | 明日首节 |
| 没课 | `没课`（次色） | `今天没有安排` | 0% | 明日首节（若有） |

课间进度口径：`(now − 上节下课) / (本节上课 − 上节下课)`；**一天第一节之前没有「上节」，记 0**
（不能拿 00:00 当上节，否则 07:00 会显示 88% 这种荒谬进度）。
