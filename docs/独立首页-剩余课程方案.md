## 1. 页面定位（重新规划）

「剩余课程」是**今天还没上完的课的清单**：按时间序列出今日尚未结束的课程（序号 + 课名 + 时间 + 地点），第一节课高亮；全部上完显示 🎉「今日课程已全部结束」，今天无课显示 📭「今天没有课」。

作为独立首页定位清晰：**回看「今天还剩什么」**，与「当前进度」（聚焦此刻）、「倒计时」（聚焦下一节）互补，构成三粒度时间视角。保留现有信息结构。

## 2. 现状 vs 独立首页标准

| 维度 | 现状 | 达标 |
|---|---|---|
| 数据自加载 | `database.init` + `getAllCourses` | ✅ |
| 主题适配 | `store.getTheme` 全变量 | ✅ |
| 加载态/空态 | 加载中 + 🎉/📭 双空态 | ✅ |
| 屏型适配 | `width >= 200` 断点 | ✅ |
| 生命周期 | 无定时器（静态清单，进页取一次数即可） | ✅ |
| 返回逻辑 | `goBack()` 直接 `router.back()` | ❌ |

**唯一缺口同第 1 页**：root 冷启动时返回逻辑失效。

## 3. 改造项

按标准 v1 第 1 条落地（与第 1 页同款）：

1. `private` 新增 `fromPanel: ""` / `isRoot: false`，`onInit` 计算 `isRoot = fromPanel !== '1'`。
2. 返回钮 + 占位符加 `if="{{ !isRoot }}"`。
3. `goBack()` 双模：`fromPanel` → `router.back()`；否则 `utils.exitApp()`。
4. `onBackPress()` 双模：`fromPanel` → `return false`；否则 `return utils.exitApp() === true`。
5. `require utils.js`。

（「更多首页」目录页已在第 1 页统一带 `fromPanel` 参数，本页无需再动目录页。）
