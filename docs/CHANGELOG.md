# 更新日志

## v1.3.138 (2026-09-02)

### 新增功能
- **添加课程 Demo**：实验室新增简易添加课程测试页面，支持选择课程表、日期、时间、位置输入，保存后显示最近添加记录
- **课程表选择器**：Demo 页面支持左右切换目标课程表，确认信息区显示当前课程表名称

### 文档
- **商业模式方案**：对比方案A（7天全功能试用）和方案B（永久基础可用+增值一次性买断），推荐方案B
- **方案B详细实施计划**：457行完整实施文档，含功能分层、弹窗文案、支付方案、技术实现、测试清单、上线计划
- **方案B整合优化**：
  - 新增"数据备份与恢复"作为隐形刚需锚点（捆绑多课表）
  - 预览排序优化：首页自定义置顶，主题缩略图折叠到最后
  - 支付失败自动转激活码兜底弹窗（应对学生绑卡率低）
  - 取消按钮统一改为"继续使用标准版"（降低心理防御）

### Bug 修复
- 修复添加课程后页面底部不显示最近添加记录的问题
- 修复添加课程 Demo 页面 `<span>` 标签导致黑屏的问题
- 修复添加课程后课程表里没有数据的问题（改用 database.insertCourse 统一接口）
- 修复保存卡住无响应的问题（database.init 初始化 + 5秒超时保护）
