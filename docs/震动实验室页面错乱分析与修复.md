## 二、发现的错乱（修复前）

### 🔴 P1 震动样式列表整体错乱（最严重）
**现象**：「震动样式」标签与样式 chip 挤在同一行，所有样式卡（短震/长震/
双短震/三连震）被压成**右半屏 80px 窄条**垂直堆叠，文字全部截断成
「长…」「持…」「双…」「轻…」。

**根因**：样式列表的父容器是裸 `<div if="{{ remindEnabled }}">` ——
**Vela 的 div 默认 flex-direction: row**。标签（80px）与 vibe-grid 横排，
grid 只剩 160−80=80px 宽，`width:100%` 的卡片随之变成窄条。
（`@media` 里 vibe-grid 的 `flex-direction: column` 只解决了 grid 内部
方向，救不了父容器。）

**修复**：父容器加 `class="style-block"`（`flex-direction: column; width:100%`）。

### 🔴 P2 「提前提醒」行横向溢出重叠
**现象**：显示为「提前提醒 − 5 … +」，label、−、数值、+ 四个元素互相
挤压重叠，数值被截成「5 …」。

**根因**：`remind-toggle-row` 是 row + space-between；「提前提醒」label
80px + `minute-row`（48+64+48=160px）= **240px > 160px 内容区**，必然溢出。

**修复**：拆成上下两行（`.minute-block` 纵向）：label 一行，步进器一行。

### 🟠 P3 步进值被截断
**现象**：「强度 500…」「间隔 800…」——`step-value` 固定宽 80px（基样式
90px），放不下「1000ms」6 字符。

**修复**：宽度统一 104px（基样式与胶囊块同步）。

### 🟠 P4 快捷预设卡文字全部截断
**现象**：预设名字「短震 长震 双…」、信息「10… 8… 10…」全截。
**根因**：三列布局 `width:31%` ≈ 50px，放不下 3 个汉字（60px）和
「100ms × 1」（约 81px）。

**修复**：改**两列** `width:47%`（含胶囊媒体块同步），名字完整；
信息文案精简为 `100×1` 格式（54px，一行放下）。

### 🟡 P5 快捷值按钮行参差
**现象**：5 个固定 48px 宽按钮换行后，第二行「800 / 1000」被
`space-between` 撑到两端，中间空洞。

**修复**：`width:31% + margin 1%` 三列均分，`justify-content: flex-start`，
形成 3+2 左对齐整齐排布。

### 🟡 P6 文案类截断（4 处）
| 位置 | 现象 | 修复 |
|---|---|---|
| hero 参数行 | 「间隔 800ms…」后截断 | 去掉中文前缀改 `500ms · 800ms · 5 次` + 字号 18 |
| 温馨提示 | 息屏提示截成一行 | `lines: 2` |
| 我的方案空提示 | 「暂无保存的…」 | 文案精简为「暂无保存的方案」 |
| notice-icon / hero-icon | ℹ 与 〰 装饰图标显突兀 | **按要求移除** |

### 🟡 P7 页面无滚动容器（上次重构遗留隐患）
长内容直接被 490px 屏高裁掉，底部内容（我的方案/保存按钮）完全不可达。
已包 `<scroll class="page-scroll">`（本次巡航验证了滚动后每一屏）。

## 四、通用教训

1. **Vela 的 `div` 默认 `flex-direction: row`**——`<div if>` 条件容器极易
   踩坑，包裹纵向内容必须显式 `flex-direction: column`。
2. **行内横向预算要先算总宽**：label 宽 + 控件组宽 > 内容区宽度就必然
   溢出重叠（160px 内容区在胶囊屏上非常紧）。
3. **固定 px 宽度的多列网格**（31%/47%）必须连同**胶囊媒体查询里的覆盖值**
   一起改，漏一处就回到错乱。
4. **不能只检查第一屏**：本页 7 处问题里 5 处在首屏之外，滚动巡航 +
   全档位截图是唯一可靠的核查方式。
