# 科目色卡 栏目 · 重构方案（更多首页 · subject-color）

> 定位：**课程的仪表盘**——课名是整屏最大字，时钟可小可无。
> 判据来自 `docs/表盘盘点与升级方案.md` §九：课名最大 → 此页归「更多首页」；若改成时钟最大，应移出本栏目。

## 0 · 共同约束（七份方案共用，写死勿破）
- 画布 **192×490**，页边距 12，卡片圆角 12。
- 色板：主 `#7ec8e3` / 正文 `#f2fbff` / 次 `#8fa6b5` / 卡底 `#16213e` / 分隔 `#0f3460`。
- **禁区**：带文字的 `transform`（必白屏）、`<scroll>+scrolltop`（引擎不认）、
  `@keyframes` 承载读数（会冻结）。动画只许 `opacity`。
- 数据只走 `require("../../data/store.js")`，分钟级刷新，禁止秒级轮询（除秒相关页）。
- 每个栏目**必须**有一个 120px 高的顶部返回热区，页面根节点不挂 onclick（防 drag 被当点击）。

## 1 · 现状实测（2026-10-20 以源码为准回写）
- 文件 `src/pages/schedule-panel-subject-color/schedule-panel-subject-color.ux`，**170 行**，已接 store。
- **最大字号 28px 是页头标题**（`.header-title` 与 ≥200px 断点下的课名共用 28px），不是读数——原 §1 把它当成视觉重心是误判。
- 结构判定（原「待核对」→ 现已核对）：**`<scroll>` 竖列表**，`for="{{ todayClasses }}"` 每节课一张卡片
  （左侧 8px 科目色条 + 课名 26px / 时间 / 地点）。**没有网格、没有当前科目区、没有图例**——
  方案 §3 的 A/B/C 在源码里全部缺失，属**新增**。
- **配色表已存在**：`SUBJECT_COLORS` 14 科 + `getSubjectColor()` 子串匹配，未命中回退 `#7f8c8d`。
  即 P2「固定配色表」**现状已达标**，本次不重写，只把它定为 #5 多彩课表的前置件。
- **无任何定时器**：`loadData()` 只在 `onInit` 跑一次，`onShow` 只刷主题。
  → 页面常驻时「当前上哪科」不会随下课点切换，必须在 P0 一并补分钟级刷新（§0 要求）。
- 卡片底色已是模板行内 `theme.card`（上一轮独立首页化改过），CSS 里无硬编码底色。

## 2 · 问题
- **最大字号只有 28px**，全栏目没有视觉重心，扫一眼分不出“现在上什么”。
- 色卡只表达“有哪些科”，不表达“现在上哪科”，信息价值低于它的占屏面积。


## 3 · 新结构
| 区 | 内容 | 字号/尺寸 |
|---|---|---|
| A 当前科目 | 色块 + 课名（**放大**） | 40px，色块 12×44 |
| B 今日色卡网格 | 2 列 × 3 行，每格 **80**×72 | 课名 18px |
| C 图例 | 小字 `今日 6 科`（超 6 科时 `今日 8 科 · 显示前 6`） | 16px |

A 130–185、B 200–432（3 行各 72 + 间距 8 = 232）、C 452–468。

**格宽 84 → 80（2026-10-20 实测修正）**：192 画布页边距 12，内容宽只有 **168px**；
`2×84 = 168` 再加列间距必然溢出。改 80 后用 `.grid-row { width: 168; justify-content: space-between }`
撑出 8px 列间距（`2×80 + 8 = 168`），不依赖 gap（本引擎 gap 不可靠）。
A 区同理：40px 课名可用宽约 148px（168 − 12 色块 − 10 间距），4 字即超宽，必须单行省略。

## 4 · 数据
科目→颜色映射需**固定表**（同一科跨天同色），存 store 或常量表；当前科目格加 2px 主色描边。
