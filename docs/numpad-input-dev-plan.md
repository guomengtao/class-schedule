# 数字输入测试页面 — 开发方案

## 概述

在功能实验室中新增一个"数字输入"页面，用于测试数字键盘输入体验。用户通过点击底部 3×4 简洁数字键盘，将数字填入上方 4×4 共 16 个格子中。

---

## 页面结构

```
功能实验室 (test-area)
├── 新增: "数字输入"行 → 跳转至 numpad-input 页面
│
numpad-input (数字输入) ← 新建页面
├── header: 返回按钮 + 标题 "数字输入"
├── 数字显示区: 4行 × 4列 = 16个格子
├── 当前选中: 高亮提示当前正在输入第几个格子
└── 数字键盘: 3列 × 4行（1-9, 清空, 0, 删除）
```

## 交互逻辑

### 数字格子（4×4）

| 行为 | 说明 |
| :--- | :--- |
| 初始状态 | 全部 16 格为空，光标定位在第 1 格 |
| 点击某个格子 | 切换光标到该格，后续输入填入该位置 |
| 输入数字 | 点击键盘上的数字，填入当前光标所在格 |
| 已填数字 | 显示已输入的数字，未填显示空白或浅色占位符 |
| 自动跳转 | 输入完当前格后，光标自动移到下一格（从左到右，从上到下） |
| 覆盖输入 | 光标在已填格子上时，新输入会覆盖旧数字 |

### 数字键盘（3×4）

| 按键 | 行为 |
| :--- | :--- |
| **1-9** | 将数字填入当前光标所在格，光标自动后移一位 |
| **0** | 将数字 0 填入当前光标所在格，光标自动后移一位 |
| **删除** | 删除当前光标所在格的数字，光标前移一位（如果当前格为空则删除前一格） |
| **清空** | 清除全部 16 格，光标回到第 1 格 |

### 光标提示

```
当前第 3 格（共 16 格）
```

在格子区域下方显示一行小字，告诉用户当前正在输入第几个格子。

## 数据模型

```javascript
// 状态
{
  cells: [null, null, null, null,   // 第1行：索引0-3
          null, null, null, null,   // 第2行：索引4-7
          null, null, null, null,   // 第3行：索引8-11
          null, null, null, null],  // 第4行：索引12-15
  cursor: 0,                        // 当前光标位置（0-15）
  theme: {}
}
```

- `cells` 数组：16 个元素，`null` 表示空，数字 0-9 表示已填入
- `cursor`：当前输入位置，点击格子或键盘输入时更新
