# 首页「总今明」按钮多屏适配机制分析

## 1. 概述

首页有三个快速导航按钮：「总」（周视图）、「今」（今天）、「明」（明天）。它们在不同屏幕上的位置不同：

| 屏幕 | 宽度 | 位置 |
|------|------|------|
| 手环 9（胶囊） | 192px | header **下方**独立一行（nav-toolbar） |
| 10 Pro（胶囊大号） | ~200px+ | header **内部**，标题和右箭头之间 |
| Watch 6（方屏） | 400px+ | header **内部**，标题和右箭头之间 |

小屏和大屏走两套完全不同的 DOM 结构，靠 `isCapsule` 标志切换。

---

## 2. 核心机制：`isCapsule` 标志

### 2.1 获取屏型

```js
// index.ux 脚本顶层
var isCapsuleScreen = false

device.getInfo({
  success: function(data) {
    var shape = data.screenShape || ""
    var capsule = (shape === "capsule" || shape === "pill-shaped")
    isCapsuleScreen = capsule
    // 回填到实例
    if (indexInstance && indexInstance.isCapsule !== capsule) {
      indexInstance.isCapsule = capsule
    }
  }
})
```

### 2.2 实例同步

模块级变量 `isCapsuleScreen` 在 `device.getInfo` 回调中异步拿到真实值后，通过引用回填给页面实例的 `this.isCapsule`：

```js
// data 默认值
private: {
  isCapsule: false
}

// onInit 中首次同步
onInit() {
  self.isCapsule = isCapsuleScreen
}
```

## 3. 大屏布局（`!isCapsule`）

三条按钮放在 header 行内，标题右侧：

```html
<div class="header">
  <div class="nav-btn-circle" onclick="prevDay">◀</div>
  <text class="day-title">{{ dayDisplayText }}</text>

  <!-- 大屏：总今明在 header 行内 -->
  <div class="day-nav-btns" if="{{ !isCapsule }}">
    <div class="day-nav-circle" onclick="goToWeekView" if="{{ showDayNavZong }}">
      <text>总</text>
    </div>
    <div class="day-nav-circle" onclick="goToToday" if="{{ showDayNavJin }}">
      <text>今</text>
    </div>
    <div class="day-nav-circle" onclick="goToTomorrow" if="{{ showDayNavMing }}">
      <text>明</text>
    </div>
  </div>

  <div class="nav-btn-circle" onclick="nextDay">▶</div>
</div>
```

大屏 header 结构：`◀ | 标题 | [总][今][明] | ▶`

---

## 4. 小屏布局（`isCapsule`）

header 行内**不渲染** `day-nav-btns`（`if="{{ !isCapsule }}"` 为 false），改在 header **下方**独立渲染 `nav-toolbar`：

```html
<div class="header">
  <div class="nav-btn-circle" onclick="prevDay">◀</div>
  <text class="day-title">{{ dayDisplayText }}</text>
  <!-- day-nav-btns 不渲染 -->
  <div class="nav-btn-circle" onclick="nextDay">▶</div>
</div>

<!-- 小屏：总今明独立一行 -->
<div class="nav-toolbar" if="{{ isCapsule && (showDayNavZong || showDayNavJin || showDayNavMing) }}">
  <div class="day-nav-circle" onclick="goToWeekView">总</div>
  <div class="day-nav-circle" onclick="goToToday">今</div>
  <div class="day-nav-circle" onclick="goToTomorrow">明</div>
</div>
```

小屏 header 结构：`◀ | 标题 | ▶`，下方 `[总] [今] [明]` 独立一行。

## 5. CSS 适配层

### 5.1 Base（手环 9）

```css
.nav-toolbar {
  flex-direction: row;
  justify-content: space-around;
  height: 48px;
  margin-bottom: 4px;
  padding: 0 4px;
}

.day-nav-circle {
  width: 44px;     /* 44px 圆——3×44 + 间距 = 148px < 160px 内容区 */
  height: 44px;
  border-radius: 22px;
  justify-content: center;
  align-items: center;
  margin-left: 4px;
}
```

### 5.2 胶囊屏 breakpoint（width >= 200px, or shape: capsule）

```css
@media (shape: capsule), (shape: pill-shaped) {
  .day-nav-circle {
    width: 48px;     /* 提到 48px */
    height: 48px;
    border-radius: 24px;
    margin-left: 2px;
  }
  /* 192px 屏幕：3×48=144 + 间距4=148 < 160 可用，刚好 */
}
```

## 6. 设置页如何模仿实现

设置页目前的 header 结构：

```html
<div class="back-header">
  <div class="back-btn-wrapper" onclick="goBack">◀</div>
  <text class="header-title">设置</text>
  <div class="header-placeholder"></div>   <!-- 占位对称 -->
</div>
```

改造目标：

| 屏幕 | 返回按钮 | 标题 | 顶部空白 |
|------|---------|------|---------|
| 手环 9 | 大圆（48×48）+ 大图标（28×28），独立在顶部 | 居中 | 无多余空行 |
| 10 Pro | 和标题同行，小一点 | 同行，可点击返回 | 无多余空行 |

### 6.1 引入 `isCapsule`

```js
// 新增：屏幕形状检测
var isCapsuleScreen = false
var settingsInstance = null

device.getInfo({
  success: function(data) {
    var shape = data.screenShape || ""
    isCapsuleScreen = (shape === "capsule" || shape === "pill-shaped")
    if (settingsInstance) {
      settingsInstance.isCapsule = isCapsuleScreen
    }
  }
})

export default {
  private: {
    isCapsule: false
  },
  onInit() {
    settingsInstance = this
    this.isCapsule = isCapsuleScreen
    // ...
  }
}
```

### 6.2 双套模板

```html
<!-- 小屏：返回按钮大圆，标题下方独立 -->
<div class="back-header-capsule" if="{{ isCapsule }}">
  <div class="back-btn-capsule" onclick="goBack">
    <image class="back-btn-icon-capsule" src="..."></image>
  </div>
  <text class="header-title-capsule" style="color: {{ theme.text }}">设置</text>
</div>

<!-- 大屏：返回+标题同行，标题可点击返回 -->
<div class="back-header-row" if="{{ !isCapsule }}" onclick="goBack">
  <image class="back-btn-icon-row" src="..."></image>
  <text class="header-title-row" style="color: {{ theme.text }}">设置</text>
</div>
```

### 6.3 CSS

小屏 base（手环 9）：

```css
.back-btn-icon-capsule { width: 28px; height: 28px; }
```

大屏（width >= 200px / 10 Pro）：
```css
.back-header-row { flex-direction: row; align-items: center; padding: 2px 4px; }
```
