# 更新说明

从 v1.3.0 到 v1.3.121 的重要更新内容

---

## 新增功能

- 软件授权系统上线，支持激活码离线验证与设备绑定
- 激活页面：三步流程（购买激活码 → 兑换 → 输入激活）
- 激活码纯数字编码，18位数字，输入更简单
- 激活码输入网格 3行×6列，减少行数更紧凑
- 激活单位升级为"月数"，可选1个月、3个月、99个月等
- 99个月激活码自动设为永久激活，无限使用
- 激活时长可累加，在现有到期时间上继续延长
- 兑换码一次性使用，防止重复激活
- 到期提醒系统，每日弹窗提醒续费
- 首页顶部激活状态提示条，颜色区分：正常 / 即将到期 / 已过期
- 功能实验室：整合设备信息、震动实验室、二维码生成等工具页面
- 首页自定义走马灯文字，可自由编辑显示内容
- 字体大小设置：首页自定义文字和中文输入法文字跟随设置缩放
- 激活页面键盘输入时震动反馈，操作更踏实

## 重要优化

- 设备ID验证改为截取后4位比对，更灵活
- 已激活用户不再弹出到期提醒
- 首页白屏/黑屏问题修复
- 设备信息页面布局改为卡片式，更清晰美观
- 功能实验室底部提示文字更清晰可见
- 去掉emoji表情，解决手环渲染方框问题
- 授权状态颜色区分：绿色（正常）→ 橙色（即将到期）→ 红色（已过期）
- 首页提醒条增加关闭按钮，可手动隐藏
- 支持永久授权，一次激活永久使用
