| `watch-face-metal.ux` | 463 | 真正的仿古青铜指针盘，但带 **5 种「找圆心」调试覆盖层**（对角 X / 十字 / 圆点 / 四角 / 边框）、5 个预设时刻按钮、「停止/继续」、版本号等**调试残留** | 目录「仿古金属表盘」 |

**结论**：名为「EV指针」的页面其实是个占位数字钟；真正可用的指针盘藏在 metal 页，且被大量调试代码包裹，不能直接作为产品页。本次重构把 **EV指针** 做成一款干净、可发布、与系列统一的仿古青铜指针表盘。

### 历史黑屏教训（必须遵守的硬约束）

来自 `docs/EV指针-仿古金属指针表盘-方案.md` §十/§十一 与 `watch-face-metal.ux` 文件头注释：

1. **Vela 禁用群组选择器** `.a, .b {}`——会导致整张样式表被丢弃，表现为黑屏。
2. **`transform` 用 `{{}}` 数据绑定会黑屏**；字面量静态 `transform` 与 `@keyframes` 动画安全。
3. 根容器必须显式 `width/height:100%` + `flex-direction: column`；绝对定位子元素需要 flex/定位上下文，否则整页塌缩成深色＝黑屏。
4. **少层少 DOM**，不用 CSS 渐变（Vela 不支持），金属质感靠「同心环 + 深浅边色」叠。

## 二、重构目标与边界

**要做的**：把 `watch-face-evpointer.ux` 重写为一款干净的仿古青铜指针表盘：

- 184px 青铜同心环盘面（外缘/中圈/内盘三层色阶造厚度）。
- 十二地支刻度（子…亥，子位 12 点，顺时针每 30°）。
- 12 个短刻度条（静态 rotate 定位）。
- 时/分/秒三针，`@keyframes` 连续走时，负 `animation-delay` 定位到当前时间。
- 盘心 EV 铭文 + 顶部品牌 + 底部数字时间/日期。
- 退出：单击任意处 → 返回目录（系列统一）；上滑 → 金属字针表，下滑 → 仿古金属表盘（维持目录环）。

- ❌ 不引入调试覆盖层、预设按钮、版本号文本。

## 三、技术方案（关键：如何绕开 transform 黑屏）

### 3.1 指针旋转 = 「整层旋转 + 内部竖条」

不直接给细针设 `transform-origin`，而是：

```
.hand-layer(184×184, 位于盘面 (0,0), 默认 transform-origin = 中心)
  └ .hand-bar(细竖条, left=90/91, top=92-长度, 指向 12 点)
```

`@keyframes spin { from rotate(0) to rotate(360) }` 作用在 **184×184 的整层**上——整层正方形的旋转中心默认就是盘心（92,92），竖条底部正好钉在盘心，绕盘心旋转即得正确指针。全程 `transform` 都是 `@keyframes` 里的**字面量**，无数据绑定。

### 3.2 走时定位 = 负延迟（仅绑定 animation-delay）

| 针 | duration | delay（秒） |
|---|---|---|
| 秒 | 60s | `-s` |
| 分 | 3600s | `-(m*60 + s)` |
| 时 | 43200s | `-((h%12)*3600 + m*60 + s)` |

`animation-delay` 通过内联 `style="animation-delay: {{delaySecond}}s"` 绑定——这是**普通样式值绑定**（`watch-face-class.ux` 已用 `style="width:{{n}}px"` 验证安全），不触碰 `transform` 绑定禁区。即便某天绑定失效，最坏是「从 12:00 起走」而非黑屏，属可接受降级。

### 3.3 几何参数（192×490）

- 盘面直径 `184`，盘心 `CX=96, CY=245`；盘面左上 `(4,153)`。
- 地支半径 `r=64`（字号 13），刻度半径 `r=80`（2×10 短条）。
- 三针长度：时 46 / 分 66 / 秒 82；针宽：5 / 4 / 2；针芯距盘心 0。
- 顶部 `y≈60` 品牌「EV」；底部 `y≈352` 日期、`y≈376` 数字时间、`y≈430` 返回。

## 八、落地结果与关键标定（2026-10-19 定稿）

### 8.1 结论先说

原方案（「整层 184×184 旋转 + 负 `animation-delay` 定位」）**实测不可用**，已作废，
改为**「60 档字面量旋转类 + class 数据绑定」**，实拍核验通过：

| 项 | 结果 |
|---|---|
| 盘面 | 184px 青铜三层同心环 + 12 刻度 + 十二地支（子位 12 点）✅ |
| 三针 | 从盘心射出、角度与盘面时间一致 ✅ |
| 走时 | 秒针每 10 秒前进 60°，真实跟随系统时间 ✅ |
| 底部 | 「10-19 周一」「16:12」「轻触返回」✅ |
| 黑屏 | 无（423 行、61 条静态 rotate、1 秒一次 class 变更）✅ |

### 8.2 两条被推翻的旧认知

**① `@keyframes` + 负 `animation-delay` 不能用来「定位到当前时刻」。**
实测同一页面连续抓帧：指针角度与盘面时间对不上、粗针周期性整根消失、
画面出现长达 12 秒的完全冻结（10 帧 md5 全同）后才跳动。判为引擎对
动画合成/负延迟支持不完整，**不是代码逻辑错**（delay 算法本身算得对）。

**② `transform-origin` 不按 CSS 语义生效 —— 引擎真实轴在【元素顶部中点】。**

4 色标定针（同几何、仅 rotate 不同、`top:12px` 即针顶离容器顶 12px）实测：

| 标定 | 期望（若轴在中心） | 实测 | 结论 |
|---|---|---|---|
| `rotate(0)` | 竖线，中心在盘心 | 竖线，**顶**在盘心、向下延伸 | 轴=顶部中点 |
| `rotate(90)` | 横线过盘心 | 横线在**盘心上方 79px**、向左 | 轴=顶部中点 |
| `rotate(270)` | 横线过盘心 | 横线在盘心上方、向右 | 轴=顶部中点 |

→ 这也是 `watch-face-metal` 长期挂着 5 种「找圆心」调试层的**真正原因**
（它把针顶对齐了圆心，却按「轴在中心」去算角度，所以永远对不上）。

### 8.3 定稿写法（照抄即可）

```html
<!-- 针顶压在盘心 (92,92)，向下延伸 -->
<div class="hand hour {{hourCls}}"></div>
```
```css
.hand { position: absolute; }
.hour  { left: 89.5px; top: 92px; width: 5px; height: 48px; }  /* top 就是盘心 Y */
/* 60 档：rotate(180 + 6N)，180° 把「向下」翻成「向上」 */
.r0  { transform: rotate(180deg); }
.r1  { transform: rotate(186deg); }
...
.r59 { transform: rotate(534deg); }
```
```js
// 每秒把当前时刻折成档位类名（只改 class，不改 transform 值）
this.secondCls = "r" + (Math.round(sec * 6 / 6) % 60)
```

要点：
- **只改 class，不改 transform 值** —— 字面量 transform 安全，动态 transform 值黑屏；
- class 必须写成「静态基类 + 动态档位」`class="hand hour {{hourCls}}"`；
  整串动态 `class="{{cls}}"`（值为 `"hand hour r15"`）实测会让**整个应用启动即退**；
- 1 秒刷新一次 class **不会黑屏**（此前「setInterval 必黑」的结论只对
  「setInterval + transform 数据绑定」成立）。
