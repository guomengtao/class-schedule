# 总课表模板选择功能实现方案

## 一、功能概述

在设置页增加「总览课表风格」选项，用户点击进入模板选择页，从多个模板中选择自己喜欢的风格。选择后，总课表页面（`week-view`）按照所选模板风格渲染展示。

```
设置页 → 总览课表风格 → 模板选择页 → 选择模板 → 总课表按模板渲染
```

---

## 二、数据模型

### 2.1 存储键

```
key: "weekview_template"
value: "minimal-char" | "minimal-en" | "standard-block" | ...
```

### 2.2 store.js 新增方法

```js
// 读取模板设置
function getWeekViewTemplate(callback) {
  storage.get({
    key: "weekview_template",
    success: function(data) {
      callback(data || "standard-block")
    },
    fail: function() {
      callback("standard-block")
    }
  })
}

// 保存模板设置
function setWeekViewTemplate(templateId, callback) {
  storage.set({
    key: "weekview_template",
    value: templateId,
    success: function() {
      if (callback) callback()
    },
    fail: function() {
      if (callback) callback()
    }
  })
}
```

### 3.2 settings.ux 脚本变更

新增方法和数据属性：

```js
private: {
  // ... existing props ...
  currentTemplateId: "standard-block",
  currentTemplateName: "标准详情"
},

// onInit 中加载
loadTemplateSetting: function() {
  var self = this
  var storage = require("@system.storage")
  storage.get({
    key: "weekview_template",
    success: function(id) {
      var tplId = id || "standard-block"
      var name = (TEMPLATES[tplId] && TEMPLATES[tplId].name) || "标准详情"
      self.currentTemplateId = tplId
      self.currentTemplateName = name
    },
    fail: function() {
      self.currentTemplateId = "standard-block"
      self.currentTemplateName = "标准详情"
    }
  })
},

// 跳转到模板选择页
openTemplatePicker: function() {
  router.push({ uri: "/pages/template-picker" })
}
```

### 4.2 选择逻辑

```js
selectTemplate: function(id) {
  var self = this
  self.selectedId = id
  var storage = require("@system.storage")
  storage.set({
    key: "weekview_template",
    value: id,
    success: function() {
      // 更新显示的模板名
      var tpl = TEMPLATES[id]
      if (tpl) self.selectedName = tpl.name
      // 返回上一页
      setTimeout(function() {
        router.back()
      }, 200)
    }
  })
}
```

## 五、week-view 页面改造

### 5.1 模板配置驱动渲染

在 `week-view.ux` 中，将当前硬编码的渲染逻辑改为由模板配置驱动。

```js
// 模板配置映射表
var TEMPLATES = {
  "minimal-char": {
    showRowNum: false,      // 隐藏行号
    showRoom: false,        // 隐藏教室
    showName: true,         // 显示课名（单字）
    showTime: false,        // 隐藏时间
    nameStyle: "char",      // 单字显示
    dayLabels: ["一","二","三","四","五","六","日"],
    cellRadius: "12px",     // 大圆角
    cellPadding: "1px",
    nameSize: "18px",
    nameWeight: "bold"
  },
  "standard-block": {
    showRowNum: true,
    showRoom: true,
    showName: true,
    showTime: true,
    nameStyle: "full",
    dayLabels: ["一","二","三","四","五","六","日"],
    cellRadius: "6px",
    cellPadding: "2px",
    nameSize: "13px",
    nameWeight: "normal"
  }
}
```

### 5.2 onShow 加载模板

```js
onShow: function() {
  var self = this
  // ... existing theme/hideWeekend loading ...

  // 新增：加载模板设置
  store.getWeekViewTemplate(function(id) {
    self.applyTemplate(id || "standard-block")
  })
},

applyTemplate: function(id) {
  var tpl = TEMPLATES[id] || TEMPLATES["standard-block"]
  this.showRowNum = tpl.showRowNum
  this.showRoom = tpl.showRoom
  this.showName = tpl.showName
  this.showTime = tpl.showTime
  this.nameStyle = tpl.nameStyle
  this.dayLabels = tpl.dayLabels
  this.cellRadius = tpl.cellRadius
  this.cellPadding = tpl.cellPadding
  this.nameSize = tpl.nameSize
  this.nameWeight = tpl.nameWeight
}
```

### 5.3 模板条件渲染

```html
<!-- 行号/时间列 -->
<text class="time-label" if="{{ showRowNum }}" style="color: {{ theme.textSecondary }}">
  {{ $item.time }}
</text>

<!-- 课名 -->
<text class="course-name" if="{{ nameStyle === 'full' }}" style="color: {{ theme.accent }}; font-size: {{ nameSize }}">
  {{ $item.course.name }}
</text>
<text class="course-char" if="{{ nameStyle === 'char' }}" style="color: {{ theme.accent }}; font-size: {{ nameSize }}; font-weight: {{ nameWeight }}">
  {{ $item.course.displayChar }}
</text>

<!-- 教室 -->
<text class="course-room" if="{{ showRoom && $item.course.location }}" style="color: {{ theme.textMuted }}">
  {{ $item.course.location }}
</text>

<!-- 时间 -->
<text class="course-time" if="{{ showTime && $item.course.time }}" style="color: {{ theme.textMuted }}">
  {{ $item.course.time }}
</text>
```

### 5.4 动态样式

```html
<!-- 课程块圆角 -->
<div class="course-cell" style="border-radius: {{ cellRadius }}; padding: {{ cellPadding }}">
```

## 七、开发步骤

### Step 1: store.js 增加存储方法

添加 `getWeekViewTemplate` 和 `setWeekViewTemplate` 两个方法，使用系统 storage API 读写 `weekview_template` 键。

### Step 2: settings.ux 增加入口

在「课程表设置」分组中，`隐藏周六日` 行下方添加分隔线和「总览课表风格」行，右侧显示当前模板名称。点击跳转到 `template-picker` 页面。

### Step 3: 创建 template-picker 页面

卡片列表布局，每项显示模板名称 + 描述 + 选中状态圆点。选择后自动保存并返回设置页。

### Step 4: week-view.ux 改造

1. 在 `onShow` 中读取模板配置
2. 将模板配置映射到页面数据属性
3. 模板中使用 `if` / `show` 条件渲染控制各元素显隐
4. 动态绑定样式变量（圆角、字号、字重等）

### Step 5: manifest.json 注册

添加 `template-picker` 页面路由。

### 8.2 新增一种模板的步骤

1. 在 `TEMPLATES` 对象中添加新模板定义
2. 在 `template-picker` 页的模板列表中添加新项
3. 如果新模板需要新的渲染逻辑，在 `week-view.ux` 中扩展条件渲染
