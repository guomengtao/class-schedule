# 激活主页面拆分方案（2026-10-21）

> 单号：evtask-D-evclass-sche-261021-e3np8g
> 原则：**老版单页的措辞、技术实现、跳转链接全部原样沿用，本次只做页面拆分，不重做流程。**

## 一、背景与用户定位

手环快应用是**标准版老用户的第一触点**：用户已使用一段时间、认可产品、想升级高级版，但不了解购买与激活流程。因此：

1. **购买是第一优先级**——不下单，激活无从谈起。购买引导必须直接呈现在主页首屏，不藏入口。
2. 已购买用户分两种：安卓 + 同步器（主推，深链自动激活）；iOS / 无同步器（兜底，网页兑换 + 手环输码）。
3. 已拿到 18 位激活码的用户：直接输入。
4. 面向学生群体，操作不熟悉：**所有措辞延续老版的谨慎风格，不夸大、不误导、条件式表达**。

## 三、技术实现沿用清单（一行不动）

| 常量 | 值 | 用途 |
|---|---|---|
| `ACTIVATION_URL` | `https://app-auth.gudq.com/activate.html?deviceId=` | 手工激活二维码（qrText），带 `&c=channel` 渠道参数 |
| `AFDIAN_REDIRECT_URL` | `https://app-auth.gudq.com/go/ev-timetable?deviceId=` | 购买跟踪跳转（afdianUrl），**带跟踪，勿改直链** |
| `APK_DL_URL` | `https://app-auth.gudq.com/apk-download.html?deviceId=` | 同步器下载二维码（apkQrText） |

deviceId 获取链（原样）：`@system.device.getDeviceId` → 空/`NA`/`unknown`/`null` → 回落 `utils/device-uuid.js` 本地 UUID。

## 五、主页改造点（唯一改动）

### 目标结构（自上而下）

```
[←]  高级版

┌── 状态卡（2 行）──────────────────┐
│ 标准版/高级版 · 到期 2026-12-31    │
└────────────────────────────────────┘

┌── 购买卡（老版步骤 1 原样上浮）────┐
│ 购买兑换码                         │
│ 爱发电购买                         │
│ [afdianUrl 二维码] 扫码购买         │
└────────────────────────────────────┘

  激活步骤指南 ›          → activation-guide（老版步骤 2、3）
  输入激活码 ›            → activation-code（老版步骤 4）
  激活历史 · 设备信息 ›   → activation-info
```

### 与现状（第3步后）的 diff

| 现状 | 目标 | 动作 |
|---|---|---|
| 「购买兑换码」文字入口行（entry-secondary，点击跳 guide 页） | 带 afdianUrl 二维码 + 说明的购买卡 | 入口行升级为卡片：引入 `AFDIAN_REDIRECT_URL` 与 deviceId 拼接逻辑 + `<qrcode>` 组件 |
| 「获取设备 ID」入口 | 取消 | deviceId 只在 guide/code/info 页需要，主页不展示 |
| 「输入激活码」入口 | 保留 | 不动 |
| 「激活历史 · 设备信息」次级入口 | 保留 | 不动 |
| 「激活步骤指南」入口 | **新增** | `router.push guide 页`（openGuidePage 已存在，只需把入口行文案/位置理顺） |

购买卡是首屏第一优先级：位于状态卡正下方、首屏内完整可见，不等滚动。
