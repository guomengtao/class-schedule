# 高级版功能分析

## 1. 分析原则

根据以下标准判断功能是否适合放入高级版（Pro）：

| 标准 | 说明 |
|------|------|
| **增值性** | 功能是否为"锦上添花"而非基础必备？基础课程表浏览应免费 |
| **复杂度** | 功能是否涉及较复杂的逻辑或数据处理？ |
| **存储/性能开销** | 功能是否涉及大量存储或计算？ |
| **使用频率** | 功能是否低频使用？高频功能不应收费 |
| **用户感知价值** | 用户是否愿意为此功能付费？ |

## 3. 推荐 Pro 功能详情

### 3.1 课程统计 — 页面内联卡片模式

**当前状态**：完整功能页面，无需解锁即可访问

**推荐改造**：
- 页面正常打开，但数据区域使用模糊遮罩
- 中心显示 Pro 解锁卡片，列出可解锁的内容
- 用户体验：看到模糊的统计图表 → 产生好奇心 → 解锁

**Pro 权益**：
- 总课程数、本周课程数、最忙日统计
- 各科数量排行（带进度条）
- 每日课程分布
- 每周趋势分析

### 3.2 数据备份与恢复 — 页面内联卡片模式

**当前状态**：已内置 `unlock-dialog` 组件，但页面可正常访问

**推荐改造**：
- 页面打开，显示备份功能说明
- 操作按钮位置显示 Pro 卡片
- 已解锁用户正常使用备份/恢复功能

**Pro 权益**：
- 一键备份全部课程数据到本地存储
- 一键恢复备份数据
- 备份包含：课程表、预设列表、首页设置、主题、提醒、解锁状态

### 3.3 首页自定义设置 — 页面内联卡片模式

**当前状态**：已内置 `unlock-dialog` 组件

**推荐改造**：
- 页面打开，显示设置项列表
- 设置项下方显示 Pro 解锁卡片
- 已解锁用户可正常切换设置

**Pro 权益**：
- 快速添加开关
- 课程提醒开关
- 自定义内容（首页显示自定义文字）
- 时钟显示控制
- 显示格式自定义

### 3.4 多课表管理 — 底部半屏抽屉模式

**当前状态**：完整功能页面

**推荐改造**：
- 页面正常打开，显示当前课表
- 点击"添加新课表"或"切换课表"时触发底部抽屉
- 抽屉显示 Pro 权益说明

**Pro 权益**：
- 创建多个课表（如：单周/双周课表）
- 课表之间快速切换
- 课表重命名

### 3.5 导出课程表 — 底部半屏抽屉模式

**当前状态**：完整功能页面

**推荐改造**：
- 页面正常打开，显示导出预览
- 点击"生成二维码"或"导出"时触发底部抽屉

**Pro 权益**：
- 将课程表生成二维码，方便分享
- 支持多种导出格式
- 导出使用说明

### 3.6 震动自定义 — 底部半屏抽屉模式

**当前状态**：完整功能页面

**推荐改造**：
- 页面正常打开，显示震动效果预览
- 点击"保存方案"或"自定义震动"时触发底部抽屉

**Pro 权益**：
- 自定义震动模式（强度、时长、次数）
- 保存多套震动方案
- 快速切换震动方案

### 3.7 文字转二维码 — 底部半屏抽屉模式

**当前状态**：完整功能页面

**推荐改造**：
- 页面正常打开，显示二维码预览
- 点击"保存"或"分享"时触发底部抽屉

**Pro 权益**：
- 将任意文字生成二维码
- 保存二维码历史
- 预设常用文字模板

## 4. 解锁流程设计

```
用户点击 Pro 功能
        │
        ▼
┌──────────────────┐
│  检查激活状态      │
└──────┬───────────┘
       │
   ┌───┴───┐
   │已激活  │           │未激活
   ▼       │           ▼
正常使用   │   ┌──────────────┐
           │   │ 页面内联卡片   │ ← 页面能打开，模糊 + Pro 卡片
           │   │ 或 底部抽屉   │ ← 从底部滑出
           │   └──────┬───────┘
           │          │
           │     ┌────┴────┐
           │     │ 了解 Pro │ → 跳转激活页面
           │     │ 暂不需要 │ → 下滑关闭
           │     └─────────┘
```

## 5. 总结

| 分类 | 数量 | 页面 |
|------|------|------|
| 免费核心功能 | 8 个 | index, add-course, course-manager, week-view, detail, settings, activation, index(首页) |
| Pro 高级功能 | 7 个 | statistics, backup-restore, homepage-settings, schedule-manager, schedule-qrcode, vibration-lab, qrcode-generator |
| 内部开发页面 | 11 个 | test-area, device-info, check-demo, accordion-demo, add-course-demo, comp-demo, activation-lab, chinese-input, nickname-edit, reset-data, full-dialog, dialog-demo, popup-test |

**Pro 套餐建议**：
- 一次性解锁，永久使用
- 包含全部 7 个高级功能
- 权益：课程统计、数据备份恢复、首页自定义、多课表管理、导出课程表、震动自定义、文字转二维码
