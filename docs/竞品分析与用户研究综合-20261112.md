## 一、执行摘要

**一句话定位**：Ev课程表是**唯一把"课表"做成四端联动生态**的手环产品 —— 腕上快应用直接编辑、手机同步器批量管理、联动表盘抬手即看、网页端电脑维护；免费版完整可用，1 元一次性买断解锁增值项。

**三项核心判断**（按 v1.9.200 闭环态修正）：

1. **护城河"双通道"已真实闭环，并升级为"四端联动"。** 独家"腕上中文输入直接编辑" + "手机侧批量导入/同步"双通道均已跑通；且进一步扩展为四端联动（手环快应用 + 五款联动表盘 + 安卓同步器 + 网页端），改一节课四处同动。原报告依据 2026-09-22 同步器分析判定的"通路未闭环"已过时作废。**当前 Ev 在竞争矩阵中处于领先地位（≈4.6/5），不再是"落后半步"。**

2. **贴身对手 BandClass 仍是"免费 + 同步"的单点产品，生态维度已被 Ev 拉开。** BandClass 同样跑在手腕上、免费、支持同步器，是价格与功能上的贴身竞争者；但它没有联动表盘、没有网页端、无自研中文输入法、无可持续商业化。Jursin/Var 仅有手机导入、无腕上编辑。Ev 的胜算在"编辑更稳 + 四端生态更完整 + 长期维护 + 清晰买断"，而非价格（它免费，我们 1 元）。

3. **用户第一道门槛仍是"首屏看得见课"和"装得上、不崩"，与同步无关，仍然成立。** v1 研究证明：192px 胶囊屏固定栏吃掉 81% 高度、课卡 0 张可见，是阻断核心任务的 P0；黑屏/输入法崩溃/小米手环 11 频繁重启类稳定性问题是留存第一道门。功能与生态已强，**体验落地（首屏空间/对比度/真机验证/稳定性）才是当前真正的瓶颈。**

**最高优先级行动**（综合两分析、按闭环态修订）：
- **P0-A**：真机验证闭环（18 项清单）—— 把静态 100 分坐实为"用户真满意"，并实测四端联动在真机上的表现。
- **P0-B**：首屏空间压缩 + 对比度修复（v1 的 A1/A3）—— 让"看课"在首屏成功。
- **P0-C**：稳定性攻坚（黑屏/输入法崩溃/小米手环 11 重启）—— 留存第一道门。
- **P1**：第三方课表格式兼容（拾光/WakeUp/星链/CSES/ICS）—— 补齐最后一处相对 Jursin/超级课程表的差距；时间步进加常用时段快捷值、加课入口归一；5 人真机任务测试 + 轻量埋点。

## 二、竞品分析（Competitive Analysis）

### 2.1 竞争格局地图（Competitive Landscape）

按"是否解决同一问题、是否在同一设备"分层：

| 层级 | 代表产品 | 与 Ev 的关系 | 威胁度 |
|---|---|---|---|
| **直接竞品（同设备·同场景）** | **BandClass**（qyhOH，米坛/轻腕）、**Jursin/Schedule-Vela**、**Var课程表** | 都在手环上跑课表快应用，正面争夺同一批用户 | 🔴 高（BandClass 免费+同步） |
| **间接/替代（手机·不同形态）** | **超级课程表**、**WakeUp**、**课程格子**、**小猴课程表**、**星课程表** | 解决"看课表"但必须掏手机；强在导入生态与社交 | 🟡 中（截留"不愿上手环"的用户） |
| **非消费（Do-Nothing）** | 纸课表、拍课表截图、记在脑子里 | 零成本零学习，但无法提醒、无法随时看 | 🟢 低（被智能方案天然替代） |
| **相邻（潜在进入者）** | 小米官方手环系统能力、其他穿戴厂商 | 若官方原生做课表/提醒，第三方快应用空间被挤压 | 🟡 中（长期结构性风险） |

**关键认知**：Ev 的"同设备直接竞品"只有手环快应用那几家；手机 App 是**替代品**而非直接对手 —— 它们的致命弱点是"必须掏手机"，这正是 Ev 的存在理由。所以真正的贴身战，发生在**米坛/HiWear 资源站的那几个手环课表快应用之间**。而 Ev 已凭"四端联动 + 联动表盘"在该小圈子里建立了对手没有的生态维度。

**对手逐项客观评估（不美化自己）**：

- **Jursin/Schedule-Vela**：开源（GPL-3.0）、导入生态最强（拾光/WakeUp/星链/CSES），但**无腕上编辑、无生态延展**、商业化弱。
- **Var课程表**：同步器插件 + 多格式导入，商业化较清晰（爱发电付费），但同样**无腕上编辑、无生态延展**。
- **超级课程表**：3618 高校一键导入 + 考试同步 + 校园社交，体量碾压；但**必须掏手机**，与 Ev 场景不重叠 —— 它是"不想用手环"用户的首选。

### 2.3 定位分析（Positioning Analysis）

**Ev 定位陈述**（闭环态修订）：
> 对于**不想每次掏手机看课表、又不愿在 192px 小屏上一门门手输课表的学生**，Ev课程表是一套**四端联动的课程表生态**：腕上快应用直接编辑、手机同步器批量导入管理、联动表盘抬手即看、网页端电脑维护，**改一节课四处同动**。不同于手机课表 App（超级课程表），它活在手腕上且无需掏手机；不同于其他手环课表（BandClass/Jursin/Var），它有**独家腕上中文输入编辑 + 五款联动表盘 + 网页端 + 一次性买断无订阅**的完整生态。

**竞品定位对比**：
| 产品 | 自称/实际定位 | 关键差异点 |
|---|---|---|
| Ev | 四端联动课程表生态 | 独家腕上输入法、联动表盘、网页端、1元买断、设备级激活 |
| BandClass | "课表和倒计时，一个快应用就够了" | 完全免费、功能细腻、已支持同步（但无生态延展） |
| 超级课程表 | 智能课表 + 校园社交 + 考试 | 海量导入生态、社交社区 |
| Jursin | 开源手环课表 | 开源、导入格式最广 |

**定位空白与机会**：
- **"四端联动 + 双通道"叙事**目前只有 Ev 能讲，尚无对手抢占 —— 原稿强调"双通道"已足够差异，闭环后进一步升级为"四端联动"，更应作为主宣传轴（而非只说"我们也有同步器"，那是在对手主场打平）。
- **第三方格式兼容**是当前唯一明显短板（3 分），Jursin/超级课程表靠它立身；补上拾光/WakeUp/CSES/ICS 兼容，可把"导入"从"够用"变"最强"，彻底封死 BandClass 的免费+同步贴身优势。
- **"不订阅、1元永久 + 设备级激活（重装不丢）"** 在学生对"隐形扣费"极度敏感的小圈子里是信任资产，竞品多为爱发电或免费无保障，Ev 反而更"正规"。

### 2.4 胜负手（Win/Loss Insights）

- **我们赢的场景（闭环后显著扩大）**：用户重视"不掏手机看课" + 想要"腕上改课" + 看重四端联动/联动表盘/长期维护与主题个性化 + 怕订阅隐形扣费（我们的设备级激活+买断正好命中）。
- **我们仍可能输的场景**：① BandClass **完全免费**（我们 1 元），价格极端敏感学生仍可能选它 —— 需用"编辑更稳/表盘更多/有人维护"建立质量差；② 第三方格式兼容尚未补齐，重度教务系统用户迁移成本仍高于 Jursin/超级课程表；③ 首装即崩/小米手环 11 重启，当场劝退（与同步无关，仍是真问题）。
- **结构性胜负点（已反转）**：原"手机导入是刚需、缺了特色也卖不出"的一票否决已解除 —— 双通道 + 四端联动现在是我们的结构性优势，而非短板。新的一票否决点转移到**稳定性（首装不崩）**与**第三方格式兼容**。

### 2.5 市场趋势（Market Trends）

| 趋势 | 信号 | 对 Ev 的含义 | 应对策略 |
|---|---|---|---|
| 手环快应用生态活跃 | 米坛/轻腕/HiWear 资源站持续有新作品；Ev 已在 HiWear 发布（272 下载） | 分发渠道在成长，获客成本可控 | 多站同步发布、维护作者口碑 |
| 双端同步成标配 | BandClass/Var/Jursin 都上了同步器；Ev 已于 v1.9.200 完成四端联动 | Ev 入场券已拿到，重心转向"四端联动体验打磨 + 第三方格式兼容" | 已闭环，转 P1 补格式 |
| 生态化是下一战场 | Ev 率先做"快应用+表盘+同步器+网页"四端，对手仍单点 | 生态维度可拉开与 BandClass 代差 | 深化 2.0 四端协同 |

## 三、用户研究综合（User Research Synthesis）

### 3.4 用户旅程与断裂点（Journey Map）

```
欢迎页 ──进入──> 首页(列表仅47px!) ──点卡──> 详情/编辑

              └─> 导入迁移：四端联动已闭环（同步器批量导入），门门手输痛点基本解除；残留=第三方格式兼容待补
```

**断裂点严重度排序（与同步无关的部分仍然成立）**：首屏看不见课（T1）＞ 装得上但崩（T3）＞ 流程过载（T5）＞ 时间低效（T6）。原"导入劝退"断裂点已随四端联动闭环而基本消除。

## 四、综合洞察与战略建议（Combined Insights）

### 4.1 竞品 × 用户 的交叉发现

1. **用户要"首屏看得见课" + 对手用"免费+同步"抢人** → Ev 不能用"更便宜"反击（BandClass 免费），只能用"编辑更稳 + 四端生态更完整 + 联动表盘 + 长期维护"建立质量差。
2. **原"导入迁移"是最大流失点，现已随四端联动闭环消除** → 这同时解了"用户流失"和"竞争劣势"—— 原 P0 风险已转化为生态优势。剩余可抢的流失点是**第三方格式兼容**（O3），需尽快补齐以彻底封死 BandClass 的免费+同步贴身优势。
3. **用户怕订阅/隐形扣费** → 与 Ev"1元买断无订阅 + 设备级激活（重装不丢）"定位天然契合，是相对爱发电竞品的信任优势，应在激活页前置强调。

### 4.2 路线图建议（Now / Next / Later）

**Now（本迭代，体验落地 + 真机验证）**
- P0-A 真机验证 18 项（坐实 100 分 + 实测四端联动真机表现）
- P0-B 首屏空间压缩 + 对比度修复（v1 的 A1/A3）
- P0-C 稳定性攻坚（黑屏/输入法崩溃/小米手环 11 重启）
- 宣传语切换为「四端联动：手机批量导入 + 腕上直接编辑 + 联动表盘」

**Next（下迭代，差异补齐 + 度量）**
- 第三方课表格式兼容（拾光/WakeUp/星链/CSES/ICS）—— 封死 BandClass 贴身优势
- 时间步进加常用时段值、加课入口归一、欢迎页改造
- 5 人真机测试 + 轻量埋点上线

- 官方原生能力风险对冲（深度个性化护城河）
