# 课程表盘 watch-face-class 双屏适配方案（336×480）

> 目标机：手环 10 Pro 336×480；回归基线：手环 9 跑道屏 192×490。
> 单号 `evtask-D-class-schedu-261026-2vn77s`。写于实施前（0 次模拟器）。

## §1 形态判定：第五种，纯布局

前四块的分型依据是「几何量放在 CSS 还是 JS」：

| 表盘 | 形态 | 路线 |
|---|---|---|
| evpointer / metal | CSS 字面量坐标 + 几何图形 | 父级 `scale()` |
| gold | 同上 + 表耳在容器外 | 父级 `scale(1.35)` + 表耳手算 |
| animated | JS 常量算 60 格坐标 | 改 JS 常量，**不能 scale** |
| pickdate | JS `CELL_H` 与 CSS 格高双控 | 两侧同步改 |
| **class** | **纯布局，无几何图形** | **字号 + 坐标重排，单类宽屏块** |

class 没有任何圆/环/刻度/指针：整页是 9 个绝对定位的文字块 + 1 个带边框的卡片 + 1 条进度条 + 3 个隐形热区。**纯文字不能用 scale**（位图会发虚，前几块已确认），只能用宽屏类重排。

## §2 三处 JS↔CSS 双控（本块的核心风险）

版面几何有两套来源，改一处漏一处不会报错，只会错位：

| 常量 | 位置 | 耦合对象 | 192 值 |
|---|---|---|---|
| `BAR_MAX` | `<script>` 第 72 行 | `.bar-track { width }` / `.bar-fill` 计算 | 156 |
| `TL_TOP` | 第 73 行 | 时间轴首行 y | 286 |
| 行距 `i * 42` | 第 289、357 行**两处字面量** | `.tl-row { height: 40 }` | 42 |

三处都要改：`BAR_MAX` 156→292、`TL_TOP` 286→280，并把 `i * 42` 抽成 `TL_GAP` 常量（42→44）——两处字面量同时改，漏一处的表现是「fallback 分支与正常分支行距不一致」，只有今天无课时才看得出来，极难发现。

## §3 横向：从「12 / 168」到「20 / 296」

## §5 隐形热区必须同步

三个热区是透明 `div`，肉眼看不见，但决定长按/双击能否命中：

| 热区 | 192 | 336 | 覆盖对象 |
|---|---|---|---|
| `.hit-clock` | 8,76 176×116 | 14,50 308×92 | 大字时间 |
| `.hit-card` | 12,198 168×74 | 20,170 296×86 | 课程卡片 |
| `.hit-corner` | 140,400 52×60 | 270,406 60×66 | 右下角双击退出 |

热区比可见块略大（长按容错），宽屏按同一相对比例放大。**热区错位的症状是"点了没反应"**，比视觉错位更难查。

## §6 192 屏改动：零

本盘 192 基线字号已全部达标（正文 13–16px、大字 48px），课程表盘的密集版面也不适合整体提字号。所以 192 一行不改，`fitScreen` 只在 `w >= 300` 时挂宽屏类。

## §7 实施步骤

1. 模板加 16 处 `{{ xxxCls }}` 绑定（混写原类，`class="xxx {{ xxxCls }}"`）
2. `script` 内 `const BAR_MAX / TL_TOP` 改 `let`，新增 `let TL_GAP = 42`，两处 `i * 42` 换成 `TL_GAP`
3. `onInit` 里调 `fitScreen()`；`fitScreen` 用**页内 `require("@system.device")`** + 异步 `success` 回调（顶部 `import` 与页内 `require` 同模块冲突，functional 那块踩过）
4. CSS 追加 16 个宽屏单类（**全部单类选择器**，Vela 不支持后代选择器）
5. 构建 → 双机部署 → 截图验收

## §8 验收判据

- 336：所有块中心 x = 168（量墨水 x 区间中心）；大字时间 y 52–136 不截字；卡片三行不溢出框；时间轴 3 行 + 底部 2 行不重叠；底余 ≥ 6px
- 192：与原基线**逐像素一致**（`.page` 之外的样样式零触碰）
- 部署次数预算：2 次

## §9 实施回填（2026-10-26 实测）

### 9.1 代码改动

`src/pages/watch-face-class/watch-face-class.ux`，670 → 912 行：

- 模板 21 处 `{{ xxxCls }}` 绑定（全部与原类混写）
- `const BAR_MAX / TL_TOP` → `let`，新增 `let TL_GAP = 42`，两处 `i * 42` / `up.length * 42` 换成 `TL_GAP`

### 9.3 修掉一处既有缺陷

`.status-right` 原 `left:124 width:56`。15px 字号下「今日 4 节」约需 68px，**实测只渲染 3 个字符簇**
（今/日/4），「节」被裁。改为 `left:112 width:68`：右端点仍是 180，`text-align:right`
让文字贴同一右端点，**不移动任何已有像素**，只是不再裁字。

宽屏侧预防性把 `.w-status-r` 从 `w100` 加宽到 `w120`（`left:196`，右端 316 不变），
覆盖两位数课次「今日 12 节」（7 字 ≈ 112px）。
