## 输入法光标位置修复（commit 799b052，已推送）
- 问题：`chinese-input.ux` 空输入时，光标 div 写死在占位提示词 text 之后 → 光标显示在提示词后面；提示词非真实输入内容，光标应在最前。
- 修复（宿主侧，**不动上游 InputMethod 组件**——铁律）：拆成两个互斥光标——空内容时 `cursor(if !inputText.length)` + 提示词（光标在最前）；有内容时 `beforeChars | cursor(if inputText.length) | afterChars`；`cursor-end-zone` 也加了有内容才渲染。
- 校验：模板深度 0 + node --check 通过。真机/模拟器验收待做（部署后看空输入态光标位置）。
- 教训：改模板互斥渲染时用 `if`（不是 `show`），两个 cursor 复用同一 `.cursor` class（闪烁动画只定义一次）。
