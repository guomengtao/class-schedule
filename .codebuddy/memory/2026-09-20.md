- 将"星期"选择从 `main-scroll` 可滚动区移到独立固定区块 `weekday-section`，置于底部"确认添加"栏正上方，加 `border-top` 分割线 + 上下 14px（胶囊屏 10px）间距，解决胶囊屏下被压缩后贴住确认按钮"挤成一行"的问题。

## 修正（同日第二次改动）
- 上一版把"星期"抽到 `main-scroll` 外做成固定区，胶囊屏高度不足时固定区块互相挤压，出现"按钮与星期重叠"。
- 改为：星期与底部按钮全部放回 `main-scroll` 滚动流内，**底部不再固定**；`.bottom-bar` 加 margin-top 14px / margin-bottom 16px（胶囊屏 10/12px）拉开距离，重叠消除。
- 最终结构：`main-scroll[ 选择课程 → 上课时间 → 上课位置 → 星期(weekday-section) → 底部按钮(bottom-bar) ]`。

## 总课表极简模板右侧余量测算（新增文档）
- 文档：`docs/总课表-极简模板右侧余量计算.md`
- 关键发现：`week-view` 胶囊屏左右 padding 已归零（`padding: 44px 0 8px 0`），真实可视宽度是 **192px**，但 `minimal-char` 的 `cellWidth:32 / cellMargin:0` 仍按历史 160px 设计 → 5 列仅占 160px，**米环9 右侧空 32px = 恰好 1 整列**（米环10 212px 空 52px = 1.63 列）。
- 公式：`g = cw + 2m + b`；`G = rw + N·g`；`W = S − 2P`；`R = W − G`；`K = R/g`。
- 口径冲突：评分手册用「内容区 160px」口径算可视列数（`160/cw ∈ [2.5,3.5]`），与 week-view 实际 192px 可视不一致；现状 cw=32 → 列数 5.0，已超手册上限，属既成事实待拍板。
- 整改两取向：填满不横滑 `cw:36 + margin:1`（G=190，剩 2px，但列数超手册区间）；合规滑动 `cw:60`（G=300，可视 3.2 列，手册 2.67 ✅，可容 2 个 28px 字）。
