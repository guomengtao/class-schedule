# 2026-09-20

## add-course.ux 课程添加页布局修复
- 将"星期"选择从 `main-scroll` 可滚动区移到独立固定区块 `weekday-section`，置于底部"确认添加"栏正上方，加 `border-top` 分割线 + 上下 14px（胶囊屏 10px）间距，解决胶囊屏下被压缩后贴住确认按钮"挤成一行"的问题。
- 新增 `scrollToCurrentDay()`，与编辑课程页（detail.ux）保持一致：模板 `weekdayScroll` 绑定 `scroll-left`，设默认值 + `$element.scrollTo` 兜底；在 `setDefaultDay`（默认今天 / 首页传入星期）和 `selectDay` 后调用，打开页自动滚到当前所选星期（如周日滚到末尾），避免二次手动滑动。

## 修正（同日第二次改动）
- 上一版把"星期"抽到 `main-scroll` 外做成固定区，胶囊屏高度不足时固定区块互相挤压，出现"按钮与星期重叠"。
- 改为：星期与底部按钮全部放回 `main-scroll` 滚动流内，**底部不再固定**；`.bottom-bar` 加 margin-top 14px / margin-bottom 16px（胶囊屏 10/12px）拉开距离，重叠消除。
- 最终结构：`main-scroll[ 选择课程 → 上课时间 → 上课位置 → 星期(weekday-section) → 底部按钮(bottom-bar) ]`。
