## 「添加课程」胶囊屏重新规划方案
- 新建 `docs/添加课程-胶囊屏重新规划方案.md`（10 章节：目标定位 / 现状问题 / UI 重设计 / 架构流程 / 时间滚轮 / 中文输入 / 胶囊屏适配 / 性能 / 异常 / 验收）
- 现状量化问题：时间步进 小时±1、分钟±5，内联展开 → 08:00→15:30 需 **15 次点击**；表单堆叠需滚动；位置每次必跳 `chinese-input`
- 核心方案：胶囊屏改**分步向导**（课程名 / 时间 / 星期 / 位置，每屏零滚动）+ **全屏滑动滚轮选时间** + **快捷时段**（15 次 → 1 次）+ 位置**选择优先、输入兜底**
- 关键技术前提：项目**无原生 picker**，滚轮须用 `<scroll scroll-y>` + 行高 48px + 吸附自研；
  **`scroll` 的偏移读取与程序化定位能力需先做真机最小验证**（不同固件可能有差异，已在文档标注）
- 滚轮参数：列宽 76×2（间隔 8，内容区 160）、行高 48px、3 行可见 144px、时 24 档 / 分 12 档（5 分粒度沿用）、有限列表（改进现状 23→0 循环）
- 吸附：onscroll 节流 80ms + 停止滚动 ~120ms 后定位一次，避免与惯性打架
- 保留能力：`checkDayConflict` 冲突检测、`isSaving` 锁、预设课程库、theme 体系、存储结构不变

## 修复「安装后无法退出」bug
- 真实根因（与 `docs/cannot-exit-analysis.md` 旧结论不同）：welcome/index 的 `onBackPress` 用 `try { app.exit() } catch(e){}` 静默吞异常后 **`return true`**；
  `return true` = 消费返回键、拦截系统默认行为 → exit 无效时**按返回键毫无反应** = 退不出去
- 修复：
  1. `src/data/utils.js` 新增 `exitApp()`，依次探测 `exit` / `terminate` / `finish` 三种退出入口
  2. 两处 `onBackPress` 改为 `return utils.exitApp() === true`（**成功才拦截，失败 return false 交还系统**）
  3. welcome 加显式「退出」按钮作为最后兜底，失败时 toast「请用系统手势退出应用」
  4. 顺带把 welcome 按钮提到 48px（胶囊屏原 40px、圆屏原 44px，此前未纳入核心页评估）
- 待真机确认：目标设备 `@system.app` 实际暴露哪个退出方法
